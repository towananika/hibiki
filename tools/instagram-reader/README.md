# Hibiki Instagram Reader

Instagramの投稿URLから、本人が閲覧できる本文・画像・投稿者を確認するローカルツール。ブラウザに表示される情報を取得し、ログイン・非公開・アクセス制限を回避しない。Instagram公式API製品ではなく、完全取得を保証しない試作版です。

## 起動

Node.js、Microsoft Edge、Playwrightが必要です。

```powershell
npm install
npm start
```

`http://127.0.0.1:9031/` を開きます。既にPlaywrightが親フォルダへインストールされている環境では追加インストール不要です。別のポートは環境変数 `PORT` で指定できます。

リンクを入力して「読み取る」。読めない場合は「ブラウザで開く」で専用Edgeを表示し、必要ならInstagram自身の画面でログインします。対象の投稿を表示して「再取得」。パスワード・二段階認証は本人が操作します。利用規約、著作権、本人のアクセス権限に従って使用してください。

## 取得範囲

- 投稿ページの本文またはメタ情報。メタ情報だけの場合は省略の可能性を表示します。
- 読み取れた画像を最大6枚。一覧の全スライドや原寸を保証しません。
- 動画そのもの・音声・コメント・画像のOCR・AI要約は未対応です。
- 「AI相談用」は引用資料として区切ったテキストのコピーのみ。自動送信や有料APIはありません。
- 失敗した投稿の内容を捏造したり、推薦投稿を対象投稿として表示したりしません。

## プライバシー

サーバーは127.0.0.1のみで待ち受け、リクエスト元とHostを検証します。LANやインターネットへ公開しないでください。認証状態は `%LOCALAPPDATA%/HibikiInstagramReader/browser-profile` に保存します。このフォルダを共有・Git登録しないでください。普段のEdgeプロファイルは使用しません。取得画像はメモリのみ。ログイン状態を消すには専用ブラウザでログアウトしてください。画像や本文の権利は投稿者に帰属し、このソフトのMITライセンスの対象外です。

## チャット連携

Codex用のローカルスキル `instagram-reader` と、1回のコマンドで取得する入口を用意しています。

```powershell
node tools/instagram-reader/read-post.cjs "https://www.instagram.com/p/POST_ID/"
```

必要時にサーバーを自動起動し、結果をJSONで返します。`--images` を付けると、読み取れた画像を `%LOCALAPPDATA%/HibikiInstagramReader/captures/` に保存し、そのパスも返します。本文・画像・ログイン状態は公開リポジトリに登録しません。チャット側のAIが取得結果を読んで分析します。全チャット・他端末に共通する常時監視ではなく、このPCでスキルが利用可能なCodex環境が対象です。

響ページの道具欄からは接続用ページ `instagram/` を開けます。実際の取得サーバーはPC内で動かし、GitHub Pagesでは実行しません。

## テスト

`npm test` でURL検証と画像ホスト制限を確認します。Instagramの仕様変更・アカウント状態によって取得できない場合があります。

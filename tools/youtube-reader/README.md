# YouTube Reader

YouTube動画1本の公開字幕を読むPC専用ツール。動画・音声はダウンロードせず、字幕がない場合や取得制限時には内容を推測しません。チャンネル・再生リスト一括取得、非公開動画、ログインや通信制限の回避は対象外です。

Python 3.11以上で専用仮想環境に `pip install -r requirements.txt`。起動は `python reader.py`、画面は http://127.0.0.1:9032/ 。CLIは `python reader.py "動画URL"` でJSONを標準出力します。取得には最大80秒の上限を設けます。

手動字幕を優先し、次に自動字幕を取得。日本語・韓国語・英語を優先しますが、自動翻訳字幕は黙って代用しません。ローリング字幕は完全一致する連続行だけを除き、重複が残る場合があります。映像の文字・映像のみの出来事は取得していません。

外部AI APIやAPIキーは使いません。YouTubeにはリクエストを送りますが、取得結果・閲覧履歴・Cookieを保存しません。文章の保存・コピーはユーザー操作時のみ。取得字幕を公開ソースへコミットしないでください。字幕をチャットに貼る場合、送信先のAIサービスへその内容が送られます。

実装は[yt-dlp公式](https://github.com/yt-dlp/yt-dlp)を利用。YouTube側の仕様や制限で取得できない場合があります。テストは `python -m unittest test_reader.py`。

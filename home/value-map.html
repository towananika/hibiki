ソウル通勤を想定。緑は経済的余力が大きい地域、赤は小さい地域。データ不足は必ず灰色です。

地域をタップすると、根拠となる数値を表示します。
地域データを読み込む

GeoJSON（行政洞・法定洞・駅徒歩圏などの境界）を選択。読み込んだデータはこの端末の画面内だけで扱い、公開リポジトリには保存しません。

境界・住居費・通勤時間・求人データは未接続です。現在、未評価地域は灰色として扱います。数値は推測で補いません。

GeoJSONの各feature.propertiesに name と、評価に応じて rent_manwon, transport_manwon, commute_minutes, job_access_score を設定します。通勤先別は commute_minutes_central / _gangnam / _yeouido / _gasan が優先されます。月22日通勤、往復時間を計算。総合評価には住居費・交通費・通勤時間の全項目が必要です。求人アクセスは独立指標で、総合純便益には混ぜません。

注意：この地図は分析基盤です。実測データのない地域に緑・赤を割り当てません。色の区切りは比較用の暫定値であり、豊かさや就職成功を保証するものではありません。地図背景：© OpenStreetMap contributors。

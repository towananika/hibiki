# 上級マクロ経済論 0講 ― やさしい土台（ここから読む）

**この講で覚えること：上級マクロは、むずかしい式の前に「たった6つの考え方」でできている。これがわかれば、8〜15講はぜんぶ読める。**

> 補足：ここは講義の回ではなく、8〜15講を読む前の「土台」です。ミクロ経済学やマクロ経済学入門で習うことを、ひとことずつにしました。

```flow
① くらべて選ぶ → ② 1つ足すと？ → ③ 買いたい・売りたいが出会う → ④ 名目と実質 → ⑤ 国全体を足す → ⑥ 今と将来
```

## 1. くらべて選ぶ（機会費用）

何かを選ぶと、ほかの何かをあきらめます。**あきらめたものの価値** を **機会費用** といいます。
- 1時間アルバイトをすると、その1時間の休みをあきらめる。
- お金を現金で持つと、預けていればもらえた利子をあきらめる。

**上級マクロの人や会社は、いつも「得るもの」と「あきらめるもの」をくらべて決めます。**

```quiz
Q: 現金を手元に持つときの機会費用（あきらめるもの）は？
1: お財布の重さ
2: 預けていればもらえた利子
3: 銀行の手数料だけ
4: 何もない
C: 2
E: 現金には利子がつかない。預けたり債券にしたりすればもらえた利子が、あきらめたもの（機会費用）。
```

## 2. 「あと1つ」で考える（限界）

経済学の「限界」は「はしっこ」ではなく、**あと1つ足したときの増え方** のことです。
- **限界生産**：働く人やオーブンを **あと1つ** 足すと、どれだけ多く作れるか。
- **限界効用**：パンを **あと1個** 食べると、どれだけうれしいか。

だいじな性質：**同じものを足し続けると、足すたびの増え方はだんだん小さくなる**（逓減、ていげん）。1個目のパンはとてもうれしいが、5個目はそれほどでもない。

**決め方のルール**：「あと1つで増える得」＞「あと1つの費用」なら、足す。等しくなったところで止める。

```quiz
Q: 経済学の「限界生産」の意味は？
1: これ以上作れない最大の量
2: あと1人（1台）足したときに増える生産
3: 会社がつぶれる生産量
4: 生産の平均
C: 2
E: 限界＝「あと1つ」。あと1つ足すと、どれだけ増えるか。
```

## 3. 買いたい量と売りたい量が出会う（需要・供給・均衡）

- **需要**：買いたい量。値段が上がると、ふつう減る。
- **供給**：売りたい（作りたい）量。値段が上がると、ふつう増える。
- **均衡**：買いたい量と売りたい量が **ちょうど同じになる** ところ。値段はそこに落ち着く。

上級マクロでは、この「出会う場所」が3つあります。

| 市場 | 何が出会う？ | 何で合わせる？ |
|---|---|---|
| 働く人の市場（労働市場） | 働きたい量 と 雇いたい量 | 給料 |
| 物の市場（財市場） | 買いたい量 と 作れる量 | 利子率 |
| お金の市場（貨幣市場） | 持ちたいお金 と 出回っているお金 | 物価や利子率 |

## 4. 数字の額と、本当に買える量（名目と実質）

- **名目**：お金の数字そのまま。給料20万円、パン100円。
- **実質**：物価を考えて「本当に何個買えるか」で見たもの。

給料が2倍になっても、物価も2倍なら、買えるパンの数は同じ。つまり **実質は変わっていない**。
> 補足（式で書くと）：実質 ＝ 名目 ÷ 物価。実質利子率 ≒ 名目利子率 − 物価の上がり方（インフレ率）。

```quiz
Q: 給料が10%上がり、物価も10%上がった。実質の給料は？
1: 10%上がった
2: 20%上がった
3: ほぼ変わらない
4: 10%下がった
C: 3
E: 名目（数字）は上がっても、買える量（実質）はほぼ同じ。
```

## 5. 国全体を足す（GDPと総需要）

- **GDP（国内総生産）**：国の中で1年に新しく作られたものの合計。国の「稼ぎ」とほぼ同じ。
- 国全体で **買いたい量**（総需要）は、4つの足し算：
  1. 家計の買い物（消費 C）
  2. 会社の機械や工場（投資 I）
  3. 政府の買い物（政府支出 G）
  4. 外国との差（輸出 − 輸入）

> 補足：上級マクロの多くの講では、話をかんたんにするため、外国との取り引きをはぶきます。

## 6. 今と将来をくらべる（利子率）

**利子率は「今のお金」と「将来のお金」の交換レート** です。
- 利子率が高い → 今使うより、ためて将来使うほうが得 → 今の買い物や機械の購入が減りやすい。
- 利子率が低い → 借りて今使いやすい → 今の買い物や投資が増えやすい。

上級マクロの8〜15講は、この6つを組み合わせて、次のことを説明します。

| 講 | テーマ | 主に使う土台 |
|---|---|---|
| 8講 | 人はいつお金を使う？（消費） | ⑥今と将来、②限界 |
| 9講 | 会社はいつ機械を買う？（投資） | ②限界、⑥利子率 |
| 10講 | 働く時間と給料（労働） | ①機会費用、③均衡 |
| 11講 | お金と中央銀行 | ①機会費用、④名目と実質 |
| 12講 | ぜんぶつり合うと？（一般均衡） | ③均衡、④名目と実質 |
| 13講 | 景気の波（均衡の波） | ③均衡 |
| 14講 | 値段がすぐ変わらないと（不均衡の波） | ③均衡がずれる |
| 15講 | 豊かさが伸び続けるには（成長） | ②限界（逓減） |

## まず、この6つ

1. 選ぶと何かをあきらめる（機会費用）。
2. 「あと1つ」で考え、増え方はだんだん小さくなる（限界・逓減）。
3. 買いたい量と売りたい量が同じになるところに落ち着く（均衡）。
4. 数字の額（名目）と、本当に買える量（実質）を分ける。
5. 国全体で買いたい量＝消費＋投資＋政府＋（輸出−輸入）。
6. 利子率は「今のお金」と「将来のお金」の交換レート。

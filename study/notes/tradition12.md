# 伝統社会と生活文化 12講 ― 奴婢の暮らし

韓国の放送大学「伝統社会と生活文化」12講（対談の講義、約45分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名や数字は聞き取りなので、少しずれているかもしれない。

```flow
生まれで奴婢になる → 国や家のために働く・物を納める → 逃げる・お金で自由を買う → 制度がゆるむ → 1894年になくなる
```

## 0. ひとことで
朝鮮王朝で、いちばん低い身分が **奴婢**（ぬひ）。生まれたときから身分が決まり、売り買い・相続される「財産」として扱われた。
それでも奴婢は **財産をため、逃げ、お金で自由を買い**、身分から抜け出そうとした。その動きが、少しずつ制度をくずしていった。

> 補足：講師は「いまでいう、生まれで人生が決まる "いちばん下の家" に近い」とたとえていた。

## 1. 奴婢ってだれ？
- **奴**（ぬ）＝男の使用人、**婢**（ひ）＝女の使用人。あわせて奴婢。
- 法律では人は **ふつうの民（良人）** と **低い身分（賤人）** の2つ（良賤制）。賤人の代表が奴婢。
- はじめは **罪をおかした人** が奴婢にされた。でも大半は **親が奴婢だから生まれつき奴婢**。

**なぜ奴婢の制度を続けたの？**
- 国や役所：税だけでは足りない **働き手と品物** を、安定して手に入れるため。
- 両班の家：毎日の **家の仕事と品物** のため。奴婢は **土地と並ぶ大事な財産** で、多いほどお金持ちのしるし。

## 2. 2つの種類：国の奴婢と家の奴婢
| | 国の奴婢（公奴婢） | 家の奴婢（私奴婢） |
|---|---|---|
| だれのもの | 王室の役所・各役所・宿駅・地方の学校 | 個人（主に両班） |
| 中の分け方 | 働きに行く（選上奴婢）／品物を納める（納貢奴婢） | 主人の家に住む（率居奴婢）／離れて住む（外居奴婢） |

- 品物を納める奴婢は、毎年 **奴は綿布2枚、婢は1枚半**。かなり重い負担。
- 働きに行く奴婢は、地方に住んでいて都の役所に通うと、もっと大変だった。

**家の奴婢の2つのくらし**
| | 主人の家に住む（率居奴婢） | 離れて住む（外居奴婢） |
|---|---|---|
| 仕事 | ごはん・洗たく・まき集め・米つき・田畑・使い走り・買い物 | 決まった品物（身貢）を納めれば終わり |
| 自由 | 主人の目がいつもあり、少ない | 自分の家と戸籍があり、ふつうの民とあまり変わらない |
| お金 | ためにくい | 空いた時間に農業や商売でふやせた |

```quiz
Q: 主人の家から離れて住み、決まった品物を納めれば自由に働けた奴婢は？
1: 主人の家に住む奴婢（率居奴婢）
2: 離れて住む奴婢（外居奴婢）
3: 働きに行く国の奴婢（選上奴婢）
4: 王室の奴婢（内奴婢）
C: 2
E: 外居奴婢は自分の家と戸籍を持ち、品物（身貢）を納めたあとの時間で財産をふやせた。
ほかの選択肢：1は主人の家で毎日働くので自由が少ない。3と4は国の奴婢で、家の奴婢の分け方ではない。
```

## 3. 奴婢も財産を持てた
朝鮮では、身分に関係なく **自分の財産（私有財産）** が認められた。
- 15世紀、忠清道に住む奴の **林福** は、不作の年に穀物を2,000石出した。王（成宗）が願いを聞くと「息子を自由に（免賤）」。反対されると、さらに1,000石出して **息子4人を自由に** した。財産は全部で8,000石あったという。
- 財産は子どもに **相続** もできた。お金持ちの奴婢は、たいてい「離れて住む奴婢」だった。

## 4. 子どもの身分は？ ― 主人に都合よく決めた
| 決まり | 中身 |
|---|---|
| 親のどちらかが奴婢なら子も奴婢（一賤則賤） | いちばん強い原則 |
| 母の身分に従う（従母法） | 子は母と同じ身分。持ち主は **母（婢）の主人** |

- 奴と **ふつうの民の女性** が結婚すると、母に従えば子は自由な民になり、奴の主人が損をする。そこで結局「どちらかが奴婢なら子も奴婢」で押し通した。
- だから両班は、奴婢とふつうの民の **結婚（良賤交婚）をわざとすすめた**。夫婦2人とも自分の奴婢なら子3人だけ。でも奴と婢をそれぞれ民と結婚させれば、子6人が全部自分のものになる。
- 主人のちがう奴と婢が結婚すると、子は婢の主人のもの。奴の主人の損は、奴が自分の財産で **つぐなった（記上）**。1637年、海南の奴が田畑や牛を出して罰をまぬがれた例がある。
- 両班が婢に産ませた子も、主人が自由にしないかぎり **奴婢のまま**。

```quiz
Q: 朝鮮の両班が、奴婢とふつうの民との結婚（良賤交婚）をすすめた理由は？
1: 奴婢をへらしたかったから
2: 親のどちらかが奴婢なら子も奴婢なので、自分の奴婢がふえたから
3: 法律で決まっていたから
4: 国から、ほうびがもらえたから
C: 2
E: 「一賤則賤」で、片方が奴婢なら子は全員奴婢。結婚相手を外に広げるほど、持ち主の奴婢がふえた。
ほかの選択肢：1は逆で、ふやすためだった。3と4は講義に出てこない。すすめたのは主人の損得だった。
```

## 5. 名前と扱い
- 両班はふだん本名で呼ばず、別の呼び名（字・号）を使った。女性も「金氏」などと呼んだ。
- 名前を **ぞんざいに付けて呼ばれたのは奴婢だけ**。「石ころ」「庭」「子犬」「小さい子」のような名前が多かった。人として軽く見られていたしるし。
- 奴婢は **売る・相続する・贈る・借金のかたにする** ことができた。法律の値段は16〜50歳で紙幣4,000張（米20石、綿布40枚ほど）。
- 子が科挙に受かったお祝いに、奴婢を6人贈った記録もある。
- 主人は重い罰も与えられた。役所が許せば死なせることも。やさしい主人の話（黄喜、李滉が赤ちゃんを産んだばかりの婢を乳母に出すのを断った話）が残るのは、それが **めずらしかったから**。

## 6. 相続で家族がばらばらに
- 朝鮮の前半は、子どもに **同じだけ分ける相続（均分相続）**。人数だけでなく、年齢や健康まで考えて公平に分けた。
- その結果、**奴婢の家族は別々の主人に分けられた**。家族ごと逃げるのを防ぐねらいもあった。
- 17世紀後半から **長男中心の相続** に変わり、娘は相続からも祭りの役目からも外されていった。

## 7. 抜け出す道
| 道 | 中身 |
|---|---|
| **逃げる（逃亡）** | いちばん多い方法。戦争（壬辰倭乱）のあとも、どんどん増えた |
| 手柄を立てる | 戦争や反乱の取りしまりで功を立てる |
| 自由の証明書を買う（免賤帖） | 不作で国が困ると、穀物やお金と引きかえに売った |
| 主人にお金を払う（贖価） | 財産のある家の奴婢が、自分で自由を買う |

- 主人は逃げた奴婢を追った（**推刷**、すいさつ）。ドラマ「推奴」はこの話。戸籍には逃げ先の見当まで書き、**100歳、200歳になっても記録し続けた** 例もある。
- 主人をなぐる・殺すといった強い反抗は、死刑になるので少なかった。それでも、主人を殺す相談をした集まり（殺主契）が見つかった記録がある。

```quiz
Q: 奴婢が身分から抜け出すために、いちばんよく使った方法は？
1: 科挙に受かる
2: 逃げる（逃亡）
3: 王に手紙を出す
4: 両班と養子縁組をする
C: 2
E: 合法の道はせまかったので、いちばん多かったのは逃亡。主人は推刷で追いかけた。
ほかの選択肢：1は奴婢は受けられない。3と4は講義に出てこない。合法の道は手柄・免賤帖・お金で買うなど。
```

## 8. 記録はどこに残った？
- 奴婢は自分で記録を残せなかった。いちばんくわしいのは **戸籍**（3年ごとに作る）。名前・年齢・結婚・主人・逃げた先まで書いてある。
- もう1つは **財産を分ける書類（分財記）**。逃げた奴婢の名前も書き、「つかまえたら、また分ける」と記した。

## 9. 制度がゆるみ、なくなるまで
```flow
軍の税が軽くなる（均役法） → 国の奴婢を持つ得が小さくなる → 逃亡が止まらない → 1801年 国の奴婢を解放 → 1894年 身分制とともに廃止
```
- 英祖のとき、民の軍の税（軍布）を軽くする **均役法**。国の奴婢の負担も、奴は2枚→1枚、婢は1枚半→半分→なしに。民と奴婢の負担が同じになり、国が奴婢を持つ意味が小さくなった。
- 国の奴婢は逃げる人が多く、残った人の負担がふえて、また逃げる。人数を固定（比総法）してもだめだった。
- **1801年**、王室と役所の奴婢を解放（内寺奴婢の革罷）。
- 家の奴婢には **母の身分に従う決まり（従母法）** が効いた。奴と民の女性の子は民になる。1669年に決まり、何度も変わって **1731年に定着**。
- 民になった人は、両班が使わない名字と本貫（家のふるさと）を名乗った。そして何代もかけて、さらに上の身分を目指す人もいた。
- **1886年** 奴婢の身分を親から子へ受けつぐことを廃止、**1894年**（甲午改革）身分制そのものとともに廃止。

```quiz
Q: 朝鮮王朝で、国の奴婢（公奴婢）の多くが解放された年は？
1: 1592年
2: 1731年
3: 1801年
4: 1894年
C: 3
E: 1801年に王室と役所の奴婢が解放された。逃亡が多く、国が持つ得も小さくなっていたから。
ほかの選択肢：1は壬辰倭乱の始まり。2は従母法が定着した年。4は身分制そのものが廃止された年。
```

## ひびきの暮らしでいうと
- 「離れて住む奴婢」は、決まった分を納めたあとの時間で財産をふやした。決まった仕事のあとの **自分の時間をどう使うか** が、人生を変える。
- 制度は、ひとりひとりの「逃げる・お金を貯めて抜け出す」という動きの積み重ねで変わった。小さな行動の積み重ねは、大きな流れをつくる。


# 上級マクロ経済論 8講 ― 人はいつお金を使う？

韓国の放送大学「上級マクロ経済論」8講を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

> 補足：8〜11講は、「使う・設備を買う・働く・お金を持つ」を、一人ひとりが「いちばん得になるように選ぶ」ところから考えなおす回。

**この回の答え：人は今月の給料ではなく、一生でもらえるお金を見て、毎年なるべく同じくらい使う。ただし、お金を借りられない人は、今の給料しだいになる。**

```flow
今の給料だけで決める（ケインズ） → 一生のお金で決める → 借りられないと今の給料しだい
```

## 1. 「今」と「未来」の2回で考える
- 一生を「今」と「未来」の2回に分けて考える（2期間モデル）。
- 給料から税をひいた残り（可処分所得）を、使うか、貯金する。足りなければ借りる。
- 1を貯金すると、未来に 1＋r になって返ってくる（r＝利子率）。

```eq
今使う分 + 未来に使う分÷(1+r) = 一生でもらえるお金
```
- 右は、一生でもらえるお金を今の値うちになおした合計（生涯の富）。この式が使えるお金の上限（生涯予算制約）。

### 1.1 いちばん満足する使い方
- 人は、今と未来を**バランスよく**使いたい。
- 今を1がまんするかわりに、未来にどれだけほしいか（限界代替率 MRS）。
- それが、貯金して増える分（1＋r）とちょうど同じになる点が、いちばんよい。

```eq
MRS = 1+r
```

```quiz
Q: 人が使うお金を決めるのは、今の給料？一生のお金？
1: 今だけでなく、一生でもらえるお金
2: 今月の給料だけ
3: 去年の物価だけ
4: 他人の給料だけ
C: 1
E: 一生でもらえるお金（生涯の富）。
```

```quiz
Q: 使えるお金の上限の式（生涯予算制約）は？
1: 今の消費＋将来の消費×(1＋r)＝今の給料
2: 今の消費＋将来の消費÷(1＋r)＝生涯の富
3: 今の消費＝将来の消費＝利子率
4: 今の消費－将来の消費＝生涯の富
C: 2
E: 今使う分 ＋ 未来に使う分÷(1＋r) ＝ 一生でもらえるお金。
```

```quiz
Q: いちばんよい使い方の条件は？
1: MRS＝0
2: 今の消費＝利子率
3: MRS＝1＋r
4: 将来の消費＝現在の人口
C: 3
E: MRS ＝ 1＋r（今の1がまんと、未来にほしい分の比が、利子とつりあう）。
```


## 2. 給料がふえると：ならして使う
- 今ふえても、未来にふえても、**一生のお金がふえるので、今も未来も両方ふやして使う**。
- 今ふえた → 一部を貯金して未来へ回す。未来にふえる → 借りて今もふやす。
- ふえた分を毎年に平らに分けること（消費の平準化）。だから国全体で、使うお金のゆれは、もうけ（GDP）のゆれより小さい。

```bars
今の給料が100ふえる | 100 | +100 | w
今使う分 | 50 | +50 | b
未来に使う分 | 50 | +50（貯金から） | s
```
- 例：利子0で、今と未来を同じだけ使いたい人の場合。

```quiz
Q: 今の給料だけふえたら、未来に使う分は？
1: 必ず減る
2: 今の給料の変化は将来に一切関係しない
3: 全額を今使うと決まっている
4: 一部を貯めて回すので増える
C: 4
E: ふえる。一部を貯金して回すから（消費の平準化）。
```

```quiz
Q: 使うお金のゆれが GDP のゆれより小さいのはなぜ？
1: 所得の変化を貯蓄などでならすから
2: 毎年の所得が必ず同じだから
3: 消費には価格がないから
4: 政府がすべての消費を固定するから
C: 1
E: ふえた分を毎年に平らに分けて使うから。
```


## 3. 利子が上がると
- **だれでも**：今使うと損が大きくなるので、今を減らして貯金する（代替効果）。
- **貯金している人**：利子が入って豊かになる → 今もふやせる（所得効果）。2つの綱引き。
- **借りている人**：利子の支払いがふえる → 今を減らす。だから**必ず減る**。

| | 今使う分は |
|---|---|
| 貯金している人 | 減る力とふえる力の綱引き |
| 借りている人 | 必ず減る |

- 国全体では、利子が上がると使うお金は減る（代替効果のほうが強い）。
- まとめると：一生のお金がふえると今使う分↑、利子が上がると↓（最適消費関数 c1＝C(we, r)）。

```quiz
Q: 利子が上がると、借りている人の今使う分は？
1: 今の消費が必ず増える
2: このモデルでは今の消費が減る
3: 借金の利子の負担がなくなる
4: 利子が上がっても返済額は必ず同じ
C: 2
E: 必ず減る。
```

```quiz
Q: 利子が上がると、貯金している人の今使う分は？
1: 利子が上がれば必ず今の消費がゼロになる
2: 貯蓄者には所得効果が存在しない
3: 代替効果と所得効果の強さで変わる
4: 貯蓄者には代替効果が存在しない
C: 3
E: 減る力（代替効果）とふえる力（所得効果）の綱引きで決まる。
```


## 4. ずっと続くお金と、たまたまのお金
- 給料 ＝ **ずっと続く分**（恒常所得：能力や学歴で決まる平均）＋ **たまたまの分**（一時所得：景気や事故など）。
- たまたまの分は、一生で足すと0になる。
- 人が使うお金は、ずっと続く分で決まる（恒常所得仮説、フリードマン）。

```eq
ずっと続く分 = r × 一生でもらえるお金
```

```bars
ずっと続く昇給 +100 | 100 | 毎年+100使う | b
一度だけのボーナス +100（r＝5%） | 5 | 毎年+5くらい | s
```
- 一度だけのお金では、使い方はほとんど変わらない。

```quiz
Q: 一度だけのボーナスで、使い方は？
1: 続く昇給より、必ず消費が大きく増える
2: ボーナスは必ず全額その日に使う
3: 収入の続く期間は消費に関係しない
4: 続く昇給より、消費の増え方は小さい
C: 4
E: ほとんど変わらない。ずっと続く昇給なら大きくふえる（恒常所得仮説）。
```

```quiz
Q: ずっと続く分（恒常所得）と一生のお金の関係は？
1: 単純な式では、恒常所得＝r×生涯の富
2: 恒常所得＝生涯の富＋人口
3: 恒常所得＝今月の臨時ボーナスだけ
4: 恒常所得＝r÷生涯の富
C: 1
E: ずっと続く分 ＝ r × 一生でもらえるお金。
```


## 5. 減税しても、人は使わない？
- 国の支出が同じなら、今税をとっても、借金して未来に税をとっても、人の使い方も利子も変わらない（リカードの等価定理）。

```flow
今年の減税 → 「あとで増税がくる」と考える → 減税分を貯金 → 使う分は同じ
```
- 理由：国も一生で見れば「使った分＝税」。とり方を変えても、人の一生のお金は変わらない。
- 利子も変わらない：国が借りる分と、人が貯金する分が同じだけふえるから。

### 5.1 現実ではくずれる理由
1. 借りる利子は貯金の利子より高い。借りられない人もいる。
2. 増税のころには引退した人や亡くなった人もいて、負担が同じ人にかかるとは限らない。

```quiz
Q: リカードの等価定理とは？
1: 減税ならどんな条件でも全額消費が増える
2: 条件の下では将来の税に備え、消費は変わらない
3: 減税すれば政府の将来の返済は必ず消える
4: 国の支出は同じでも必ず利子がゼロになる
C: 2
E: 国の支出が同じなら、減税しても人は将来の増税にそなえて貯金し、使う分も利子も変わらない。
```

```quiz
Q: リカードの等価定理が現実でくずれる理由を2つ。
1: 全員が将来の税を同じように負担することだけ
2: 全員が自由に同じ利子で借りられることだけ
3: 借入れの制約や、税負担の世代の違い
4: 家計が一生の所得を考えることだけ
C: 3
E: 借りる利子が高い・借りられない人がいる。増税の負担が同じ人にかかるとは限らない。
```


## 6. お金を借りられないと
- 未来の給料をあてに借りられず、今の手取りの範囲でしか使えない（流動性制約）。
- このとき給料がふえると、**ふえた分を全部、今使う**。

```bars
借りられる人（一度だけ+100） | 5 | +5くらい | s
借りられない人（一度だけ+100） | 100 | +100全部 | r
```
- 現実のデータとも合う：使うお金が、理論より今の給料に左右される（消費の過剰感応性）。貧しい国では、使うお金のゆれが給料のゆれより大きい（消費変動性のパズル）。
- 国が安い利子で借りて減税すると、借りられない人に安く貸したのと同じ → 減税分を使う → **リカードの等価定理がくずれる**。

```quiz
Q: 借りられない人（流動性制約）の給料がふえたら？
1: 必ず全額を将来へ貯める
2: 今の消費は給料に全く反応しない
3: 必ず消費が減る
4: この講の制約下では増えた分を今の消費へ回す
C: 4
E: ふえた分を全部、今使う。
```

```quiz
Q: 消費の過剰感応性とは？
1: 消費が理論の予想より今の給料に反応すること
2: 消費が今の給料に全く反応しないこと
3: 所得と関係なく物価だけが2倍になること
4: すべての人の消費が同額になること
C: 1
E: 使うお金が、理論の予想より今の給料に左右されること。
```


## 7. 銀行が貸ししぶるとき（2008年の金融危機）
### 7.1 返せる人か分からない
- 返す力は、借りる人は知っていても、銀行は知らない（情報の非対称性）。
- 見分けられないので、銀行は全員に高い利子をつける。

```eq
貸す利子 = (1+貯金の利子)÷a − 1
```
- a＝ちゃんと返す人の割合。返さない人が多いほど、貸す利子が高い。
- 貸す利子と貯金の利子の差（債務不履行プレミアム）。危機で差が広がる → 借りにくい → 使うお金が減る。

### 7.2 家をあずけて借りる
- 銀行は家などをあずかって貸す（担保）。借りられるのは家の値うちまで（LTV＝家の値うちの何割まで借りられるか）。

```flow
家の値段が下がる → 借りられる額が減る → 今使うお金が減る
```
- 信用の低い人向けの住宅ローン（サブプライムローン）が返されず、家の値段が下がり、使うお金が大きく落ちた。

```quiz
Q: 債務不履行プレミアムとは？
1: 銀行口座を開設する一度限りの手数料
2: 返済されない危険に対する貸出金利の上乗せ
3: 預金者全員に必ず支払う賞金
4: 中央銀行が発行する紙幣の額面
C: 2
E: 貸す利子と貯金の利子の差。返さない人が多いほど大きい。
```

```quiz
Q: 家の値段が下がると、家をあずけて借りる人は？
1: 担保で借りられる額が必ず増える
2: 家の価格は借りられる額に無関係
3: 担保で借りられる額と、消費が減る方向
4: 返済されない危険が必ずゼロになる
C: 3
E: 借りられる額が減り、使うお金が減る。
```


## 8. まとめ（6点）
1. 人は一生のお金を見て、今と未来に分けて使う（MRS＝1＋r）。
2. 給料がふえた分は、毎年に平らに分けて使う（消費の平準化）。
3. 利子が上がると、借りている人は必ず使う分を減らす。全体でも減る。
4. 一度だけのお金では、使い方はほとんど変わらない（恒常所得仮説）。
5. 減税しても使わない（リカードの等価定理）。ただし現実ではくずれる。
6. 借りられない人・家の値段が下がった人は、使うお金が今の状況に左右される。

## 9. 自分の暮らしにつなげる
- ボーナスのような一度だけのお金は、全部使わずに少しずつ分けると、毎月の暮らしが平らになる。

# 上級マクロ経済論 10講 ― 働く時間と給料は、どう決まる？

**働く人は「給料と休み」を比べ、会社は「増える生産と給料」を比べます。** 同じ給料でも、働きたい量と雇いたい量は違います。

## 1. あと1時間、働く？ 休む？

休日に「1時間働けば、好きなランチ1回分を買える」とします。

- ランチより休む時間が大事なら、休みたい。
- ランチのほうが大事なら、働きたい。

このように、休みを1時間減らして得られる物と、休みの大事さを比べます。実際には勤務時間を自由に選べないこともありますが、この講では選べると考えます。

```eq
休む1時間の価値 = 働く1時間で買える物
```

正式には **MRS＝w**。MRS は休みと消費の交換の目安（限界代替率）、w は物価を考慮した給料（実質賃金）です。

```quiz
Q: 働く人は、休む1時間と何を比べている？
1: 会社全体の従業員数
2: その1時間働いて買える物
3: 中央銀行の準備だけ
4: 昨日の睡眠時間だけ
C: 2
E: このモデルでは、休みの価値と、1時間働くことで得られる消費の価値を比べます。
```


## 2. 給料が上がったら、必ず多く働く？

気持ちは、2つの方向に動きます。

| 気持ち | 働く時間 | 正式な名前 |
|---|---|---|
| 休むと、もらい損ねる給料が大きい | 増やしたい | 代替効果 |
| 前より少ない時間でも生活できる | 減らしたい | 所得効果 |

**どちらが強いかで結果は変わります。** この講では、給料が上がると働く量が増える場合を考えます。

給料以外のお金、たとえば配当が増えると、もっと休めるので働く量を減らす方向です。

利子が上がると、今働いて貯めたお金が将来増えやすくなります。「今働き、休みは将来に回そう」という動きを **労働の異時点間代替** といいます。

```flow
今の貯金が有利になる → 今働いて貯める → 将来の休みや消費に回す
```

> 補足：利子の効果も条件によります。ここでは、この「時期を入れ替える効果」が働くモデルを学んでいます。

```quiz
Q: 給料が上がったら、必ず働く時間が増える？
1: 所得効果と代替効果の強さで変わる
2: 必ず増える
3: 必ず減る
4: 給料は働く時間に影響しない
C: 1
E: 必ずではありません。「休むのがもったいない」と「少なく働いても暮らせる」のどちらが強いかによります。
```

```quiz
Q: 異時点間代替の「時点間」とは？
1: 違う会社と会社の間
2: 違う国と国の間
3: 今と将来の間
4: 同じ日の朝と昼の賃金差だけ
C: 3
E: 今と将来の間、という意味です。利子が高いと今働いて貯め、休みを将来に回す動きが例です。
```


## 3. パン屋は、もう1時間分の人手を雇う？

人手を1時間分増やすと、パンが追加で8個できるとします。給料がパン5個分なら、雇うと得です。でも、人だけ増やしてもオーブンは混み合うので、追加の生産はだんだん小さくなります。

```eq
追加の人手が増やす生産 = その人手への実質の給料
```

会社は、このつり合いを目安にします（**MPL＝w**）。MPL は労働の限界生産、つまり「人手をもう1単位足す効果」です。

- 給料が上がる → 同じ生産力なら、雇いたい量は減る。
- 技術が進む → 同じ人手で多く作れるので、雇いたい量は増える方向。

```quiz
Q: MPL＝w は、誰の判断？
1: 将来の物価を予測する中央銀行
2: 追加の生産と給料を比べる会社
3: 税率を決める政府
4: 休みたい時間だけを考える家計
C: 2
E: 会社の判断です。追加の人手で増える生産と、支払う実質の給料を比べます。
```


## 4. 働きたい量と、雇いたい量が出会う

給料が自由に動くモデルでは、両方の量が同じになる所で、給料と雇用が決まります（労働市場の均衡）。

ただし、**完全雇用は失業者ゼロという意味ではありません。** 転職のために探している人などは残りえます。

| 考え方 | 注目すること |
|---|---|
| 古典派の基本モデル | 給料が動いて、働きたい量と雇いたい量を合わせる |
| ケインズ派 | 給料などがすぐ動かず、働きたいのに働けない場合がある |

この講では、利子が上がると今の労働供給が増え、雇用と生産が増えると考えます。**縦軸が実質利子率、横軸が生産**の図では、実質総供給曲線は右上がりになります。

技術が進むと、同じ利子率でも多く作れるので線は右へ。政府の購入が増え、将来の税負担を見込んで人が多く働く場合も右へ動きます。

```quiz
Q: 完全雇用なら、失業者は必ずゼロ？
1: 必ずゼロ
2: 仕事探し中などの失業は残りうる
3: 転職する人も一切いない
4: 給料が全員同じになる
C: 2
E: 完全雇用は、転職などに伴う失業もゼロという意味ではありません。給料が調整される基本モデルと、仕事探しに時間がかかる現実を区別します。
```


## 5. なぜ、仕事探し中の人が残る？

仕事を辞める人と、新しく仕事に就く人が、毎期いるからです（労働探索モデル）。

「この給料以上なら受けたい」という最低の給料を **留保賃金** といいます。提示された給料がそれ未満なら、探し続けます。

```flow
仕事の誘いが来る → 自分の条件と比べる → 受けるか、探し続けるか決める
```

失業率が落ち着くのは、次の人数が同じになるときです。

```eq
仕事を辞める人数 = 新しく仕事に就く人数
```

たとえば、働く90人のうち毎月2人が辞め、失業中の10人のうち毎月2人が就職すれば、失業者の人数は変わりません。**同じ10人がずっと失業しているとは限りません。**

### 試験の式を日本語にすると

**s(1−U)＝U×p×H(w*)**。

- U：失業率。1−U：働いている人の割合。
- s：働いている人のうち辞める割合。
- p：失業中の人に仕事の誘いが来る確率。
- w*：留保賃金。H(w*)：誘いの給料が、その基準以上である確率。

左は「辞める割合」、右は「就職する割合」です。ここでは主に、仕事探しに時間がかかる **摩擦的失業** を説明しています。

失業手当が増えると、この単純なモデルでは、条件のよい仕事を待ちやすくなり留保賃金が上がります。ただし、訓練や仕事探しの支援も含む現実の制度では、就職への効果は一方向には決まりません。

```quiz
Q: 留保賃金とは？
1: 法律が決めた全国共通の給料
2: 会社全体が払う給料の合計
3: 退職した人の以前の給料
4: この給料以上なら受けたいという最低額
C: 4
E: この給料以上なら仕事を受けたい、という最低の給料です。
```

```quiz
Q: 失業率が一定なら、誰も就職していない？
1: 辞める人と就職する人が同数でも一定になる
2: 失業率一定なら誰も就職していない
3: 失業率一定なら誰も辞めていない
4: 同じ人が永久に失業していると決まる
C: 1
E: 違います。辞める人数と就職する人数が同じでも、失業率は一定になります。
```


## 6. まず、この3つ

1. 働く人は、給料だけでなく休みの価値も考える。
2. 会社は、追加の生産と給料を比べる。
3. 失業率が一定でも、辞める人と就職する人は入れ替わっている。

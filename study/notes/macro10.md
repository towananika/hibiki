# 上級マクロ経済論 10講 ― 人はどれだけ働く？

韓国の放送大学「上級マクロ経済論」10講を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

**この回の答え：人は「休む時間の大事さ」と「1時間の給料」をくらべて働く量を決め、会社は「1人ふやして増える生産 ＝ 給料」になるまで人をやとう。**

```flow
働く人が決める → 会社が決める → 働く量と給料が決まる → 国の生産が決まる
```

## 1. 働く人はどう決める？（労働供給）
- 1日の時間は決まっている。休む時間（余暇）をへらせば、そのぶん働ける。
- 「休む1時間」と「働いて買える物」をくらべて、つり合うところで決める。

```eq
休む1時間の大事さ = 1時間で買える物（実質賃金）
```
- 正式には **MRS ＝ w**（限界代替率 ＝ 実質賃金）。
- 休む方が大事 → 働く量をへらす。給料の方が大事 → もっと働く。

## 2. 働く量はなにで変わる？
| 何が上がる | 今働く量 | わけ |
|---|---|---|
| 給料以外のお金（配当など） | **へる** | 豊かになり、もっと休みたくなる |
| 給料（実質賃金） | ふつう**ふえる** | 休むのが「もったいない」気持ちが勝つ |
| 利子（実質利子率） | **ふえる** | 今働いて貯めると得なので、今働き、休みはあとに回す |

- 給料が上がったとき：「休むのがもったいない」（代替効果）が「豊かだから休もう」（所得効果）より大きい、と考える。
- 利子が上がって、今働いて休みをあとに回すこと ＝ **労働の異時点間代替**。

```eq
働く量 = Ns(w,r,π)
```
- w（給料）↑で↑、r（利子率）↑で↑、π（給料以外のお金）↑で↓。

## 3. 会社はどう決める？（労働需要）
```eq
1人ふやして増える生産 = 給料
```
- 正式には **MPL ＝ w**（労働の限界生産 ＝ 実質賃金）。
- 給料が上がる → やとう人はへる。
- 技術が進む（全要素生産性 z↑）→ 1人の生産が増える → やとう人がふえる。

## 4. 働く量と給料が決まる（労働市場の均衡）
- 給料が自由に動くと、「働きたい量 ＝ やといたい量」で決まる。
- その給料で働きたい人はみんな働ける ＝ **完全雇用**。

| 考え方 | 失業の見方 |
|---|---|
| 古典派 | 給料がすぐ動くので、失業は「自分で選んだ」「職さがし中」だけ（自発的・摩擦的失業） |
| ケインズ派 | 給料がすぐには動かないので、働きたいのに働けない人が出る（非自発的失業） |

## 5. 国の生産の線（実質総供給曲線）
```flow
利子が上がる → 今もっと働く → やとう人がふえる → 生産がふえる
```
- だから利子率に対して**右上がり**。
- 線が右に動く（生産がふえる）とき：
  - 技術が進む（全要素生産性↑）。
  - 国の支出がふえる（政府支出↑）→ あとで税がふえると思い、もっと働く。

## 6. 職さがしのモデル（労働探索モデル）
- 「職さがし中の失業（摩擦的失業）」がどれだけ残るかを考える。
- 毎期、働く人の一部がやめる（**離職率 s**）。失業中の人の一部に仕事の誘いが来る（**職業提案率 p**）。

### 6.1 この給料なら受ける
- 仕事を受けるのに最低ほしい給料（**留保賃金 w***）。誘われた給料がそれ以上なら受け、下なら断ってさがし続ける。
- 正式には「働いたときの満足 ＝ 失業のままの満足」になる給料（Ve(w*) ＝ Vu）。
- 失業手当がふえる・誘いがふえる → 失業でも困りにくい → 留保賃金は**上がる**。

### 6.2 失業の割合が落ちつくところ
```eq
やめる人 = 新しく職につく人
```
- 正式には **s(1−U) ＝ U×p×H(w*)**。U＝失業の割合、H(w*)＝留保賃金以上の誘いを受ける割合。
- この失業率は**自然失業率**、正確には**摩擦的失業率**に近い（仕事の種類のずれ＝構造的失業は考えない）。

| できごと | 失業の割合 |
|---|---|
| 失業手当をふやす（条件なし） | **上がる**（えり好みして受けない） |
| 失業手当をふやす（職さがし・訓練が条件） | 下がることもある |
| 誘いがふえる（p↑） | どちらもある |

> 補足：誘いがふえると、よりよい職をさがしてやめる人もふえる（例：コロナ後のアメリカの「大退職」）。

## 7. まとめ（6点）
1. 働く人：休む大事さ ＝ 給料（MRS＝w）。
2. 給料↑・利子↑で今もっと働き、給料以外のお金↑で働く量はへる。
3. 利子↑で今働き休みをあとに回す ＝ 労働の異時点間代替。
4. 会社：1人ふやして増える生産 ＝ 給料（MPL＝w）。技術が進むとやとう人がふえる。
5. 国の生産の線（実質総供給曲線）は右上がり。技術↑・政府支出↑で右へ。
6. 職さがしモデル：留保賃金と「やめる人＝職につく人」で失業の割合が決まる。

A: 1人ふやして増える生産 ＝ 給料、になるまで（MPL＝w）。
Q: 技術が進む（全要素生産性↑）と、やとう人は？

## 9. 自分の暮らしにつなげる
- 転職するときは、「この給料以上なら受ける」という自分の留保賃金を先に決めておくと迷いにくい。

# 貨幣金融論 11講 ― 人はなぜお金を持つ？（1）

韓国の放送大学「貨幣金融論」11講（スライド24枚）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
お金の回る速さ（流通速度） → 買い物の合計（物価×量） → 人が持ちたいお金の量（貨幣需要）
```

## 0. ひとことで
「世の中の人は、どれくらいお金を手元に持ちたがるのか（貨幣需要）」を考える回。
昔の経済学（古典派）には2つの考えがある。**フィッシャー**は「お金は**買い物に使う道具**」、**ケンブリッジ学派（マーシャルたち）**は「お金は買い物の道具で、しかも**財産をためる箱**」。
この2つ目が、次の12講のケインズにつながる。

## 1. 「お金の需要」ってなに？
- 中央銀行と銀行がお金を**出す**（通貨供給）。家計・会社・政府がお金を**持ちたがる**（貨幣需要）。
- 何が「持ちたいお金の量」を決めるのか、それが変わるとどうなるのか、を調べるのが**貨幣需要の理論**。
- 11講は古典派、12講はケインズ派とマネタリスト（通貨主義）。

## 2. フィッシャーの式（貨幣数量説）
1911年の本『貨幣の購買力』で出した**交換の式（交換方程式）**：

**お金の量 × 1年に回る回数 ＝ 物価 × 買われた量**（M・V = P・T）

お米だけの国で考えると：
| | 数字 |
|---|---|
| 1年に買われるお米（取引量 T） | 10袋 |
| 1袋の値段（物価 P） | 10万ウォン |
| 買い物の合計（P×T） | 100万ウォン |

- お金が**50万ウォン**なら、1年に平均**2回**使われればいい。**20万ウォン**なら**5回**。
- この「回る回数」が**お金の回る速さ（流通速度 V）**。同じお金が何度も使われるから、お金の量と買い物の合計は同じでなくていい。


```quiz
Q: 1年の買い物の合計が100万ウォンで、お金が20万ウォンしかないとき、お金は平均何回使われる？
1: 2回
2: 5回
3: 10回
4: 20回
C: 2
E: 100万 ÷ 20万 ＝ 5回。お金の回る速さ（流通速度）が5ということ。
```

## 3. 式を使いやすくする
- 「買われた量（T）」は、株・家・中古品まで入るので**数えにくい**。
- そこで、数えやすい**国全体で作ったものの量（実質国民所得 y）**に置きかえる。作る量が増えれば、買う量も増えるから。
- すると **M・V = P・y**。P×y は「その年の値段で数えた国の稼ぎ（名目国民所得 Y、名目GDP）」。
- 持ちたいお金の量は **M = (1/V)・Y**。

**フィッシャーたちの考え**：お金の回る速さ（V）は、給料日の決まりや人の使い方の**くせ（制度・習慣）**で決まるので、**短い間は変わらない**。
→ だから **国の稼ぎ（名目所得）が増えると、持ちたいお金も同じように増える**（正の関係）。
→ 速さと量が変わらなければ、**物価はお金の量だけで決まる**。

## 4. ケンブリッジ学派の考え（現金残高説）
- お金の役目は2つ：**買い物の道具（交換の仲立ち）**＋**財産をためる箱（価値の保存）**。
- 財産が増えると、家・金（実物資産）、株・債券（金融資産）と同じように、**お金で持つ分も増える**。
- 財産は稼ぎに比例するので、持ちたいお金も稼ぎに比例する：

**持ちたいお金 ＝ k × 国の稼ぎ**（Md = k・Y）

- **k（マーシャルの k）**＝ 稼ぎのうち、お金で持っておく割合。

> 補足：お金が1年に6回回るなら、1回のお金は平均**2か月**だれかの手元にある（1年の1/6）。k は「お金が手元にとどまる長さ」と考えるとわかりやすい。


```quiz
Q: マーシャルの k が表すものは？
1: 中央銀行の金利
2: 稼ぎのうち、お金で手元に持っておく割合
3: 1年に作ったものの量
4: 銀行に積ませるお金の割合
C: 2
E: k は持ちたいお金と稼ぎの比。お金が手元にとどまる長さとも読める。
```

## 5. 金利が上がると、k は変わる
```flow
金利が上がる → 利息のつく株・債券が得になる → お金をそっちへ移す → 手元のお金（k）が減る
```
- ここで初めて「**金利がお金の需要を動かすかもしれない**」という考えが出た。
- これが**ケインズの理論のもと**になる（12講）。

## 6. 2つの考えのくらべ
| | フィッシャー（貨幣数量説） | マーシャルとピグー（現金残高説） |
|---|---|---|
| 持つお金の決まり方 | 取引の量やくせで決まる | ある程度、自分で選ぶ（金利も考える） |
| お金の役目 | 買い物の道具 | 買い物の道具＋財産をためる箱 |
| お金の回る速さ | 短い間は変わらない | 短い間でも変わる（得な財産に移すから） |


```quiz
Q: 「お金の回る速さは短い間でも変わる」と考えたのは？
1: フィッシャー
2: マーシャルとピグー（ケンブリッジ学派）
3: どちらも変わらないと考えた
4: 中央銀行
C: 2
E: ケンブリッジ学派は、金利などで得な財産が変わると、手元のお金の量（k）も変わると考えた。
```

## ひびきの暮らしでいうと
- 給料のうち、すぐ使うお金と、ためておくお金。金利が高いときは**預金や投資に移して、手元のお金を少なく**する。これがそのまま k が下がる動き。
- 物価が上がるかどうかを考えるときは「お金の量」と「お金の回る速さ」の両方を見る。

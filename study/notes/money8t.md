# 貨幣金融論 8講【会話で読む】― お金はどう増える？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money8)」。

> 補足：韓国の中央銀行は「韓国銀行」（日本の日本銀行にあたる）。お金の単位はウォン。

## 1. 国の銀行（中央銀行）のしごと（5分）

```talk
B: 中央銀行って、何をする銀行？
A: いちばんの目的は、物の値段を安定させること。2011年からは、お金の世界があぶなくならないようにすること（金融の安定）も加わったよ。
B: しごとは？
A: 3つ。お札を作って出す（発券）、銀行のための銀行、国（政府）のための銀行。
C: 発券、銀行の銀行、政府の銀行。
```

```card
要点
- 目的：物価の安定（＋2011年から金融の安定）
- しごと：発券／銀行の銀行／政府の銀行
- 中央銀行が貸す相手は、銀行と政府。家計には直接貸さない
```

## 2. お金のもと（本源通貨）（5分）

```talk
B: 「お金のもと」って？
A: 中央銀行から世の中に出たお金のこと。正式には本源通貨。
B: 何でできてるの？
A: 2つ。人が持っている現金と、銀行が残しているお金（支払準備金）。
B: 銀行が残すお金は、どれくらい？
A: 決まりで最低これだけ残す分（法定準備金）と、自分で多めに残す分（超過準備金）がある。最低の割合を、残す割合 r（法定準備率）という。r＝10%なら、預金100のうち少なくとも10は残す。
C: お金のもと ＝ 現金 ＋ 銀行が残すお金。
```

```card
要点
- お金のもと（本源通貨）＝ 人の現金 ＋ 銀行が残すお金
- 銀行が残すお金 ＝ 法定準備金（最低分）＋ 超過準備金（多めの分）
- M1（使えるお金）＝ 現金 ＋ いつでも引き出せる預金
```

## 3. お金のもとが出る3つの道（5分）

```talk
B: お金のもとは、どうやって世の中に出るの？
A: 3つの道がある。政府、銀行、外国。
B: 政府は？
A: 中央銀行が政府に貸すと、増える。でも、ふつうの銀行が国債（政府の借金の証書）を買っても、変わらないよ。
B: 外国は？
A: 輸出でもらった外国のお金をウォンにかえると増える。輸入すると減る。
C: 政府に貸す・銀行に貸す・輸出で増える。輸入は減る。
```

```card
要点
- 増える：中央銀行が政府に貸す／銀行に貸す／輸出（外国のお金をウォンにかえる）
- 変わらない：ふつうの銀行が国債を買う
- 減る：輸入
```

## 4. 預金がふくらむしくみ（信用創造）（10分）

```talk
B: 銀行は、預かったお金を全部貸していいの？
A: 最低の分（r）だけ残して、あとは貸せるよ。借りた人が、また銀行に預ける。
B: 例は？
A: r＝10%、はじめ100億。A銀行は10億残して90億を貸す。B銀行は90億のうち9億残して81億を貸す。次は72.9億…と続く。
B: 全部でいくらになる？
A: 100億 ÷ 0.1 ＝ 1,000億。10倍にふくらむ。
B: rが小さいと？
A: たくさん貸せるから、もっとふくらむ。r＝20%なら 100億 ÷ 0.2 ＝ 500億。
C: 預金のふえ方 ＝ お金のもとのふえ方 ÷ r。
```

```eq
預金のふえ方 = お金のもとのふえ方 ÷ r
```

```card
要点
- 預金は「お金のもと ÷ 残す割合 r」までふくらむ
- r＝10% → 10倍、r＝20% → 5倍、r＝5% → 20倍
- rが小さいほど、預金は大きくふくらむ
```

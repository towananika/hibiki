# 貨幣金融論 9講【会話で読む】― 銀行のお金は、どう増える？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money9)」。

## 1. 口座の数字も、お金（5分）

```talk
B: 銀行が貸すと、お金が増えるの？
A: 銀行が会社に貸すと、会社の口座に預金ができる。会社がそのお金で仕入れ代を払うと、取引先の口座の預金になる。
B: 預金も、支払いに使えるお金なんだね。
A: そう。だから、お金の量を考えるときは、現金だけでなく預金も数える。銀行の貸し出しが預金を生むことを、信用創造という。
B: じゃあ、貸すほど社会が豊かになる？
A: ちがう。借りた会社は返す義務がある。預金が増えるのと、豊かになるのは別の話。
C: 貸し出し → 預金ができる。これが信用創造。
```

```card
要点
- 銀行の貸し出しが預金を生む（信用創造）
- 預金が増えても、返す義務がある。社会が豊かになるのとは別
```

## 2. いくらでも貸せるわけではない（5分）

```talk
B: 銀行は、いくらでも貸せるの？
A: 送金や引き出しにそなえて、準備金を持つ必要がある。法律で決まった最低の割合が、法定準備率。
B: 計算は？
A: 準備率10%なら、準備100で預金1,000を支えられる。この倍率を通貨乗数という。この例では10倍。
B: 必ず10倍になる？
A: ならない。これは仕組みを理解するための単純なモデル。実際は、借りたい人がいるか、返してもらえるかなども考える。
C: 準備100 ÷ 準備率0.1 ＝ 預金1,000。
```

```card
要点
- 準備率 r ＝ 預金のうち、準備として持つ割合
- 現金も余分な準備もない世界の乗数 ＝ 1 ÷ r（r＝10%なら10倍）
- あくまで説明用のモデル。必ず10倍になる約束ではない
```

## 3. 倍率を小さくする3つのこと（10分）

```talk
B: 倍率が小さくなるのは、どんなとき？
A: 3つ。人が財布に現金を多く持つ。銀行が準備を多めに残す。定期預金（貯蓄性預金）が多い。
B: 現金を持つと、なぜ小さくなる？
A: 現金は消えないけど、銀行の準備として使えなくなる。同じ土台のお金でも、預金は増えにくい。例では10倍が4倍になる。
B: 余分な準備は？
A: 最低10%に加えて、余分に10%残すなら合計20%。準備100で支えられる預金は500。
B: 定期預金は？
A: この講では「現金＋いつでも引き出せる預金」だけを数える。でも、定期預金にも準備が必要だから、定期が多いと、数えるお金は増えにくい。
C: 現金・余分な準備・定期預金。どれも倍率を下げる。
```

```card
要点
- 現金を多く持つ → 倍率が小さくなる（例：10倍 → 4倍）
- 余分な準備（超過準備金）を多く残す → 倍率が小さくなる
- 貯蓄性預金（定期など）が多い → 倍率が小さくなる
```

## 4. 土台 × 倍率（5分）

```talk
B: お金の量は、結局、何で決まるの？
A: 2つ。土台のお金（本源通貨）と、倍率（通貨乗数）。
B: 式にすると？
A: お金の量 ＝ 土台 × 倍率。土台が100、倍率が3なら300。土台が200になると600。
B: 土台が同じなら？
A: 倍率が下がれば、お金の量は減る。中央銀行だけでなく、人や銀行の行動も、お金の量に関わっているんだ。
C: M ＝ m × B。
```

```eq
お金の量 M = 倍率 m × 土台 B
```

```card
要点
- 土台 B（本源通貨）＝ 現金 ＋ 銀行の準備金
- 倍率 m ＝ 通貨乗数。M ＝ m × B、増えた分は ΔM ＝ m × ΔB
- 中央銀行だけでなく、人と銀行の行動も、お金の量を決める
```

## 5. 試験用の記号と公式（10分）

```talk
B: 試験には、どんな記号が出るの？
A: 金額は M（数えるお金）、B（土台）、C（現金）、D（いつでも引き出せる預金）、T（貯蓄性預金）、E（超過準備金）。
B: 割合は？
A: c＝C÷D（現金預金比率）、r（要求払い預金の準備率）、r′（貯蓄性預金の準備率）、t＝T÷D、e＝E÷D（超過準備率）。
B: c＝0.2は？
A: 預金100に対して現金20、という意味。現金＋預金の合計の20%ではないよ。分母は D。
B: 乗数の式は？
A: すべてあると (1＋c)÷(c＋r＋r′×t＋e)。c＝0.2、r＝0.1で、ほかがなければ (1＋0.2)÷(0.1＋0.2)＝4。
C: 現金だけなら (1＋c)÷(r＋c)。余分な準備だけなら 1÷(r＋e)。
```

```card
要点
- c＝C÷D（現金÷預金）、t＝T÷D、e＝E÷D。分母はどれも D
- 現金あり：m ＝ (1＋c)÷(r＋c)　／　超過準備あり：m ＝ 1÷(r＋e)
- すべてあり：m ＝ (1＋c)÷(c＋r＋r′×t＋e)
- 例：r＝0.1、c＝0.2 なら m＝1.2÷0.3＝4
```

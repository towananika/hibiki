# 上級マクロ経済論 11講【会話で読む】― お金と中央銀行の働き

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro11)」。

## 1. すぐ使えるお金を持ちたい（5分）

```talk
B: 家や株を持っていても、お金は必要なの？
A: 家や株は、今日のスーパーの支払いには使えない。売るのに時間がかかるから。すぐ使えることを使いやすさ（流動性）という。
B: じゃあ全部現金にすればいい？
A: それだと、預けたり運用したりすればもらえた利子をもらいそこねる。
B: お金の役目は？
A: 3つ。買い物に使う（交換の手段）、価値をとっておく（価値の保存）、値段をはかる物差し（価値の尺度）。
C: 安心と利子の、はかりにかけ。
```

```card
要点
- 流動性：すぐ支払いに使えること
- お金の3つの役目：交換の手段／価値の保存／価値の尺度
- 現金のままだと、もらいそこねる利子がある
```

## 2. 持ちたいお金は、収入と利子で決まる（5分）

```talk
B: 持ちたいお金の量は、何で決まる？
A: 2つ。収入（所得 Y）がふえると、買い物や急な出費がふえるから、もっと持ちたくなる。
B: もう1つは？
A: 利子（i）が上がると、現金のままだともらいそこねる利子が大きくなるから、あまり持ちたくなくなる。
B: ケインズは、持つ理由を分けたよね。
A: 3つ。買い物のため（取引的需要）、急な出費にそなえて（予備的需要）、株や債券を買うタイミングを待つため（投機的需要）。流動性選好説という。
C: L(Y, i)。Y↑でふえる、i↑で減る。
```

```card
要点
- 収入（Y）がふえる → 持ちたいお金は増える
- 利子（i）が上がる → 持ちたいお金は減る
- ケインズの3つ：取引的／予備的／投機的需要（流動性選好説）
- L(Y,i)：L＝持ちたいお金の量、Y＝実質所得、i＝名目利子率
```

## 3. 「お金の量」はどこまで数える？（5分）

```talk
B: お金の量って、現金だけ数えるの？
A: 数える範囲で変わる。せまい順に、M1、M2、Lf・L。
B: それぞれ何？
A: M1は現金と、いつでも出し入れできる預金。M2は、M1に定期預金などを足したもの。Lf・Lは、さらにいろいろな金融商品まで足したもの。
B: 国で違う？
A: これは韓国の分け方。M2には、ふつう満期2年未満の定期預金などが入る。国によって範囲はちがう。
C: M1 ＜ M2 ＜ Lf・L。
```

```card
要点
- M1：現金＋いつでも出し入れできる預金
- M2：M1＋定期預金など（韓国では満期2年未満など）
- Lf・L：さらに広い金融商品まで
```

## 4. お金がふくらむしくみ（10分）

```talk
B: 銀行預金は、どうやってふくらむ？
A: お金には2種類ある。中央銀行が出すお金（本源通貨、お金のもと）と、銀行の預金。お金のもと ＝ みんなの現金 ＋ 銀行が残すお金。
B: 銀行は、貸すと預金を作るの？
A: そう。貸すと、借りた人の口座に預金ができる（信用創造）。
B: 20%を残す例は？
A: 最初の預金が1,000。200を残して800を貸す。その800が別の銀行に預けられ、また20%を残して640を貸す。…と続いて、合計は 1,000 ÷ 0.2 ＝ 5,000に近づく。
B: 現金も持つ人がいると？
A: 財布に持つ分は銀行に戻らないので、ふくらみ方（通貨乗数）は小さくなる。銀行が多めに残すときも小さくなる。
B: 式は？
A: m ＝ (c＋1)÷(c＋z)。c ＝ 現金÷預金、z ＝ 準備÷預金。世の中のお金 ＝ m × お金のもと。
C: だから、お金のもとを増やしても、世の中のお金が同じ割合で増えるとは限らない。
```

```card
要点
- お金のもと ＝ みんなの現金 ＋ 銀行が残すお金
- 20%残す → 預金の合計は 1,000 ÷ 0.2 ＝ 5,000（条件つき）
- 現金を持つ・銀行が多めに残す → 通貨乗数は小さくなる
- m ＝ (c＋1)÷(c＋z)。世の中のお金 ＝ m × お金のもと
```

## 5. 中央銀行は何を動かす？（5分）

```talk
B: 中央銀行は、何をねらって動くの？
A: 銀行どうしが1日だけお金を貸し借りするときの金利（コールレート）を、ねらった高さに近づける。
B: 道具は？
A: 4つ。国債の売り買い（公開市場操作）、銀行に貸すときの金利、残す割合（支払準備率）、預け金への利子（付利）。
B: 国債を買うと？
A: 銀行の手元のお金がふえる。
C: 金利を下げる → 借りやすい → 買い物や投資がふえる。
```

```card
要点
- ねらうのは、銀行どうしの1日だけの貸し借りの金利（コールレート）
- 道具：国債の売買／貸す金利／支払準備率／付利
- 金利を下げる → 借りやすくなる → 買い物・投資がふえる
```

## 6. 金利を0近くまで下げても足りないとき（5分）

```talk
B: もう金利を下げられないときは？
A: 金利はふつう0より大きく下げにくい。ゼロ金利制約という。そのときの方法は3つ。
B: 3つは？
A: お金を大量に流す（量的緩和、QE）。先に約束する（フォワード・ガイダンス）。金利をマイナスにする（マイナス金利）。
B: マイナス金利は？
A: 銀行が国の銀行に預けたお金の一部に、逆に手数料のような利子をかける。少しならマイナスにもできる。
B: 韓国は？
A: 1998年から、「物価の上がり方はこのくらい」と目標を決めて動いている（物価安定目標制）。
C: QE・約束・マイナス金利。
```

```card
要点
- ゼロ金利制約：金利は0より下げにくい
- 3つの方法：量的緩和（QE）／フォワード・ガイダンス／マイナス金利
- 韓国は1998年から物価安定目標制
```

## 7. 金利を下げると、5つの道で届く（5分）

```talk
B: 金利を下げると、どうして景気に届くの？
A: 5つの道。借りる（ローンが楽になる）、株や家（値段が上がって使いたくなる）、為替（ウォン安で輸出がふえる）、銀行が貸す、予想（低い金利が続くと思われる）。
B: いつも同じ強さで効く？
A: ちがう。物価に届くまで時間もかかる。
C: 借りる・株や家・為替・貸し出し・予想。
```

```card
要点
- 5つの道：借りる／株や家／為替／銀行が貸す／予想
- どの道もいつも同じ強さではなく、時間もかかる
```

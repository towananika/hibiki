# 伝統社会と生活文化 11講 ― 女性の結婚・愛・仕事

韓国の放送大学「伝統社会と生活文化」11講（対談の講義、約45分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名や数字は聞き取りなので、少しずれているかもしれない。

```flow
儒教が入る（高麗の終わり） → 結婚の決まりが変わる → 再婚がむずかしくなる → 妻と妾の順番 → 身分の低い女性の仕事
```

## 0. ひとことで
「朝鮮の女性は地位が低かった」というイメージは、**朝鮮の後半の、それも一部の女性** の話。
儒教が入ってから、結婚のやり方・再婚・妻と妾の順番が少しずつ変わった。でも **暮らしの文化が変わるには、とても長い時間がかかった**。
そして家の仕事・子育て・機織りなどを実際に担ったのは、多くが **身分の低い女性** だった。

## 1. 結婚は「家と家」のむすびつき
- 両班にとって結婚は **家と家のむすびつき**（二姓之合）。だから両班の男性の妻は、必ず両班の女性（**同じ身分どうしの結婚**＝身分内婚）。
- 物語「春香伝」の李夢龍と春香は、身分がちがうので本当は **結婚の相手にはなれない**。恋愛結婚もなく、**仲人を通す結婚（仲媒婚）**。

**国がすすめた「よい結婚」**
- 仲人を通す／**同じ名字どうしは結婚しない**（同姓不婚）／喪の間は結婚しない／ぜいたくにしない
- 30歳をこえても結婚できない女性は、**国がお世話して結婚させる**
- 苦労をともにした妻（糟糠の妻）を捨てない

## 2. 何歳で結婚した？
- 法律（経国大典）では、両班の男性15歳・女性14歳から。
- 戸籍などの研究では、実際は **女性17.5歳・男性18歳** ごろ。中国と同じくらい、日本やヨーロッパより早い。
- 「年上の花嫁と小さな花婿」のイメージは、研究ではちがった。**同い年と、花嫁が年上が、同じくらいの割合**。
- 結婚は早いのに、**1人目の子は遅い**。花嫁が結婚後しばらく実家にいて（于帰）、夫婦が会う日が少なかったから。

```quiz
Q: 研究でわかった、朝鮮の両班の実際の結婚の年齢に近いのは？
1: 女性10歳・男性10歳
2: 女性17.5歳・男性18歳
3: 女性25歳・男性30歳
4: 女性14歳・男性30歳
C: 2
E: 戸籍などの研究で、女性17.5歳・男性18歳ごろ。同い年や花嫁が年上の夫婦も多かった。
ほかの選択肢：1は早すぎる（法律でも14〜15歳から）。3は遅すぎる。4のような大きな年の差がふつうだったわけではない。
```

## 3. 再婚：男性はできて、女性はむずかしい
**男性（両班）**
- 出産で亡くなる妻が多く、男性は「跡つぎの息子が必要」と再婚、3回目もめずらしくなかった。
- ただし相手は **初婚の女性** だけで、家柄も前の妻より下がりがち。50歳をこえると再婚せず、妾と暮らすことが多かった。

**女性（両班）**
- 高麗までは再婚する女性も多かった（王妃にも）。
- 儒教が広まると「再婚は貞節を失うこと」と考えられた。
- 国は再婚を直接禁止せず、**再婚した女性の名を名簿（恣女案）にのせ、子や孫が役人になる道をふさいだ**。息子の出世を止めてまで再婚する母は、ほとんどいなかった。
- 朝鮮の後半には、両班の女性の再婚は **ほぼ不可能**。これは韓国の歴史の大きな特徴。

**国のほうび（旌表政策）**
- 夫に尽くした妻（烈女）・忠臣・孝行者を表彰し、家の門（旌閭門）を建て、税を軽くした。
- 表彰されると家の名誉になり、税も軽くなった。そのため、両班でないふつうの家の女性まで、夫が死んだあと再婚せず一人で暮らすようになった。
- さらに後の時代には、夫が死ぬと妻も自分で命を絶つ（殉死）ことまで「りっぱなこと」としてほめられるようになった。実学者（現実に役立つ学問を重んじた学者）はこれを批判したが、なくならなかった。

```quiz
Q: 朝鮮で、国が両班の女性の再婚をおさえた方法は？
1: 再婚した女性をろうやに入れた
2: 再婚した女性の子や孫が役人になる道をふさいだ
3: 再婚した女性に税をかけた
4: 再婚を法律で直接禁止した
C: 2
E: 再婚した女性を名簿（恣女案）にのせ、子や孫の出世の道をふさいだ。母は息子のために再婚をあきらめた。
ほかの選択肢：1と3は講義に出てこない。4は逆で、国は直接禁止せず、遠回しにおさえた。
```

## 4. 結婚式とすまいの変化
| やり方 | 中身 |
|---|---|
| もとの朝鮮のやり方（男帰女家） | 花婿が **花嫁の家** に入って式をし、そこで暮らす |
| 中国式（親迎） | 花婿が花嫁を **自分の家** に連れてきて式をし、そこで暮らす |
| 16世紀の折衷（半親迎） | 花嫁の家で、**その日のうちに** 式をする。すまいはもとのやり方のまま |
| 朝鮮の後半（于帰） | 式は花嫁の家。花嫁はしばらく実家にいて、年が明けたころ夫の家に入る |

- 儒学者は、朝鮮の建国のころから中国式をすすめた。理由は「男（陽）が女（陰）に従うのはおかしい」「式の3日前に夫婦が先に同じ部屋で寝るのは、はしたない」。
- 16世紀の学者・柳希春の日記（**眉巌日記**、1567〜1577年の11年分）に、孫の結婚の様子がくわしく残る。結婚では **相手の家の財産** をとても気にしていた。相手の家が「柳家は貧しすぎる」と思い、何年も式をのばしたほど。
- **500年かけて**、花嫁が夫の家で暮らす形になった。実家で育った女性が急に夫の家で暮らすので、「嫁ぎ先の暮らしは唐辛子より辛い」と言われたのかもしれない。

```quiz
Q: 花婿が花嫁の家に入って式をし、そこで暮らす、朝鮮のもとの結婚のやり方は？
1: 親迎
2: 男帰女家（婿入り婚）
3: 于帰
4: 仲媒婚
C: 2
E: もとの朝鮮は花嫁の家で式をして暮らす形。儒学者はこれを中国式（親迎）に変えようとした。
ほかの選択肢：1は花嫁を夫の家に連れてくる中国式。3は花嫁がのちに夫の家に入ること。4は仲人を通す結婚のこと。
```

## 5. 妻と妾（めかけ）
- 朝鮮は「1人の夫に1人の妻」ではなく、正しくは **1人の妻と、何人もの妾**（一夫一妻多妾）。
- 高麗の終わりには妻を何人も持つ人もいた。でも **李芳遠（のちの太宗）の「王子の乱」** で、先に結婚した妻の子が勝ち、あとの妻の子は不利になった。それ以降、両班の女性が2人目の妻や妾になることは、ほぼなくなった。
- 妾になるのは、ふつうの民やもっと低い身分の女性。地方に赴任した役人が、身のまわりの世話をする女性（妓生など）を妾にすることも多かった。夫婦がいっしょに暮らす割合は半分以下のことも多かった。

| | 妻 | 妾 |
|---|---|---|
| 選び方 | 家の跡つぎのため、同じ身分から | 夫の好みで |
| 立場 | 社会に認められ、結婚は続く | 家族の中のいちばん下 |

- 「君臣・嫡妾・嫡庶」の順番を守ることが、家の平和だと考えた。
- 柳希春の妾は、夫の死後も一人で暮らし、夫のそばにうめてほしいと願った。いまもお墓が残り、子孫がまつっている（妾のお墓が残るのはめずらしい）。

> 補足：柳希春の妻・宋徳峰は、すぐれた詩人。位牌の裏には本名が書かれていて、「両班の女性には名前がなかった」というイメージがちがうことがわかる。

## 6. 身分の低い女性の仕事
| 仕事 | 中身 |
|---|---|
| そばで仕える | 主人に一日中つきそい、外出にもついていく。結婚のとき実家から連れてくる（轎奴婢）こともあった |
| 乳母 | 赤ちゃんを産んだ女性が、主人の子に乳をあげて育てる。自分の子と2人を育てるのはとても大変。ある日記では、乳母が病気で亡くなり、その子も亡くなった |
| 台所 | 両班の女性は台所の仕事を取りしきるが、実際に作るのは **台所の女性**（廚婢）。主人の口に合う料理を求められた |
| 機織り・養蚕 | 絹・木綿・麻の布は、服の材料で **税にも使えた**。いちばん生産的な仕事 |
| 市場で売る | 主人に言われて、酒・もち・服を作って市場で売った |

- **養蚕（かいこを育てて絹をとる）**：王妃が自分でかいこを育てる儀式（親蚕礼）でお手本を見せた。1909年の写真も残る。両班の妻も熱心で、村の養蚕の名人から技術を習った。16世紀には、かいこの卵をかえす技術も広まった。

```quiz
Q: 朝鮮で、女性の仕事のうち「いちばん生産的」とされ、税にも使えるものを作った仕事は？
1: 乳母
2: 機織り・養蚕（布や絹を作る）
3: 台所の仕事
4: そばで仕える仕事
C: 2
E: 絹・木綿・麻の布は、服の材料であり、税として納めることもできた。
ほかの選択肢：1、3、4も大事な仕事だが、税になる「もの」を作る仕事ではない。
```

## 7. まず、この3つ
1. 結婚は家と家のむすびつき。同じ身分どうしで、仲人を通した。実際の結婚年齢は女性17.5歳・男性18歳ごろ。
2. 儒教で、両班の女性の再婚はほぼ不可能に。結婚のやり方は、花嫁の家で暮らす形から、夫の家で暮らす形へ、ゆっくり変わった。
3. 1人の妻と何人もの妾。家の仕事・乳母・機織りの多くは、身分の低い女性が担った。

## ひびきの暮らしでいうと
- 法律や考え方が変わっても、**暮らしの習慣は何十年、何百年もかけて変わる**。自分の習慣を変えるときも、すぐに変わらなくてあたりまえ。
- 柳希春の日記のように、毎日書きのこした記録は、何百年後にも役に立つ。ひびきの日記や記録も、未来の自分の宝になる。

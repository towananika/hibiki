# 上級マクロ経済論 8講【会話で読む】― 人はいつお金を使う？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro8)」。

## 1. 今と未来、2回で考える（5分）

```talk
B: 人は、お金をいつ使うか、どう決めるの？
A: 一生を「今」と「未来」の2回に分けて考える（2期間モデル）。給料から税を引いた残りを、使うか貯金する。足りなければ借りる。
B: 貯金すると？
A: 1を貯金すると、未来に 1＋r になって返る。r は利子率。
B: 使えるお金の上限は？
A: 一生でもらえるお金を、今の値うちになおした合計（生涯の富）。それが上限で、生涯予算制約という。
C: 今使う分 ＋ 未来に使う分÷(1＋r) ＝ 生涯の富。
```

```card
要点
- 一生を「今」と「未来」の2回で考える（2期間モデル）
- 1を貯金すると、未来に 1＋r（r＝利子率）
- 生涯予算制約：今使う分 ＋ 未来に使う分÷(1＋r) ＝ 生涯の富
- いちばん満足する点：MRS（今をがまんして未来にほしい量）＝ 1＋r
```

## 2. 給料がふえたとき：ならして使う（5分）

```talk
B: 今の給料が100ふえたら、100全部使う？
A: 使わない。一生のお金がふえたと考えて、今も未来も両方ふやして使う。今ふえた分の一部は、貯金して未来へ回す。
B: 未来に給料がふえるなら？
A: 借りて、今もふやして使う。
B: これを何という？
A: 消費の平準化。ふえた分を毎年に平らに分けること。だから国全体では、使うお金のゆれは、もうけ（GDP）のゆれより小さい。
C: 例：今+100なら、今+50、未来+50。
```

```card
要点
- 給料がふえると、今も未来もふやして使う（消費の平準化）
- 例：今の給料+100 → 今+50、未来+50（貯金から）
- 国全体で、消費のゆれ ＜ GDPのゆれ
```

## 3. 利子が上がると（5分）

```talk
B: 利子が上がると、今使う分はどうなる？
A: だれでも、今使うと損が大きくなるので、今を減らして貯金したくなる（代替効果）。
B: 貯金している人は？
A: 利子が入って豊かになるので、今もふやせる（所得効果）。2つの綱引き。
B: 借りている人は？
A: 利子の支払いがふえるから、今を減らす。必ず減る。
C: 国全体では、代替効果のほうが強く、使うお金は減る。
```

```card
要点
- 貯金している人：減る力（代替効果）とふえる力（所得効果）の綱引き
- 借りている人：必ず減る
- 国全体：利子が上がると消費は減る
- 最適消費 c1 ＝ C(we, r)：生涯の富 we↑で今の消費↑、利子 r↑で↓
```

## 4. ずっと続くお金とたまたまのお金（5分）

```talk
B: ボーナスが出たら、全部使う？
A: 給料は「ずっと続く分（恒常所得）」と「たまたまの分（一時所得）」に分かれる。人が使うお金は、ずっと続く分で決まる（恒常所得仮説、フリードマン）。
B: 例は？
A: ずっと続く昇給+100なら、毎年+100使う。一度だけのボーナス+100（利子5%）なら、毎年+5くらい。
B: 一度だけだと、ほとんど変わらないの？
A: そう。一生に分けると、毎年のふえ方が小さくなるから。
C: ずっと続く分 ＝ r × 生涯の富。
```

```card
要点
- 給料 ＝ 恒常所得（ずっと続く）＋ 一時所得（たまたま）
- 使い方は恒常所得で決まる（恒常所得仮説）
- 一度だけのお金では、使い方はほとんど変わらない
```

## 5. 減税しても、人は使わない？（10分）

```talk
B: 減税したら、みんな使うよね？
A: このモデルでは使わない。今年の減税は、「あとで増税が来る」と考えて、貯金するから。国の支出が同じなら、今税をとっても借金して未来にとっても、人の使い方も利子も変わらない。これがリカードの等価定理。
B: 利子も変わらないの？
A: 国が借りる分と、人が貯金する分が、同じだけふえるからね。
B: でも現実は？
A: くずれる。理由は2つ。借りる利子は貯金の利子より高くて、借りられない人もいる。それと、増税のころには引退した人や亡くなった人もいて、負担が同じ人にかかるとは限らない。
C: 減税 → 貯金 → 使う分は同じ。
```

```card
要点
- リカードの等価定理：国の支出が同じなら、減税しても使い方・利子は変わらない
- 理由：「あとで増税」と見こんで、減税分を貯金する
- 現実でくずれる理由：借りられない人／負担が同じ人にかかるとは限らない
```

## 6. 借りられないとき（5分）

```talk
B: お金を借りられないと、どうなる？
A: 未来の給料をあてにできず、今の手取りの範囲でしか使えない。これを流動性制約という。
B: そのとき給料がふえたら？
A: ふえた分を全部、今使う。例：一度だけ+100なら、借りられる人は+5くらい、借りられない人は+100全部。
B: 現実のデータは？
A: 使うお金が、理論より今の給料に左右される（消費の過剰感応性）。貧しい国では、使うお金のゆれが給料のゆれより大きい（消費変動性のパズル）。
B: 減税は？
A: 国が安い利子で借りて減税すると、借りられない人に安く貸したのと同じ。減税分を使うので、リカードの等価定理がくずれる。
C: 借りられない人は、今の給料しだい。
```

```card
要点
- 流動性制約：借りられず、今の手取りの範囲でしか使えない
- 給料がふえると、ふえた分を全部、今使う
- 借りられない人がいると、リカードの等価定理はくずれる
```

## 7. 銀行が貸ししぶるとき（2008年の金融危機）（10分）

```talk
B: 銀行は、なぜ貸ししぶるの？
A: 返す力は、借りる人は知っていても、銀行は知らない（情報の非対称性）。見分けられないから、全員に高い利子をつける。
B: 式は？
A: 貸す利子 ＝ (1＋貯金の利子)÷a − 1。a は、ちゃんと返す人の割合。返さない人が多いほど、利子が高い。
B: 危機のときは？
A: 貸す利子と貯金の利子の差（債務不履行プレミアム）が広がる。借りにくくなって、使うお金が減る。
B: 家をあずけて借りる場合は？
A: 銀行は家などをあずかって貸す（担保）。借りられるのは、家の値うちまで（LTV）。家の値段が下がると、借りられる額が減って、今使うお金が減る。
B: 2008年は？
A: 信用の低い人向けの住宅ローン（サブプライムローン）が返されず、家の値段が下がって、使うお金が大きく落ちた。
C: 差が広がる → 借りにくい → 使わない。
```

```card
要点
- 情報の非対称性：銀行は、返す力を見分けられない
- 債務不履行プレミアム ＝ 貸す利子と貯金の利子の差。危機で広がる
- 担保・LTV：家の値段が下がると、借りられる額が減る
- 2008年：サブプライムローンが返されず、家の値段が下がった
```

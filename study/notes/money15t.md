# 貨幣金融論 15講【会話で読む】― 物価決定モデル

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money15)」。

## 1. 総需要曲線（AD曲線）（5分）

```talk
B: 14講のIS-LMでは物価を動かさなかったよね。物価が動くとどうなるの？
A: 物価が上がると、お金がほしい量（貨幣需要）がふえて、LM曲線が左（上）へ動く。だから均衡国民所得がへる。物価が下がると逆で、右（下）へ動いて国民所得がふえる。
B: それをグラフにすると？
A: 物価と国民所得の関係を表す、右下がりの線。これが総需要曲線（AD曲線）。
B: ADが動くのは？
A: 物価が同じでも国民所得（総需要）が変わるとき。IS曲線かLM曲線が右へ動けばADも右へ。左へ動けばADも左へ。拡大的な財政・金融政策は右へ、緊縮的な政策は左へ。
C: ADは右下がり。ISかLMが動けばADも動く。
```

```card
要点
- AD曲線：物価と均衡国民所得の関係。右下がり
- 物価↑ → 貨幣需要↑ → LMが左へ → 国民所得↓
- IS・LMが右へ → ADも右へ／左へ → 左へ
- 拡大的な政策 → ADが右へ／緊縮的な政策 → 左へ
```

## 2. 総供給曲線（AS曲線）（10分）

```talk
B: 総供給曲線は何を表すの？
A: 物価と総供給量（国全体で作る量）の関係。作る量を決めるのは会社で、カギは生産要素の価格、とくに賃金。賃金がいつ調整されるかで、短期と長期に分ける。
B: 短期は？
A: 物価が変わっても賃金は変われないくらいの期間。物価が上がると収入がふえて、費用は同じだから利益がふえて、生産がふえる。だから短期総供給曲線（SAS）は右上がり。ADとSASが交わる所が短期均衡。
B: 長期は？
A: 生産がふえると労働の需要がふえて、長期には賃金が変わる。国民所得は、自然失業率のもとでの国民所得、つまり完全雇用国民所得に近づく。だから長期総供給曲線（LAS）は、完全雇用国民所得で垂直。
C: 短期は右上がり、長期は垂直。
```

```card
要点
- 短期AS（SAS）：右上がり。賃金が変わらず、物価↑で利益↑ → 生産↑
- 長期AS（LAS）：完全雇用国民所得で垂直
- 短期均衡：ADとSASが一致する所
- 自然失業率：完全雇用のときの失業率
```

## 3. 不況と過熱のときの調整（10分）

```talk
B: 国民所得が完全雇用国民所得より少ないとき（不況）は？
A: 労働の需要が少なくて、労働市場は超過供給。賃金が下がるので、会社の費用が下がって、SASが右へ動く。超過供給があるかぎり動き続けて、完全雇用国民所得で止まる。物価は下がる。
B: 多すぎるとき（過熱）は？
A: 労働の供給が少なくて、超過需要。賃金が上がって、SASが左へ動く。完全雇用国民所得で止まる。物価は上がる。
C: 不況はSASが右へ、過熱はSASが左へ。
```

```card
要点
- 不況：超過供給 → 賃金↓ → SASが右へ → 物価↓
- 過熱：超過需要 → 賃金↑ → SASが左へ → 物価↑
- どちらも完全雇用国民所得に着いたら止まる
```

## 4. 自律調整と政府の介入（10分）

```talk
B: その調整って、ほうっておいていいの？
A: 自律調整メカニズムといって、短期に景気がわるくなっても、市場の調整で長期には完全雇用国民所得になる。ここで学派が分かれる。
B: どう分かれるの？
A: 通貨主義学派は、賃金が伸縮的で、すぐ動くから、政府は介入せずに待つほうがよい、と考える。ケインズ学派は、賃金に下方硬直性があって、失業が出てもすぐには賃金が下がらない。長期に解決しても、そのあいだの問題を放っておけないから、積極的に介入すべき、と考える。
B: 介入するとどうなる？
A: 不況のとき、拡大的な政策でADを右へ動かすと、早く完全雇用国民所得に戻れる。ただ、物価は待つ場合より高めになる。過熱のときは、緊縮的な政策でADを左へ動かして、物価が上がらずにすむ。
C: 待つのが通貨主義学派、介入するのがケインズ学派。
```

```card
要点
- 自律調整：市場の調整で、長期には完全雇用国民所得になる
- 通貨主義学派：賃金は伸縮的 → 介入せず待つ
- ケインズ学派：賃金は下方硬直的 → 積極的に介入
- 不況で介入：ADが右へ。早く戻れるが物価は高め
- 過熱で介入：ADが左へ。物価は上がらずにすむ
```

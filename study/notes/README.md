# 絵の出る md の書き方

`study/view.html?n=<名前>` が `notes/<名前>.md` を読み、図つきで見せる。`##` ごとにカードになり、上に目次が出る。

| ブロック | 1行の書き方 | 出るもの |
|---|---|---|
| ```` ```bars ```` | `ラベル \| 値 \| 表示 \| 色(b s w r m)` | 横棒グラフ |
| ```` ```timeline ```` | `年 \| できごと \| ひとこと` | 年表 |
| ```` ```eq ```` | `予測 + 判断 = 決定` | 式の図 |
| ```` ```flow ```` | `A → B → C` | 流れ図 |
| ```` ```quiz ```` | `Q: 問い` / `1:〜4: 選択肢` / `C: 正答番号` / `E: 解説` | 選ぶと正誤と理由が出る4択問題 |

1章に図は3〜6個。1つの考えに1つの図。説明した節の直後に quiz を置く。最後に問題だけをまとめない。

## 改行
- 本文で行を変えると、画面でも改行する。空行は段落を分ける。
- `<br>`・`<br/>` も改行として使える。それ以外のHTMLは文字として表示する。
- 箇条書きの続きを次の行に書くときは、先頭に空白を2つ以上入れる。
- 引用は各行の先頭に `>` を付ける。クイズの質問・答えも、次の行へ続けて書ける。

## 言葉のきまり
- ハングルは使わない。原本が韓国語でも、日本語に言いかえる。
- 韓国ならではの言葉（制度・道具・ことわざ）は、出てきた所に `> 補足：…` か、箇条書きの「補足：…」で短く説明する。

## 言葉の質問（あとで聞く）
- ひびきさんが勉強ページで言葉を選ぶと、`hibiki-words-v1` に保存される（`study/words.js`）。一覧は `study/words.html`。
- 答えは `study/glossary.json` に「言葉: 意味」で足す。足すと、一覧と選んだ時にすぐ出る。
- 新しい教材を書くときは、難しい漢字・用語を先に glossary.json に入れておく。

## ゲームと質問バーの版（claude.ai）
- `view.html` の `PLAY` に名前と claude.ai のページを入れると、ノートの上に「あそんで覚える」ボタンが出る。
- そのページは `/mnt/project-files/hibiki/study/chat/` の `template.html` に md を埋めて作る（`python3 build.py notes/xxx.md out.html` → Artifact で公開）。GitHub Pages は静的で Claude を呼べないため、claude.ai のページに置く。
- 上級マクロ経済論 8〜15講は1枚のページ（講えらび＋「上がる？下がる？」ゲーム＋クイズ＋質問バー）：`python3 build_macro.py <notes フォルダ> out.html` → https://claude.ai/artifact/JwgD4K9REUU99uP2QTMidM に同じファイルで公開しなおす。ゲームの問題は `macro-template.html` の `AR`。
- 質問とこたえは、そのページの db の `asks` に残る。「ノートに足して」を押したもの（`improve: true`）を読んで md を直し、同じページを公開しなおす。

## 4択で確認する

各問題には異なる選択肢を4つ、正答番号を1つ、理由の説明を付ける。間違えやすい考えを誤答にし、正答位置も分散する。選択後は正解・理由を表示し、「もう一度考える」でやり直せる。従来の `Q:` / `A:` 形式も読み込める。

```text
Q: 物事が変わり続けることを何という？
1: 執着
2: 無常
3: 涅槃
4: 正語
C: 2
E: 無常は変わり続けること。執着は、とらわれて離れられないことです。
```
- サイトの中で遊べる4択ゲーム：`study/games/<科目>.json`（`{"8":[[場面,問い,正解番号,説明,[選択肢4つ]],…]}`、選択肢を省くと「ふえる/へる/変わらない/どちらも」）。view.html が macro・tradition のノートの上に出す。

# 絵の出る md の書き方

`study/view.html?n=<名前>` が `notes/<名前>.md` を読み、図つきで見せる。`##` ごとにカードになる。上の細い帯で講をえらび、目次は「目次」を開いたときだけ出す。ノートの下に、ふり返り・ゲーム・となりの講へのボタンが出る（2026-11-21：学習に集中できる形に）。

| ブロック | 1行の書き方 | 出るもの |
|---|---|---|
| ```` ```bars ```` | `ラベル \| 値 \| 表示 \| 色(b s w r m)` | 横棒グラフ |
| ```` ```timeline ```` | `年 \| できごと \| ひとこと` | 年表 |
| ```` ```eq ```` | `予測 + 判断 = 決定` | 式の図 |
| ```` ```flow ```` | `A → B → C` | 流れ図 |
| ```` ```quiz ```` | `Q: 問い` / `1:〜4: 選択肢` / `C: 正答番号` / `E: 解説` | 選ぶと正誤と理由が出る4択問題 |

1章に図は3〜6個。1つの考えに1つの図。説明した節の直後に quiz を置く。最後に問題だけをまとめない。

## 改行
- 本文で行を変えると、画面でも改行する。空行は段落を分ける。
- `<br>`・`<br/>` も改行として使える。それ以外のHTMLは文字として表示する。
- 箇条書きの続きを次の行に書くときは、先頭に空白を2つ以上入れる。
- 引用は各行の先頭に `>` を付ける。クイズの質問・答えも、次の行へ続けて書ける。

## 言葉のきまり
- ハングルは使わない。原本が韓国語でも、日本語に言いかえる。
- 韓国ならではの言葉（制度・道具・ことわざ）は、出てきた所に `> 補足：…` か、箇条書きの「補足：…」で短く説明する。

## 言葉の質問（あとで聞く）
- ひびきさんが勉強ページで言葉を選ぶと、`hibiki-words-v1` に保存される（`study/words.js`）。一覧は `study/words.html`。
- 答えは `study/glossary.json` に「言葉: 意味」で足す。足すと、一覧と選んだ時にすぐ出る。
- 新しい教材を書くときは、難しい漢字・用語を先に glossary.json に入れておく。
- 記号（M・V・k など）を使うときは、毎回となりに言葉の意味を書く（例：M（お金の量））。ひびきが確実にわかるまで続ける（2026-10-31）。
- 説明は文章を中心にする。数式は「> 補足（式で書くと）：…」に回し、本文は式がなくてもわかるように書く（2026-10-31）。
- 練習問題の解説（E:）には、正解の理由に加えて「ほかの選択肢：…」で、まちがいの選択肢がなぜちがうかも書く（2026-10-31）。
- 選択後の「あとで聞く」は選択を終えた位置の近くに表示する。画面下端では上に出し、保存ボタンを選択位置に寄せる。画面外にはみ出さず、Escape・閉じる・本文のスクロールで閉じる。保存先は従来と同じ。

## 4択で確認する

各問題には異なる選択肢を4つ、正答番号を1つ、理由の説明を付ける。間違えやすい考えを誤答にし、正答位置も分散する。選択後は正解・理由を表示し、「もう一度考える」でやり直せる。従来の `Q:` / `A:` 形式も読み込める。

```text
Q: 物事が変わり続けることを何という？
1: 執着
2: 無常
3: 涅槃
4: 正語
C: 2
E: 無常は変わり続けること。執着は、とらわれて離れられないことです。
```
- サイトの中で遊べる4択ゲーム：`study/games/<科目>.json`（`{"8":[[場面,問い,正解番号,説明,[選択肢4つ]],…]}`、選択肢を省くと「ふえる/へる/変わらない/どちらも」）。view.html が macro・tradition のノートの下に出す。

## 思い出す練習と復習

- `view.html` の既存4択に、初回の正解数・時間をあけて正解した問題数・復習したい問題数を表示する。未回答は不正解に数えない。
- 間違えた問題は本文を隠して解き直せる。直後の正解は理解の確認として扱い、間隔をあけた正解や初回の正解数には加算しない。
- 間違えた後は10分、最初の正解後は翌日が再確認の目安。復習予定を迎え、前の回答から10分以上あけて正解すると、次は1日・3日・7日・14日・30日と間隔を延ばす。これは練習用の目安であり、学習効果を保証する数値ではない。
- 記録は `hibiki-study-recall-v1`。講・問題文・選択肢・正答・解説で識別し、教材の問題が変われば別の記録になる。初回の成績と、過去に時間をあけて正解できた問題数を区別する。
- 正解音は初期状態でオフ。`hibiki-study-sound-v1` に設定を保存し、オンにした場合だけ短い音をWeb Audioで作る。不正解時やページを開いたときには鳴らさない。外部の音声ファイルは取得しない。
- 旧形式の「答えを見る」問題は、そのまま表示する。ゲームの回答は復習成績に混ぜず、音の設定だけを共用する。

## 確認テスト（2026-11-21、ひびきと決めた形）
各講の最後に「〇講の確認テスト（10分）」を1つ置く。学校の小テストの形で、中身は `study/test.js`。

- **100点満点・70点以上で合格**（1問1点を100点に直す）。答えは採点まで見えない。結果は「〇点・合格／もう少し」と、✕の問題の正しい答え。最高点は `hibiki-study-test-v1` に講ごとに残る。
- **大問は5つ、この順で**（`## 見出し` で区切る。全部で12〜16問）：
  1. 穴うめ（4問）：文の中に `{{正解|まちがい|まちがい|まちがい}}`。最初が正解、画面では順番をまぜる。
  2. ○×（4問）：行頭に `○` か `×` を書き、そのあとに文。
  3. 組み合わせ（4問）：`言葉 = 意味`。同じ大問の「意味」が選択肢になる。
  4. 並べかえ（1〜2問）：`A → B → C`。正しい順に書く。画面ではまぜる。
  5. 4択（2問）：問いの最後に `{{正解|…}}`（文の最後にあると空らんは出ない）。
- 合格点を変えるときは最初の行に `合格: 80`。
- **重要度と配点（2026-11-21）**：各問の行頭に `★★★`（必ず覚える）・`★★`（大事）・`★`（知っておく）を付ける（省くと★★）。配点は重要度に比例し、合計がちょうど100点になる。各大問の中は★の多い順に並べる。★★★は講の中心の言葉・考え（1講に4〜5問）。採点後は、まちがえた問題を★の多い順に「まず覚える／次に覚える／余裕があれば」として正しい答えつきで出し、★★★の正解数も出す。
- 選択肢の中に ` → ` や ` = ` があってもよい（`{{ }}` がある行は選ぶ問題として読む）。
- 本文の文をそのまま写さず、言いかえて聞く。まちがいの選択肢は、同じ講の似た言葉や、よくある思いこみにする。見本は `notes/ch14.md`。

# 開かれた社会と21世紀 15講 ― まちの記録庫（アーカイブ）をつくる

韓国の放送大学「開かれた社会と21世紀」15講（最終回、講義資料24ページ）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
なぜ広がった？ → まちの記録ってなに？ → ふつうの記録管理とのちがい → 実例 → 計画と作業（全体の計画 → 集める → 使う） → 続けるために
```

## 0. ひとことで
**まちのアーカイブ** は、まちの歴史といまのようすを残した **記録** と、それを集めた **場所** の両方のこと。
国や役所の記録からこぼれた **ふつうの人のくらし** を、**住民自身が記録し、使う**。
14講の最後の「まずは記録から」の続きの回。

## 1. なぜ広がった？
- 自治体のまちづくりや、住民が中心の草の根の運動の一つとして関心が高まった。
- **役所中心の記録は、かたよっている** という批判もあった。
- 社会の大きな考えや大きな話の中で **かくれてしまった人たちに光を当て**、うらにある新しい価値を見つけようとする試み。

**まちのアーカイブの意味**
- まちの歴史の記録なので **歴史性** がある。集めた資料は、できごとに参加した人自身が書いた **いちばん直接の資料（1次資料）**。
- まちの共同体が続いていくための悩みや活動の **あと** を、みんなで分け合い、共感できるように整理して管理する場所。

**歴史の上での2つの意味**
1. まちの場所の歴史を記録し組み立て直して、**まちらしさ（アイデンティティ）** と **市民の意識** を高める。
2. くらしの歴史だけでなく、建築・美術・音楽などの研究の土台や、まちの環境を考える **実務の資料** にもなる。

**地域らしさ（ローカリティ）とまちらしさ（アイデンティティ）**
- 景色を写すだけでなく、まちの歴史・文化・くらしを残して、地域の遺産を守る **まちづくりの活動** でもある。
- 住民が近づきやすく、**住民が記録を残す人（アーキビスト）でもあり、使う人でもある**。

```quiz
Q: まちのアーカイブの特徴として、講義に合うものは？
1: 専門の職員だけが記録を作り、住民は見るだけ
2: 住民が記録を残す人（アーキビスト）であり、同時に使う人にもなれる
3: 国の大きなできごとだけを記録する
4: 景色の写真だけを集める
C: 2
E: まちのアーカイブは住民が近づきやすく、住民が作り手でも使い手でもある。ほかの選択肢：1は住民参加という特徴に合わない。3は逆で、大きな話にかくれたふつうの人のくらしに光を当てる。4は景色だけでなく、歴史・文化・くらしを残す。
```

## 2. まちの記録ってなに？
- まちの共同体と、その活動にかかわる人や団体が作る **すべての種類の記録**。
- 活動の悩み・流れ・結果を見せるものなら何でも記録になる。だから **住民みんなが記録の作り手**（1人でも、何人でも、小さな会でもよい）。

**種類**
| 分け方 | 例 |
|---|---|
| テーマで | まちの自然、文化、ある場所、住民のくらし、ある人や会、まちの歴史、覚えておきたいできごと、特別な物語 |
| 形で | **紙**（文書、ポスター、写真、手紙、まちの学びの教材、会議の記録、発表文、声明、署名用紙）／**電子**（写真・動画・音声のファイル）／**音と映像** |
| そのほか | **古い木**、まちにある **アート作品** など、意味のあるものなら何でも |

**場所の記録と、場所でない記録**
- **場所の記録**（空間記録物）：古い地図、まちの景色の絵はがき、地形や建物の写真など、場所と結びついたもの。
- **場所でない記録**（非空間記録物）：その場所の歴史をふくむ人生の話（生活史）、インタビュー、動画、文書、研究資料。
- まちのアーカイブは、この **2つのつながり** をうまく見せられるのがよいところ。

**まちの記録の2つの特徴**
1. 作り手がいろいろで、まちごとにちがうので、記録の種類は **いくらでも広がる**。
2. 国や役所のように **決まった形（標準化）で管理する必要がなく、やり方が自由**。まちごとの個性が出るよう、**工夫した管理方法** が必要。

## 3. ふつうの記録管理とのちがい
| | ふつうの記録管理（役所など） | まちのアーカイブ |
|---|---|---|
| よりどころ | 法律や規則で **決められている** | 共同体の **共通の思い** にもとづく **自主的なもの** |
| いちばんの役目 | 説明する責任を果たす（説明責任） | **話し合いの道具、文化を楽しむ、共同体をとりもどす** |
| だれがする | 記録の管理者 | **住民の会**、つながりのやり方が大事 |
| 組織 | 記録館 | まちの会の中の一部 |
| 集め方 | 移してもらう（移管）が中心 | **集めること** と **わざわざ作ること** が大事 |
| 何を集める | 仕事や役目による | **まちの成り立ち** による |
| 管理 | 管理者や専門の組織 | 歴史・自然・共同体の文化・まちのつながり、**ボランティア** |
| サービス | 広くいろいろ | **展示・イベント** が中心 |

```quiz
Q: ふつうの記録管理とくらべた、まちのアーカイブの特徴として正しいのは？
1: 法律で決められているので、必ずしなければならない
2: いちばんの役目は、役所の説明責任を果たすこと
3: 共同体の共通の思いにもとづく自主的なもので、話し合いや共同体をとりもどす役目がある
4: 専門の記録館だけが管理する
C: 3
E: まちのアーカイブは自主的で、話し合いの道具・文化を楽しむ・共同体をとりもどす役目を持つ。ほかの選択肢：1、2、4は、ふつうの（役所などの）記録管理の特徴。
```

## 4. 実例
| 例 | ポイント |
|---|---|
| **洪城郡・洪東面のパルマル図書館** | まちの図書館が地域の集まりの場になり、いろいろなプログラムの中で記録が **作られ、集まる** 典型 |
| **まちの新聞**（マウル新聞） | 小さな日常を分け合って **仲間の気持ち** を育てる。記事だけでなく、取材メモ・写真・録音・動画まで記録になる。記録を作り集める **中心（ハブ）** になれる |
| **聞き取りの記録**（口述インタビュー） | 自分や家族、まわりの人の記録。青少年センターや主婦の文化教室などで集めた日常の話は、世代ごとの悩みや幸せを分け合い、**心をいやす場** になる |
| **416記憶貯蔵所** | フェイスブックなどの **SNS** でも記録を電子で保存し、広めている |

> 補足：「416記憶貯蔵所」は、2014年4月16日の旅客船セウォル号の事故を記録する場所。

## 5. 計画と作業
**① まちの成り立ちを知る**（アーカイブの基本）
| 分野 | 例 |
|---|---|
| 自然の空間 | 景色、山、川、動物、植物、こわれたところと直したところ |
| 人の空間 | 道、路地、建物、田畑、公共の施設、まちの神のほこら、遺跡 |
| 歴史 | まちのはじまり、人物、言い伝え、昔からいままで、まちの物語 |
| 共同体の会 | 村全体の会（大同契）、となり組（班会）、助け合いの会（トゥレ・プマシ）、青年会、婦人会、老人会 |
| 共同体の文化 | 季節の行事（小正月、端午、秋夕、冬至など）、まちの行事 |
| くらしと経済 | 農業、畜産、まちの店、特別な事業 |
| 小さな会 | 勉強部屋、読書会、芸術・運動・ボランティアの会 |
| 各家 | 家族の活動、家ごとの季節の習わしや文化 |
| つながり | 市場、役所の窓口、農協、姉妹のまち |

> 補足：トゥレとプマシは、田植えなどでおたがいに働き手を貸し合う、朝鮮の昔からの助け合いのしくみ。

**② 全体の計画**
- まず、**何のためのアーカイブか（目標）** と、**どの場所・どの時代まで入れるか（範囲）** を決める。目標で、集める資料や分け方が変わる。
- 時間と場所には限りがあるので、はじめに **参加できる人、お金の出どころ、技術の手伝い、最後の形** を話し合う。

**③ 集める**
- いちばんの目的は、価値ある記録を残して、**まちの人どうしで話し合い、分け合う** こと。宣伝・展示・本づくりにも使う。
| 集め方 | 中身 |
|---|---|
| 会が持っている記録 | 団体から集める |
| 人が持っている記録 | 個人から集める |
| **イベントで集める** | テーマ・人・できごとを決めて、みんなから集める。**コンテスト（公募展）** が多く、賞状・賞金・記念品を出すことも |

**④ 使う（アーカイブを広げるサービス）**
| 使い方 | 中身 |
|---|---|
| **展示** | 人が集まる場所で見せ、記録になじみのない人の **興味を引く**。記録を守る関心を高め、学びの価値を示すいちばんの方法 |
| **本・案内をつくる**（出版物の制作） | パンフレット、リーフレット、案内の冊子。いまはウェブサイトや動画でも |
| **学びのプログラム**（教育） | とても大事。目的を決め、参加者と求めを知り、プログラムを作り、結果をふり返る。**先生と生徒** 向けなど、相手で変える |

```quiz
Q: テーマ・人・できごとを決めて、コンテスト（公募展）などでみんなから記録を集める方法は？
1: 会が持っている記録を集める
2: 人が持っている記録を集める
3: イベントで集める
4: 移してもらう（移管）
C: 3
E: イベントで集める方法。参加者に賞状・賞金・記念品を出すこともある。ほかの選択肢：1は団体から、2は個人から集める方法。4は役所などのふつうの記録管理の集め方。
```

## 6. まとめと、続けるために
- いまのまちづくりがめざすのは、**場所の歴史と特徴をふまえ、人がまじり合って新しい価値を作るまち**。お金の論理で動いていた町を、くらし・活気・となり近所の関係がある **話し合いの場所** に作り直すこと。まちのアーカイブも、その一つ。
- アーカイブ作りは大変。**全体の計画 → 集める → 整理する → 形にする → 使って足し続ける** をくり返す。
- 考えておくこと：**お金と技術の支援**、**もとの資料を公開するか**、**著作権**。
- よりどころになる法律：公共記録物の管理に関する法律、建築基本法、文化財保護法など。法律の知識も必要。
- **自治体としっかり協力し、いろいろなつながりと結びつく** ことで、長く続けられる。

## まず、この3つ
1. まちのアーカイブは、まちの記録と、それを集めた場所。**住民が作り手で使い手**。かくれたふつうの人のくらしに光を当てる。
2. 役所の記録管理は「法律・説明責任・移管」、まちのアーカイブは「**自主・話し合いと共同体・集めて作る**」。
3. 進め方：**まちを知る → 全体の計画 → 集める（団体・個人・イベント）→ 使う（展示・本・学び）**。お金・公開・著作権・自治体との協力が課題。

## ひびきの暮らしでいうと
- このサイトの「人生タイムライン」や日記も、ひびきの小さなアーカイブ。**自分が作り手で、使い手**。
- 何のために残すか（目標）と、どこまで残すか（範囲）を先に決めると、記録が続けやすい。

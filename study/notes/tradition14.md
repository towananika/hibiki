# 伝統社会と生活文化 14講 ― お葬式と先祖の祭り

韓国の放送大学「伝統社会と生活文化」14講（対談の講義、約45分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名や数字は聞き取りなので、少しずれているかもしれない。

```flow
長男が家をつぐ決まり（宗法） → お葬式（喪葬礼）を3年かけて → 先祖の祭り（祭礼）を毎年 → 一族（門中）がまとまる → いまは小さく、形を変えて残る
```

## 0. ひとことで
人生の4つの儀式（冠婚喪祭）のうち、**喪（お葬式）と祭（先祖の祭り）** の回。
朝鮮王朝の学問（朱子学＝性理学）は、儀式を「個人の行事」ではなく、**父方の一族（門中）をまとめ、長男が家をつぐ社会をつくる道具** として使った。
いまは小さくなったけれど、一族の会（宗親会）は形を変えて残っている。

> 補足：冠婚喪祭（かんこんそうさい）は、大人になる儀式・結婚・葬式・先祖の祭りの4つ。13講は「生まれる・結婚」、14講は「葬式・祭り」。

## 1. 父方の一族と「長男がつぐ」決まり
- 結婚のあと、夫婦は **夫の家の近く** に住むようになった。すると **同じ名字の人ばかりの村（同族村）** ができ、地方に大きな一族が生まれた。
- 亡くなった人の立場（地位や財産）は、正妻の **長男（嫡長子）だけ** がつぐ。この決まりを **宗法**（そうほう）という。
  - 前は兄が死ぬと弟がつぐこともあった（朝鮮のはじめの王・定宗と太宗は兄弟）。
  - 長男1人にしぼると **不平等** だが、兄弟の争いがへり **安定** する。
- でも朝鮮では「妻の家・母の家」を大事にする習慣が強く、反発も大きかった。そこで **結婚式は妻の家で、そのあと夫の家で暮らす**（半親迎）という折衷案ができた。

## 2. 一族の長男の家（宗家）の役目
- 一族の本家を **宗家**、本家の長男を **宗孫**、その妻を **宗婦** という。
- 大事な仕事は **先祖の祭りとお客のもてなし（奉祭祀・接賓客）**。祭りは年に40〜60回。
- ある宗家では、1年に米300かますを食べたという。計算すると **1回の食事に40〜50人**。泊まりの客に服まで作ってあげた。
- 村の綱引きや祭りにお金を出し、困った家を助ける。宗家は **地域の政治と文化の中心** だった。
- 宗孫に息子がいないと、親せきから **養子** をむかえた。息子が先に亡くなれば **孫がつぐ**（承重）。

```quiz
Q: 亡くなった人の地位や財産を、正妻の長男だけがつぐ決まりを何という？
1: 宗法
2: 均分相続
3: 輪回奉祀
4: 兄亡弟及
C: 1
E: 宗法は「嫡長子（正妻の長男）がつぐ」決まり。不平等だが、兄弟の争いがへって安定する。
ほかの選択肢：2は子に同じだけ分ける相続で、宗法の前のやり方。3は子どもが順番に祭りをする前のやり方。4は兄から弟へつぐやり方で、宗法がやめさせたもの。
```

## 3. 朱子学式のお葬式（喪礼）の流れ
| 順番 | すること |
|---|---|
| 亡くなる | 家のいつもの部屋（正寝）で。家の外で亡くなるのは不吉とされた |
| たましいを呼ぶ（招魂・皐復） | 亡くなった人の服を持って屋根に上がり「戻れ」と3回呼ぶ |
| 体を整える（襲・小斂・大斂） | 体を洗い、服を着せ、布でつつんで棺に入れる |
| 場所と日を決める（治葬） | お墓の場所と日を決め、位牌（神主）を作る |
| 送り出す（発靷） | 輿（喪輿）にのせてお墓へ |
| うめたあと（虞祭） | 位牌を持ち帰り、たましいがさまよわないよう3回まつる |

**3年の喪（三年喪）**
```flow
亡くなる（1年目） → 満1年：小祥 → 満2年：大祥 → 27か月目：禫祭 → ふだんの暮らしへ（吉祭）
```
- 禫祭（たんさい）の「禫」は「心がおだやか」の意味。ここで肉も食べられるようになる。
- いまは、お墓にうめて終わり。土葬も **火葬** にかわってきた。

> 補足：ドイツの修道士（ヴェーバー神父）が1911年と1925年に朝鮮を訪れ、葬式を記録した。講義はその再現映像を使っていた。

```quiz
Q: 朝鮮の三年喪で、亡くなって27か月目に行い、肉を食べられるようになる祭りは？
1: 小祥
2: 大祥
3: 禫祭
4: 虞祭
C: 3
E: 禫祭（たんさい）。「心がおだやかになる」という意味で、ここから日常にもどっていく。
ほかの選択肢：1は満1年、2は満2年の祭り。4はうめたあと、たましいを落ち着かせる祭り。
```

## 4. 朝鮮らしいお葬式の習慣
- **骨を大切にする（洗骨）**：たましいの力は骨に宿ると考え、肉がくちたあと骨だけ集めてうめた。20世紀でも、西南の海岸では草でおおって置き（草墳）、あとで骨をうめた。
- **お葬式の夜に、にぎやかに遊ぶ**：王朝の記録に「葬式に芸人を呼んで遊ぶのはよくない」という批判が何度も出る。
- **珍島のダシレギ**：亡くなる人を楽しく送り出す、歌と踊りの劇。最後に **赤ちゃんが生まれる場面** があり、死の悲しみを新しい命の喜びにかえる。国の無形文化財。いまも珍島では、おくやみに行ったら歌を1曲歌うのが礼儀だという。
- **生きているうちの供養（生前預修斎）**：高麗の仏教のころからある。死んだあとではなく、生きているうちにお経を読み、紙のお金をささげる。いまは祭りのように大勢で行うことも。

```quiz
Q: 珍島に伝わる「ダシレギ」の説明として正しいのは？
1: お墓をつくる道具
2: 葬式の夜、歌や踊りで遺族をなぐさめ、死者を楽しく送る劇
3: 3年目の祭り
4: 家系図の本
C: 2
E: ダシレギは、死を悲しみだけにせず、赤ちゃんの誕生の場面で新しい命の喜びにかえる劇。
ほかの選択肢：1と4は関係がない（家系図は族譜）。3は大祥のこと。
```

## 5. 先祖の祭り（祭礼）の3つ
| 名前 | いつ | どこで・だれが |
|---|---|---|
| 命日の祭り（忌祭祀） | 亡くなった日に毎年 | 家で。**4代前（高祖父母）まで**。娘も参加 |
| お正月などの祭り（節祀） | 正月・寒食・端午・秋夕 | **お墓**で。墓の手入れもする |
| 一族の祭り（時祭・墓祭） | 主に陰暦10月 | 5代より前の先祖のお墓で。**男性だけ**。一族の力を見せる |

- 朱子の本（朱子家礼）では、ふつうの人は親の祭りまで。朝鮮ではむしろ広がり、**奴婢まで4代前まで** まつった（四代奉祀）。
- 朱子家礼にはお正月の祭りはない（季節ごとの祭りだけ）。朝鮮は **お墓をとても大事にした** ので、名節にお墓でまつるようになった。
- 前は、息子も娘も **順番に祭りをした（輪回奉祀）**。のちに **長男だけ** がするようになった。
- 一族の祭り（時祭）は、昔は何百人も集まった。朝鮮総督府の報告には「陰暦10月は、役所の仕事が止まるほど、えらい人たちが全国を回る」とある。

```quiz
Q: 主に陰暦10月、5代より前の先祖のお墓で、男性だけが集まって行う一族の祭りは？
1: 命日の祭り（忌祭祀）
2: 一族の祭り（時祭）
3: 生前預修斎
4: ダシレギ
C: 2
E: 時祭（墓祭）は男性だけの儀式で、一族（門中）の団結と力を外に見せる場だった。
ほかの選択肢：1は家で4代前までをまつり、娘も参加する。3は生きているうちの仏教の供養。4は葬式の夜の劇。
```

## 6. 一族の力を見せるもの：家系図と「ずっとまつる先祖」
**家系図（族譜）**
- 族譜は「この一族の一員だ」というしるし。避難のときも胸に抱いて逃げた。身分の証明にも使われた。
- 16世紀ごろまでは、父方も母方も、娘の夫の家も、えらい人は全部のせた（**内外譜**）。
- のちに **父方だけ** でまとまれるようになり、娘の側は夫までにしぼった。
- 19世紀には、ばらばらだった家どうしが「もとは同じ血すじ」とまとまり、大きな族譜（**大同譜**）が多く作られた。

**ずっとまつる先祖（不遷位）**
- ふつう、命日の祭りは4代前まで。それより古い先祖の位牌は、お墓にうめる。
- でも国が認めたえらい先祖は、位牌をうめずに **祠堂にずっとまつれる**。これが **不遷位**（ふせんい）。はじめは国に手柄のあった功臣だけ、のちに有名な学者も。
- 書院（私立の学問所）にまつられると、一族だけでなく **地域の学者みんな** が祭りに来る。地域の行事になる。

```quiz
Q: 国が認めたえらい先祖の位牌を、4代をこえても祠堂にずっとまつることを何という？
1: 不遷位
2: 大同譜
3: 内外譜
4: 承重
C: 1
E: 不遷位（ふせんい）。「位牌をうめずに永遠にまつる」意味で、一族の大きな誇りになった。
ほかの選択肢：2は一族をまとめた大きな族譜。3は父方も母方ものせた古い族譜。4は息子が先に亡くなったとき孫がつぐこと。
```

## 7. いまの一族（門中）
- 西洋の考え、**一人ひとりを大事にする考え（個人主義）**、**女性の地位の向上**、そして **身分制がなくなった** ことで、儀式は小さくなった。「むだなぜいたく（虚礼虚飾）」と言われることも。
- それでも、一族の会（**宗親会**）は今も続く。奨学金、会社への投資、療養病院の運営まで。国や社会の福祉のすきまをうめている。
- 中国でも、文化大革命でこわれた一族の会がもどってきている。

## ひびきの暮らしでいうと
- 宗家は、地域の人を食べさせ、困った人を助けて、信頼を集めた。**人に与える人のまわりに人が集まる** のは、いまも同じ。
- ダシレギのように、つらいことを「次の命」や「次の一歩」に変える考え方は、心を守る知恵になる。


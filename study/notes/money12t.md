# 貨幣金融論 12講【会話で読む】― 人はなぜお金を持つ？（2）

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money12)」。

## 1. お金を持つ3つの理由（ケインズ）（5分）

```talk
B: ケインズは、なぜ人がお金を持つと言ったの？
A: 3つの理由。1つめは買い物のため（取引的動機）。日々の支払いに使うお金。
B: 2つめは？
A: もしものため（予備的動機）。急な出費にそなえる、へそくりや非常金。
B: 3つめは？
A: もうけのチャンスを待つため（投機的動機）。よい投資先が来たら、すぐ動けるように持っておくお金。
B: それぞれ、何で決まる？
A: 1つめと2つめは稼ぎ（名目国民所得）。3つめは金利。
C: 稼ぎで決まる2つと、金利で決まる1つ。
```

```card
要点
- 取引的動機：買い物のため／稼ぎで決まる
- 予備的動機：もしものため／稼ぎで決まる
- 投機的動機：もうけを待つため／金利で決まる
```

> 補足：流動性は「すぐお金として使えること」。流動性選好は「すぐ使えるお金で持ちたい気持ち」。

## 2. 金利と債券の値段（5分）

```talk
B: 3つめの理由は、どうして金利で決まるの？
A: まず債券から。債券は借用書で、毎年決まった利息がもらえる。1,000ウォンの債券が毎年100ウォンをくれるなら、表面金利は10%。
B: 世の中の金利が20%に上がったら？
A: 1,000ウォンを預ければ200ウォンもらえる。100ウォンの債券は1,000ウォンでは買われない。値段は500ウォンに下がる。
B: 5%に下がったら？
A: 預けても50ウォンしかもらえない。債券はほしがられて、2,000ウォンに上がる。
C: 金利が上がると、債券の値段は下がる（シーソー）。
```

```eq
債券の値段 = 毎年の利息 ÷ 世の中の金利
```

```card
要点
- 金利が上がる → 債券の値段は下がる
- 金利が下がる → 債券の値段は上がる
- 例：利息100ウォン、金利20%なら500ウォン、5%なら2,000ウォン
```

## 3. 先の金利の予想（5分）

```talk
B: 人は、これからの金利をどう読んで動くの？
A: 金利が上がりそうなら、債券の値段は下がりそう。だから債券を売ってお金で持つ。もうけ待ちのお金は増える。
B: 下がりそうなら？
A: 債券の値段が上がりそうだから、お金で債券を買う。もうけ待ちのお金は減る。
B: 「ふつうの金利」って？
A: 人にはそれぞれ「だいたいこれくらい」という感覚がある（正常利子率）。いまの金利がふつうより高いと「そのうち下がる」と思って債券を買う。お金は減る。
B: だから結局？
A: いまの金利が高いほど、もうけ待ちのお金は減る。
C: 金利が高い → お金は減る。金利が低い → お金は増える。
```

```card
要点
- 金利が上がりそう → 債券を売る → もうけ待ちのお金は増える
- 金利が下がりそう → 債券を買う → もうけ待ちのお金は減る
- いまの金利が高いほど、もうけ待ちのお金は減る
```

## 4. ケインズの式とグラフ（10分）

```talk
B: 持ちたいお金は、どんな式になる？
A: 稼ぎで決まる分と、金利で決まる分の足し算。Md ＝ L₁(Y) ＋ L₂(i)。L₁は買い物ともしものため、L₂はもうけ待ち。
B: グラフにすると？
A: たて軸が金利、よこ軸が持ちたいお金。金利が下がるほど、持ちたいお金は増えるから、右下がり。
B: 金利がとても低いときは？
A: みんな「もう上がるしかない」と思って、債券を売って全部お金で持つ。線が横にねる。これが流動性のわな（流動性の罠）。
B: そのとき、中央銀行がお金を増やしたら？
A: 全部手元にたまるだけで、金利はもう下がらない。不景気が長く続くと、はまりやすい。
C: 金利がとても低い → 流動性のわな。
```

```card
要点
- Md ＝ L₁(Y) ＋ L₂(i)。稼ぎ Y と同じ向き、金利 i とは逆向き
- 貨幣需要曲線は右下がり
- 金利がとても低いと線が横にねる ＝ 流動性のわな（お金を増やしても金利は下がらない）
```

## 5. フリードマンの考え（10分）

```talk
B: フリードマンは、どう考えたの？
A: お金を、たくさんある財産の1つとして見た。財産には、お金・債券・株・物（家や車など）がある。
B: 持つお金は何で決まる？
A: 財産全体の大きさと、それぞれのもうけの見こみの差。特に、長い目で見た平均の稼ぎ（恒常所得）が大事。
B: 恒常所得って？
A: 1年ごとの上がり下がりをならした、長い目の平均の稼ぎ。ゆっくりしか動かない。
B: 結論は？
A: 持ちたいお金は、金利にあまり反応しない。恒常所得で決まるから安定していて、お金の回る速さも安定して予想できる。
C: ケインズは不安定、フリードマンは安定。
```

```card
要点
- お金は財産の1つ。債券・株・物ともくらべて選ぶ
- 持ちたいお金は、恒常所得（長い目の平均の稼ぎ）が多いほど増える
- 債券・株のもうけの見こみや、予想インフレ率が高いほど減る
- 金利にあまり反応しない → 安定、回る速さも安定
```

## 6. ケインズとフリードマンのくらべ（5分）

```talk
B: 2人をくらべると？
A: お金の代わりになる財産は、ケインズは債券だけ。フリードマンは債券・株・物。
B: 金利が変わると？
A: ケインズは大きく反応する（不安定）。フリードマンはあまり反応しない（安定）。
C: 回る速さも、ケインズは不安定、フリードマンは安定。
```

```card
要点
- ケインズ：財産は債券だけ／金利に大きく反応／回る速さは不安定
- フリードマン：財産は債券・株・物／金利にあまり反応／回る速さは安定
```

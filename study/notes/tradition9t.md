# 伝統社会と生活文化 9講【会話で読む】― 学校と役人試験

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition9)」。

## 1. 学校のしくみ（5分）

```talk
B: 朝鮮時代の学校は、どんな種類があった？
A: 4つ。村の塾（書堂）は小学校。私立の学問所（書院）は、高校〜大学の研究寄りで、地元の名家が作り、国が支援。都の学校（学堂）・地方の学校（郷校）は高校。都の最高学府（成均館）は大学で、国が作った。
B: 何を学ぶ？
A: 「文・史・哲」（文章・歴史・哲学）。中心は儒学の古典（四書五経）。
B: 学期や時間割は？
A: ない。来られるときに来て、泊まりこみで、自分のペースで先生に習う。
C: 朝鮮王朝は「儒学の国」。ゴールは役人になる国家試験。
```

```card
要点
- 書堂（村の塾）＝小学校／郷校・学堂＝高校／書院（私立）＝高校〜大学／成均館＝最高学府
- 学ぶ中身：文・史・哲。中心は儒学の古典（四書五経）
- 学期も時間割もなく、自分のペースで学ぶ
```

## 2. 家での勉強の流れと試験の種類（10分）

```talk
B: 勉強は、何歳から？
A: 6〜7歳で漢字の入門書（千字文）→ 子ども向けの道徳の本（小学）→ 古典（四書三経）。10代前半で基本の古典はほぼ読み終える。
B: 試験の種類は？
A: 文科は文の役人（いちばん格が高い）。武科は軍の役人。雑科は通訳・医者・天文・法律などの専門職。生員・進士試は役人ではなく資格で、最高学府に入れる。
B: 文科の試験は？
A: 3年ごとの定期試験（式年試）と、国にお祝いがあったときの臨時試験がある。
B: 勉強法は？
A: 何百冊も読む必要があるので、大事なところを選んで、何百回も読み返す。
C: 文科・武科・雑科・生員進士試。
```

```card
要点
- 6〜7歳：千字文 → 小学 → 四書三経。10代前半で基本の古典を読み終える
- 文科（文の役人、いちばん格が高い）／武科（軍）／雑科（専門職）／生員・進士試（資格）
- 文科：式年試（3年ごと）と臨時試験
- 勉強法：大事なところを何百回も読み返す
```

## 3. どれくらい難しい？（5分）

```talk
B: 合格は、どれくらい難しい？
A: 文科の合格者は、500年で約14,600人（1年に約30人）。生員・進士は、約47,000人（1年に約100人）。地方の資格試験の倍率は、1605年に約30倍、1872年に約300倍。
B: 平均年齢は？
A: 文科の合格は平均36.4歳（15世紀は約30歳、19世紀後半は39歳）。最高齢は90歳（お年寄り向けの特別試験・耆老科）。
B: 有名な李珥（栗谷）は？
A: 「9回トップ合格」と言われるが、文科のトップは29歳。昔は「40歳でやめる」が目安で、のちに「50歳まで」と言う人が増えた。
C: とても狭き門で、合格は36歳ごろ。
```

```card
要点
- 文科合格者：500年で約14,600人（1年に約30人）
- 生員・進士：500年で約47,000人（1年に約100人）
- 倍率：1605年 約30倍 → 1872年 約300倍
- 文科合格の平均年齢：36.4歳。最高齢は90歳（耆老科）
```

## 4. 合格したら、試験と学問（5分）

```talk
B: 合格したら、どうなる？
A: 発表は張り紙。こわくて自分では見に行かず、人に見に行かせることが多かった。合格証は、文科が赤い紙（紅牌）、資格試験が白い紙（白牌）。今も家宝として残る。王さまからお祝い、芸人を連れて都をパレード、先輩たちの新人歓迎。村じゅうのお祭りにもなった。
B: 試験の勉強と、本当の学びは？
A: 試験の勉強は効率重視で、深く考える時間がけずられる。学者たちは「試験は学問のじゃま」と考えた。弟子が「試験はやめて哲学だけやる」と言うと、大学者の李滉（退渓）はこまった。家のためにも、受けてもいい。
B: 答えは？
A: 「10時間のうち7時間は学問、3時間は試験勉強」。「受けてもいい。でも合否にこだわらない」。
C: 受けるけれど、結果にとらわれすぎない。
```

```card
要点
- 合格証：文科＝赤い紙（紅牌）／資格試験＝白い紙（白牌）
- 合格すると、王のお祝い、都のパレード、村のお祭り
- 試験の勉強は効率重視で、深く考える時間がけずられる
- 李滉（退渓）：受けてもいい。でも合否にこだわらない
```

# 貨幣金融論 15講 ― 物価決定モデル（物価は、どう決まる？）

韓国の放送大学「貨幣金融論」15講（スライド29枚）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

> 5〜10分で読む「[会話で読む版](view.html?n=money15t)」もあります。

> 14講のIS-LMモデルの続きです。IS-LMでは物価を一定と考えていました。15講は **物価も動く** ようにします。

```flow
物価の変化 → 総需要曲線（AD）→ 総供給曲線（AS）→ ADとASが交わる所で物価と国民所得が決まる → 景気がわるい・よすぎるときの調整と、政府の介入
```

## 0. ひとことで
- **物価決定モデル（AD-ASモデル）** は、**総需要曲線（AD）** と **総供給曲線（AS）** が交わる所で、**物価と国民所得** が決まるモデル。
- **AD曲線** は、14講のIS-LMから作る。物価が上がると、お金がほしい量がふえて、国民所得が **へる**（右下がり）。
- **AS曲線** は、会社の生産の決まり方から作る。**短期** は右上がり、**長期** は **完全雇用国民所得** で **垂直**。
- 景気がわるくても、よすぎても、長い目で見ると **賃金が動いて**、完全雇用国民所得に戻る（自律調整メカニズム）。ただし、そのあいだ待つか、政府が助けるかで、意見が分かれる。

## 1. 総需要曲線（AD曲線）― 物価と、国全体の買いたい量

**総需要曲線（AD曲線）** は、**物価** と、均衡状態で決まる **国民所得（国全体の買いたい量）** の関係を表す曲線。

- 国内の総需要は **消費C＋投資I＋政府支出G**。
- 総需要は、**IS曲線とLM曲線が交わる点** で決まる国民所得と同じ大きさ。

> 補足：国民所得（総生産）と総需要は、均衡では等しい。だから「総需要曲線」は、物価と国民所得の関係を表す曲線になる。

### ADはどうやって作る？（14講のIS-LMから）
物価が変わると、IS-LMの中で **LM曲線が動く**。その結果、均衡の国民所得が変わる。

```flow
物価↑ → お金がほしい量（貨幣需要）↑ → LM曲線が左（上）へ → 均衡国民所得↓
```

```flow
物価↓ → お金がほしい量（貨幣需要）↓ → LM曲線が右（下）へ → 均衡国民所得↑
```

- 物価と国民所得のペアを、物価の高さごとに点で打つと、**右下がりの線**（AD曲線）になる。

```quiz
Q: 物価が上がったとき、AD曲線を作る過程（IS-LM）で起きることは？
1: お金がほしい量がふえ、LM曲線が左（上）へ動いて、均衡国民所得がへる
2: お金がほしい量がへり、LM曲線が右（下）へ動いて、均衡国民所得がふえる
3: IS曲線が右へ動いて、均衡国民所得がふえる
4: 物価はIS-LMに影響せず、何も動かない
C: 1
E: 物価が上がると、同じ買い物でも必要なお金がふえるので、お金がほしい量（貨幣需要）がふえる。お金の市場が引き締まったのと同じなので、LM曲線は左（上）へ動き、均衡国民所得はへる。
ほかの選択肢：2は物価が下がったとき。3は財政政策の動き。4は、14講では物価を一定としていたので、物価が動けば影響が出る。
```

### ADの形（右下がり）
- 物価が **高い** → 国民所得が **少ない**。物価が **低い** → 国民所得が **多い**。だから **右下がり**。

### ADが動くとき（ADの移動）
- 物価が同じでも、**国民所得（総需要）が変わる** と、AD曲線そのものが動く。
- **IS曲線かLM曲線が動く** → 均衡国民所得が変わる → **AD曲線が動く**。
  - IS または LM が **右へ** → 国民所得↑ → AD が **右へ**。
  - IS または LM が **左へ** → 国民所得↓ → AD が **左へ**。

| | 何が変わる？ | AD曲線 |
|---|---|---|
| **拡大（膨張）的な財政・金融政策** | 独立の消費↑・投資↑・政府支出↑・税収↓・お金の量↑ | **右へ** |
| **緊縮（引き締め）的な財政・金融政策** | 独立の消費↓・投資↓・政府支出↓・税収↑・お金の量↓ | **左へ** |

> 補足：「独立の消費・投資」は、所得や金利に関係なく決まる分の消費と投資のこと。

```quiz
Q: AD曲線を右へ動かすものは？
1: お金の量（貨幣供給量）の減少
2: 独立の投資の減少
3: 政府支出の増加
4: 税収の増加
C: 3
E: 拡大的な政策（政府支出↑・減税・お金の量↑・独立の消費や投資↑）は、IS曲線やLM曲線を右へ動かし、AD曲線も右へ動かす。
ほかの選択肢：4は緊縮財政で、ADは左へ。1はお金の市場が引き締まるのでLMが左へ、ADも左へ。2は投資が減るのでISが左へ、ADも左へ。
```

## 2. 総供給曲線（AS曲線）― 物価と、会社が作る量

**総供給曲線（AS曲線）** は、**物価** と **総供給量（国全体で作る量）** の関係を表す曲線。

- 総供給量を決めるのは **会社（供給する側）**。
- カギは **生産要素の価格**。とくに **労働の価格＝賃金** がいつ調整されるか。

会社が生産量を決めるとき、賃金がすぐ変わるかどうかで、考える期間を2つに分ける。

| | 短期の見方 | 長期の見方 |
|---|---|---|
| 考える期間 | 賃金の調整が行われる **前** | 賃金の調整が **十分に** できる |
| 曲線 | **短期総供給曲線（SAS）** | **長期総供給曲線（LAS）** |

### 短期総供給曲線（SAS）― 右上がり
- **短期** とは、**物価が変わっても、生産要素の価格（賃金）は変われない** くらいの期間。
- 物価↑ → 売上（収入）↑、費用は変わらない → **利益↑** → 生産量↑。
- 物価↓ → 売上（収入）↓、費用は変わらない → **利益↓** → 生産量↓。
- だから **右上がり**。

```flow
物価↑ → 収入↑（費用は同じ）→ 利益↑ → 生産量↑（SASは右上がり）
```

### 短期の均衡
- **短期均衡** は、短期に **ADとSASが一致** する状態（交わる点）。そこで、物価と国民所得が決まる。

```quiz
Q: 短期総供給曲線（SAS）が右上がりになる理由として、正しいものは？
1: 政府が物価に合わせて税金を下げるから
2: 短期は賃金が変わらないので、物価が上がると利益がふえ、生産量がふえるから
3: 短期は賃金がすぐに上がるので、物価が上がっても利益は変わらないから
4: 物価が上がると、人々がお金をたくさん持ちたくなるから
C: 2
E: 短期は賃金などの費用が変えられない。物価が上がって収入がふえても、費用は同じなので利益がふえ、会社は生産をふやす。
ほかの選択肢：3は長期の考え方に近い。4は貨幣需要の話で、AS曲線の理由ではない。1は関係がない。
```

### 長期総供給曲線（LAS）― 垂直
- 物価が上がると、会社はまず生産をふやす（短期）。生産がふえると **労働の需要がふえる**。
- 労働の需要が変わると、**長期には賃金が変わり**、会社の費用に影響する。

**賃金は労働市場で決まる。** ここで使う言葉：
- **自然失業率**：完全雇用のときの失業率（失業がゼロという意味ではない）。
- 労働の需要↑ → 失業率 **<** 自然失業率 → **賃金上昇**。
- 労働の需要↓ → 失業率 **>** 自然失業率 → **賃金下落**。

> 補足：自然失業率は、仕事の入れ替わりなどで、ふつうの状態でも残る失業の割合。

- 長い目で見ると、国民所得は **自然失業率のもとでの国民所得（完全雇用国民所得）** に近づく。
- だから **長期総供給曲線（LAS）** は、**完全雇用国民所得のところで垂直**。物価がいくら変わっても、長期の生産量は変わらない。

```quiz
Q: 長期総供給曲線（LAS）についての説明で、正しくないものは？
1: 完全雇用国民所得の水準で垂直になる
2: 長期には賃金が十分に調整される
3: 長期の国民所得は、自然失業率のもとでの水準に近づく
4: 物価が上がるほど、長期の生産量はふえ続ける
C: 4
E: LASは垂直。長期には賃金が調整されるので、物価が変わっても生産量は完全雇用国民所得のまま変わらない。
ほかの選択肢：1・2・3は正しい。
```

## 3. 景気がわるい・よすぎるとき ― 長期にはどう戻る？

短期均衡の国民所得が、完全雇用国民所得とちがうとき、労働市場を通じて **SAS曲線が動き**、最後は完全雇用国民所得に戻る。

### 不況（景気がわるい）のとき
- **短期均衡の国民所得 ＜ 完全雇用国民所得**。
- 労働の需要が少ないので、労働市場は **超過供給**（働きたい人が多すぎる）。
- → **賃金下落** → 会社の費用が下がる → **SAS曲線が右へ** 動く。
- 超過供給がある **かぎり** 右へ動き続ける。**完全雇用国民所得** に着いたら、そこで止まる。
- そのとき、**物価は下がる**。

```flow
不況（国民所得が少ない）→ 労働の超過供給 → 賃金↓ → SASが右へ → 物価↓・国民所得↑ → 完全雇用国民所得で止まる
```

### 景気過熱のとき
- **短期均衡の国民所得 ＞ 完全雇用国民所得**。
- 労働の供給が少ないので、労働市場は **超過需要**（働き手がほしすぎる）。
- → **賃金上昇** → 会社の費用が上がる → **SAS曲線が左へ** 動く。
- 超過需要がある **かぎり** 左へ動き続け、完全雇用国民所得に着いたら止まる。
- そのとき、**物価は上がる**。

```flow
過熱（国民所得が多すぎ）→ 労働の超過需要 → 賃金↑ → SASが左へ → 物価↑・国民所得↓ → 完全雇用国民所得で止まる
```

| | 不況 | 過熱 |
|---|---|---|
| 短期均衡の国民所得 | 完全雇用より **少ない** | 完全雇用より **多い** |
| 労働市場 | 超過供給 | 超過需要 |
| 賃金 | 下落 | 上昇 |
| SAS曲線 | **右へ** | **左へ** |
| 物価 | 下がる | 上がる |
| 終点 | 完全雇用国民所得（そこで止まる） | |

```quiz
Q: 不況のとき（短期均衡の国民所得が完全雇用国民所得より少ない）、長期の調整として正しいものは？
1: AD曲線が自動的に右へ動く
2: LAS曲線が左へ動く
3: 労働市場が超過供給になって賃金が下がり、SAS曲線が右へ動く
4: 労働市場が超過需要になって賃金が上がり、SAS曲線が左へ動く
C: 3
E: 不況では労働の需要が少なく、働きたい人が余る（超過供給）。賃金が下がって会社の費用が下がるので、SASは右へ動き、完全雇用国民所得に着くまで続く。
ほかの選択肢：4は過熱のとき。1・2は、この調整で動くのはSASであり、ADやLASは動かない。
```

```quiz
Q: 景気過熱のとき、調整が終わったあとの物価と国民所得は？
1: 物価は上がり、国民所得は完全雇用国民所得に戻る
2: 物価は下がり、国民所得は完全雇用国民所得に戻る
3: 物価は上がり、国民所得はふえ続ける
4: 物価も国民所得も変わらない
C: 1
E: 過熱では賃金が上がってSASが左へ動く。物価は上がり、国民所得は減って、完全雇用国民所得に戻って止まる。
ほかの選択肢：2は不況のときの物価の動き。3は、国民所得は完全雇用の水準で止まる。4は、物価は動く。
```

## 4. 自律調整メカニズム ― 待つ？ 助ける？

**自律調整メカニズム（self-correcting mechanism）** は、短期的に景気がわるくなったり、過熱したりしても、**市場の自律的な調整** によって、**長期には完全雇用国民所得が達成される** こと。

- ただし、この調整を **待つべきか、政府が助けるべきか** で、学派の意見が分かれる。

| | 通貨主義学派 | ケインズ学派 |
|---|---|---|
| 主張 | 政府が財政政策や金融政策で **積極的に介入しない** で、市場の自律的な調整を **待つ** ほうがよい | 長期には解決しても、それまでの経済問題を放っておけないので、**積極的に介入** すべき |
| 根拠 | 賃金は比較的 **伸縮的**（動きやすい）。超過需要や超過供給が出れば、すぐに賃金が動き、SASが動く | 賃金は **下方硬直性**（なかなか下がらない）がある。失業（超過供給）が出ても、すぐには賃金が下がらない |

> 補足：下方硬直性は、「下がりにくい」という性質。働く人が賃金の引き下げをいやがったり、契約で賃金が決まっていたりするため。

```quiz
Q: ケインズ学派が、不況のときに政府が積極的に介入すべきだと考える根拠は？
1: 賃金がとても伸縮的で、すぐに調整されるから
2: 長期総供給曲線が右上がりだから
3: 物価が下がると国民所得が必ず減るから
4: 賃金に下方硬直性があり、失業が出てもすぐには賃金が下がらないから
C: 4
E: ケインズ学派は、賃金が下がりにくい（下方硬直性）ので、自律調整に時間がかかり、そのあいだ失業などの問題が続くと考える。だから政府が介入する。
ほかの選択肢：1は通貨主義学派の根拠。2は長期総供給曲線は垂直なので誤り。3は、そのような考えではない。
```

### 政府が介入すると ― 不況のとき
- 不況（点A：ADとSASの交点、国民所得が完全雇用より少ない）から、2つの道がある。
  - **待つ（介入しない）**：SASが右へ動いて、**点C**（完全雇用国民所得）。物価は **低い**。ただし、時間がかかる。
  - **介入する**：拡大的な財政・金融政策で **ADを右へ** 動かして、**点B**（完全雇用国民所得）。物価は **高め**。早く戻れる。

### 政府が介入すると ― 過熱のとき
- 過熱（点A：国民所得が完全雇用より多い）から、
  - **待つ**：SASが左へ動いて、完全雇用国民所得に戻る。物価は **上がる**。
  - **介入する**：緊縮的な政策で **ADを左へ** 動かして、完全雇用国民所得に戻す。物価は **上がらずにすむ**（待つ場合より低い）。

| | 待つ（自律調整） | 介入する（ADを動かす） |
|---|---|---|
| **不況のとき** | SASが右へ。物価は低い。時間がかかる | ADが右へ。物価は高め。早く戻れる |
| **過熱のとき** | SASが左へ。物価は **上がる** | ADが左へ。物価は上がらずにすむ |

```quiz
Q: 不況のとき、政府が拡大的な政策でADを右へ動かした場合と、介入せずに自律調整を待った場合を比べると？
1: 介入すると、完全雇用国民所得には戻れない
2: 介入すると、早く完全雇用国民所得に戻れるが、物価は高めになる
3: 介入すると、時間がかかるが、物価は低くなる
4: 介入しても待っても、物価も戻る速さも同じ
C: 2
E: 待つと、SASが右へ動いて物価は低くなるが、時間がかかる。介入すると、ADが右へ動いて早く戻れるが、物価は待つ場合より高めになる。
ほかの選択肢：3は逆。4は、同じではない。1は、ADを動かして完全雇用国民所得に戻すことはできる。
```

## まず、この3つ
1. **AD曲線**は右下がり（物価↑ → LM左 → 国民所得↓）。IS・LMが右へ動けば、ADも右へ動く。
2. **AS曲線**は、**短期は右上がり**（賃金が変わらないので物価↑で利益↑）、**長期は完全雇用国民所得で垂直**。
3. 不況なら賃金↓でSASが右へ、過熱なら賃金↑でSASが左へ。最後は完全雇用国民所得に戻る（**自律調整**）。待つのが通貨主義学派、介入するのがケインズ学派。

## ひびきの暮らしでいうと
- 景気がわるいと、お店は物を安くしても売れず、働く人の給料も上がりにくい。しばらくして物価が下がり、また元気になっていくのが、自律調整のイメージ。
- 政府が景気をよくしようとお金を使うと、早く元気になる代わりに、物の値段が高めになることがある。

```quiz
E: 過熱では労働の供給が少なく、超過需要になる。賃金は上がり、SASは左へ動く。超過供給で賃金が下がるのは不況のとき。
ほかの選択肢：2・3・4は正しい。
```

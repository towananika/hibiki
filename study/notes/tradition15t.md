# 伝統社会と生活文化 15講【会話で読む】― 村の祭りと家の神さま

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition15)」。

## 1. 村と国の祭り（10分）

```talk
B: 昔の村ってどんなところ？
A: 3つの顔。国から見た一番小さい単位（税を集める）、血のつながる人の集まり、いっしょに働く仲間（生産共同体）。一生その村から出ない人も多く、村が世界のすべてだった。
B: だから？
A: 村の安全と豊作を祈る祭り（洞祭）をした。願いはいつも、家族が無事（安寧）で豊か（豊饒）なこと。
B: お手本は？
A: 国の祭り（三壇一廟）。学校の廟で孔子、社稷壇で土地と穀物の神、厲壇でうらみを残した死者、城隍壇で土地の山の神をまつった。
C: 国の祭りが、村の祭りのお手本。
```

```card
要点
- 村＝税の単位／血縁共同体／生産共同体。村が世界のすべて
- 洞祭：村の安全と豊作を祈る。願いは安寧と豊饒
- 三壇一廟：文廟（孔子）・社稷壇・厲壇・城隍壇
```

## 2. 村の祭りの2つの形（10分）

```talk
B: 村の祭りの形は？
A: 2つ。祭りの形（祭祀）は、村の男性代表（祭官）が儒教式で、祝文を読みお酒を3回ささげる。巫女の儀式の形（クッ）は、楽器隊（風物）や巫堂が歌・踊り・楽器で神をよぶ。お金がかかるので3年に1回ほど。
B: 順番は？
A: ふつうはまず代表が祭りの形で祈り、そのあと巫女が儀式をする。いちばん多い名前は別神クッ。「別に、特別にする祭り」の意味。
B: 例は？
A: ソウル弘智洞の山神祭は、豚の頭をそなえ、紙に願いを書いて燃やす（焼紙）。京畿道旺南洞の堂祭は、元気な人を堂主に選び、牛の頭をそなえる。龍仁の村は、家ごとに同じ額を出し、陳設図が残る。いまは自分たちらしさを確かめ合う場。
C: 祭祀と、クッ。
```

```card
要点
- 祭祀（儒教式・男性代表・祝文）／クッ（巫堂・風物・歌と踊り）
- 別神クッ：特別にする祭り。クッは3年に1回ほど
- 例：弘智洞（豚の頭）／旺南洞（牛の頭、堂主）／龍仁（陳設図）
```

## 3. 家の神さま（10分）

```talk
B: 家の中にも神さまが？
A: 場所ごとに役目のちがう神さま（職能神）がいる。成造は家そのもの・一家の主。梁を上げた日が誕生日で、紙を折って梁にむすぶ。土主は家の土地。竈王は台所と火で、のちに家族全体を守る。
B: ほかには？
A: 三神おばあさんは子ども。7日ごとに3回（21日まで）まつる。業（オプ）は財産で、ヒキガエルやヘビの姿。霊登は風と雨。陰暦2月1日に天から下り、15日に帰る。嫁と来ると雨、娘と来ると風。
B: 家長が変わったら？
A: 成造も新しくする（成造と家長は1つ）。まつる時期は、お正月（小正月の15日まで）と秋（陰暦10月）。
C: 願いは安寧と豊饒。
```

```card
要点
- 成造（家・主）／土主（土地）／竈王（台所・火）
- 三神おばあさん（子ども）／業（財産）／霊登（風と雨）
- 家長が変わると成造も新しくする
- まつる時期：お正月と秋（陰暦10月）
```

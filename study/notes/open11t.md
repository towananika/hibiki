# 開かれた社会と21世紀 11講【会話で読む】― まちと人をつなぐ（組織化）

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=open11)」。

## 1. 組織化ってなに？（5分）

```talk
B: 組織と組織化は、どうちがう？
A: 組織は、人が集まって役わりを持つ会（自治会、商店会、協同組合など）。組織化は、同じ困りごとや目標を見つけて、協力して動けるようにしていく流れ。
B: おしゃべりや人数集めは？
A: それだけでは組織化ではない。住民が自分で参加し、自分たちで決め（自治）、意見のちがいを話し合い、別の案（代案）を考えるところまで入る。
C: 会を作ることでなく、関係を育てること。
```

```card
要点
- 組織：役わりを持つ会／組織化：協力して動けるようにする流れ
- 新しい会を作る前に、いまある会と決め方を調べる
```

## 2. 4つのはたらき（10分）

```talk
B: 組織化のはたらきは？
A: 4つ。参加をうながす（参加の促進）、学ぶ（学習）、人や物をつなぐ（資源のネットワーク化）、自分たちで決める力がつく（能力と影響力の向上）。
B: つながりは？
A: ぐるぐる回って、おたがいを強くする。困ったときに助け合える関係を、社会関係資本という。
C: 参加・学び・つなぐ・決める力。
```

```card
要点
- 参加の促進／学習／資源のネットワーク化／能力と影響力の向上
- 4つはぐるぐる回って、おたがいを強くする
- 社会関係資本：困ったときに助け合える関係
```

## 3. だれが何をする？（5分）

```talk
B: 役わりは？
A: 住民が主役。まちのリーダーは、えらい人ではなく住民の一人として、意見を聞き、会議をまわし、もめごとをまとめる。手伝う人（専門家・支援団体）は、住民が自分たちで動けるように手伝う。
B: 手伝う人にたよると？
A: たよりすぎると、まちの力が育たない。ただ、中にリーダーがいないときは、外から迎えることもある。
C: 代わりに決め続けない。
```

```card
要点
- 住民＝主役／リーダー＝住民の一人／手伝う人＝自分で動けるよう支える
- たよりすぎるとまちの力が育たない
```

## 4. 進め方と3つのやり方（10分）

```talk
B: アリンスキーは何を大事にした？
A: アメリカの住民運動家。ちゃんと話が通じ合うことと、ありのままの現実から始めること。理想をあきらめるのではなく、いまを知って変え方が見える。
B: 進め方は？
A: 調べる・準備（調査・準備）→ 計画（組織化・計画）→ 実行 → ふり返り（評価・再組織化）。結果だけでなく進め方もふり返る。
B: やり方は？
A: 3つ。困りごと中心（課題中心）は目の前の問題。分野ごとの事業（社会経済プロジェクト）は教育・医療・文化など。まち全体を育てる（統合的地域社会開発）は長く続くまちに。
C: どのまちにも使える手順書はない。
```

```card
要点
- アリンスキー：話が通じ合うこと／現実から始める
- 調査・準備 → 計画 → 実行 → 評価・再組織化
- 課題中心／社会経済プロジェクト／統合的地域社会開発
- 会の形も場所も、まちに合わせる
```

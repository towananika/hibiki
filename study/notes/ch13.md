# デジタル経済 13講 ― デジタル経済の利益：無料の便利さを、どう測る？

**払う金額がゼロでも、役に立つ価値がゼロとは限りません。** 地図や検索の便利さから、GDPの読み方と競争の問題へ進みます。

添付の講義ノートをもとにした教材です。日常の例や図は、理解を助ける補足です。

## 1. 生産の大きさと、暮らしの満足は別

**GDP** は、一定期間に国内で生み出した付加価値などから、生産の大きさを測る指標です。幸福や便利さを、そのまま全部足した数字ではありません。

無料の地図が道探しの時間を減らしても、その便利さ全体が購入額として現れるわけではありません。一方、サービスを作る会社や広告などの経済活動は、国民経済計算と無関係ではありません。

```flow
無料の地図 → 探す時間や迷う負担が減る → 便益全体をGDPだけでは測れない
```

> 補足：講義の「無料サービスの価値を測りにくい」という点と、「関連する生産がGDPに一切入らない」という主張は区別します。

```quiz
Q: 無料の地図の便利さとGDPの関係は？
1: 価格ゼロなら経済的な価値もゼロ
2: 関連する広告や会社の活動もすべて統計と無関係
3: GDPだけでは利用者の便益全体を測れない
4: GDPは幸福を完全に測っている
C: 3
E: GDPは生産の指標です。無料サービスの利用者が得る価値や、生活の質とは、測る対象が違います。
```

## 2. 同じ金額でも、性能は変わる

昔と同じ価格のパソコンでも、今は多くのことができる場合があります。品質向上を十分に考慮しないと、「物価がどれだけ変わったか」「実際の生産がどれだけ増えたか」を見誤ります。

共有サービス、国境をまたぐプラットフォーム、クラウド、データなども、分類や測定を難しくします。

講義では、デジタルの取引方法や産業を分けて見る表や、既存の統計を補う指標も扱います。数字が不完全だから無意味なのではなく、**何を測れて、何を測りにくいか**を確かめます。

```quiz
Q: 新しい機器の品質向上を十分に考慮しないと、何が難しくなる？
1: 機器の色を見分けることだけ
2: 人口を数えることだけ
3: GDPの数字を一切計算できなくなる
4: 実際の生産や物価の変化を正しく比べること
C: 4
E: 価格の比較では、同じ性能の物を比べているかが大切です。品質の変化は、実質の成長の測定に影響します。
```

## 3. 便利な道具があるのに、生産性が伸びない？

同じ時間で生み出せる量や付加価値が **労働生産性** です。

```eq
労働生産性 = 生み出した量や付加価値 ÷ 働いた時間など
```

技術が進んでも、統計の生産性の伸びが小さいことがあります（生産性の謎）。測定の問題だけが理由とは限りません。投資の不足、競争、技術の広がり方、仕事の組み直しなど、複数の説明があります。

```flow
道具を入れる → 仕事の流れや教育を整える → 効果が出るまで時間がかかることもある
```

AIを入れたという事実と、仕事が改善したという結果を分けて見る考えにもつながります。

```quiz
Q: 新技術の導入直後に、生産性の数字が必ず大きく上がる？
1: 組織や技能の変更、測定などの問題があり、必ずではない
2: 必ず上がる
3: 上がらなければ技術は永久に無価値
4: 導入した台数だけで生産性が決まる
C: 1
E: 道具を活用する補完的な投資や、効果が広がる時間が必要な場合があります。原因を1つに決めつけず検討します。
```

## 4. 利用者の「得」を、別に考える

あるサービスに月1,000円まで払ってもよいと思い、実際には300円払ったとします。差の700円が、その人の **消費者余剰** です。説明のための仮の数字です。

```eq
消費者余剰700円 = 払ってもよい1,000円 − 実際の支払い300円
```

価格がゼロでも、利用の価値があるなら余剰はありえます。ただし、支払ってもよい額は、実際に口座へ入る収入ではありません。

社会全体を見るときには、作る側の利益や、ほかの人への負担なども考えます。

```quiz
Q: 1,000円まで払ってよいサービスを300円で使えたら、消費者余剰は？
1: 1,300円
2: 700円
3: 300円
4: 現金収入が1,000円増える
C: 2
E: 支払ってもよい額と、実際の支払いの差です。計算上の便益で、現金を受け取ることとは違います。
```

## 5. 「使えなくなるなら、いくら必要？」と聞く

無料サービスを使えない期間に、どれだけの補償が必要かを聞く方法があります（受取補償額・WTA）。実際の利用停止と報酬を組み合わせた実験も、講義で紹介されています。

| 方法 | 気をつけること |
|---|---|
| 減った時間を換算する | 時間にどんな価値を置くか |
| 使えない場合の補償を聞く | 大きく答える動機や、質問の条件 |
| サービス間を比較する | 代替手段や、人・国による違い |

GDP-Bなどは、こうした便益を見てGDPを補う試みです。「GDPに無料の価値を足せば、幸福の正解が出る」という単純な式ではありません。

```quiz
Q: 利用停止への補償額を聞けば、誰にとっても正確な価値が1つに決まる？
1: 必ず1つに決まる
2: どの国でも同じ額になる
3: 質問の条件や代替手段などで結果が変わりうる
4: 高く答えれば実際の収入が必ず増える
C: 3
E: 価値を測る工夫ですが、質問への反応や、使えない期間、代わりの手段などに注意が必要です。
```

## 6. 便利な大企業なら、競争の問題はない？

利用者・データ・関連サービスが集まると、大きい企業がさらに有利になりえます。便利になる面と、新しい企業が入りにくくなる面の両方があります。

```flow
利用者が集まる → データや関連サービスが充実 → 利用が増え、参入の壁にもなりうる
```

講義では、マイクロソフトのOSとブラウザーの組合せをめぐる競争問題も扱います。組合せによる便利さと、競争相手を不当に排除する行為は、別に検討します。

**会社が大きいことだけで、直ちに違法と決めるわけではありません。** 新しい参入、乗換え、革新、利用者への影響を具体的に見ます。

```quiz
Q: デジタル市場の競争で、調べるべきなのは？
1: 会社の名前だけ
2: サービスの価格が無料かどうかだけ
3: 便利なら将来の競争は一切考えない
4: 参入や選択を妨げる行為と、利用者への影響
C: 4
E: 市場の大きさや料金だけでは判断できません。無料でも品質・情報・選択への影響がありえます。
```

## 7. 持ち帰る考え

便利な道具を評価するときは、**生産の数字・利用者の得・競争への影響**を分けられます。無料や大規模という言葉だけで、価値や問題を決めないことが大切です。

# 世界の宗教 9講 ― 命を守る・分かち合う・人を結ぶ

**どう生きればよいのか。その答えは、宗教によってどう違う？**

第8講は仏教でした。今回は、ジャイナ教・シク教・バハイ信仰の3つを比べます。まずは「何を大切にするか」からつかみ、名前はあとから結びつけましょう。

添付の配布資料は見出し中心です。以下の説明は、見出しを理解するための背景補足も含みます。講義音声の文字起こしではありません。

## 1. 最初は、この3つだけ

| 宗教 | まずつかむ中心 |
|---|---|
| ジャイナ教 | 命を傷つけず、欲や執着を減らす |
| シク教 | 神を思い、誠実に働き、人と分かち合う |
| バハイ信仰 | 宗教や人々の違いを越え、一体性を重んじる |

これは、入口となる見取り図です。3つがまったく同じ教えだという意味でも、どれかが優れているという順位でもありません。

たとえば「誰かを助けたい」という行動にも、命を傷つけない、分かち合う、人の隔たりを越える、と違う意味づけができます。

```quiz
Q: 今回の3つを区別する組み合わせとして、適切なのは？
1: ジャイナ教＝所有を増やす、シク教＝働くことを避ける、バハイ＝宗教の対立を広める
2: ジャイナ教＝非暴力、シク教＝祈りと労働と分かち合い、バハイ＝宗教や人類の一体性
3: ジャイナ教＝祈りの回数だけ、シク教＝無所有だけ、バハイ＝白い衣だけ
4: 3つは名前が違うだけで、教えも実践もすべて同じ
C: 2
E: まず中心となる考えを区別します。3つとも、教えと日々の行動のつながりを見て学びます。
```

## 2. 仏教と違う、苦行への見方

資料は、**釈迦が離れた厳しい苦行を、マハーヴィーラは重視した**という対比から始まります。マハーヴィーラは、ジャイナ教の重要な教え手です。

苦行とは、欲望や身体の快楽を厳しく抑える修行のこと。仏教にも修行はありますが、厳しい苦行そのものの位置づけが同じではありません。

ジャイナ教の世界観には、**ジーヴァ**と**アジーヴァ**という区別があります。

| 用語 | 入口となる説明 |
|---|---|
| ジーヴァ | 魂、生命の原理 |
| アジーヴァ | 物質など、魂ではない非生命的な要素 |

背景として、行いに関わる**業（ごう）**が魂を縛り、輪廻につながると考えます。欲や執着を減らし、そこから解放されることを目指します。輪廻とは、生まれては死ぬことを繰り返すという考えです。

```flow
欲や執着を減らす → 行動を厳しく律する → 魂の解放を目指す
```

> 第8講の「私を5つの働きに分けて見る」という説明と、今回の「魂」を、そのまま同じものとして覚えないようにします。

```quiz
Q: 仏教とジャイナ教の違いについて、資料が最初に示す対比は？
1: 釈迦は厳しい苦行から離れ、マハーヴィーラはそれを重視した
2: どちらにも修行という考えがない
3: ジャイナ教には魂という考えがない
4: 仏教とジャイナ教では、苦行の位置づけが必ず同じ
C: 1
E: 資料2〜3ページの対比です。仏教が修行を一切否定した、という意味ではありません。
```

## 3. ジャイナ教の5つの誓い

「欲を減らす」を、具体的な行動にしたものとして、次の5つを押さえます。

| 誓い | 名前 | やさしく言うと |
|---|---|---|
| 不殺生・非暴力 | アヒンサー | 生き物を傷つけない |
| 無所有・不執着 | アパリグラハ | 持ち物や所有へのこだわりを減らす |
| 不妄語 | サティヤ | うそをつかない |
| 不盗 | アステーヤ | 与えられていないものを取らない |
| 不淫・禁欲 | ブラフマチャリヤ | 性に関する欲や行動を慎む |

たとえば「もっと欲しい」と思ったとき、必要かどうかを考えるのは、無所有・不執着を身近に考える入口です。ただし、教え全体を「買い物を減らすだけ」に置き換えるものではありません。

出家して修行に専念する人と、家庭や仕事を持つ在家の信徒では、実践の厳しさが異なります。禁欲も、全員がまったく同じ暮らしをするという意味ではありません。

```quiz
Q: 「持ち物を増やすことや、所有することにとらわれすぎない」に対応するのは？
1: サティヤ（不妄語）
2: アステーヤ（不盗）
3: ブラフマチャリヤ（禁欲）
4: アパリグラハ（無所有・不執着）
C: 4
E: アパリグラハは、所有や執着に関わる誓いです。サティヤはうそをつかない、アステーヤは盗まない、ブラフマチャリヤは禁欲です。
```

## 4. 空衣派と白衣派：同じ宗教の中にも違いがある

資料には、ジャイナ教の2つの宗派が出てきます。

| 宗派 | 名前と結びつけて覚える特徴 |
|---|---|
| 空衣派（くうえは） | 「空間を衣とする」。一部の男性出家修行者が衣服も持たない修行を行う |
| 白衣派（びゃくえは） | 白い衣を着る出家修行者で知られる |

両者とも、非暴力や執着を減らす実践を重んじます。衣服の違いは覚える手がかりですが、宗派の違いがそれだけというわけではありません。

**信徒全員が衣服を持たない、という説明は誤りです。** 宗派と、出家者・在家信徒の違いを分けて考えましょう。

```quiz
Q: 「空衣派」と聞いたとき、気をつけたいのは？
1: 白衣派はジャイナ教とは無関係だと考えること
2: どちらの宗派にも共通する教えがないと考えること
3: 一部の出家者の修行を、信徒全員の暮らしに当てはめないこと
4: 衣服の色だけが宗派のあらゆる違いだと決めること
C: 3
E: 空衣派の一部の男性出家者の実践と、すべての信徒の生活は同じではありません。
```

## 5. シク教の祈り・仕事・助け合い

シク教は、唯一の神への信仰を大切にします。資料が挙げる3つの実践は、次の通りです。

```eq
神を思い、歌い、瞑想する + 誠実に働く + 人と分かち合う
```

たとえば、祈る時間だけで信仰が終わるのではなく、仕事に誠実に取り組み、得たものを人のためにも使う。**日々の生活の中で実践する**ことが、大きな手がかりです。

資料の「悪習の撤廃」は、社会の慣行を問い直すという観点です。背景として、シク教は出生による身分差にとらわれず、人を等しく見る理想を重んじます。「苦難の歴史」も、学習する見出しとして挙げられています。

### 「ブレンド」という説明を、どう読む？

資料はシク教を「巧みなブレンド」と表現します。異なる宗教文化との関わりを見るための表現ですが、**他の宗教を足しただけではなく、独自の伝統を持つ宗教**として理解します。

```quiz
Q: シク教の3つの実践に合う暮らし方は？
1: 神を思うことを、誠実な仕事や分かち合いにもつなげる
2: 祈る人は、働いたり人を助けたりしてはいけない
3: 仕事で得たものは、どんな場合も他人と分けない
4: 身分の低い人には、宗教的な価値がないと考える
C: 1
E: 資料15ページは、神に仕え歌い瞑想すること、働くこと、分かち合うことの3つを示します。
```

## 6. バハイ信仰と宗教の一体性

バハイ信仰で大切なのは、**神の一体性、宗教の一体性、人類の一体性**という見方です。

違う時代や場所に現れた宗教を、互いに無関係なものではなく、同じ神による導きの流れとして理解します。これは、バハイ信仰の立場からの見方です。

```flow
異なる時代や場所の教え → 同じ神からの導きと理解する → 宗教や人類の一体性を重んじる
```

中心人物は**バハーウッラー**です。資料は、弥勒仏・メシア・クリシュナの化身・再臨のイエスという期待を、バハーウッラーに結びつける図で示しています。

これは、信徒による位置づけとして学びます。**他の宗教の信徒も全員、この見方を認めているという意味ではありません。**

資料の「ブレンド」という表現も、教えを好きなように混ぜるという意味ではなく、宗教を結びつけて理解する見方として読みましょう。

```quiz
Q: 資料が複数の宗教の期待をバハーウッラーに結びつける図は、どう読む？
1: すべての宗教が、すべての教義を同じにしたという歴史的事実
2: バハーウッラーが登場する前に宗教がなかったという説明
3: 他の宗教の信徒も全員、この見方に同意しているという意味
4: バハイ信仰の側から、宗教的な期待を結びつける理解
C: 4
E: 信仰内部の見方と、他の宗教も共有する事実とは区別します。バハイ信仰の一体性という考えを理解するための図です。
```

## 7. バハイ信仰の祈りと断食

資料18ページは、祈り・年19日間の断食・飲酒の禁止・祝祭日を守ることを挙げます。

| 資料の要点 | 誤解しないための補足 |
|---|---|
| 1日3回の祈り | これは中程度の義務祈祷の形式に対応する。ほかに1日1回の形式もあり、3つの形式から一つを選ぶ |
| 年19日間の断食 | 19日間の各日、日の出から日没まで。19日間ずっと何も取らないという意味ではない |
| 飲酒の禁止 | 日常の行動に関する規範 |
| 祝祭日を守る | 宗教上の暦や特別な日を大切にする |

祈りの回数と断食の時間帯は、配布資料の短い表現を、バハイ公式資料で補足しました。信徒の義務を、読者に勧めたり課したりする説明ではありません。

```quiz
Q: 資料の「年19日間の断食」を、より正確に説明すると？
1: 19日間、昼夜を通して何も取らない
2: 19日間の各日、日の出から日没まで断食する
3: 毎月19日間、同じ断食をする
4: 19年に一度だけ、1日断食する
C: 2
E: 期間は年に19日間、時間帯は各日の日の出から日没までです。公式資料で、配布資料の短い記載を補っています。
```

## 8. 最後は、名前を見ずに説明してみる

- 命を傷つけず、欲や執着を減らす道を、何という宗教で学んだ？
- 祈り・誠実な仕事・分かち合いの3つを重んじるのは？
- 宗教や人類の一体性を重んじ、バハーウッラーを中心に据えるのは？

名前だけでなく、**その教えが、日々のどんな行動につながるか**を一つずつ言えたら、中心をつかめています。

第8講との違いは、仏教の復習を続けるのではなく、別の伝統が命・欲・仕事・人のつながりをどう捉えるかを比較するところです。

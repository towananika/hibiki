# 世界の宗教 9講 ― ジャイナ教・シク教・バハイ信仰

**「生き物を傷つけない」「働き、分かち合う」「人類は一つ」。3つの宗教が何を大切にするかを、違いと共通点から学びます。**

添付の第9講講義録に沿った教材です。見出しの意味を説明する宗教史・用語の補足と、身近な例を加えています。ここでの短い合言葉だけで、それぞれの宗教全体を表せるわけではありません。

## 1. 3つの宗教を、混ぜずに見分ける

| 宗教 | 主な出発点 | この講での注目点 |
|---|---|---|
| ジャイナ教 | 古代インドの修行の伝統 | 不殺生・無所有と、魂の解放 |
| シク教 | インドのパンジャーブ地方 | 一つの神への信仰と、労働・分かち合い |
| バハイ信仰 | 19世紀のイラン | 宗教のつながりと、人類の一体性 |

講義録ではシク教・バハイ信仰を、異なる宗教との関係からも紹介します。ただし、**「ほかの宗教を混ぜただけ」と覚えると、それぞれ独自の教えや歴史を見失います。**

```eq
比較する = 共通点を知る + 違いも残す
```

```quiz
Q: 3つの宗教を比較するとき、大切なのは？
1: 似た言葉があれば、同じ宗教だと考える
2: 共通点を探しつつ、それぞれの教えや歴史も区別する
3: 信者が少ない宗教には、独自の教えがないと考える
4: 発祥地が近ければ、神についての考えも同じだと決める
C: 2
E: 他の宗教との関係や共通点を学ぶことと、同一視することは別です。独自の教えと背景を区別して理解します。
```

## 2. ジャイナ教：なぜ、厳しく自分を律する？

第8講の仏教では、ブッダが極端な苦行を離れたことを学びました。第9講は、それと対比して、ジャイナ教のマハーヴィーラの厳しい修行を紹介します。

> 補足：マハーヴィーラは、ジャイナ教で大切にされる24番目のティールタンカラ（解放への道を示した師）です。単に「最初に作った人」と覚えるより、先行する伝統を含む位置づけを押さえます。

ジャイナ教には、**生命・魂であるジーヴァ** と、**非生命であるアジーヴァ** という区別があります。ここでいう生命・魂は、現代生物学の定義そのものではありません。

行為に関わる **業（カルマ）** が魂を束縛し、輪廻が続くと考えます。欲望や行為を律し、業の流入を防ぎ、蓄積した業を取り除いて、解放を目指します。

```flow
魂が業に束縛される → 欲望と行為を律する → 業からの解放を目指す
```

> 補足：この流れはジャイナ教の教義の要約です。仏教の「業」「輪廻」と同じ語があっても、魂についての考え方まで同じではありません。

```quiz
Q: ジャイナ教のジーヴァとアジーヴァは、何の区別？
1: 僧侶と在家信者
2: 祈りと労働
3: 生命・魂と、非生命
4: 白い服と、黒い服
C: 3
E: ジーヴァは生命・魂、アジーヴァは非生命を指します。魂の束縛と解放を理解するための、基本的な区別です。
```

## 3. ジャイナ教の5つの誓い

中心となるのは、**できる限り生き物を傷つけない、不殺生（アヒンサー）** です。ほかの誓いも、欲望と行動を律することにつながります。

| 誓い | やさしくいうと |
|---|---|
| 不殺生：アヒンサー | 生き物に危害を加えない |
| 真実：サティヤ | うそをつかない |
| 不盗：アステーヤ | 与えられていない物を取らない |
| 禁欲：ブラフマチャリヤ | 性に関わる欲望や行動を律する |
| 無所有：アパリグラハ | 所有や執着を抑える |

「欲しいから取る」「都合が悪いからうそをつく」といった行動を、欲望との関係から考えると理解しやすくなります。

**出家修行者の厳しい誓いと、在家信者の生活に合わせた誓いは区別します。** 禁欲や所有についても、全員が同じ生活をする意味ではありません。

```quiz
Q: ジャイナ教の誓いについて、適切なのは？
1: 不殺生を重視し、出家者と在家信者では実践の厳しさに違いがある
2: 生き物を傷つけなければ、盗みは認められる
3: 無所有とは、信者全員が同じ財産を持つという意味である
4: 欲望は行動に影響しないので、律する必要はない
C: 1
E: 不殺生を中心に、真実・不盗・禁欲・無所有を重視します。出家者には厳格な実践が求められ、在家信者には生活に応じた実践があります。
```

## 4. 空衣派と白衣派：何が違う？

講義では、ジャイナ教の主要な2つの宗派が紹介されます。

| 宗派 | 名前から覚える手がかり |
|---|---|
| 空衣派（ディガンバラ派） | 厳格な男性出家修行者が衣服を持たない実践で知られる |
| 白衣派（シュヴェーターンバラ派） | 出家修行者が白い衣をまとう |

**これは、信者全員の服装を分けた表ではありません。** 所有をどこまで離れるかという修行の違いを、衣服から見る入口です。両派には聖典などをめぐる違いもあります。

```quiz
Q: 空衣派と白衣派について、誤解を避けた説明は？
1: 空衣派では、すべての在家信者も衣服を持たない
2: 白衣派はジャイナ教とは関係がない
3: 衣服の違いだけで、教義はすべて同じである
4: 出家修行者の衣服への姿勢が、両派を見分ける手がかりになる
C: 4
E: 宗派の特徴としての出家者の実践を、全信者の生活に広げないことが大切です。名前は入口ですが、違いのすべてではありません。
```

## 5. シク教：祈る・働く・分かち合う

シク教は、グル・ナーナクに始まる伝統です。「グル」は教え導く師を意味します。一つの神を信仰し、身分などによる差別にとらわれず、人の平等を重視します。

講義の3つの柱は、次のように覚えられます。

```flow
神を思い、祈り、歌う → 誠実に働く → 得たものを分かち合う
```

これは、どれか一つが終われば次へ進む順番というより、日々の暮らしの中で共に実践する柱です。

> 補足：寺院で誰でも食事を共にする「ランガル」は、平等と奉仕を理解するための例です。宗教を問わず食事を分かち合う実践として知られます。

たとえば「自分の仕事を誠実に行い、その収入や時間をほかの人のためにも使う」という形で、労働と信仰が結びつきます。講義は、差別的な慣行への批判や、迫害・対立を経験した歴史にも触れています。

```quiz
Q: シク教の3つの柱に合う組み合わせは？
1: 苦行・無所有・白い衣
2: 神を思うこと・誠実な労働・分かち合い
3: 身分による区別・競争・富の独占
4: 祈りだけを行い、働くことと奉仕は避ける
C: 2
E: 神への信仰を、誠実な仕事と分かち合いにも結びつけます。講義では、祈り・労働・施しの3つが示されます。
```

## 6. バハイ信仰：異なる宗教を、どうつなぐ？

バハイ信仰は、バハーウッラーを中心とする、19世紀のイランに始まる宗教です。**神は一つ、人類は一つであり、宗教の歴史にはつながりがある**と考えます。

講義録では、仏教の弥勒、メシア、クリシュナの化身、キリストの再臨への期待との関連が図で示されます。これは、**バハイ信仰の側からの宗教理解**として読みます。他の宗教の信者も、全員がこの理解に同意しているわけではありません。

```flow
時代や地域で異なる教え → 神の導きのつながりとして理解する → 人類の一体性を重視する
```

> 補足：「段階的啓示」とは、神の導きが時代に応じて示されるという考えです。違う宗教の儀式を、好みに応じて自由に組み合わせることとは区別します。

```quiz
Q: バハイ信仰による、異なる宗教のつながりの理解として適切なのは？
1: 他の宗教の信者は全員、すでにバハイ信仰に同意している
2: 自分の好きな儀式だけを集めれば、独自の教えは不要になる
3: 他の宗教は、歴史的に存在しなかったと考える
4: 異なる時代の教えを、神の導きのつながりとして理解する
C: 4
E: バハイ信仰の立場から、宗教の歴史をつながりのあるものとして理解します。その立場を、他の宗教すべての共通見解と取り違えないことが大切です。
```

## 7. バハイ信仰の日々の実践

講義録は、祈り・年19日間の断食・飲酒の禁止・定められた日の遵守を挙げます。

| 実践 | 誤解しないための補足 |
|---|---|
| 義務の祈り | 講義録は1日3回と記すが、回数の異なる3種類から一つを選ぶ仕組みがある |
| 年19日間の断食 | 対象者が期間中の日の出から日没まで飲食を控える。19日間ずっと飲食しない意味ではない |
| 飲酒の禁止 | 宗教上の生活規範として理解する |
| 定められた日の遵守 | 共同体の暦に沿った実践として理解する |

> 補足：祈りには1日1回の短い祈り、1日3回の中くらいの祈り、1日1回の長い祈りがあります。断食には年齢・健康・妊娠などに関わる免除条件もあります。ここは、講義録の短い記述を文字どおり全員一律と受け取らないための補足です。

```quiz
Q: 講義録の「年19日間の断食」は、どう理解するとよい？
1: 対象者が期間中の日中に行い、健康などによる免除もある
2: 19日間、夜も含めて一切水を飲まない
3: 年齢や健康状態に関係なく、全員が同じ条件で行う
4: バハイ信仰には断食の実践はない
C: 1
E: 年19日という期間と、日の出から日没までという毎日の時間帯を分けて考えます。対象や免除もあり、危険な一律の実践として受け取らないようにします。
```

## 8. 仏教と比べると、何が見える？

```eq
同じ語がある ≠ 同じ教えである
```

| 比べる観点 | 見えてくる違い |
|---|---|
| 厳しい苦行 | 仏教のブッダは極端な苦行を離れた。ジャイナ教では厳格な修行を重視する |
| 魂 | ジャイナ教はジーヴァを認める。仏教は固定した自己を想定する見方を問い直す |
| 信仰と暮らし | シク教は祈り・誠実な労働・分かち合いを結びつける |
| 宗教の多様性 | バハイ信仰は、異なる宗教を導きのつながりとして理解する |

「どれが一番正しいか」を決める前に、何を問題とし、どんな生き方を示すかを見比べると、講義の内容を整理できます。

```quiz
Q: 第8講の仏教と、第9講のジャイナ教を比べた説明として適切なのは？
1: どちらも同じ言葉を使うので、魂についても同じ立場である
2: ブッダもマハーヴィーラも、厳しい苦行だけが唯一の道とした
3: 業や解放を扱っても、魂や苦行についての立場には違いがある
4: ジャイナ教は、行為と欲望の関係を考えない
C: 3
E: 共通する語だけで同一視しないことが大切です。ブッダの中道とジャイナ教の厳格な修行、仏教の自己への問いとジャイナ教のジーヴァを区別します。
```

## 9. 持ち帰る考え

**ジャイナ教は「傷つけず、執着を抑える」、シク教は「祈り・労働・分かち合い」、バハイ信仰は「宗教のつながりと人類の一体性」。** まずこの入口から、教えと日々の行動を結びつけて覚えます。

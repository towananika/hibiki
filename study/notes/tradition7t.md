# 伝統社会と生活文化 7講【会話で読む】― 食べものと食の暮らし

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition7)」。

## 1. 食べることへの考え方と、食事の回数（5分）

```talk
B: 韓国の人は、食べることを大事にしてる？
A: 関心がとても高い。「金剛山も食後景」（景色より先に食事）ということわざがある。日本語の「花より団子」に近い。
B: 昔の人は、どれくらい食べた？
A: 昔の男の大人は、1食で約420cc。今の大人の約3倍。
B: 1日何食？
A: 1日2食が普通。三国時代からの伝統。夏は、軽い昼のおやつ（点心）が入った。1日3食は、20世紀の後半にやっと広がった。
C: 昔は2食、3食は20世紀後半から。
```

```card
要点
- 「金剛山も食後景」：景色より先に食事（花より団子に近い）
- 昔の男の大人の1食は約420cc（今の約3倍）
- 1日2食が普通。夏は軽い昼のおやつ（点心）。3食は20世紀後半から
```

## 2. 主食は米、副食はキムチ（10分）

```talk
B: 主食は？
A: 米。お金の代わりにもなった。凶作の年にお上が飢えた民におかゆを配るときも、麦ではなく米を出した。栄養が豊富で収穫も多い。
B: 弱点は？
A: 稲は育てる条件が難しい（気温・日照・雨）。干ばつと洪水に弱く、手間もかかる。
B: キムチは？
A: 膳立てで一番大事な副食。キムチの器は、おかずの数に数えない。ごはんを進ませ、ビタミンを補う。入っている塩辛はたんぱく質のもと。三国時代より前からあって、朝鮮後期に白菜と唐辛子が入って大きく変わった。
C: 米は主食でお金、キムチは数に入らない大事な副食。
```

```card
要点
- 主食は米：お金の代わりにもなった／凶作のおかゆも米／弱点は育てる条件が難しいこと
- キムチ：最も大事な副食。器はおかずの数に数えない
- 朝鮮後期に白菜と唐辛子が入ってキムチが変わった
```

> 補足：韓国の正式な膳は、ごはん・汁・キムチなどのほかに並べるおかずの品数で、膳の格を表す。

## 3. 肉と魚、飢饉と救荒食（10分）

```talk
B: 肉は、よく食べた？
A: 肉を食べる習慣は、モンゴル侵攻のあとに入ってきた。でも日常食ではなかった。農耕に要る牛を守るため、牛の屠殺を禁じる「牛禁」もあった。
B: 魚は？
A: 肉より下の食品と見られた。交通が未発達で、内陸では特に手に入りにくかった。
B: 食べものは足りてた？
A: 18世紀末の人口は約1000万人。必要な穀物は年6000万石で、生産は約5700万石。毎年300万石足りなかった。
B: 救荒食は？
A: 朝鮮後期に、さつまいもとじゃがいもが入った。でも全国で作られるようになったのは、日本の植民地期になってから。
C: いつも飢えがあった。
```

```card
要点
- 肉：モンゴル侵攻のあとに入るが、日常食ではない。牛禁（牛を殺すことを禁じる）
- 魚は肉より下の食品。内陸では手に入りにくい
- 18世紀末：必要6000万石、生産5700万石 → 毎年300万石不足
- 救荒食：さつまいも・じゃがいも（全国で作られたのは植民地期）
```

## 4. 小盤（一人膳）と匙（10分）

```talk
B: 食卓は、どんな形？
A: 中国やヨーロッパは長い食卓でみんな一緒に食べた。韓国と日本は、小さなお盆（小盤）を置いて、一人ひとりの膳で食べた。
B: なぜ？
A: 台所・内房・舎廊房が分かれていて、かまどが低いところにあった。お盆で運んで、そのまま食卓になった。小さな膳には多くの料理を並べられないので、一人前ずつ。
B: 箸と匙は？
A: 箸は韓国・中国・日本のどこでも使われた。13〜14世紀ごろから、中国と日本では匙は使われなくなった。韓国は汁もの（国）が多い食文化なので、今も匙をよく使う。
C: 一人ひとりの膳と、匙。
```

```card
要点
- 小盤：小さなお盆がそのまま食卓。相席ではなく一人ひとりの膳
- 低いかまど・分かれた部屋 → お盆で運ぶ → 一人膳
- 箸は3か国で使われた。匙は中国・日本で廃れたが、韓国は汁ものが多いので今も使う
```

> 補足：内房は女性が暮らす家の奥の部屋、舎廊房は男性が過ごし客を迎える部屋。

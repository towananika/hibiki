# 開かれた社会と21世紀 14講 ― まちの物語をつくる（ストーリーテリング）

韓国の放送大学「開かれた社会と21世紀」14講（講義資料25ページ）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
物語で伝える力（ストーリーテリング） → 場所を売りこむ・心地よさ → まちのテーマを決める → 4つの段階で物語を育てる → 成功例と、気をつけること
```

## 0. ひとことで
情報はあふれていて、**人の関心のほうが貴重** な時代。まちが選ばれるには、**そのまちだけの物語** が必要。
まちの物語は、外から借りてくるより、**まちに眠っている小さくて大切なもの** から見つけるのが基本。
でも物語は **何でも治す薬ではない**。成功の保証はない。

## 1. ストーリーテリングってなに？
- 「物語（ストーリー）＋伝える（テル）」。ただ口で話すことではなく、**五感に届く伝え方** 全体のこと。
- 事実をならべるだけではない。**その場にいる感じ（現場性）** と **くり返し体験できる感じ（再演性）** を持ち、ことば・絵・音などで **やりとりする** もの。
- いまは、話（演説・講演・交渉・読み聞かせ）、まんが・ドラマ・映画・公演・お祭り、インターネットやゲームなど、いろいろな形と結びついている。
- 文化や芸術、会社の宣伝だけでなく、スポーツ・観光・地域づくり、学校の授業にも広がっている。

## 2. なぜ、まちに物語が必要になった？
**きっかけ**：工場がへり、仕事がへり、町の中心がさびれた欧米の町が、**文化で地域を元気にする作戦** を始めた。その土地の産業と文化こそが、問題を解く **創造の力のもと** だと気づいた。
- 例：スペイン・バルセロナの **カサ・ミラ**（建築家ガウディの作品。ユネスコ世界遺産、1984年）とその物語。

**時代の流れ**
- 交通・通信・インターネットで、人は場所や商品の情報を集めて、くらべやすくなった。
- 週5日勤務になり、**5日は町、2日は田舎**（5都2村）。田舎の景色・伝統・くらしで町の人と交流がふえた。
- 泊まって楽しむ **グリーンツーリズム** が広がり、余暇とお金の使い方がふえている。

**課題**
- ノーベル経済学賞のハーバート・サイモン：**「情報はどんどんありふれ、関心はどんどん貴重になる」**。
- これまでのまちは、**成長と成果第一の考え方の犠牲** になってきた（開発中心・政策中心）。
- みんなで長く暮らせるまちになるには、**見た目の成長や建物中心の開発を乗りこえる** 必要がある。
- 物語は、文化と気持ちの時代に合った **新しい価値を生む力** で、まちを育てる道具になる。

```quiz
Q: 「情報はどんどんありふれ、関心はどんどん貴重になる」と言った人は？
1: アントニ・ガウディ
2: ハーバート・サイモン

C: 2
E: ノーベル経済学賞を受けた認知心理学者ハーバート・サイモンのことば。だからまちは、関心を集めるテーマを見つける必要がある。ほかの選択肢：1はカサ・ミラの建築家。3は「ドリーム・ソサエティ」を予告した人。4は境港の妖怪の道のもとになったまんが家。
```

## 3. 場所を売りこむ（場所マーケティング）と、心地よさ（アメニティ）
**場所マーケティング**：ある場所を魅力的にするため、**そこだけのイメージ** を作り、新しい価値を生む作戦。
| 種類 | 例 |
|---|---|
| ① 宣伝・販売 | 広告やキャンペーン |
| ② 文化の建物を作る | 博物館、劇場 |
| ③ イベント・お祭り | 江原道・華川の **やまめ（山川魚）祭り**、京畿道・加平の **ジャラ島ジャズ祭り** |
| ④ 文化の通り・地区を作る | 文化の通り、芸術の地区 |
| ⑤ 歴史のある建物や場所を守る | 古い建物の保存 |
| ⑥ スポーツの行事 | 大会 |

**アメニティ**：ヨーロッパから始まった考え。**くらしに必要な、全体としての心地よさ**。
- 人と環境がふれ合って生まれる、あたたかさ・さわやかさ・満足・安心・しあわせ。
- ふるさとのあたたかさ、田舎らしさ、町の魅力など。
- いまは、守るために使う人がお金を出す **みんなの財産（公共財）** と考えられている。

```quiz
Q: ある場所を魅力的にするため、そこだけのイメージを作って新しい価値を生む作戦を何という？
1: 場所マーケティング
2: アメニティ
3: グリーンツーリズム
4: まちの記録庫（アーカイブ）
C: 1
E: 場所マーケティング。宣伝、文化施設、お祭り、文化の通り、歴史的な場所の保存、スポーツ行事の6つに分けられる。ほかの選択肢：2はくらしの全体的な心地よさ。3は泊まって田舎を楽しむ余暇。4はまちの記録を集めて残すこと。
```

## 4. まちのテーマをどう作る？
- どんな商品・サービス・まちも、**ほかとちがう物語がなければ、人の心は動かない**。よそを **まねするだけ（まねベンチマーキング）には限界** がある。
- どのまちにも、形のあるもの・ないものの大切な資源と物語がある。それを **見つけ、価値を見直し、テーマにする知恵** が必要。

**まちのテーマ** とは
- まちの資源と特徴を使って、まちを育てる作戦の **中心のテーマ**。
- 土地にもとからある資源がいちばんだが、**新しく作ることもできる**。
- **1つのことばや文で言えて、まちのイメージがすぐ浮かぶ**、短いしるし。

**物語にする目的**：まちのイメージを高め、訪れる人をふやし、ふれ合いと体験の機会を広げ、**口コミ** で収入と地域の経済を育てる。

**大事なこと：しぼって集中する（選択と集中）**
- テーマや物語が多すぎると、かえって **まちらしさがぼやける**。代表的な1つか少しだけ選ぶ。
- 物語のもと：まちの人物、自然と景色、文化遺産、特産品、神話・伝説・昔話。
- 伝える手段：お祭り、案内、公演や再現、体験・学びのプログラム、展示、インターネット・スマホ、案内板。

## 5. 物語を育てる4つの段階
```flow
① 準備 → ② 物語を掘り起こす → ③ 体験できるようにする → ④ 物語を分け合う
```
| 段階 | すること |
|---|---|
| ① **準備** | 住民が参加して主役になることが大事。必要性・目的・日程を共有し、**まちの人みんなに参加をよびかける** |
| ② **物語を掘り起こす**（中心の段階） | 物語を「文化・自然・産業・場所や施設」に分けて一覧にする → 住民のワークショップで、まちのビジョンに合う物語を選ぶ → いちばん覚えやすい **しるし（テーマ）** を決める |
| ③ **体験できるようにする** | 1つのテーマをいろいろな形で使い、価値を最大にする（**OSMU：ワンソース・マルチユース**）。**体験の場**（お祭り・イベント・体験プログラム、聞いていた物語を確かめられる本物）と **情報の場**（旅のはじめから終わりまで、同じイメージの案内）を作る |
| ④ **物語を分け合う** | **まちが作った物語** と **訪れた人が作った物語** がまじり合い、信頼が積み重なっていく。まちと訪問者、住民どうし、訪問者どうしのやりとり |

```quiz
Q: 1つのテーマを、お祭り・商品・案内・ネットなど、いろいろな形で使って価値を最大にすることを何という？
1: ワンソース・マルチユース（OSMU）
2: 選択と集中
3: 5都2村
4: まねベンチマーキング
C: 1
E: OSMU。1つのもと（ソース）を、いろいろに使う（マルチユース）。ほかの選択肢：2はテーマを少しにしぼること。3は5日は町、2日は田舎ですごす暮らし方。4はよそをまねするだけのやり方で、講義は限界があるとした。
```

## 6. 物語でまちが元気になった例
| まち | 物語のもと | ポイント |
|---|---|---|
| **統営・トンピラン**（慶尚南道） | 港で働く人たちが住んだ丘の村。2007年、市民の会「青い統営21」が **壁画コンテスト** を開き、全国18の団体が参加 | 取りこわし予定の村が「東洋のナポリ」、**統営いちばんの名所** に。全国の壁画村の始まり。でも「住民は本当に幸せか？」という問いも |
| **任実チーズ村**（全羅北道） | 1958年、ベルギーから来た **池正煥（チ・ジョンファン）神父** が、やぎ2頭からチーズ作りを始めた | もとは土地の資源ではないものから物語を作った例。何度もの対立や失敗を乗りこえ、**住民中心のまちの経済** に。村とテーマパークのちがいにも注意 |
| **加平・ジャラ島国際ジャズ祭り**（京畿道） | 毎年10月はじめ。世界の一流ジャズ演奏家が来る | 音楽と関係なかった加平を **ジャズ** でまとめた。ジャズマッコリ、ジャズワインなど特産品も。国の優秀なお祭りに3年続けて選ばれ、2014年に最優秀。効果には別の意見も |

## 7. これからの、まちの物語
- ロルフ・イェンセンが予告した **「ドリーム・ソサエティ」**（夢の社会）のように、いまは **気持ちに届く宣伝（感性マーケティング）** が価値を生む時代。
- まちの物語とテーマは、地域をもう一度元気にする手段で、**まちの人が営む小さな商い（コミュニティビジネス）** の資源にもなる。

**作るより、見つけて守る**
- **「お年寄りが1人亡くなると、まちから博物館が1つ消える」**。住民1人ひとりが、まちの歴史で物語。
- 講義の問い：トンピランをマンション街にしていたら、壁画村は生まれた？ お金と技術で新しくするだけで、心が動く？ よそのまねで、そのまちの心や歴史まで写せる？
- **小さくても大切なもの、まちだけのもの、守りたいもの** を見つけて守る気持ちが大事。

**気をつけること**
- まちどうしの競争ははげしい。どの資源・テーマ・物語でも **成功の保証はない**。**何でも治る薬だという夢はすてる**。
- ふだん気にとめなかった、はずかしいと思っていたまちの姿も、**見方を変えれば宝** になる。
- まず、かくれた資源の価値を見つけることから。**まちの記録庫（マウルアーカイブ）を作る**。

## まず、この3つ
1. 関心が貴重な時代。まちには **そのまちだけの物語（テーマ）** が必要。しぼって集中する。
2. 物語を育てる4段階：**準備 → 掘り起こす → 体験できるようにする（OSMU）→ 分け合う**。
3. 物語は作るより **見つけて守る**。でも何でも治る薬ではない。まず記録から。

## ひびきの暮らしでいうと
- 自分の発信も同じ。テーマを1つにしぼり、いろいろな形（文章・写真・動画）で使い回すと、伝わりやすい。
- 「はずかしい」と思っていた自分の経験も、見方を変えれば、だれかの役に立つ物語になる。

# 開かれた社会と21世紀 14講 ― まちの物語をつくる（ストーリーテリング）

**この講で覚えること：人の関心が足りない時代、まちが選ばれるには「そのまちだけの物語」がいる。物語は外から借りるより、まちに眠っているものから見つけ、1つにしぼって育てる。でも、何でも治る薬ではない。**

## 0. この講の地図（3分）

同じような観光地が、たくさんあります。人はネットで簡単にくらべられます。
**では、人はなぜ、あるまちを選んで行くのか？** これが14講の問いです。答えは「そのまちだけの物語があるから」。

```flow
① 言葉をそろえる → ② なぜ物語が必要？ → ③ テーマを1つにしぼる → ④ 物語を育てる4段階 → ⑤ 成功した4つのまち → ⑥ 作るより、見つけて守る
```

読む前に思い出しておくと楽です。
- **8講**：まちづくりは、建物より「暮らす人と、人のつながり」。
- **12講**：まちづくりは、準備 → 調べる → 目標 → 計画 → 実行 と段階で進める。

14講の物語づくりも同じ考えです。主役は住民で、段階をふんで進めます。

## 1. まず言葉をそろえる（5分）

この講で何度も出てくる言葉は4つだけです。

```card
14講の4つの言葉
- ストーリーテリング：物語を、五感に届く形で伝えること（話す・見せる・体験させる）
- 場所マーケティング：その場所だけのイメージを作って、人を呼ぶ作戦
- まちのテーマ：ひとことで言えて、まちの姿がすぐ浮かぶ「しるし」
- OSMU（ワンソース・マルチユース）：1つの物語を、祭り・商品・案内など、いろいろな形で使うこと
```

鳥取県の境港で考えます。漁業がおとろえた町が、この町出身のまんが家・水木しげるの **妖怪** をテーマに決めました。通りの像、街灯、電車、お店まで妖怪でそろえると、年に300万人以上が来る町になりました。

```flow
まちに眠っていたもの（妖怪まんが） → テーマを1つに決める → いろいろな形で使う（OSMU） → 人が来て、話が広がる
```

この流れが14講の全体です。

```quiz
Q: 「まちのテーマ」の説明として正しいのは？
1: まちの資源をできるだけ多くならべた一覧
2: ひとことで言えて、まちの姿がすぐ浮かぶしるし
3: 人気のある別のまちと同じ名前
4: 市役所が決める正式な地名
C: 2
E: まちのテーマは、短くて、聞けばまちのイメージがすぐ浮かぶしるし。
ほかの選択肢：1は多すぎてかえってぼやける。3はまねで、講義は限界があるとした。4は地名の話でテーマではない。
```

## 2. なぜ、まちに物語が必要になった？（8分）

理由は2つです。

**① 関心が足りない時代になった**
ノーベル経済学賞のハーバート・サイモンは言いました。**「情報はどんどんありふれ、関心はどんどん貴重になる」**。
ネットで場所をくらべやすくなった今、ただ「きれいな町」では選ばれません。

**② 建物を建てるだけの開発に限界が来た**
工場がへってさびれた欧米の町は、**文化で地域を元気にする作戦** を始めました。例はスペイン・バルセロナの **カサ・ミラ**（建築家ガウディの建物）とその物語です。
これまでのまちは「成長と成果が第一」の開発でつかれてきました。物語は、建物を増やさずに新しい価値を生む道具です。

> 補足：講義には、週5日を町で、2日を田舎ですごす暮らし（5都2村）や、田舎に泊まって楽しむ旅（グリーンツーリズム）が広がった話も出ます。田舎の物語にも人が集まる背景です。

```quiz
Q: 「情報はどんどんありふれ、関心はどんどん貴重になる」と言った人は？
1: アントニ・ガウディ
2: ハーバート・サイモン
3: ロルフ・イェンセン
4: 水木しげる
C: 2
E: ノーベル経済学賞を受けたハーバート・サイモンのことば。だからまちは、関心を集めるテーマが必要になる。
ほかの選択肢：1はカサ・ミラの建築家。3は「夢の社会（ドリーム・ソサエティ）」を予告した人。4は境港の妖怪まんがの作者。
```

## 3. テーマを1つにしぼる（8分）

人を呼ぶ作戦（場所マーケティング）には、いろいろな形があります。

```card
場所マーケティングの6つの形
- 宣伝・広告
- 博物館や劇場などの文化の建物
- イベント・お祭り（例：加平のジャズ祭り）
- 文化の通り・芸術の地区
- 古い建物や歴史のある場所を守る
- スポーツの大会
```

どの形を使うにしても、真ん中にいるのが **まちのテーマ** です。大事なのは2つ。

- **まねをしない**：よそをまねするだけ（まねベンチマーキング）では、人の心は動かない。
- **しぼって集中する（選択と集中）**：テーマが多すぎると、まちらしさがぼやける。代表を1つか少しだけ。

物語のもとは、まちの人物・自然と景色・文化遺産・特産品・昔話などです。土地にもとからあるものがいちばんですが、新しく作ることもできます。

> 補足：講義には **アメニティ**（くらしの全体的な心地よさ。ふるさとのあたたかさや田舎らしさ）も出ます。物語だけでなく、住んで気持ちいいことも、まちの魅力です。

```quiz
Q: まちのテーマを決めるとき、講義が大事だとしたことは？
1: 人気のテーマを、できるだけ多く集める
2: 成功したまちのテーマを、そのまま使う
3: 代表的なテーマを1つか少しにしぼる
4: テーマは毎年かならず変える
C: 3
E: 選択と集中。テーマが多いと、まちらしさがぼやける。
ほかの選択肢：1は多すぎてぼやける。2はまねで、心が動かない。4は講義にない。
```

## 4. 物語を育てる4つの段階（10分）

```flow
① 準備 → ② 掘り起こす → ③ 体験できるようにする → ④ 分け合う
```

- **① 準備**：まちの人みんなに参加をよびかける。**主役は住民**。
- **② 掘り起こす**（いちばん大事）：まちの物語を集めて一覧にし、住民の話し合いで、覚えやすいテーマを1つ選ぶ。
- **③ 体験できるようにする**：1つのテーマを、祭り・体験・商品・案内など、いろいろな形で使う（**OSMU**）。旅のはじめから終わりまで、同じイメージで案内する。
- **④ 分け合う**：**まちが作った物語** に、**訪れた人が作った物語**（感想や写真）がまじり合い、信頼が積み重なる。

覚え方：**集める → 選ぶ → 使い回す → 広がる**。

```quiz
Q: 1つのテーマを、お祭り・商品・案内・ネットなど、いろいろな形で使って価値を最大にすることを何という？
1: ワンソース・マルチユース（OSMU）
2: 選択と集中
3: 5都2村
4: まねベンチマーキング
C: 1
E: OSMU。1つのもと（ソース）を、いろいろに使う（マルチユース）。
ほかの選択肢：2はテーマを少しにしぼること。3は5日は町、2日は田舎ですごす暮らし方。4はよそをまねするだけのやり方。
```

## 5. 物語でまちが元気になった4つの例（10分）

どれも「何がもとで → どうなったか → 残る問い」で見ます。

```card
① 統営・トンピラン（韓国の港町）
- もと：港で働く人が住んだ丘の村。2007年に壁画コンテスト
- 結果：取りこわし予定の村が、町いちばんの名所に。全国の壁画村の始まり
- 残る問い：住民は本当に幸せか？（人が来すぎる）
```

```card
② 任実チーズ村（韓国の農村）
- もと：1958年、ベルギーから来た神父が、やぎ2頭からチーズ作りを始めた
- 結果：住民が中心のまちの経済に
- ポイント：もとは土地の資源ではないものから物語を作った例
```

```card
③ 加平・ジャラ島ジャズ祭り（韓国）
- もと：音楽と関係なかった町が、ジャズをテーマにした
- 結果：国の最優秀のお祭りに。ジャズの名前をつけた特産品も
- 残る問い：効果には別の意見もある
```

```card
④ 境港・水木しげるロード（日本・鳥取県）
- もと：町出身のまんが家の妖怪
- 結果：街灯・電車・空港まで妖怪でそろえ、年300万人以上
- 残る問い：人口がへる問題は残っている
```

**どの例にも「残る問い」がある** ことが、この講の大事な点です。

```quiz
Q: もともと土地の資源ではなかったものから、テーマと物語を作ったと講義が紹介したまちは？
1: 任実チーズ村
2: カサ・ミラ
3: 華川のやまめ祭り
4: 統営トンピラン
C: 1
E: 任実チーズ村は、ベルギー人の神父がやぎ2頭から始めたチーズ作りが物語になった。
ほかの選択肢：2はバルセロナのガウディの建物。3は場所マーケティングのお祭りの例。4は丘の村に壁画を描いて名所になった例。
```

## 6. 作るより、見つけて守る（5分）

**「お年寄りが1人亡くなると、まちから博物館が1つ消える」**
住民1人ひとりが、まちの歴史で、物語です。

講義の問い：トンピランをマンション街にしていたら、壁画村は生まれた？ よそのまねで、そのまちの心まで写せる？

```card
これからの3つの心がまえ
- 小さくても大切な、まちだけのものを見つけて守る
- はずかしいと思っていたまちの姿も、見方を変えれば宝になる
- 物語は何でも治る薬ではない。成功の保証はない
```

だからまずは、まちの記録を集めることから始めます。これが次の **15講（まちの記録庫＝アーカイブ）** につながります。

> 補足：講義には、気持ちに届く宣伝が価値を生む「夢の社会（ドリーム・ソサエティ、ロルフ・イェンセン）」や、物語を **住民が営む小さな商い（コミュニティビジネス）** に生かす話も出ます。

```cloze
物語は作るより {{見つけて守る}}。でも {{何でも治る薬}} ではない。まず {{記録}} から。
```

## まず、この3つ

1. 関心が貴重な時代。まちには **そのまちだけの物語（テーマ）** が必要。**1つにしぼる**。
2. 物語を育てる4段階：**準備 → 掘り起こす → 体験できるようにする（OSMU）→ 分け合う**。
3. 物語は作るより **見つけて守る**。でも何でも治る薬ではない。まず記録から。

## ひびきの暮らしでいうと

- 自分の発信も同じ。テーマを1つにしぼり、文章・写真・動画でいろいろに使うと伝わりやすい（OSMU）。
- 「はずかしい」と思っていた自分の経験も、見方を変えれば、だれかの役に立つ物語になる。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。

```quiz
Q: まちのテーマとストーリーテリングについて、正しくないものは？
1: テーマや物語が多すぎると、かえってまちらしさがぼやける
2: テーマは土地の資源がいちばんだが、新しく作ることもできる
3: 物語を作れば、どのまちでも必ず成功する
4: まちが作った物語と、訪れた人が作った物語がまじり合うことが大事
C: 3
E: 講義は、成功の保証はなく、何でも治る薬だという夢はすてるべきだとした。
ほかの選択肢：1、2、4はどれも講義のとおり正しい。
```

```quiz
Q: 「お年寄りが1人亡くなると、まちから（　）が1つ消える」。（　）に入る言葉は？
1: 博物館
2: 学校
3: お祭り
4: 市場
C: 1
E: 住民1人ひとりがまちの歴史で物語、という意味。だからまちの記録（アーカイブ）を作ることから始める。
ほかの選択肢：2、3、4は講義のことばではない。
```

```quiz

1: 準備
2: 物語を掘り起こす
3: 体験できるようにする
4: 物語を分け合う
C: 2
E: 掘り起こす段階で、物語を集めて一覧にし、住民の話し合いでテーマを選ぶ。ここが中心。
ほかの選択肢：1は参加のよびかけ。3はOSMUで使い回す段階。4は訪れた人の物語とまじり合う段階。
```

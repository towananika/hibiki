# 伝統社会と生活文化 10講 ― 役人と両班の暮らし

韓国の放送大学「伝統社会と生活文化」10講（対談の講義、約44分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名や数字は聞き取りなので、少しずれているかもしれない。

```flow
家柄（両班） → 役人になる（試験・家柄の推薦） → 都で勤める → 地元で村を動かす
```

## 0. ひとことで
朝鮮王朝は「家柄の人（両班）と役人（官僚）で動く国（両班官僚制）」。両班が家柄を守るいちばんの道は**役人になること**。
でも役人の暮らしは、服代・新人いじめ・地方への赴任など**意外と大変**。そして両班の大半は役人になれず、**地元で村を動かす人**として忙しく暮らした。

## 1. 「両班」ってだれ？
- もとは役人の2つのグループ、**文の役人（文班）と武の役人（武班）**のこと。のちに「家柄（身分）」の名前になった。
- 法律の上では、人は**ふつうの民（良人）**と**低い身分（賤人、代表は奴婢）**の2つ。役人はふつうの民の中の「王を助けて国を治める人」。
- 役人の子や孫が代々役人になるうちに、その一族ぜんぶが特別あつかいされ、「両班」と呼ばれるようになった。

## 2. 役人になる3つの道
| 道 | どんなもの | 有名な人 |
|---|---|---|
| 文の試験（文科） | いちばん確か。でも合格は1年に約30人 | ― |
| 武の試験（武科） | 軍の役人 | 李舜臣 |
| 家柄・推薦（蔭官） | 高い役人の子や孫が簡単な試験（蔭取才）で入る。のちに試験はなくなり推薦（薦挙）に | 宋時烈、朴趾源 |

- 絵かき・医者などの専門職も、長く勤めると地方の長（守令）になれた。画家の金弘道（檀園）も地方の長になった。
- 文の試験組は、外交文書・学校・出版の部署で見習い → 王の相談役（弘文館）など**文の役人だけの部署**へ。推薦組は**王のお墓の管理（参奉）**から始めることが多い。


```quiz
Q: 両班が役人になるいちばん確かな道は？
1: 文の役人の試験（文科）に受かる
2: お金で役職を買う
3: くじ引き
4: 王に手紙を書く
C: 1
E: いちばん確かなのは文科の合格。ただし1年に約30人しか受からないので、家柄の推薦（蔭官）で入る人も多かった。
```

## 3. 役人になってからの苦労
- **ひとり暮らしの赴任（他郷暮らし）**：交通も連絡も不便。遠い国境では風土病にかかることも。遠くの任地を言われて辞める人もいた。
- **服が高い（官服）**：帽子・上着・帯・革の靴をそろえる。絹などで作るので、月給の**半年分以上**。人に借りたり、借金をしたりした。
- **新人いじめ（免新礼）**：いまでいう「新人歓迎の儀式」。何か月も続き、宴会代で**破産する人**、事故で**亡くなる人**まで出た。国が何度も禁止したのに、最後まで消えなかった。

## 4. 都の役所街と働き方
- 宮殿（景福宮）の門の前の大通りに、6つの省（六曹）などが並ぶ**役所通り（六曹通り）**。いまのソウルの世宗路あたり。
- 王のすぐそばで働く役所（秘書・護衛・相談役など）は、**王が住む宮殿に合わせて引っこし**した。
- 1つの役所には、高い役人（堂上官）・その下の役人（堂下官）・事務係（胥吏）・使い走り（使令）がいた。

| | 決まり | 実際 |
|---|---|---|
| 勤務時間 | 朝6時〜夕方6時（冬は8時〜4時） | 交代制でかなり自由 |
| 休みの日 | 決まった休日なし | 5日出て2日休み、3人で3日ずつ交代（月に約10日）など |
| 夜 | 当番が泊まる（宿直） | 出勤しない日も外の仕事あり（いまの出張） |

> 補足：講師は「いまでいうフレックス制（時差出勤）に近い」と話していた。

## 5. 休み・給料・定年
**休み（休暇）**は「理由ごとに日数」が決まっていた。
| 理由 | 日数 |
|---|---|
| 親に会いに行く・お墓参り | 7日（移動は別） |
| 妻のお葬式 | 15日 |
| 親の病気 | 遠い地方70日・中くらい50日・都の近く30日 |

- ただし昇進には**出勤日数**が必要（6品以上は900日、7品以下は450日）。休みは数えないので、みんな日数を熱心に計算した。
- **給料（俸禄）**：はじめは年4回、のちに毎月。でも**家族が暮らせる額ではなかった**（月数両で、食費だけで約3両）。暮らしは家の田畑と奴婢の農業で支えた。
  - 給料は「仕事のお礼」より「国の役目を果たすための活動費」に近い考え方だった。
  - 地方の長（守令）は、税を国に納めた残りを使えたので比べると豊か。都の役人や親せきに**贈り物**をした。王も米や魚を贈った。
- **定年**：決まった定年はない。地方の長は65歳まで任命、任期があるので実際は約70歳まで。70歳をこえて勤める高い役人には、王がひじ置きと杖（几杖）を贈った。でも多くの人は途中で役職から外れていった。


```quiz
Q: 朝鮮時代の役人の給料について、正しいのは？
1: とても多く、ぜいたくに暮らせた
2: 家族が暮らすには足りず、家の農業で暮らしを支えた
3: 給料は一切なかった
4: 毎日お金で払われた
C: 2
E: 給料は活動費に近く、家族の暮らしには足りなかった。家の田畑や奴婢を使った農業の収入で生活した。
```

## 6. 役人になれなかった両班の暮らし
両班の大半は役人になれなかった。とくに地方は推薦してくれる人が少なく、**ソウルの人のほうが有利**だった。でも、ひまではない。
- **農業の経営者**：自分で田んぼに入らないが、1年の農作業を動かす（いまの自営業）
- **子どもの先生**：学校がないので家で教える（村の塾の先生も仕事になった）
- **祭りと客のもてなし（奉祭祀・接賓客）**：儒教のやり方で先祖をまつる。お金がかかっても、それが両班のしるし
- **受験生**：何十年も試験を受け続ける。合格より**家柄を守るため**、そして「学ぶ人だ」と示すため
- **村の役目**：地方の学校（郷校）・私立の学問所（書院）、役所を手伝う会（留郷所）、村のきまりの会（郷約）で働く
- **儒教の正しさを守る**：兵役を免除され、王に意見書（上疏）を出したり、みんなの意見（公論）をまとめたりした

## 7. 両班の名簿に入るのはむずかしい
- 16世紀後半、両班は地元の**両班名簿（郷案）**を作ってまとまり、村の運営に加わった。
- 地方の学校（郷校）は両班でない人も入れた。でも書院と名簿は**推薦＋全員の投票**。ある地域では**16人中15人の賛成**が必要だった。
- 入れない両班も多く、名簿をめぐって両班どうしで争いも起きた。


```quiz
Q: 両班の名簿（郷案）に入るには、何が必要だった？
1: お金を払うだけ
2: 試験で1位になる
3: 推薦を受け、ほぼ全員の賛成票をもらう
4: 王の許可
C: 3
E: 推薦された人について投票し、ほぼ全員の賛成が必要だった（16人中15人など）。両班でも入れない人が多かった。
```

## 8. 両班とふつうの人のちがい
考え方の上では、**儒教を学び、実行する人**が両班。でもそれは両班でなくてもできる。だから両班は書院や名簿という**自分たちだけの組織**を作って、ほかの人と区別しようとした。

## ひびきの暮らしでいうと
- 給料だけで暮らせず「家の収入」で支えるのは、いまの**副収入や資産で暮らしを支える**考えに近い。
- 昇進に出勤日数が必要で、みんな日数を数えた。資格の勉強も**締め切りから逆算して日数を数える**と続けやすい。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。


```quiz

2: 新人いじめ（免新礼）は国が禁じても続いた
3: 給料だけで家族がゆとりをもって暮らせた
4: 交代で勤め、宿直もあった
C: 3
E: 給料は活動費に近く、家族の暮らしには足りなかった。家の農業で支えた。
```

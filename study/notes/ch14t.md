# デジタル経済 14章【会話で読む】― 仕事の未来

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=ch14)」。

## 1. 技術が進めば、全員が豊かになる？（5分）

```talk
B: 技術が進めば、すぐ全員が豊かになる？
A: 産業革命では、新しい仕事も生まれた。でも、従来の技能の価値が下がった人もいた。技術が変わると、利益を得る人と負担する人が分かれる。
B: 利益が広がるまでは？
A: 時間がかかる。その間の苦しさも無視できない。この講の入口は、技術の目標を、生産量だけでなく、余暇や生活の質から考えること。
C: 利益を得る人と、負担する人が分かれる。
```

```card
要点
- 技術が変わる → 利益を得る人と負担する人が分かれる
- 利益が広がるまでの時間と、その間の苦しさも見る
- 目標を、生産量だけでなく、余暇や生活の質からも考える
```

## 2. 仕事を「作業」に分けて見る（5分）

```talk
B: 仕事がAIに代わられるか、どう考える？
A: 仕事を作業に分ける。動画を作る仕事なら、資料を集める、構成を考える、字幕を作る、相手に確認する、など。
B: 見方は？
A: 職業単位は「この職業が自動化されそうか」。作業単位は「中のどの作業を代わり、どこを助けるか」。見方によって、将来の雇用の予測も違う。
B: 注意は？
A: 「自動化できる可能性」と「実際に採用されること」は別。
C: 仕事を分ける → 代われる作業を見つける → 残る作業や新しい役割も考える。
```

```card
要点
- 職業単位：この職業が自動化されそうか
- 作業単位：中のどの作業を代わり、どこを助けるか
- 自動化できる可能性 ≠ 実際に採用されること
```

## 3. 仕事が減る力と、増える力（10分）

```talk
B: 雇用は、技術でどう変わる？
A: 4つの効果がある。代替効果は、人の作業を機械が代わる。補完効果は、機械を生かす人の役割がふえる。生産効果は、安くなって需要がふえ、生産や人手がふえる。波及・拡散効果は、新しい商品や産業が育つ。
B: 結局、雇用は？
A: 雇用への影響 ＝ 減る力と増える力の組合せ。費用が下がっても、価格が十分下がらなかったり、需要がふえなかったりすれば、人手がふえるとは限らない。
B: 工場が戻れば、昔と同じ人数が働ける？
A: 同じとは限らない。「どの国で作るか」と「どの作業を人がするか」は、関連するけど別の問い。
C: 代替・補完・生産・波及・拡散。
```

```eq
雇用への影響 = 減る力と増える力の組合せ
```

```card
要点
- 代替効果：機械が人の作業を代わる（減る力）
- 補完効果：機械を生かす人の役割がふえる
- 生産効果：安くなる → 需要↑ → 生産・人手↑
- 波及・拡散効果：新しい商品や産業が育つ
- 「どの国で作るか」と「どの作業を人がするか」は別の問い
```

## 4. 柔軟に働けることと、安心して働けること（5分）

```talk
B: 在宅やプラットフォームの仕事は、いいことだらけ？
A: 時間や場所を選びやすい面がある。でも、負担もある。
B: 負担は？
A: いつも連絡に対応する圧力、収入や勤務時間の不確実さ、保険・年金・休業時の保障。
B: 大切なのは？
A: 仕事の数だけでなく、仕事の質も見ること。
C: 自由と、不安定さは、セット。
```

```card
要点
- 自由になる面：時間や場所を選ぶ／少ない時間から参加／複数の仕事を組み合わせる
- 確かめる負担：連絡への対応の圧力／収入や勤務時間の不確実さ／保険・年金・休業時の保障
- 仕事の数だけでなく、質も見る
```

## 5. 自分の仕事で、どこを助けてもらう？（5分）

```talk
B: 自分の仕事では、どう考える？
A: 自分の作業を1つ選ぶ → 道具で試す → 時間と品質を比べる → 人が担う部分を決める。
B: 必要な力は？
A: 新しい道具に詳しいことだけでなく、問題を見つけ、結果を確かめ、相手に伝える力も必要。
B: 学び直しは個人の責任？
A: 個人に任せきりにせず、教育・働くルール・移行期の支援を、社会がどう整えるかも問い。
C: 「何を任せ、空いた時間をどう使うか」。
```

```card
要点
- 自分の作業を1つ選ぶ → 道具で試す → 時間と品質を比べる → 人が担う部分を決める
- 問題を見つけ、結果を確かめ、相手に伝える力も必要
- 学び直しだけを個人に任せず、教育・ルール・移行期の支援を整える
```

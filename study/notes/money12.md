# 貨幣金融論 12講 ― 人はなぜお金を持つ？（2）

韓国の放送大学「貨幣金融論」12講（スライド31枚）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
お金を持つ3つの理由（ケインズ） → 金利が上がると、持ちたいお金がへる → 金利がとても低いと「お金の落とし穴」 → フリードマンは「長い目の稼ぎ」で考えた
```

## 0. ひとことで
11講は昔の経済学（古典派）。12講はその次の2人。
- **ケインズ**（1936年）：人がお金を持つ理由は3つ。その1つは **金利で大きく変わる**。だから、持ちたいお金の量はゆれやすい。
- **フリードマン**（通貨主義＝マネタリスト）：人は **長い目で見た稼ぎ** で、持つお金を決める。だから、持ちたいお金の量は **安定している**。

> 補足：11講の「貨幣需要（持ちたいお金の量）」の続き。中央銀行と銀行がお金を出し、家計・会社・政府がお金を持ちたがる。何がその量を決めるのかを考える。

## 1. お金を持つ3つの理由（ケインズの流動性選好説）
ケインズは、本『雇用・利子および貨幣の一般理論』（1936年）で、昔の考えを退け、**金利がお金の持ち方をどう変えるか** を説明した。

| 理由 | 中身 | 何で決まる？ |
|---|---|---|
| **買い物のため**（取引的動機） | 日々の支払いに使うお金 | 稼ぎ（名目国民所得）。稼ぎがふえると、ふえる |
| **もしものため**（予備的動機） | 急な出費にそなえるお金（へそくり・非常金） | これも稼ぎ。稼ぎの一定の割合 |
| **もうけのチャンスを待つため**（投機的動機） | よい投資先が来たらすぐ動けるよう持っておくお金 | **金利** |

> 補足：「流動性」は、すぐにお金として使えること。現金はいちばん流動性が高い。「流動性選好」は「すぐ使えるお金で持っておきたい気持ち」のこと。

```quiz
Q: ケインズが考えた、お金を持つ3つの理由に入らないものは？
1: 買い物のため（取引的動機）
2: もしものため（予備的動機）
3: もうけのチャンスを待つため（投機的動機）
4: 国に税金を納めるため（納税的動機）
C: 4
E: ケインズの3つは、買い物・もしも・もうけのチャンス。ほかの選択肢：1、2、3はどれもケインズの3つの理由そのもの。4はケインズの分け方にない。
```

## 2. 「もうけのチャンス」と金利（ここがいちばん大事）
ケインズは、**お金で持つか、債券で持つか** をくらべて説明した。

**債券のしくみ（まずここ）**
- 債券は「借用書」。持っていると、毎年 **決まった額の利息** がもらえる。
- 例：1,000ウォンで出した債券が、毎年100ウォンの利息をくれる（表面金利10%）。

**世の中の金利（市場金利）が変わると、債券の値段が変わる**
| 世の中の金利 | 1,000ウォンをふつうに預けると | この債券（毎年100ウォン） | 債券の値段 |
|---|---|---|---|
| 20%に上がる | 200ウォンもらえる | 100ウォンしかくれない → 1,000ウォンではだれも買わない | **500ウォン** に下がる |
| 5%に下がる | 50ウォンしかもらえない | 100ウォンくれる → みんなほしがる | **2,000ウォン** に上がる |

**覚えること：金利が上がると債券の値段は下がる。金利が下がると債券の値段は上がる。**（シーソーの関係）

> 補足（式で書くと）：債券の値段 ＝ 毎年の利息 ÷ 世の中の金利。100 ÷ 0.2 ＝ 500、100 ÷ 0.05 ＝ 2,000。

```quiz
Q: 毎年100ウォンの利息をくれる債券がある。世の中の金利が20%になると、この債券の値段はどうなる？
1: 2,000ウォンに上がる
2: 1,000ウォンのまま
3: 500ウォンに下がる
4: 100ウォンに下がる
C: 3
E: 1,000ウォンを預ければ200ウォンもらえるので、100ウォンしかくれない債券は500ウォンでないと売れない（100÷0.2＝500）。ほかの選択肢：1は金利が5%に下がったとき。2は金利が10%のまま変わらないとき。4は計算が合わない。
```

## 3. 「先の金利」をどう読むかで、持つお金が変わる
人は「これから金利がどうなるか（予想金利）」で動く。
| 予想 | 債券の値段は？ | どうする？ | もうけ待ちのお金 |
|---|---|---|---|
| 金利が **上がり** そう | 下がりそう | 債券を売って、お金で持つ | **ふえる** |
| 金利が **下がり** そう | 上がりそう | お金で債券を買う | **へる** |

**「ふつうの金利」（正常利子率）という考え**
- 人はそれぞれ「金利はだいたいこれくらいがふつう」という感覚を持っている。
- いまの金利が **ふつうより高い** → 「そのうち下がる」と思う → 債券を買う → お金はへる。
- いまの金利が **ふつうより低い** → 「そのうち上がる」と思う → 債券を売る → お金はふえる。
- だから **いまの金利が高いほど、「下がる」と思う人がふえ、もうけ待ちのお金はへる**。

```quiz
Q: ケインズの考えで、いまの金利が上がると、もうけ待ちのお金（投機的な貨幣需要）はどうなる？
1: ふえる
2: へる
3: 変わらない
4: 金利とは関係ない
C: 2
E: 金利が高いほど「このあと下がる（債券の値段が上がる）」と考える人がふえ、お金を債券にかえるので、手元のお金はへる。ほかの選択肢：1は金利が下がったとき。3と4は、ケインズが「金利で大きく変わる」と言った点に合わない。
```

## 4. ケインズの式（持ちたいお金 ＝ 稼ぎの分 ＋ 金利の分）
文で言うと：**持ちたいお金は、「稼ぎで決まる分（買い物＋もしも）」と「金利で決まる分（もうけ待ち）」の足し算**。

| | 稼ぎ（Y）が… | 金利（i）が… |
|---|---|---|
| 買い物＋もしもの分（L₁） | ふえると、ふえる | 関係しない |
| もうけ待ちの分（L₂） | 関係しない | 上がると、へる／下がると、ふえる |

> 補足（式で書くと）：Md ＝ L₁(Y) ＋ L₂(i)。Md＝持ちたいお金の量、L₁＝買い物ともしものためのお金、Y＝稼ぎ（名目国民所得）、L₂＝もうけ待ちのお金、i＝金利。稼ぎとは同じ向き（正の関係）、金利とは逆の向き（逆の関係）。

## 5. 持ちたいお金のグラフ（貨幣需要曲線）
たて軸に金利、よこ軸に持ちたいお金。**金利が下がるほど、持ちたいお金はふえる** ので、線は **右下がり**。

```flow
金利がとても高い（線はまっすぐ立つ） → ふつう（右下がり） → 金利がとても低い（線は横にねる＝お金の落とし穴）
```

| 場所 | ようす | ことば |
|---|---|---|
| 金利が **とても高い**（i₁より上） | みんな「もう下がるしかない」と思い、すでに債券で持っている。金利がさらに上がっても、手元のお金はほとんどへらない | 線が **まっすぐ立つ**。金利への反応がゼロ（利子弾力性が0） |
| 金利が **とても低い**（i₂） | みんな「もう上がるしかない」と思い、債券を売って全部お金で持つ | 線が **横にねる**。金利への反応が無限大（利子弾力性が無限大）＝**流動性のわな** |

> 補足：「利子弾力性」は、金利が少し動いたとき、持ちたいお金がどれだけ大きく動くか、という反応の大きさのこと。

**流動性のわな（流動性の罠）**
- 金利がとても低いと、だれも債券を持たず、財産を全部お金で持つ。
- このとき中央銀行がお金をふやしても、ぜんぶ手元にたまるだけで、金利はもう下がらない。
- **不景気が長く続くと、このわなにはまりやすい**。

```quiz
Q: 金利がとても低く、みんなが債券を売って財産を全部お金で持つ状態を何という？
1: 流動性のわな（流動性の罠）
2: 正常利子率
3: 交換方程式
4: マーシャルの k
C: 1
E: 流動性のわな。持ちたいお金の線が横にねて、金利への反応が無限大になる。ほかの選択肢：2は人が「ふつう」と思う金利の水準。3と4は11講の古典派の考え（フィッシャーの式、ケンブリッジ学派）。
```

## 6. フリードマンの考え（新しい貨幣数量説）
フリードマンは、お金を **たくさんある財産の1つ** として見た（資産選択の理論）。
- 財産の持ち方には、お金・債券・株・家や車などの物（実物資産）がある。
- どれをどれだけ持つかは、**財産全体の大きさ** と、**それぞれのもうけの見こみの差** で決まる。

**持つお金を決めるもの**
| もの | 持ちたいお金との関係 |
|---|---|
| **長い目で見た平均の稼ぎ**（恒常所得） | 多いほど、**ふえる** |
| 債券のもうけの見こみ（お金とくらべて） | 高いほど、へる |
| 株のもうけの見こみ（お金とくらべて） | 高いほど、へる |
| 物の値段の上がり方の見こみ（予想インフレ率） | 高いほど、へる（お金の価値が落ちるので） |

- 人は「お金の **数字**」ではなく、「そのお金で **何がどれだけ買えるか**（実質）」で考える。
- **恒常所得** は、1年ごとの上がり下がりをならした「長い目の平均の稼ぎ」。ゆっくりしか動かない。

> 補足（式で書くと）：Md/P ＝ f(yp, rb−rm, re−rm, πe−rm)。Md/P＝本当に買える量で見た持ちたいお金（実質貨幣残高）、yp＝恒常所得、rb＝債券のもうけの見こみ、re＝株のもうけの見こみ、πe＝予想インフレ率、rm＝お金を持つことのもうけの見こみ。「−rm」は「お金とくらべた差」という意味。

**フリードマンの結論**
- 持ちたいお金は **金利にはあまり反応しない**（利子弾力性が低い）。
- ゆっくりしか動かない **恒常所得で決まるので、安定している**。
- だからお金の回る速さ（流通速度＝名目国民所得 ÷ お金の量）も **安定していて、予想できる**。

```quiz
Q: フリードマンが、持ちたいお金の量を決めるいちばん大事なものと考えたのは？
1: その日の金利
2: 長い目で見た平均の稼ぎ（恒常所得）
3: 今年だけの稼ぎ
4: 中央銀行の気分
C: 2
E: フリードマンは、ゆっくり動く恒常所得でお金の量が決まるので、お金の需要は安定していると考えた。ほかの選択肢：1は金利に敏感と考えたケインズ寄りの答え。3は1年ごとの稼ぎで、恒常所得ではない。4は理論と関係ない。
```

## 7. ケインズとフリードマンのくらべ
| | ケインズ | フリードマン |
|---|---|---|
| お金の代わりになる財産 | 債券だけ | 債券・株・物（家具や車など長く使う物） |
| お金のもうけの見こみ | 一定 | 変わる |
| 金利が変わると、持ちたいお金は | **大きく反応**（だから不安定） | **あまり反応しない**（恒常所得で決まるので安定） |
| お金の回る速さ | 不安定 | 安定 |

## ひびきの暮らしでいうと
- 金利が高いときは、手元のお金をへらして預金や債券に。金利が低いときは「もう上がるかも」と様子を見る。これがケインズの「もうけ待ち」のお金。
- フリードマンのように、**1か月ごとの収入より「長い目の平均の収入」** で生活費を決めると、暮らしが安定する。ひびきの貯金の習慣とも同じ考え方。

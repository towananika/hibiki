# 伝統社会と生活文化 9講 ― 学校と役人試験

韓国の放送大学「伝統社会と生活文化」9講（対談の講義、約44分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名などの漢字は分かる範囲で書いた。

```flow
村の塾（書堂） → 地方の学校（郷校）・私立の学問所（書院） → 都の最高学府（成均館） → 役人試験（科挙）
```

## 0. ひとことで
朝鮮王朝は「儒学（孔子の教え）の国」。学校はその教えを学ぶ場で、ゴールは**役人になる国の試験（科挙）**。
試験はとても狭き門で、合格はおよそ**36歳**。受かると村じゅうのお祭りになった。でも「試験のための勉強は本当の学びじゃない」という悩みもずっとあった。

## 1. 学校のしくみ
| いまでいうと | 名前 | だれが作った |
|---|---|---|
| 大学 | 都の最高学府（成均館） | 国 |
| 高校 | 都の学校（学堂）・地方の学校（郷校） | 国 |
| 高校〜大学（研究寄り） | 私立の学問所（書院） | 地元の名家、国が支援 |
| 小学校 | 村の塾（書堂） | 地元の名家や村 |

- 学ぶ中身は「**文・史・哲**」（文章・歴史・哲学）。中心は儒学の古典（四書五経）。技術は教えない。
- 学期も時間割もない。**来られるときに来て、泊まりこみで、自分のペースで**先生に習う。生徒の多くは大人で、家の仕事もあったから。
- 最高学府の暮らし：寮は東と西に約100人ずつ。**太鼓の合図**でごはんと授業。食堂の席は最初は成績順、のちに**年の順**。朝夕2回食堂で食べると「その日出席」になった。


```quiz
Q: 朝鮮時代の学校に学期や時間割がなかったのはなぜ？
1: 先生が足りなかったから
2: 国が学校を禁止していたから
3: 生徒の多くが大人で、家の仕事もあったから
4: 試験がなかったから
C: 3
E: 生徒は大人が多く、家の仕事や農作業もあった。来られるときに泊まりこみで、自分のペースで学んだ。
```

## 2. 家での勉強の流れ
6〜7歳：漢字の入門書（千字文）→ 子ども向けの道徳の本（小学）→ 古典（四書三経）。
10代前半で基本の古典はほぼ読み終える。そのあと先生をたずねたり、仲間と泊まりこみの**模擬試験合宿（居接）**をしたりする。勉強が集中するのは**農作業がひまな季節**。

## 3. 試験の種類
- **文科**：文の役人（いちばん格が高い）
- **武科**：軍の役人
- **雑科**：通訳・医者・天文・法律などの専門職
- **生員・進士試**：役人ではなく「資格」。最高学府に入れる
- 文科は**3年ごとの定期試験（式年試）**と、国にお祝いがあったときの**臨時試験**がある。
> 補足：いまの大学入試の「一般入試」と「随時の入試」に近い、と講師は説明していた。

**勉強法**：何百冊も読む必要がある → 大事なところを選んで**何百回も読み返す**。答えは文章で書くので、**何千編も書いて練習**した（2,664編を書き写した練習帳も残っている）。

## 4. どれくらい難しい？
| | 数字 |
|---|---|
| 文科合格者 | 500年で約14,600人（1年に約30人） |
| 生員・進士 | 500年で約47,000人（1年に約100人） |
| 倍率（地方の資格試験） | 1605年 約30倍 → 1872年 約300倍 |
| 合格の平均年齢 | 文科 36.4歳（15世紀 約30歳 → 19世紀後半 39歳） |
| 最高齢の合格 | 90歳（お年寄り向けの特別試験・耆老科） |

- 有名な学者・李珥（栗谷）は「9回トップ合格」と言われるが、文科のトップは29歳。それまでは落ちていた。
- 昔は「40歳でやめる」が目安。のちに「50歳まで」と言う人が増えた。


```quiz

3: 約50歳

C: 2
E: 平均は36.4歳。15世紀は約30歳、19世紀後半は39歳と、後になるほど遅くなった。
```

## 5. 合格したら
- 発表は張り紙。こわくて自分では見に行かず、人に見に行かせることが多かった。
- 合格証は、文科が**赤い紙（紅牌）**、資格試験が**白い紙（白牌）**。今も家宝として残る。
- 王さまからお祝い → 芸人を連れて都をパレード → 先輩たちの新人歓迎（いじりもあった）→ 故郷でも宴会。人が集まりすぎて**家がこわれ、木が折れた**という日記もある。あいさつ回りに2〜3か月かかった。


```quiz
Q: 文科に受かった人がもらう合格証の色は？
1: 白（白牌）
2: 黄色
3: 青
4: 赤（紅牌）
C: 4
E: 文科は赤い紙の紅牌。資格試験（生員・進士試）は白い紙の白牌。
```

## 6. 試験の勉強と本当の学び
- 試験の勉強は効率重視で、深く考える時間がけずられる。学者たちは「試験は学問のじゃま」と言った。
- 弟子が「試験はやめて哲学だけやる」と言うと、大学者の李滉（退渓）はこまった。家のための試験は**親への務め**だから。
- 出た答え：「10時間のうち7時間は学問、3時間は試験勉強」「受けてもいい。でも合否にこだわりすぎない」。それでも悩みは消えなかった。

## ひびきの暮らしでいうと
- 放送大学の勉強も「大事なところを何度もくり返す」が昔からの王道。
- 「受けるけれど、結果にとらわれすぎない」は、締め切りがある今の勉強にもそのまま使える。

# 貨幣金融論 14講 ― IS-LMモデル（物の市場とお金の市場を、いっしょに見る）

韓国の放送大学「貨幣金融論」14講（スライド29枚）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

> 5〜10分で読む「[会話で読む版](view.html?n=money14t)」もあります。

> 動かして理解する「[IS-LMを動かす](islm.html)」（5分）もあります。

```flow
IS-LMモデルとは → IS曲線（物の市場） → LM曲線（お金の市場） → 2つが交わる所（同時の均衡） → 財政政策と金融政策の効き方
```

## 0. ひとことで
- **IS-LMモデル**は、**物の市場（財貨市場）** と **お金の市場（貨幣市場）** が **同時に** つり合う状態を調べるモデル。
- IS曲線は物の市場、LM曲線はお金の市場。**2つが交わる所** で、国民所得（国の所得）と金利（利子率）が決まる。
- 13講の「簡単な所得決定モデル」と、ちがう点は **金利を入れた** こと。

## 前に習ったことを、思い出そう（IS-LMを読む道具）
IS-LMは、これまでの講で習った3つの道具を、**組み合わせただけ**。忘れていたら、ここだけ読めば大丈夫。

**道具1：国の所得の決まり方（13講）**
- 国全体で「買いたい量（消費C＋投資I＋政府G）」と「作る量Y」が一致した所で、国の所得（国民所得Y）が決まる。
- 所得のうち使わない分が **貯蓄S**。民間だけで見ると、**投資I＝貯蓄S** のとき、物の市場がつり合う。
- 支出が少し変わると、所得は **何倍にも** 変わる（乗数効果）。
- ただし13講では **金利が出てこなかった**。

**道具2：お金を持ちたい量（11・12講）**
- お金を持つ理由は3つ（ケインズ）。**買い物のため・もしものため**＝所得で決まる。**もうけのチャンスを待つため**＝**金利**で決まる。
- 金利が上がると、債券の値段が下がり、債券が得になる → お金で持つ分が **へる**。金利がとても低いと **流動性のわな**（お金をふやしても金利が下がらない）。
- 古典派（11講）は、持ちたいお金は所得だけで決まり、金利は関係ない、と考えた。
- 式：持ちたいお金（貨幣需要）＝ 所得で決まる分 L1(Y) ＋ 金利で決まる分 L2(i)。

**道具3：お金の量を出す側（8〜10講）**
- お金の量（貨幣供給）＝ 土台（中央銀行が出したお金、ベースマネー）× 倍率（貨幣乗数）。
- 中央銀行が土台をふやすと、お金の量がふえる。

**この3つで、ISとLMは言える**
| | IS（物の市場） | LM（お金の市場） |
|---|---|---|
| 覚え方 | **I**nvestment（投資）＝**S**aving（貯蓄） | **L**iquidity（お金がほしい量）＝**M**oney（お金の量） |
| 使う道具 | 道具1（13講） | 道具2＋3（8〜12講） |
| 金利が上がると | 投資が減り、所得が **減る**（右下がり） | 所得がふえると金利が **上がる**（右上がり） |

```flow
金利↑ → 投資↓ → 所得↓（IS） ／ 所得↑ → お金がほしい↑ → 金利↑（LM） → 2本の線が交わる所が答え
```

## 1. IS-LMモデルってなに？
| 言葉 | 意味 |
|---|---|
| **IS-LMモデル** | 物の市場とお金の市場が、同時につり合う状態を調べるモデル |
| **IS**（実物部門） | 物の市場（財貨市場）のつり合い |
| **LM**（金融部門） | お金の市場（貨幣市場）のつり合い |

**13講のモデルとのちがい**（例：政府支出がふえたとき）
- 簡単な所得決定モデル：政府支出↑ → 国民所得↑（乗数 1/(1−b) 倍）。ここで終わり。
- IS-LMモデル：政府支出↑ → 国民所得↑ → お金がほしい量（貨幣需要）↑ → お金の市場の金利↑ → 会社の投資↓ → 国民所得↓（一部が打ち消される）。

> 補足：b は限界消費性向（収入がふえたとき、消費にまわす割合）。13講の記号と同じ。

## 2. IS曲線 ― 物の市場がつり合う組み合わせ
**IS曲線**は、物の市場の均衡条件 **I＝S（投資＝貯蓄）** を満たす、**国民所得と金利の組み合わせ** を表す曲線。

- 金利↑ → 投資↓ → 均衡国民所得↓。だから **右下がり**（右下がりの傾き）。

**傾きを決めるもの**（金利が変わったとき、均衡国民所得がどれだけ動くか）
- **投資の金利弾力性**（金利が変わったとき、投資がどれだけ変わるか）が大きい → 金利が少し上がるだけで投資が大きく減る → IS曲線は **ゆるやか（平ら）**。小さい → **急**。
- **乗数が大きい**（限界消費性向が大きい）→ IS曲線は **ゆるやか**。限界消費性向が小さい → **急**。

**IS曲線の移動**（同じ金利のまま、均衡国民所得が変わる）
- 独立の消費・投資、政府支出、税収が変わると、IS曲線全体が動く。
- **財政政策**（政府支出や税収を変えて目標をめざす政策）で動かせる。
  - **拡大財政政策**（政府支出↑・減税）→ IS曲線が **右へ**。
  - **緊縮財政政策**（政府支出↓・増税）→ IS曲線が **左へ**。

## 3. LM曲線 ― お金の市場がつり合う組み合わせ
**LM曲線**は、お金の市場の均衡条件 **L＝M（貨幣需要＝貨幣供給）** を満たす、**国民所得と金利の組み合わせ** を表す曲線。

```eq
お金の量（供給）＝ お金がほしい量（需要）
```

> 補足（式で書くと）：M^s（供給）＝ mB。M^d（需要）＝ L1(Y) ＋ L2(i)。m は貨幣乗数、B はベースマネー（中央銀行が出したお金のもと）。国民所得 Y が上がると取引用のお金の需要が、金利 i が下がると投機用のお金の需要が、ふえる。

- 国民所得↑ → お金がほしい量↑ → 貨幣需要曲線が右へ → 均衡金利↑。だから LM曲線は **右上がり**。

**傾きを決めるもの**
- **貨幣需要の所得弾力性**（所得がふえたとき、お金がほしい量がどれだけふえるか）が大きい → LM曲線は **急**。
- **貨幣需要の金利弾力性**（金利が変わったとき、お金がほしい量がどれだけ変わるか）が **小さい** → 金利を大きく上げないと超過需要が消えない → LM曲線は **急**。
  - **古典派**：貨幣需要は所得だけで決まり、金利と関係がない → 金利弾力性は 0 → LM曲線は **垂直**。
  - **ケインズ**：**流動性のわな**（金利が低すぎて、お金を持つほうが得だと思う状態）→ LM曲線は **水平**。

**LM曲線の移動**
- 貨幣供給量が **ふえる** → 均衡金利が下がる → LM曲線は **右（下）へ**。
- ただし貨幣需要の金利弾力性が **大きい** ほど、移動の幅は **小さく** なる。流動性のわなでは、お金をふやしても金利が下がらないので、LM曲線は **まったく動かない**。

## 4. 同時の均衡と、政策の効き方
**物の市場とお金の市場の同時均衡**
- IS曲線とLM曲線が **交わる点** の金利と国民所得で、2つの市場が同時につり合う。

```flow
財政政策 → IS曲線が動く ／ 金融政策 → LM曲線が動く → 交わる点がずれる → 国民所得と金利が変わる
```

### 財政政策（政府支出や税収を変えて目標をめざす政策）
- 政府支出↑・減税 → IS曲線が右へ → **国民所得↑、金利↑**。
- **押し出し効果（クラウディング・アウト）**：政府支出の増加が金利を上げ、**民間の投資を減らす** 効果。膨張的な財政政策では、乗数効果で国民所得がふえたあと、金利の上昇で投資が減って、国民所得がまた減る。
- 押し出し効果の大きさは **貨幣需要の金利弾力性**（LM曲線の傾き）で決まる。
  - **完全な押し出し効果**：貨幣需要の金利弾力性が 0 → LM曲線は垂直 → 国民所得は **ふえず**、金利だけが上がる。
  - **流動性のわなのとき**：LM曲線は水平 → 金利が上がらず、押し出しは起きない → **財政政策は最大の効果**（IS曲線が動いた分だけ、国民所得がふえる）。

### 金融政策（貨幣供給量を変えて目標をめざす政策）
- 貨幣供給量↑ → お金の市場で金利↓ → 物の市場で投資↑ → **国民所得↑**。LM曲線が右へ動く。
- 効果が **大きい** のは次の場合：
  - **貨幣需要の金利弾力性が小さい**（LM曲線が急）。
  - **投資の金利弾力性が大きい**（IS曲線がゆるやか）。
- 効果が **小さい** のは、投資の金利弾力性が小さいとき（IS曲線が急）や、流動性のわなのとき（LM曲線が水平で動かない）。

| | LM曲線が急（垂直に近い） | LM曲線が水平（流動性のわな） |
|---|---|---|
| 財政政策 | 押し出しが大きく、効果は小さい | 押し出しがなく、効果は最大 |
| 金融政策 | 効果は大きい | 効果はない |

## まず、この3つ
1. IS曲線は **右下がり**（物の市場）、LM曲線は **右上がり**（お金の市場）。2つの交点で、国民所得と金利が決まる。
2. 財政政策はIS曲線を、金融政策はLM曲線を動かす。財政政策には **押し出し効果** がある。
3. LM曲線が **垂直** なら、財政政策の効果はゼロ（完全な押し出し）、金融政策の効果は大きい。LM曲線が **水平**（流動性のわな）なら、財政政策の効果は最大、金融政策の効果はゼロ。

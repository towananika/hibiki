# 開かれた社会と21世紀 13講【会話で読む】― まちを調べて記録する

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=open13)」。

## 1. なぜ、何のために調べる？（10分）

```talk
B: まちを調べる意味は？
A: まちの探究（マウル探究）は、歴史・自然・人・活動・物語を見つけて記録すること。そのスタートがまちの調査。人類学の現地調査（フィールドワーク）から始まった。住民の意見を集める欠かせない方法で、調べる人とまちが話し合う両方向のやりとりでもある。
B: 目的は？
A: ふつうの調査は6つ。探る（探索）、書き表す（記述）、説明する、たしかめる（検証）、評価する、ものさしを作る（指標開発）。
B: 政策から見ると？
A: 3つ。まちが本当に必要なものを知る（政策需要の把握）、手続きの根拠、情報を分け合う（政策情報の共有）。
C: 調査は、まちとの両方向のやりとり。
```

```card
要点
- まちの探究：歴史・自然・人・活動・物語を記録する。スタートがまちの調査
- 6つの目的：探索・記述・説明・検証・評価・指標開発
- 政策から：需要の把握／手続きの根拠／情報の共有
```

## 2. 数かことばか、3つの段階（10分）

```talk
B: 調査のやり方の分け方は？
A: 数で見る調査（量的調査）は、結果が数字で、まち全体への影響を広く知れる（アンケート）。ことばで見る調査（質的調査）は、結果が文章で、まちの物語や歴史・文化を知る（ワークショップなど）。
B: どちらがいい？
A: ぶつかり合うものではなく、おぎない合うもの。両方使うことが多い。
B: 段階は？
A: 3つ。計画と下調べ（企画・基礎調査）→ 現地調査 → 分析・整理。計画と下調べがとても大事で、目的・方法・日程、期間・人数・お金を決め、できるかを下調べ（探索的調査）で確かめる。質問票を下書きし、ためしに使って直す（予備調査）。
C: 最初の準備をいいかげんにしない。
```

```card
要点
- 量的調査（数・全体を広く）／質的調査（文章・物語や文化）。おぎない合う
- 計画と下調べ → 現地調査 → 分析・整理
- 下調べ：探索的調査／標本抽出／質問票の下書き／予備調査
```

## 3. 5つの調べ方と心がまえ（10分）

```talk
B: 調べ方は？
A: 5つ。すでにある資料（2次資料調査）、アンケート（設問調査）、じっくり聞く（深層インタビュー）、みんなで地図を作る（コミュニティマッピング）、ワークショップ。
B: 調べるときのコツは？
A: 成功は最初の出会いでほぼ決まる。あいさつ、目的の説明、個人情報をどう守るかの説明で安心してもらう。
B: 守る決まり（調査の倫理）は？
A: 情報を外にもらさない、他の目的に使わない。留守でも勝手にほかの人にかえない。1つの家で2人以上を調べない。答えに誘導しない。答えを勝手に変えて書かない。
C: 中立と情報の秘密を守る。
```

```card
要点
- 2次資料／アンケート／深層インタビュー／コミュニティマッピング／ワークショップ
- 最初の出会いでほぼ決まる
- 倫理：秘密を守る／相手をかえない／1家で2人以上調べない／誘導しない／答えを変えない
```

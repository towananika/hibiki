# 上級マクロ経済論 15講【会話で読む】― 豊かさは、どう増え続ける？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro15)」。

## 1. 設備だけ増やし続けたら？（5分）

```talk
B: パン屋に、オーブンを増やし続けたらどうなる？
A: 1台もなければ、最初の1台は大きな助け。でも、働く人が同じでオーブンが100台あれば、101台目の効果は小さい。これが資本の限界生産の逓減。
B: 設備が役に立たなくなるの？
A: ちがう。もう1台の効果が小さくなる、という意味。
B: 製法を改善したら？
A: 同じ人数・同じオーブンで多く焼ける。生産性が上がる。
C: 設備を増やす効果には、限りがある。
```

```card
要点
- 資本の限界生産の逓減：設備が多いほど、もう1台の効果は小さくなる
- 設備全体が役に立たなくなるわけではない
- 生産性を上げると、同じ人手・設備で多く作れる
```

## 2. 国全体と1人あたり（5分）

```talk
B: 国の生産が2倍になったら、豊かになった？
A: 人口も2倍なら、1人あたりは変わらない。1人あたりの所得 ＝ 国全体の所得 ÷ 人口。この講は、主に1人あたりの実質所得の長期的な伸びを考える。
B: 成長の理由は？
A: 2つ。入れる量をふやす外延的成長（人やオーブンをふやす）と、同じ量から多く作る内包的成長（製法や仕組みの改善）。
C: ふやす成長と、よくする成長。
```

```card
要点
- 1人あたりの所得 ＝ 国全体の所得 ÷ 人口
- 外延的成長：入れる量をふやす（人・設備）
- 内包的成長：同じ量から多く作る（製法・仕組み）
```

## 3. 成長会計（5分）

```talk
B: 成長のうち、設備・労働・生産性は、それぞれどれだけ効いた？
A: それを計算するのが成長会計。生産の成長率 ＝ 生産性の成長率 ＋ α×資本の成長率 ＋ (1−α)×労働の成長率。
B: α は？
A: 資本への所得の取り分。1−α は労働への取り分。
B: 例は？
A: 生産が4%伸び、設備と労働で説明できる分が3ポイントなら、残りの1ポイントが生産性の伸びの目安。この残りがソロー残差。
B: 残りは発明の量？
A: ちがう。稼働率の変化や測定誤差なども含まれる。
C: 残りが、生産性の伸びの目安。
```

```card
要点
- 成長会計：生産の成長を、資本・労働・生産性に分ける
- 生産の成長率 ＝ 生産性の成長率 ＋ α×資本の成長率 ＋ (1−α)×労働の成長率
- 例：4% − 3ポイント ＝ 1ポイント（ソロー残差）
- 残差＝発明の量、ではない
```

## 4. ソロー・モデル（10分）

```talk
B: ソロー・モデルは、どんな考え？
A: 所得の一部を貯蓄して、それが新しい設備になる。ただし、毎年、古くなって使えなくなる設備と、人口がふえた分の新しい設備を補う必要がある。
B: つり合うと？
A: 貯蓄から生まれる投資 ＝ 補う投資 になると、1人あたりの設備はふえなくなる。技術が一定なら、1人あたりの所得も一定。これを定常状態という。
B: 式は？
A: s×z×f(k) ＝ (n＋d)×k。k は1人あたりの設備、z×f(k) は1人あたりの生産、s は貯蓄の割合、n は人口増加率、d は減価償却率。
B: 左右を比べると？
A: 左が大きければ、1人あたりの設備はふえる。等しければ維持。小さければ減る。
C: 左は新たな投資、右は現状を保つのに必要な分。
```

```eq
貯蓄から生まれる投資 = 古くなる分と人口増を補う投資
```

```card
要点
- 定常状態：1人あたりの設備がふえなくなる（技術が一定なら、所得も一定）
- s×z×f(k) ＝ (n＋d)×k（左＝新たな投資、右＝現状を保つ分）
- k：1人あたり設備／s：貯蓄率／n：人口増加率／d：減価償却率
```

## 5. 「高くなる」と「伸び続ける」（5分）

```talk
B: 貯蓄率を上げたら、ずっと成長する？
A: しばらくは成長する。でも、設備がふえるほど追加の効果は小さくなり、新しい定常状態に近づく。所得の高さは上がるけど、成長率が永遠に高くなるわけではない。
B: 人口増加率が上がると？
A: 1人あたりの設備を保つのに多く必要になり、所得の到達する高さは下がる。
B: 伸び続けるのは？
A: 生産性が進歩し続けるとき。このモデルでは、長期に1人あたり所得を伸ばす源は、持続的な技術進歩。ただし、技術がなぜ進歩するかは、モデルの外から与える（外生的成長理論）。
C: 高さが上がる ≠ 伸び続ける。
```

```card
要点
- 貯蓄率↑：所得の到達する高さは上がるが、成長率が永遠に高くなるわけではない
- 人口増加率↑：到達する高さは下がる
- 生産性が進歩し続ける：1人あたり所得も伸び続けられる
- ソロー：技術進歩はモデルの外から与える（外生的成長理論）
```

## 6. 貧しい国は、必ず追いつく？（5分）

```talk
B: 貧しい国は、速く伸びて追いつく？
A: 設備が少ない国では、追加の設備の効果が大きいので、速く伸びる可能性がある。でも、貯蓄率・人口増加率・技術が違えば、めざす所得の高さも違う。
B: 予測は？
A: 条件が同じ国どうしなら、1人あたり所得が近づく。これを条件つき収束という。すべての国が無条件に同じ所得になる、とは予測しない。
B: データでは？
A: 投資率の高い国は1人あたり所得も高い、などの関係がある。でも、国どうしの関連だけで「貯蓄をふやせば同じ結果になる」とは言えない。
C: 条件つき収束。
```

```card
要点
- 条件つき収束：条件が同じ国どうしなら、1人あたり所得が近づく
- 無条件にすべての国が同じ所得になる、とは予測しない
```

## 7. 新しい考え：知識は、どう生まれる？（10分）

```talk
B: 知識は、設備とどう違う？
A: パンの作り方を別の店も使っても、元の店は使えなくならない。これが知識の非競合性。みんなが同時に使える。ただし、必ず無料という意味ではなく、特許などで制限もできる。
B: 知識が広がると？
A: 作った人以外にも利益が生まれる（知識の外部性）。研究した本人が、社会全体の利益を全部受け取れるとは限らない。
B: 技術がどう生まれるかを説明する理論は？
A: 内生的成長理論。2つの型がある。AKモデルは、知識なども含む広い資本を考え、経済全体では追加の効果が小さくならないと仮定する。式は y ＝ A×k。
B: もう1つは？
A: 研究開発（R&D）モデル。利益や特許などの動機で研究し、新しい知識を作る。単純な式は、知識の成長率 ＝ a×λ×N。a は研究の効率、λ は研究する人の割合、N は人口。研究者の人数が多いほど、知識の成長率は高い。
C: 知識は、みんなで同時に使える。
```

```card
要点
- 知識の非競合性：みんなが同時に使える（必ず無料とは限らない）
- 知識の外部性：作った人以外にも利益が広がる
- 内生的成長理論：技術や知識の生まれ方をモデルの中で説明
- AKモデル：y ＝ A×k（追加の効果が小さくならない）／R&Dモデル：知識の成長率 ＝ a×λ×N
```

# デジタル経済 12講 ― 移動産業：便利な通勤と、街全体の負担

**自分にとって便利な移動でも、渋滞や空気の汚れを、ほかの人に負担させることがあります。** 乗り物の新技術と、みんなの使い方を整える制度を、分けて考えます。

添付の講義ノートをもとにした教材です。日常の例や図は、理解を助ける補足です。

## 1. 車の値段だけで、通勤を比べてよい？

車・電動の乗り物・公共交通を比べるとき、買う値段だけでは十分ではありません。使う間の費用、通勤時間、駐車場所、充電や給油のしやすさも違います。

```eq
総保有費用 = 購入後の値下がり + 燃料・電気 + 保険・税・整備など
```

購入額全部を数える方法なら、最後に売って戻る金額を差し引きます。購入額と値下がりを、二重に足さないようにします。

| 比較するもの | 確かめること |
|---|---|
| お金 | 同じ年数・距離で比較する |
| 時間 | 運転・乗換え・待ち時間 |
| 生活への適合 | 荷物、天候、通れる道、駐車・充電 |

> 補足：ここでの式は比較のための整理です。時間の価値を費用に加えるときは、その前提も分けて書きます。

```quiz
Q: 車の総保有費用を比べるとき、適切なのは？
1: 購入価格だけを見る
2: 同じ利用期間や距離で、維持費と売却時の価値も考える
3: 購入価格と値下がりを常に両方まるごと足す
4: 燃料が安ければ保険や整備は不要と考える
C: 2
E: 長く使う費用を同じ条件で比べます。購入額から売却額を引くことと、値下がりを費用にすることを二重に数えないようにします。
```

## 2. 電動化は、何を変える？

**電動化** は、動力を電気モーターへ移すこと。車だけでなく、スクーターや自転車にも関わります。

| 型 | 大まかな違い |
|---|---|
| バッテリー式（BEV） | 外から充電した電池で走る |
| 外からも充電できるハイブリッド（PHEV） | エンジンと電気を使う |
| 燃料電池式（FCEV） | 水素などから電気を作って走る |

静かさや、走行時の排気の少なさが利点になる一方、価格・充電設備・電池の寿命などが課題です。環境への影響も、発電や電池の製造を含めて見ます。

**電気で走ることと、自動で運転することは別です。**

```quiz
Q: 電動車の環境への影響を見るときに必要なのは？
1: 排気管がなければ全過程の負担がゼロとする
2: 電動車はすべて完全自動運転とする
3: 走行中だけでなく、発電や電池製造も考える
4: どの国でも必ず同じ電気が使われるとする
C: 3
E: 走行中の排出だけでなく、車や電池の製造、電気を作る方法も影響します。自動運転は別の技術です。
```

## 3. 自動運転の「できる」は、どの条件で？

運転支援と、条件内でシステムが運転を担うことは違います。レベルが高くても、道路や天候などの条件に制限がありえます。

| 区分の目安 | 誰が運転を監視・担当する？ |
|---|---|
| レベル0〜2 | 人が運転を担当・監視する |
| レベル3 | 条件内ではシステム。求められたときの引継ぎが必要 |
| レベル4 | 決められた運行条件内で、システムが対応する |
| レベル5 | 人が運転できる広い条件に対応する完全自動運転の区分 |

> 補足：自動運転の区分を整理した学習用の表です。「今どの地域でどの車が使えるか」は、この講義資料だけで最新状況を断定できません。

```flow
周囲を捉える → 状況を予測・判断する → 車を動かす
```

センサーやAIだけでなく、道路・通信・安全・責任のルールも必要です。

```quiz
Q: 運転支援のレベル2で、運転の監視を担うのは？
1: どんな状況でもシステムだけ
2: 道路を管理する人だけ
3: 乗客全員が交代で必ず担当する
4: 運転する人
C: 4
E: 運転支援は、運転者が監視する前提です。条件つきの自動運転や、運行条件が限定された高いレベルとも区別します。
```

## 4. 乗り物を持つ代わりに、移動を組み合わせる

自転車を借り、バスへ乗り、必要ならタクシーを使う。出発から到着までの移動を、連続したサービスとして考えるのが **MaaS（サービスとしての移動）** です。

```flow
出発 → 借りた自転車 → 公共交通 → 到着
```

| サービス | 違い |
|---|---|
| 車両の共有 | 借りた人が運転する |
| 相乗り | 同じ車を複数の利用者で使う |
| 配車サービス | 車と運転者を呼んで利用する |

乗換え・予約・料金やデータの連携が重要です。1つのアプリに並べるだけで、すべての移動が便利になるとは限りません。

```quiz
Q: MaaSで重視するのは？
1: 複数の手段を、移動の目的に合わせてつなぐこと
2: 全員が車を所有すること
3: すべての道路を無料にすること
4: 乗り物の種類を1つに限定すること
C: 1
E: 所有だけでなく、必要な移動を途切れずに実現することに注目します。データや料金、事業者どうしの連携も必要です。
```

## 5. 渋滞の時間は、誰が負担する？

自分の車が混む道へ入ると、ほかの人の待ち時間も増えます。その負担を自分の判断に十分含めていないことが、**交通の外部性** です。

```flow
自分が車で入る → 道が混む → ほかの人の時間や環境にも負担
```

道路を増やしても、便利になって車の利用が増え、混雑が戻ることがあります。混む時間や場所に料金をつけ、ほかの人への負担を判断に含めるのが **混雑料金** です。

時間の変更や相乗り、公共交通と組み合わせて考えます。料金収入の使い方や、代わりの手段がない人への影響も重要です。

```quiz
Q: 混雑料金が目指すことは？
1: 車の購入価格だけを高くする
2: 他人へ生じる混雑の負担も、利用の判断に含める
3: すべての移動を禁止する
4: 料金を取れば代替交通は不要になる
C: 2
E: 自分だけの便利さでは見えにくい負担を、利用の判断へ反映する考えです。制度の効果や公平さも確かめます。
```

## 6. 新技術だけで、混雑は消える？

自動運転で移動中に休めるようになれば、長い移動を選ぶ人も増えるかもしれません。相乗りが広がれば車を減らせても、車を呼びやすくなったため利用が増える可能性もあります。

**1台が賢くなることと、街全体が混まなくなることは別です。** 効率的な経路や相乗りと、料金などの制度を合わせて考えます。

```quiz
Q: 自動運転が普及すれば、混雑は必ずなくなる？
1: 必ずなくなる
2: 道路の容量が無限になる
3: 移動の需要も変わるので、必ずとはいえない
4: 人が運転しなければ車の台数は無関係になる
C: 3
E: 移動の負担が下がると利用が増えることもあります。技術と、混雑の負担を反映する制度を一緒に見る必要があります。
```

## 7. 電動車に補助金を出す理由は？

社会にとっての利益が、買う人や作る人だけの利益より大きい場合、補助を考える理由があります。

- 汚染を減らすことが、周囲の人の健康などにも役立つ。
- 生産経験から得た知識が、ほかの会社にも広がる（学習の波及）。

ただし、「新しい」「作る量が増えると安い」だけで、補助が必ず必要とは決まりません。どの市場の失敗を、いくらの費用で直すかを確認します。

効果が薄れたり条件が変わったりすれば、対象や金額を見直します。

```quiz
Q: 補助金を考える経済学的な理由として適切なのは？
1: 新技術には無条件で永久に補助すること
2: 人気がある商品なら必ず補助すること
3: 生産者が希望した金額をそのまま支払うこと
4: 本人以外にも利益があるのに、十分に普及しない場合
C: 4
E: 外部性など、市場だけでは適切な量にならない問題が根拠になります。補助の費用、効果、変化する必要性も検証します。
```

## 8. 持ち帰る考え

移動を選ぶときは、**自分の総費用・時間と、周囲への負担**を分けて見られます。新技術は、使い方や制度と組み合わせて評価します。

# 開かれた社会と21世紀 12講 ― まちづくりの計画と実行

韓国の放送大学「開かれた社会と21世紀」12講（講義資料28ページ）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
準備する → 調べて分析する → 目標の姿と作戦を決める → くわしい計画を立てる → やってみて、ふり返る
```

## 0. ひとことで
まちづくりは、**住民が自分で参加し、決め、動く** 計画。上から専門家が決める計画とはちがう。
進め方はだいたい **5つの段階**。でも、どのまちも同じ手順でやるわけではなく、**まちに合わせて、ゆっくり、みんなで** 進める（「のろのろの哲学」）。

## 1. まちの約束（マウル議題）と、まちづくりの計画
- **まちの議題**（マウル議題）：まちの単位で、**長く続くまちのために何をするか** を具体的に書いたもの。
- 目標は **「幸せに、元気に、ずっと暮らすこと」**。そのために必要な3つ：
  1. 住民のつながり（地域共同体）を作る
  2. まちらしさ（アイデンティティ）を守り、育て、受けつぐ
  3. 自然といっしょに、みんなで仲よく暮らす

| 言葉 | 意味 |
|---|---|
| まちづくりの **企画** | まちの「こうなりたい未来」を決め、そこへ行く道すじを選んでいく流れ |
| まちづくりの **計画** | 企画から生まれた、くわしい実行の中身。まちの人・物・中と外・形のあるもの・ないもの、すべての資源を使う |

- この計画は **住民が主役**（住民主導型）。専門家が上から決める計画や、形だけ住民に聞く計画とはちがう。

```quiz
Q: 講義でいう「まちづくり計画」の特徴として、正しいのは？
1: 専門家が技術を中心に、上から決める
2: 住民の意見は形だけ聞けばよい
3: 住民が参加し、決め、実行する、住民主導の計画
4: 役所が一度決めたら変えない
C: 3
E: まちづくり計画は住民主導型。ほかの選択肢：1は昔の「上からの計画」。2は形だけの住民参加で、講義はこれと区別している。4は、まちに合わせて見直すという考えに合わない。
```

## 2. いろいろな手順の例
まちの特徴・住民・関心ごとがちがうので、手順も1つではない。講義はお手本を3つ紹介した。

**日本の「まちづくりデザインの流れ」**（日本建築学会、2002年）
| 段階 | すること |
|---|---|
| ① まちを調べる | 歩いて調べる、資料を調べる、前の計画を見直す |
| ② 分析して評価する | 良いところ・弱いところ・問題をまとめ、めざす姿をキーワードにする |
| ③ 未来の姿を考える | 目標の姿（ビジョン）と、全体の大きな図（マスタープラン）を作る |
| ④ まちの空間をデザインする | 地区・道・場所をどう変えるか、くわしく決める |
| ⑤ まちのルールを作る | 未来の姿を実行する組織や、決まりを作る |

**釜山のまちづくりマニュアル（7段階）**：仲間づくり（パートナーシップ）→ まちの分析 → 目標の姿を決める → 取り組むことを選ぶ → 作戦を立てる → 実行 → 結果をふり返って次に生かす

> 補足：釜山マニュアルの1段階めには、「まちのリーダー塾（マウルリーダーアカデミー）」でリーダーを育てることや、主な人たちの関心ごとを地図にすること（マッピング）が入っている。

## 3. 5つの段階（講義のまとめ）
```flow
① 準備 → ② 調査・分析 → ③ 目標の姿と作戦 → ④ くわしい実行計画 → ⑤ 実行とふり返り
```

### ① 準備
住民が「まちづくりが必要だ」と感じ、仲間を広げる準備。
- まちのあらまし、リーダー（公式の人も、そうでない人も）、困りごと、住民の願いを知る
- 住民の話し合いの会（懇談会）、リーダー塾、必要性を共有するワークショップ
- まちづくりを進める会を作る
- 大事な3つ：**調べて理解する**、**情報を分け合う**、**やる気を引き出す**（動機づけ）

### ② 調査・分析
まちの資源・まわりの環境・住民の願いを調べ、次の段階の土台を作る。
| 調べること | やり方 |
|---|---|
| **資源調査** | 形のあるもの・ないものを種類ごとに探して分ける。資源の図鑑を作る |
| **まちの環境分析** | まち歩き、**まちの地図づくり**、**SWOT分析**、ワークショップ |
| **住民の願いの調査** | アンケート、インタビュー、**マインドマップ**（考えを地図のように絵にする） |

- いろいろな人（専門家・まちのリーダー・役所の人）が参加できるが、**いちばん大事なのは、たくさんの住民の参加**。
- 考えのちがいを知り、ゆずり合い、合意をつくるきっかけになる。

> 補足：**SWOT分析** は、まちの **強み（S）・弱み（W）・チャンス（O）・おびやかすもの（T）** の4つを書き出して、進む方向を考える方法。

```quiz
Q: まちの強み・弱み・チャンス・おびやかすものの4つを書き出して、進む方向を考える方法は？
1: マインドマップ
2: SWOT分析
3: ストーリーテリング
4: 評価会
C: 2
E: SWOT分析。強み（S）、弱み（W）、チャンス（O）、おびやかすもの（T）。ほかの選択肢：1は考えを地図のように絵にする方法。3はまちの物語を作って伝える方法。4は実行のあとのふり返りの会。
```

### ③ 目標の姿と作戦（ビジョンと実践戦略）
- 調べた結果をまとめて、住民がのぞむ **未来の姿（ビジョン）** と方向を決める。
- 大事なキーワードで **まちのテーマ** を決め、それをもとに **作戦（実践戦略）** を立てる。作戦は「目標への道しるべ（ガイドライン）」。
- やり方：ブレインストーミング、SWOT分析、できるかどうかの評価（妥当性評価）、ワークショップ、まち会議、住民説明会、現場フォーラム。
- **だれか1人が勝手に決めたり、あせって決めたりしない**。住民が自由に意見を言い、みんなが納得することが大事。

### ④ くわしい実行計画
- **だれが・いつ・どうやって・だれと** やるかを決める、いちばんくわしい段階。
- 大事さ・できるかどうか・お金・ほかの事業とのつながりを見て、**順番（優先順位）** をつける。
- 実行する組織を作る。**まちの約束（まち規約）**、まちの会社なら **定款** など、守るルールを作る。
- することの例：組織とお金の計画、話し合う場所や連絡の手段、住民の勉強会、宣伝、**ストーリーテリング**（まちの物語を作って伝える）。

### ⑤ 実行とふり返り
- 役所の担当、まちづくりを手伝う団体（中間支援組織）、その事業だけの組織などで、「まちの公募事業」「住民提案事業」として行う。
- 住民・専門家・自治体が **協力して** 進める。
- 新しい資源とまちの資源が合わさって、**住民の意識・暮らしの心地よさ（アメニティ）・まちの経済** といった、**まちの信頼のつながり（社会関係資本）** が育つ。
- 思わぬ問題やもめごとは、**早めに見つけて、みんなで解決** する。
- **ふり返り（評価）** で見ること：目標を達成したか、住民はどれだけ参加したか、お金は正しく使われたか、住民は満足しているか。
- やり方：ふり返りの会（評価会）、アンケート、**まちのお祭り**（マウル祭り）。

```quiz
Q: 実行のあとのふり返り（評価）で、講義が見るべきとしたものに入らないのは？
1: 目標を達成したか
2: 住民がどれだけ参加したか
3: お金が正しく使われたか
4: 役所の担当者が何回表彰されたか
C: 4
E: 講義は、目標の達成・住民の参加・お金の使い方・住民の満足度を見るとした。ほかの選択肢：1、2、3はどれも講義があげた、ふり返りで見ること。
```

## 4. まちづくりの企画で大事なこと
- まちごとに、状況・資源・住民の力・外からの手伝いがちがう。だから **同じマニュアルをそのまま使うより、まちに合う手順** を選ぶ。
- 段階ははっきり分かれず、**つながり、重なり合う**。現場では2つの段階を同時に進めることも多い。
- まちづくりはいろいろな人の協力。まちの姿は **短い時間では変わらない**。
- だから **ともに生きる価値（共生）** と **「のろのろの哲学」**（ゆっくり進む考え方）で、協力と続ける力を大事にする。

## まず、この3つ
1. まちづくり計画は **住民主導**。目標は「幸せに、元気に、ずっと暮らすこと」。
2. 5つの段階：**準備 → 調査・分析 → 目標の姿と作戦 → くわしい実行計画 → 実行とふり返り**。
3. まちに合わせて、段階は重なってもよい。**ゆっくり、みんなで** 続ける。

## ひびきの暮らしでいうと
- 自分の3年計画も同じ形。**いまの自分を調べる → なりたい姿を決める → 作戦 → くわしい計画 → やってふり返る**。
- SWOT分析は、自分の強み・弱み・チャンス・不安を書き出すのにも使える。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。

```quiz
Q: 講義のまちづくりの5つの段階について、正しくないものは？
1: 準備の段階で、まちのリーダーや住民の願いを知る
2: 調査・分析の段階で、資源調査や住民の願いの調査をする
3: どのまちも、必ず同じマニュアルを同じ順番で使う
4: くわしい実行計画の段階で、だれが・いつ・どうやってするかを決める
C: 3
E: まちごとに状況がちがうので、まちに合う手順を選ぶ。段階は重なることもある。ほかの選択肢：1、2、4はどれも講義のとおり正しい。
```

```quiz
Q: まちの目標を達成するための大事な取り組みで、「道しるべ（ガイドライン）」の性格を持つものを（　）という。
1: 実践戦略（作戦）
2: マインドマップ
3: まちのお祭り
4: 資源図鑑
C: 1
E: 実践戦略は、ビジョンを実現するための中心の課題で、道しるべの役目をする。ほかの選択肢：2は考えを絵にする方法。3はふり返りの段階で使う方法。4は調査の段階で作るもの。
```

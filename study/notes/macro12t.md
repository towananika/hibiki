# 上級マクロ経済論 12講【会話で読む】― お札が増えると、豊かになる？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro12)」。

## 1. パンもお金も2倍になった？（5分）

```talk
B: お札が2倍になったら、豊かになる？
A: パンが1個100円の町で、お金の量だけが2倍になって、パンも200円になったとする。1,000円が2,000円になっても、買えるのはどちらも10個。
B: パンを作る力は？
A: 増えていなければ、お札が増えただけでは豊かにならない。
B: 名目と実質って？
A: お金で測った額が名目。物価を考えた購買力や量が実質。この講の「所得」は主に実質所得。
C: 名目が2倍でも、物価も2倍なら、実質は同じ。
```

```card
要点
- 名目：お金で測った額／実質：物価を考えた購買力や量
- お金も物価も2倍 → 買える量は同じ
```

## 2. 3つの市場を、同時に見る（5分）

```talk
B: 一般均衡って？
A: 労働・物・お金の3つの市場が、同時につり合うこと。労働の市場は雇用 N と実質賃金 w、物の市場は所得 Y と実質利子率 r、お金の市場は物価 P を決める。
B: 8〜11講とのつながりは？
A: 労働は10講、物は8・9講、お金は11講。ここで1つにまとめる。
C: 3つの市場が同時につり合う。
```

```card
要点
- 労働の市場：雇用 N・実質賃金 w
- 物の市場：所得 Y・実質利子率 r
- お金の市場：物価 P
- 一般均衡：3つが同時につり合う
```

## 3. 実際の量と、お金の数字はわかれている（5分）

```talk
B: このモデルの特徴は？
A: 所得・雇用・実質賃金・実質利子率（実質の量）は、お金と関係なく、労働と物の市場だけで決まる。お金の市場が決めるのは、物価（名目の量）だけ。
B: 名前は？
A: 古典派の二分法。その結果、お金の量を変えても実質の量は変わらない。これが貨幣の中立性。
B: 実質のお金は？
A: 実質のお金の量 ＝ 名目のお金の量 ÷ 物価。名目が2倍でも、物価が2倍なら同じ。
C: 実質と名目は別々に決まる。
```

```card
要点
- 古典派の二分法：実質の量は実物の市場、物価だけがお金の市場で決まる
- 貨幣の中立性：お金の量を変えても、実質の量は変わらない
- 実質のお金の量 ＝ 名目のお金の量 ÷ 物価
```

## 4. 実質利子率の決まり方（5分）

```talk
B: 実質利子率は、お金の市場で決まる？
A: ちがう。物の市場（資金の貸し借り）で決まる。貸付資金説という。
B: 何と何がつり合う？
A: 家計の貯蓄（出す側）＝ 会社の投資 ＋ 政府の赤字（使う側）。式は S(Y,r) ＝ I(r) ＋ (G−T)。
B: 記号は？
A: S は貯蓄、Y は実質所得、r は実質利子率、I は投資、G は政府の購入、T は税。
C: だから、お金の量を変えても、実質利子率は動かない。
```

```card
要点
- 貸付資金説：貯蓄 ＝ 投資 ＋ 政府の赤字 で、実質利子率が決まる
- 物の市場のつり合いを書き直しただけ
- お金の量を変えても、実質利子率は動かない
```

## 5. 総需要・総供給のモデルとのちがい（10分）

```talk
B: 以前のモデルと、何がちがう？
A: 3つ。①作り方：以前は消費や投資の決め方を仮定する。この講は、人や会社の最適な行動から導き出す。②お金：以前はお金が金利を通じて実質に影響する。この講はお金は中立。③値段と給料：以前は短期は給料が硬い。この講は短期でも自由に動き、いつもつり合う。
B: ①の理由は？
A: ルーカス批判。昔のデータで決めた式は、政策が変わると、人の予想や行動が変わるので、使えなくなる、という注意。
B: データを使うな、という意味？
A: ちがう。だから行動のルールを、最初から最適な行動で導いておこう、という考え。
C: 作り方・お金・値段と給料の3つ。
```

```card
要点
- ①導き出す（以前は仮定）／②お金は中立（以前は金利を通じて影響）／③短期でも自由に動く（以前は硬い）
- ②の理由：金利の決まり方が違う（この講は物の市場で決まる）
- ルーカス批判：政策が変わると、過去の関係が変わりうる
```

## 6. 政府の購入がふえると（10分）

```talk
B: 政府が道路工事をふやすと？
A: 物の買いたい量がふえる。さらに、このモデルでは、将来の増税を見こんで、家計は使えるお金が減ったと感じ、休みを減らして多く働く。
B: 変数はどうなる？
A: 所得 Y は必ずふえる。実質利子率 r は、資金の需要がふえるので上がるのが基本ケース。雇用 N はふえ、実質賃金 w は下がる。
B: 物価は？
A: お金の需要の考え方しだい。持ちたいお金が所得で決まると考える古典派では下がる。金利にも敏感だと考えるケインズの見方では上がることもある。
C: Y↑、r↑、N↑、w↓。
```

```card
要点
- 理由：将来の増税を見こむ → 労働供給がふえる
- 所得 Y は必ずふえる／実質利子率 r は上がるのが基本／雇用 N↑／実質賃金 w↓
- 物価はお金の需要の考え方しだい
```

## 7. お金の量をふやすと（5分）

```talk
B: 中央銀行がお金の量を2倍にしたら？
A: 物価 P も同じ割合で上がる（2倍）。所得・雇用・実質賃金・実質利子率は、何も変わらない。
B: 現実でも、そうなの？
A: 信じられていない。理由は2つ。実際のデータでは、お金の量は所得・消費・投資・雇用と同じ方向に動く。それと、金利は「お金の価格」なのに、お金の量が金利に関係しないという貸付資金説の結論は、納得しにくい。
C: モデルの中では中立、現実では疑わしい。
```

```card
要点
- お金の量2倍 → 物価2倍、実質の量は変わらない
- 現実で疑われる理由：お金の量が実質と同じ方向に動く／金利は「お金の価格」
```

## 8. 生産性がよくなると（5分）

```talk
B: 生産性がよくなったら？
A: 今よくなる場合は、労働の需要がふえて、実質利子率は下がる。雇用と所得はふえ、物価は下がる。
B: 将来よくなると予想したら？
A: 今のうちに設備を買うので、投資がふえる。実質利子率は上がる。雇用と所得はふえ、物価は下がる。
B: 利子率と働き方は？
A: 利子率が上がると、今働いて休みを将来に回す。下がると、今休む。これが異時点間代替。
C: 今よくなる → r↓、将来よくなる → r↑。
```

```card
要点
- 今、生産性↑：労働需要↑、実質利子率↓、雇用・所得↑、物価↓
- 将来の生産性↑の予想：投資↑、実質利子率↑、雇用・所得↑、物価↓
- 技術の改善がいつも金利を下げる、という暗記はしない
```

## 9. 金融危機はこのモデルで説明できる？（5分）

```talk
B: 2008年のような危機は、説明できる？
A: 不安が広がり、土地や株が下がり、借りにくくなって、消費や投資が減る。実質利子率は下がり、労働供給が減って、雇用・所得が減る。
B: 実質賃金と物価は？
A: モデルの答えは、実質賃金と物価は上がる。
B: 現実と合う？
A: 消費・投資・所得・雇用が減るのは合う。でも、物価と実質賃金が上がるのは合わない。実際は給料が上がらず、物価も上がらない・下がった。
C: 「借りにくくなる」を足しただけでは、不況は説明しきれない。
```

```card
要点
- モデルの答え：消費・投資・所得・雇用↓、実質賃金・物価↑
- 合う：消費・投資・所得・雇用が減る
- 合わない：物価・実質賃金が上がる
```

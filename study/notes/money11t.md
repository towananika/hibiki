# 貨幣金融論 11講【会話で読む】― 人はなぜお金を持つ？（1）

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money11)」。

## 1. お金の需要ってなに？（5分）

```talk
B: 「お金の需要」って、どういうこと？
A: 中央銀行と銀行がお金を出す（供給）。家計・会社・政府が、お金を持ちたがる（需要＝貨幣需要）。
B: 何を調べるの？
A: 何が「持ちたいお金の量」を決めるのか。11講は昔の経済学（古典派）、12講はケインズたち。
C: 出す側が供給、持ちたい側が需要。
```

## 2. フィッシャーの式（5分）

```talk
B: フィッシャーは、何を言った人？
A: 1911年に、交換の式を出した。お金の量 × 1年に回る回数 ＝ 物価 × 買われた量。
B: 記号では？
A: M・V ＝ P・T。M＝お金の量、V＝回る回数（流通速度）、P＝物価、T＝買われた量。
B: 例は？
A: お米だけの国。年に10袋売れて、1袋10万ウォンなら、買い物の合計は100万ウォン。お金が50万ウォンなら、年に2回使われればいい。20万ウォンなら5回。
B: V は変わる？
A: フィッシャーたちは、給料日の決まりや使い方のくせで決まるから、短い間は変わらないと考えた。
C: V が変わらないなら、物価はお金の量だけで決まる。
```

```eq
お金の量 M × 回る回数 V = 物価 P × 買われた量 T
```

```card
要点
- M・V ＝ P・T（交換の式、貨幣数量説）
- V（流通速度）は、制度やくせで決まり、短い間は変わらない
- だから、国の稼ぎが増えると、持ちたいお金も同じ割合で増える
```

## 3. 式を使いやすくする（5分）

```talk
B: T（買われた量）は、数えにくいね。
A: 株や家や中古品まで入るからね。そこで、国全体で作ったものの量（実質国民所得 y）に置きかえる。
B: すると？
A: M・V ＝ P・y。P×y は、その年の値段で数えた国の稼ぎ（名目国民所得 Y）。
B: 持ちたいお金は？
A: M ＝ (1/V)・Y。お金の量 ＝ 国の稼ぎ ÷ 回る回数。
C: 小文字のyは実質、大文字のYは名目。
```

```card
要点
- T を y（実質国民所得）に置きかえる：M・V ＝ P・y
- P×y ＝ 名目国民所得 Y
- 持ちたいお金 M ＝ (1/V)・Y
```

## 4. ケンブリッジ学派の考え（10分）

```talk
B: ケンブリッジ学派は、何がちがうの？
A: お金の役目を2つ考えた。買い物の道具（交換の仲立ち）と、財産をためる箱（価値の保存）。
B: 式は？
A: Md ＝ k・Y。Md＝持ちたいお金の量、k＝稼ぎのうちお金で持つ割合、Y＝国の稼ぎ。k＝0.2なら、稼ぎの2割をお金で持つ。
B: V とのつながりは？
A: k ＝ 1 ÷ V。お金が1年に6回回るなら、1回のお金は平均2か月、だれかの手元にとどまる。
B: 金利は関係する？
A: ここが大事。金利が上がると、利息のつく株や債券が得になる。お金をそっちへ移すので、k が減る。つまり、金利がお金の需要を動かすかもしれない、という考えが出た。これがケインズ（12講）につながる。
C: kは「手元にとどまる長さ」と考えるとわかりやすい。
```

```eq
金利が上がる → 株・債券が得 → お金を移す → k が減る
```

```card
要点
- お金の役目：買い物の道具＋財産をためる箱
- 持ちたいお金 Md ＝ k・Y。k ＝ 1 ÷ V
- 金利が上がると、k は減る → 次のケインズの考えのもと
```

## 5. 2つの考えのくらべ（5分）

```talk
B: 2つをくらべると？
A: フィッシャー（貨幣数量説）は、お金は買い物の道具。取引の量やくせで決まり、回る速さは短い間は変わらない。
B: ケンブリッジ学派（現金残高説、マーシャルとピグー）は？
A: 買い物の道具＋財産をためる箱。ある程度自分で選べて、金利も考える。回る速さは、得な財産に移すので、短い間でも変わる。
C: 変わらない速さ vs 変わる速さ。
```

```card
要点
- フィッシャー：道具／取引やくせで決まる／V は短期では不変
- ケンブリッジ：道具＋財産の箱／自分で選ぶ（金利も考える）／V は短期でも変わる
```

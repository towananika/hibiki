# 上級マクロ経済論 11講 ― お金と中央銀行の働き

**この講で覚えること：人は「すぐ使えるお金」をどれくらい持ちたいか。そして、国の銀行（中央銀行）がお金の量と金利をどう動かすか。**

```flow
すぐ使えるお金を持ちたい → 銀行が預金を作ってふやす → 国の銀行が金利で調整する → 景気と物価に届く
```

## 1. 貯金があっても、すぐ使えるお金は必要

家や株を100万円分持っていても、今日のスーパーの支払いには使えません。売るのに時間がかかるからです。
反対に、全部を財布の現金にしておくと、預けたり運用したりすればもらえた利子をもらいそこねます。

```flow
すぐ払える安心 → 手元にお金を置きたい → でも利子をもらいそこねる
```

- すぐ支払いに使えることを **使いやすさ**（流動性）といいます。
- お金の3つの役目：**買い物に使う**（交換の手段）、**価値をとっておく**（価値の保存）、**値段をはかる物差し**（価値の尺度）。

```quiz
Q: 財産をたくさん持っていることと、すぐ使えるお金を持っていることは同じ？
1: 同じ。財産は必ず全部現金で持つ
2: ちがう。家や株は、今日の支払いにすぐ使えるとは限らない
3: すぐ使えるお金を持っても、損は何もない
4: 預金はお金に数えない
C: 2
E: 家や株は売るのに時間がかかる。お金の需要は「すぐ使える形で持ちたい量」で、財産全体の量とはちがう。
```


## 2. 持ちたいお金の量は「収入」と「利子」で決まる

| こうなると | すぐ使えるお金を | わけ |
|---|---|---|
| 収入（所得）がふえる | もっと持ちたくなる | 買い物や急な出費がふえるから |
| 利子（利子率）が上がる | あまり持ちたくなくなる | 現金のままだと、もらいそこねる利子が大きくなるから |

ここで比べているのは、**利子のつかない現金** と **利子がもらえる債券（国や会社の借用書）** です。
> 補足：ふつうの預金もお金に数えることがあるので、「銀行に預けたらお金ではなくなる」わけではありません。

**まとめ：収入がふえると、持ちたいお金はふえる。利子が上がると、持ちたいお金は減る。**

ケインズという学者は、お金を持つ理由を3つに分けました（流動性選好説）。
1. **買い物のため**（取引的需要）
2. **急な出費にそなえて**（予備的需要）
3. **株や債券を買うタイミングを待つため**（投機的需要）

> 補足（式で書くと）：L(Y,i)。L＝持ちたいお金の量（実質貨幣需要）、Y＝収入（実質所得）、i＝利子（名目利子率）。

```quiz
Q: 利子が上がると、現金のまま持っておく「損」はどうなる？
1: もらいそこねる利子がふえるので、大きくなる
2: 現金が消えるので、大きくなる
3: 利子とは関係ないので、ゼロになる
4: 収入が同じなら、まったく変わらない
C: 1
E: 債券などにしておけばもらえた利子が大きくなるので、現金で持つ損も大きくなる。
```


## 3. 「お金の量」は、どこまで数えるかで変わる

財布の現金だけ数えるか、銀行の預金も数えるかで、合計はちがいます。数える範囲が広い順に、名前がついています。

```flow
せまい（M1） → 少し広い（M2） → もっと広い（Lf・L）
```

- **せまいお金（M1）**：現金と、いつでも出し入れできる預金。
- **少し広いお金（M2）**：M1に、定期預金なども足したもの。
- **もっと広いお金（Lf・L）**：さらにいろいろな金融商品まで足したもの。

> 補足：これは韓国の分け方です。M2には、ふつう満期2年未満の定期預金などが入ります。国によって範囲はちがいます。

```quiz
Q: せまいお金（M1）と少し広いお金（M2）の関係は？
1: まったく別のもので、重なりはない
2: M2はM1を全部ふくんだ、もっと広い範囲
3: M1は現金だけ、M2は金貨だけ
4: M2は国の銀行のお金だけ
C: 2
E: M2はM1に定期預金などを足したもの。数える範囲が広いだけ。
```


## 4. 中央銀行のお金と、銀行預金の違い

**ひとことで：お金には「中央銀行が出すお金」と「銀行が作る預金」の2種類がある。銀行は預金の一部だけを残して貸すので、預金は元のお金の何倍にもふくらむ。**

### 4-1. 2種類のお金
- **中央銀行が出すお金**（本源通貨）：みんなが財布に持つ現金と、銀行が中央銀行に預けて残しているお金（準備）。いわば「お金のもと」。
- **銀行の預金**：私たちの口座の数字。これも支払いに使えるお金。
- 銀行がだれかにお金を貸すと、借りた人の口座に預金ができる。つまり**銀行は貸すことで預金を作る**（信用創造）。

```eq
お金のもと = みんなの現金 + 銀行が残すお金
```

### 4-2. なぜ何倍にもふくらむ？（20%を残す例）
1. 最初に1,000の預金がある。銀行は20%の200だけ残し、800を貸す。
2. 借りた人がその800を別の銀行に預ける。その銀行も20%を残し、640を貸す。
3. これがくり返されて、預金はどんどん積み重なる。

```bars
最初の預金 | 1000 | 1,000 | b
次の預金 | 800 | 800 | s
その次 | 640 | 640 | w
```

**全部足すと、預金の合計は5,000に近づく。** 元の1,000の5倍。残す割合が20%（5分の1）だから5倍、と覚える。
> 補足：計算では 1,000 ÷ 0.2（残す割合）＝ 5,000。1,000に5,000を足すのではなく、合計が5,000。

ただし、これは「だれも現金を手元に持ち出さない」「銀行が余分に残さない」「借りたい人がいる」という条件のときの話。現実の銀行がいつもここまで貸すわけではない。

### 4-3. みんなが現金も持つと、ふくらみ方は小さくなる
- お金の一部を**財布に現金で持つ人**がいると、その分は銀行に戻らず、貸し出しに回らない。だから、ふくらむ倍率（**通貨乗数**）は小さくなる。
- 銀行が**多めに残す**ときも、貸す分が減るので倍率は小さくなる。
- 現金をどれくらい持つか、銀行がどれくらい残すかは、人や銀行の気持ちで変わる。だから**中央銀行がお金のもとを増やしても、世の中のお金が同じ割合で増えるとは限らない。**

> 補足（式で書くと）：倍率 m ＝ (c＋1) ÷ (c＋z)。c＝現金÷預金（みんなが現金で持つ割合）、z＝準備÷預金（銀行が残す割合）。世の中のお金 ＝ 倍率 m × お金のもと。c も z も大きいほど、倍率 m は小さくなる。

```quiz
Q: 単純な例で、最初の預金1,000、残す割合20%なら預金の合計は？
1: 合計1,200に近づく
2: 合計800に近づく
3: 合計5,000に近づく
4: 合計200に近づく
C: 3
E: 5,000に近づきます。現金の持ち出しや余分な準備がない、などの仮定があります。
```


## 5. 国の銀行（中央銀行）は、何を動かす？

いちばんの仕事は、**銀行どうしが1日だけお金を貸し借りするときの金利** を、ねらった高さに近づけることです。

```flow
国の銀行が金利を下げる → お金を借りやすくなる → 買い物や会社の投資がふえる
```

| 道具 | やさしく言うと |
|---|---|
| 国債の売り買い（公開市場操作） | 国の借用書を売ったり買ったりする。買うと、銀行の手元のお金がふえる |
| 銀行に貸すときの金利 | 国の銀行が銀行にお金を貸す条件を変える |
| 残す割合（支払準備率） | 銀行が預金のうち必ず残す割合を変える |
| 預け金への利子（付利） | 銀行が国の銀行に預けたお金につく利子を変える |

> 補足：銀行どうしの1日だけの貸し借りの金利を **コールレート** といいます。どの道具を中心に使うかは、国や時代でちがいます。

```quiz
Q: 国債の売り買い（公開市場操作）とは？
1: 政府がお店の値段を決めること
2: 全員の銀行口座を公開すること
3: 家族が株を買うこと
4: 国の銀行が国債などを売ったり買ったりすること
C: 4
E: 国の銀行が国債などを売り買いして、銀行の手元のお金や金利を動かす。
```


## 6. 金利を0近くまで下げても足りないとき

金利はふつう0より大きく下げにくい。これを **金利を下げられない壁**（ゼロ金利制約）といいます。そのときの特別な方法は3つ。

- **お金を大量に流す**（量的緩和、QE）：長い期間の国債などをたくさん買って、長い期間の金利も下げる。
- **先に約束する**（フォワード・ガイダンス）：「しばらく金利を低くします」と前もって言い、みんなの予想に働きかける。
- **金利をマイナスにする**（マイナス金利）：銀行が国の銀行に預けたお金の一部に、逆に手数料のような利子をかける。

> 補足：少しならマイナスにもできるので、「0より下は絶対にむり」という意味ではありません。

韓国は1998年から、「物価の上がり方はこのくらいにします」と目標を決めて動いています（物価安定目標制）。
> 補足：似た方法に「物価の高さそのもの」を目標にするやり方（物価水準目標制）もあります。こちらは、前に目標からずれた分も取り戻そうとします。

```quiz
Q: 先に約束する方法（フォワード・ガイダンス）は、何に働きかける？
1: 今月の税金だけ
2: お札の色
3: お店の値札を直接決める
4: これから先の金利についての、みんなの予想
C: 4
E: 「しばらく低い金利を続けます」と伝えて、人々の予想を通して金利や行動を動かす。
```


## 7. 金利を下げると、5つの道で景気に届く

| 道 | 金利を下げたときに起こりそうなこと |
|---|---|
| 借りる | ローンが楽になり、買い物や会社の投資がふえる |
| 株や家 | 値段が上がり、気が大きくなってお金を使う |
| お金の交換（為替） | ウォンが安くなり、輸出がふえる |
| 銀行が貸す | 銀行がお金を貸しやすくなる |
| 予想 | 「低い金利が続く」と思われ、長い期間の金利も下がる |

どの道も、いつも同じ強さで効くわけではありません。物価に届くまで時間もかかります。

```quiz
Q: 金利を下げたら、すぐに物価が上がる？
1: いくつもの道を通るので、時間がかかる
2: 下げた瞬間に必ず上がる
3: 金利は物価にまったく関係ない
4: 必ず物価が2倍になる
C: 1
E: 買い物・投資・予想などの道を通って、時間をかけて届く。
```


## 8. まず、この3つ

1. 持ちたいお金とは「すぐ使える形で持ちたい量」。財産全体の量ではない。
2. 国の銀行が出すお金（お金のもと）と、私たちの銀行預金は分けて考える。
3. 国の銀行は金利を動かし、その効き目は借りる・株や家・為替・貸し出し・予想の道を通って、景気と物価に届く。

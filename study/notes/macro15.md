# 上級マクロ経済論 15講 ― 国はどうやって豊かになる？

韓国の放送大学「上級マクロ経済論」15講（最終回）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

**この回の答え：機械や設備をふやすだけでは、成長はいつか止まる。ずっと成長できるのは、技術が進み続けるときだけ。その技術がどう生まれるかまで説明するのが、新しい成長の考え方（内生的成長理論）。**

```flow
データを見る → 成長の中身を分ける → ソローの考え → 新しい考え（AK・R&D）
```

## 1. データで分かっていること
| | 分かっていること |
|---|---|
| ① | 1人あたりの所得と設備は、いっしょにふえてきた |
| ② | 投資の割合（投資率）が高い国ほど、1人あたり所得が高い |
| ③ | 人口のふえ方（人口増加率）が大きい国ほど、1人あたり所得が低い |
| ④ | 貧しい国と豊かな国の差は**ちぢまらない**。豊かな国（OECD）どうしではちぢまる |
| ⑤ | 成長の速さは国によって大きくちがう |

## 2. 成長の中身を分ける（成長会計）
- 量で伸びる（外延的成長）：設備や人を**たくさん入れる**。いつか限界がくる。
- 質で伸びる（内包的成長）：**技術**を上げる。限界が少ない。

```eq
所得の伸び = 技術の伸び + α×設備の伸び + (1−α)×人の伸び
```
- α ＝ 所得のうち設備の取り分。1−α ＝ 人（労働）の取り分。
- 技術の伸びは直接は測れないので、**引き算の残り**で出す（ソロー残差）。技術以外の原因もまざる。
- 韓国など東アジアの速い成長は、**主に量で伸びた**ものだった（ヤングら）。

## 3. ソローの考え（ソロー・モデル）
- 設備を積み上げて成長する、という代表的な考え。
- 毎年、所得の一部を貯金して設備にする。でも人口がふえる分と、設備が古くなる分は、うめないといけない。

```eq
新しくふやす設備 = 人口増と古くなる分をうめる設備
```
- 正式には **s×z×f(k) ＝ (n＋d)×k**（s＝貯金の割合、k＝1人あたり設備、n＝人口のふえ方、d＝古くなる割合）。
- 左と右が同じになると、1人あたりの設備・所得はもうふえない（定常状態）。
- 止まる理由：設備をふやすほど、1台ふやしたときの効き目が小さくなるから（資本の限界生産の逓減）。

### 3.1 何が変わると、どうなる？
| できごと | 1人あたり所得の**高さ** | ずっと続く**伸び** |
|---|---|---|
| 貯金の割合が上がる | 上がる | ない |
| 人口のふえ方が大きくなる | 下がる | ない |
| 技術が**進み続ける** | 上がり続ける | **ある** |

- **ずっと成長できるのは、技術が進み続けるときだけ。**

### 3.2 データとくらべる
| ソローの答え | データ |
|---|---|
| 貯金が多いと豊か、人口増が大きいと貧しい | ②③と合う ○ |
| 貧しい国は速く伸びて、豊かな国に追いつく（収束） | ④と合わない ✕ |

- 条件（貯金の割合・人口のふえ方・技術）が同じ国どうしなら追いつく ＝ 条件つき収束。豊かな国どうしで差がちぢまるのは、これで説明できる。

### 3.3 ソローの2つの弱いところ
1. 技術の進み方は、考えの**外**で決まる（外生的成長理論）。だから研究開発や国の産業の後押しの効果を説明できない。
2. 国ごとの差を説明しにくい（みんな追いついてしまう）。
- 原因はどちらも同じ：**ふやすほど効き目が小さくなること**（資本の限界生産の逓減）。

## 4. 新しい成長の考え（内生的成長理論）
- 技術や知識の伸びを、考えの**中**で説明する。

### 4.1 知識のとくちょう（ローマー）
- 一度知られると、だれでもただで使える（非競合性）。
- 使わせないようにできる知識（特許・有料ソフト）と、できない知識（ピタゴラスの定理）がある（不完全な排除可能性）。
- 使わせないようにできない知識は、作った人の得が社会の得より小さい（外部性）。

### 4.2 2つの型
| 型 | 考え方 |
|---|---|
| AK モデル | みんなの知識が上がると、どの会社の生産性も上がる（知識の外部性）。だから国全体では効き目が**へらない** |
| R&D モデル | 研究開発の部門が、特許などで守れる知識を**わざと**作る |

```eq
AK： y = A×k
```
```eq
R&D： 所得の伸び = a × λ × N
```
- AK：貯金の割合や人口のふえ方が、所得の**高さではなく伸び**を決める（ソローと反対）。
- R&D：a＝研究の効率、λ（ラムダ）＝研究で働く人の割合、N＝人口。研究開発がソローの「貯金」の役をする。
- どちらも、**ずっと成長できる**こと、**国ごとの差がちぢまらない**ことを説明できる。

## 5. くらべる
| | ソロー | AK | R&D |
|---|---|---|---|
| ふやしたときの効き目 | へる | へらない | へる |
| ずっと続く成長 | 外からの技術が必要 | 中で説明 | 中で説明 |
| 国の差がちぢまる？（収束） | する | しない | しない |

## 6. まとめ（6点）
1. データ：投資が多い国は豊か、人口増が大きい国は貧しい。貧しい国と豊かな国の差はちぢまらない。
2. 成長は「量で伸びる」と「質（技術）で伸びる」に分けられる。技術の分は引き算の残り（ソロー残差）。
3. ソロー：設備をふやすほど効き目が小さくなるので、成長はいつか止まる（定常状態）。
4. 貯金の割合や人口は、所得の高さだけを変える。ずっと伸びるのは技術が進むときだけ。
5. ソローは技術を外で決める（外生的）ので、国の差もずっと続く成長もうまく説明できない。
6. 新しい考え：AK（知識の外部性で効き目がへらない）、R&D（研究開発で技術を作る）。

## 8. 自分の暮らしにつなげる
- 働く時間をふやす（量で伸びる）には限界がある。新しい知識や技術を身につける（質で伸びる）ほうが、ずっと伸び続けられる。

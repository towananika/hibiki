# 世界の宗教 12講 ― 韓国：歴史の変化と、日々の実践

**社会が変わるとき、宗教は人々の暮らしにどう関わった？**

第11講は日本での宗教の出会いでした。今回は韓国です。東学・天道教、円仏教、大倧教を分け、教えと生活、歴史とのつながりを見ます。

配布資料は見出し中心です。背景や用語の説明は学習用補足であり、講義音声の再現ではありません。

## 1. 東学：教えと農民運動を分けて見る

東学は、19世紀の朝鮮で生まれた宗教運動です。補足すると、1860年に崔済愚（さいせいう）が始めました。資料では、東学の農民軍が掲げた四つの原則を紹介しています。

| 原則の内容 | 何を目指したか |
|---|---|
| むやみに人を殺さず、財産を奪わない | 人や暮らしを守る |
| 忠・孝を重んじ、世を救い民を安んじる | 社会を立て直す |
| 外部勢力を退ける | 当時の対外的な危機に応じる |
| 軍を率いて都へ進み、権力者を倒す | 当時の政治を変える |

これは**歴史上の運動が掲げた原則**の説明です。現代の行動指示ではありません。また、宗教としての東学と、東学に関わる農民の武装運動を、完全に同一視しないことが大切です。

```flow
当時の社会の困難 → 教えを支えに人々が集まる → 政治や社会への運動にもつながる
```

```quiz
Q: 資料の東学農民軍の原則を読むときに適切なのは？
1: 現代の読者への政治的な行動指示として受け取る
2: 宗教の信徒は、全員必ず武装したと考える
3: 当時の運動の目標として読み、宗教全体と運動を区別する
4: 東学には、社会との関わりがなかったと考える
C: 3
E: 宗教の成立、信仰の実践、歴史上の運動は関わりますが、同じ範囲を指すわけではありません。
```

## 2. 天道教：信仰を日常で続ける

天道教は、東学の流れを受け継ぐ宗教です。資料の**五つの義務**は、信仰を祈りや生活の中で続けるための実践として整理できます。

| 名称 | やさしい説明 |
|---|---|
| 三七呪（さんしちじゅ） | 21文字からなる祈りの言葉を唱える |
| 清水奉奠（せいすいほうてん） | 清らかな水を供える |
| 侍日儀礼（じじつぎれい） | 定められた礼拝の日の儀礼 |
| 誠米（せいまい） | 信仰のために米を取り分けて供える |
| 祈祷（きとう） | 祈る |

> 補足：名称は漢字に置き換えて示しています。三七呪の「三七」は21文字のこと。ここでは「必ず21回唱える」という回数の意味にしません。

```flow
祈りの言葉 → 水や米を供える日々の実践 → 礼拝や祈りを続ける
```

図は覚えるための並べ方であり、すべてをこの順で行うという儀式の手順ではありません。

```quiz
Q: 天道教の五つの義務の捉え方として適切なのは？
1: 祈りや供え物、礼拝を通じて信仰を日常で続ける実践
2: 東学農民軍の四原則を五つに数え直したもの
3: 全員が農業だけを仕事にするという規則
4: 三七呪を一日に必ず21回唱えるという意味だけ
C: 1
E: 五つは、日常と信仰をつなぐ実践として整理できます。農民軍の原則とは別の項目です。
```

## 3. 円仏教：暮らしの中で学び、行動する

円仏教は、20世紀に朝鮮半島で生まれた宗教です。資料には**四恩四要・三学八条**という教えのまとまりが出てきます。最初から全部の名称を暗記するより、生活との結びつきをつかみましょう。

補足すると、四恩は、天地・父母・同胞・法律という、自分の生活を支える関係への恩を考えるものです。四要は、その実践上の重要な方針です。

三学は、次の三つを結びつけて考えると理解しやすくなります。

| 名称 | 入口となる説明 |
|---|---|
| 精神修養 | 心を整える |
| 事理研究 | ものごとの道理を調べ、考える |
| 作業取捨 | 行動の中で、何を行い何を控えるか選ぶ |

```flow
心を整える → 道理を考える → 行動を選ぶ → また見直す
```

これは学びの関わりを示す図です。三学は、一度ずつ終わらせる作業ではありません。八条は修行に関する八つの項目で、この資料には個別の説明がありません。

```quiz
Q: 円仏教の三学を、やさしくまとめたものは？
1: 祈りの言葉・清水・誠米
2: 創造・維持・破壊
3: 都への進軍・外部勢力の排除・武装
4: 心を整える・道理を考える・行動を選ぶ
C: 4
E: 三学は精神修養・事理研究・作業取捨です。作業取捨を「仕事をすべて捨てる」と読み違えないようにします。
```

## 4. 大倧教：宗教と民族の歴史

資料は大倧教（だいそうきょう）と、抗日武力闘争との関わりを挙げます。背景として、大倧教は檀君を重んじる宗教です。

> 補足：檀君は、朝鮮の始まりに関わる伝承上の人物です。信仰の中での位置づけと、歴史学的に確認できる事実は区別します。

ここで押さえるのは、宗教が個人の内面だけでなく、民族意識や政治の歴史とも関わりうることです。宗教全体を武力闘争だけに置き換えて理解しないようにしましょう。

```quiz
Q: この資料で大倧教について示される歴史的な関わりは？
1: 日本の神仏習合の成立
2: 抗日武力闘争との関わり
3: インドのヴィシュヌ信仰の成立
4: 中国の道徳経の編纂
C: 2
E: 資料7ページの項目です。宗教の教え全体と、歴史上の政治・社会との関わりを分けて学びます。
```

## 5. 仏教・プロテスタント・カトリックも見る

資料は、外来宗教の展開として、近代の仏教・プロテスタント・カトリックにも触れます。仏教が近代に初めて朝鮮半島へ入った、という意味ではありません。古くから伝わった宗教が、近代にも変化を経験したという区別が必要です。

**成立した場所・伝来した時期・後の変化**を分けると、混乱が減ります。韓国の人が全員同じ宗教を信じているわけでもありません。

```quiz
Q: 「近代の仏教」という項目の読み方として適切なのは？
1: 仏教が朝鮮半島へ初めて伝わったのは近代だと決める
2: 仏教とキリスト教は、同じ宗教の別名だと考える
3: 古くから伝わった仏教にも、近代の展開があると捉える
4: 韓国では仏教以外の信仰は存在しないと考える
C: 3
E: 伝来した時期と、後の時代に起こった変化を区別します。
```

## 6. 北朝鮮について、資料からどこまで言える？

配布資料には「北朝鮮の宗教」という見出しがありますが、制度・人数・信仰生活などの詳しい説明はありません。そのため、この資料だけで現在の状況を断定することはできません。

国の制度、宗教団体の活動、個人の信仰は、調べる対象が異なります。**書かれていない内容を、書かれているように補わない**ことも学びの一部です。

```quiz
Q: この資料だけを使った説明として適切なのは？
1: 北朝鮮の宗教は見出しのみなので、現在の詳しい状況は別の資料で確認する
2: 見出しが短いので、信仰する人はいないと断定する
3: 見出しがあるので、完全な信教の自由が確認できる
4: 現在の信徒数を、この資料から計算できる
C: 1
E: 見出しから詳しい現状を推測しません。情報の範囲を意識して読む問題です。
```

# 上級マクロ経済論 14講 ― 値段がすぐ変わらないと、何が起こる？

**売れなくなったとき、値段をすぐ下げられないなら、店は作る量や人手を減らすことがあります。** この講は、その「調整に時間がかかる」話です。

## 1. パンが売れなくなった

いつも100個売れるパンが、今日は70個しか売れないとします。パン屋がすぐ値段を変えられないなら、翌日は作る量を減らし、必要な人手も減らすかもしれません。

```flow
買いたい量が減る → 値段はすぐ変えない → 作る量を減らす → 人手も減らす
```

値段や給料が変わりにくいことを **硬直性（こうちょくせい）** といいます。「絶対に変わらない」ではなく、変わるまでに時間がかかるという意味です。

第13講は、つり合う場所自体が動く話でした。第14講は、価格調整が遅いため、生産や雇用が本来の水準から外れる話です。

```quiz
Q: 硬直性とは、絶対に変わらないこと？
1: 調整に時間がかかること
2: 永久に変わらないこと
3: 値段が必ず毎日変わること
4: すべての値段が同じになること
C: 1
E: 違います。値段や給料の調整に時間がかかる、という意味です。
```


## 2. 給料の「額」が変わりにくい場合

月給が20万円で決まっているとします。物価が下がれば、同じ20万円でも前より多くの物を買えます。

```eq
実質賃金 = 給料の額 ÷ 物価
```

働く人にとっては購買力が上がります。でも、会社の商品の売値が下がり、給料の額がそのままなら、会社にとって人を雇う負担は重くなります。

```flow
需要が減る → 売値が下がる → 給料の額はそのまま → 雇う負担が重くなる → 雇用が減る
```

この仕組みを **名目賃金が硬直的なモデル** といいます。名目賃金は、物価で調整する前の給料の額です。

### 給料を決め直す時期も違う

会社ごとに契約の更新月が違うと、経済全体の給料は一度には変わりません。さらに、ほかの人との給料の差を気にすると、調整が長引くことがあります（テイラーの重複賃金契約モデル）。

弱点は、この単純な説明だと「不況で実質賃金が上がる」方向になることです。第13講で扱った、好況で実質賃金が上がるデータとは合いにくくなります。

```quiz
Q: 月給が同じで物価が下がると、実質賃金は？
1: 実質賃金は下がる
2: 実質賃金は上がる
3: 実質賃金は必ず同じ
4: 名目賃金も自動的に2倍になる
C: 2
E: 上がります。同じ月給で買える物が増えるからです。
```


## 3. 給料の「買える力」が変わりにくい場合

今度は、会社が実質の給料を高めに保つ場合です。人材が辞めにくくなったり、仕事への意欲が高まったりするなら、会社にも理由があります（**効率賃金**）。

ただし、その高い給料では、会社が全員を雇うとは限りません。働きたいのに働けない **非自発的失業** が残りえます。

- 生産性が上がる → 同じ給料でも雇う価値が高まり、雇用と生産が増える方向。
- 買いたい量だけが増える → この単純なモデルでは、雇用や生産は増えない。

そのため、縦軸が実質利子率・横軸が生産の図では、実質総供給曲線が垂直になります。給料が実質で一定だとする、このモデルでの結果です。

```quiz
Q: 効率賃金を払う会社でも、働きたい人を全員雇うとは限らないのは？
1: 給料が高いと従業員が全員辞めるから
2: 実質賃金と名目賃金が常に同じだから
3: 会社は生産を一切考えないから
4: 高い給料では、必要な雇用量が限られることがある
C: 4
E: 人材を保つなどの理由で高めの給料を払っても、その給料で採算が合う雇用量には限りがあり、非自発的失業が残りえます。
```


## 4. 商品の値段が変わりにくい場合

値札だけでなく、メニュー・広告・契約なども変える手間があります。値段を変える費用を **メニューコスト** といいます。

値段が据え置きで、注文を増やせば対応できる余力があるなら、注文が増えた店は生産を増やします。注文が減れば、生産を減らします。

```flow
注文が増える → 作る量が増える → 雇う人手が増える
```

短期に価格を固定するこのモデルでは、**総需要（買いたい量）が、生産を動かす**ことが大切です。ただし、店が無限に作れるという意味ではありません。

### 第12講と、どこが違う？

| お金や金利への働きかけ | 第12講のモデル | この節のモデル |
|---|---|---|
| 価格の調整 | 自由に動く | 短期には動きにくい |
| 生産・雇用への影響 | お金の量だけでは変わらない | 需要を通して変わりうる |

```quiz
Q: 商品の値段を変えず、注文が減ったら、店はどう対応しうる？
1: 値段を変えなくても必ず全量売れる
2: 注文が減れば生産を必ず増やす
3: 作る量や人手を減らすことがある
4: 雇用は注文に一切影響されない
C: 3
E: 作る量や人手を減らすことがあります。それが経済全体に広がると、生産や雇用が減ります。
```

```quiz
Q: メニューコストとは？
1: メニューに載った商品の仕入れ代金だけ
2: 客が料理を選ぶための時間だけ
3: 価格変更で得た利益だけ
4: 値札や広告など、価格変更の手間や費用
C: 4
E: 値札・広告・契約の変更など、価格を変えるための手間や費用です。
```


## 5. 金利で、注文を支える

借りる利子が下がれば、家計や会社が買いやすくなります。需要不足のときには、中央銀行の金利引下げが、生産や雇用を支える可能性があります。

```flow
金利を下げる → 消費や投資を支える → 注文が増える → 生産や雇用が回復する方向
```

ここで2つの言葉を押さえます。

- **自然利子率**：値段が柔軟に動くとき、需要と、本来の生産力がつり合う実質利子率。
- **総生産ギャップ**：実際の生産と、本来の生産水準との差。不況で実際の生産が下回れば、マイナスのギャップ。

自然利子率は、銀行の店頭に表示される金利ではありません。直接は見えず、推計する目安です。また、中央銀行が決める政策金利は通常、名目の短期金利。需要には、物価上昇の予想を考えた **実質金利** が重要です。

> 補足：金利を下げれば必ず回復するわけではありません。下げられる幅や、借り手の状態、物価の動きなどにも左右されます。

```quiz
Q: 需要不足で実際の生産が本来の水準を下回ると、総生産ギャップは？
1: ギャップはマイナス
2: ギャップはプラス
3: ギャップは必ずゼロ
4: ギャップは名目金利と同じ値
C: 1
E: マイナスです。金利への働きかけなどで需要を支える理由になります。
```


## 6. 3つの「動きにくさ」を整理する

| 動きにくいもの | 最初に見ること |
|---|---|
| 給料の額（名目賃金） | 売値が下がると、会社の実質の人件費が上がる |
| 給料の購買力（実質賃金） | 高めの給料でも、全員を雇うとは限らない |
| 商品の値段 | 注文に応じて、生産や人手が動く |

講義で扱う比較では、商品価格が動きにくいモデルは、消費・投資・雇用・実質賃金が好況で増える動きを説明しやすいとされます。どんな不況も1つのモデルだけで説明できるわけではありません。

実際の値段は、商品によって変える頻度が違います。「一部は数か月で値段が変わる」ことも、経済全体がすぐ調整できることを意味しません。どの程度の硬直性で、どれだけ長い不況を説明できるかが課題です。

## 7. まず、この3つ

1. 値段や給料がすぐ変わらないと、生産や雇用で調整することがある。
2. 名目賃金と実質賃金は違う。給料の額が同じでも、物価が下がれば購買力は上がる。
3. 需要不足では、金利への働きかけが生産や雇用を支える可能性がある。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。上級マクロは重点科目なので6問。


```quiz
Q: 値段や給料がすぐには変わらないことを何という？
1: 硬直性
2: 中立性
3: 逓減
4: 流動性
C: 1
E: 硬直性。「絶対に変わらない」ではなく、変わるのに時間がかかること。
ほかの選択肢：中立性はお金の話。逓減は増え方が小さくなる話。流動性は使いやすさの話。
```

```quiz
Q: 名目賃金（給料の額）が変わりにくいモデルの弱点は？
1: 不況で実質賃金が上がる方向になり、データと合いにくい
2: 失業が説明できない
3: 物価が説明できない
4: 利子率が説明できない
C: 1
E: 不況で物価が下がっても給料の額が同じなら、実質賃金が上がってしまう。
ほかの選択肢：このモデルでも失業・物価・利子率は説明できる。弱点は「実質賃金の向き」がデータと合わないこと。
```

```quiz
Q: 会社が実質の給料を高めに保ち、働きたいのに働けない人が残ることを何という？
1: 非自発的失業
2: 自発的失業
3: 摩擦的失業
4: 完全雇用
C: 1
E: 非自発的失業。高い給料で人材の意欲を保つ考え（効率賃金）。
ほかの選択肢：自発的失業は自分で選んで働かない人。摩擦的失業は仕事探しの時間。完全雇用は失業がない状態。
```

```quiz
Q: 値札やメニューを変える手間のことを何という？
1: メニューコスト
2: 機会費用
3: 使用者費用
4: 減価償却
C: 1
E: メニューコスト。だから商品の値段はすぐには変わりにくい。
ほかの選択肢：機会費用はあきらめたもの。使用者費用は機械を使う費用。減価償却は古くなる分。
```

```quiz
Q: 商品の値段が短期に変わらないモデルで、生産を動かすものは？
1: 総需要（買いたい量）
2: 人口
3: 天気
4: 税の種類
C: 1
E: 値段が据え置きなら、注文（需要）がふえると生産がふえる。
ほかの選択肢：人口・天気・税の種類は、この短期のモデルで生産を動かす中心ではない。
```

```quiz
Q: 「実際の生産」と「本来の生産水準」との差を何という？
1: 総生産ギャップ
2: 自然利子率
3: 相対変動性
4: 成長会計
C: 1
E: 総生産ギャップ。不況ではマイナスになる。自然利子率は、需要と本来の生産力がつり合う実質利子率。
ほかの選択肢：自然利子率は利子率の目安。相対変動性は揺れの大きさ。成長会計は成長を分ける計算。
```

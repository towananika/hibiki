# 上級マクロ経済論 14講 ― 値段が動かないと景気はどうなる？

韓国の放送大学「上級マクロ経済論」14講を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

**この回の答え：給料や値段はすぐには変わらない。だから経済はちょうどよい所から外れて、景気に波が出る。データにいちばん合うのは「品物の値段が固い」考え方で、これが国の銀行が金利で景気をととのえる理由になる。**

## 1. 前の回とのちがい
| | 13講 | 14講 |
|---|---|---|
| 景気の波とは | ちょうどよい所そのものが動く（均衡景気循環理論） | 給料や値段が固くて、ちょうどよい所から外れる（不均衡景気循環理論） |
| 国が景気をととのえること（安定化政策） | いらない | **いる** |

- 14講の考え方は、ケインズの流れをくむ人たち（ケインズ派・新ケインズ派）のもの。
- 固いものによって、考え方（モデル）が3つある。

```flow
給料の額が固い → 物価を引いた給料が固い → 品物の値段が固い
```

> 補足：「景気がよいとふえる」ものを「景気順応的」、「景気がよいとへる」ものを「景気逆行的」という。

## 2. 給料の額が固い（名目賃金が固いモデル）
### 2.1 契約の時期がずれると、給料はなかなか下がらない
- テイラーの考え（重複賃金契約モデル）。会社は1年ごとに給料を決める。
- 物価が下がったとき、給料が直るまでの時間がちがう。

| 契約の決め方 | 直るまで |
|---|---|
| 全部の会社が1月にいっせいに決める（同時契約） | 1年以内 |
| 半分は1月、半分は7月に決める（重複契約） | **何年も**かかる |

- なぜ？ 人は「ほかの人とくらべた給料」（相対賃金）を気にする。自分だけ先に下がるのはいやなので、少しずつしか下げない。
- ケインズも同じ考え：物価が上がって実質の給料が下がるのは、みんな同じなのでがまんする。でも給料の額が下がるのには強く反対する。

### 2.2 投資がへると
```flow
投資がへる → 物価が下がる → 給料の額は固い → 実質の給料が上がる → 雇う人がへる
```

### 2.3 データと合う？
| | このモデル | データ |
|---|---|---|
| 消費・投資・雇う人 | 景気がよいとふえる | 合う ○ |
| 実質の給料 | 景気がよいと**へる**（逆行的） | 合わない ✕ |
| 物価・実質の金利 | 景気がよいと**ふえる**（順応的） | 合わない ✕ |

- **量は合うが、値段の動きが合わない。**
- 実質の給料がへるのは、雇う人がふえると1人がふやせる生産がへるから（労働需要曲線にそって動く）。

## 3. 物価を引いた給料が固い（実質賃金が固いモデル）
- 会社は、人がまじめに働く高めの給料（効率賃金）を払い続ける。だから実質の給料が固い。
- 例：賃上げの要求は「物価の上がり分＋α」。最低賃金も物価を見て決める。
- 景気を動かすのは、**生産性が変わること**（生産性ショック）。

```flow
生産性が上がる → 会社がもっと雇う → 生産がふえる → 所得がふえる・金利と物価が下がる
```

- 高めの給料なので、働きたいのに働けない人（非自発的失業）がいる。生産性が上がると、その人がへる。
- 雇う人の数は金利と関係ない → 作れる量の線はまっすぐ立つ（実質総供給曲線が垂直）。
- だから、**買う量がふえても（総需要ショック）所得は変わらない**。
- データとの合い方は、前の回の RBC とほぼ同じ。
- ただし実質の給料は景気と関係なく動かない（無循環）。「市場の給料が上がると、クビの損が小さくなるので、効率賃金も上げる」と考えると、景気がよいと上がる形にできる。

## 4. 品物の値段が固い
- 値段を変える手間（メニューコスト）があるので、会社は値段を変えずに、作る量で合わせる。
- ほかとのちがい2つ：
  1. 短い間、値段が変わらない → 所得は**買う量（総需要）だけ**で決まる。
  2. 国の銀行は、目標の金利（政策金利）を決めて、お金の量でそこに合わせる。

### 4.1 ちょうどよい所から外れたまま
- 品物は売れ残る（超過供給）。値段を下げられないから。
- 値段が自由なら品物がちょうど売れる金利 ＝ 自然な金利（自然利子率）。そのときの所得 ＝ みんなが働けるときの所得（完全雇用の所得）。
- 実際の所得との差 ＝ 総生産ギャップ。

### 4.2 投資がふえると
```flow
投資がふえる → 作る量がふえる → 雇う人がふえる → 実質の給料が上がる → 国の銀行がお金をふやす
```
- 消費・投資・雇う人・実質の給料・お金の量が、みんな景気がよいとふえる → **データによく合う**。

### 4.3 金利で景気を戻せる
```flow
国の銀行が金利を自然な金利まで下げる → 消費と投資がふえる → 所得がもとに戻る
```
- 値段が固いので、お金の量の変化は物価ではなく**金利**に出る → 所得や雇う人を動かす。
- つまり、お金は景気に効く（お金は中立ではない）。だから**国が景気をととのえる意味がある**。

### 4.4 弱いところ
```bars
これまでの考え：値段を変える間隔 | 12 | 1年に1回 | w
アメリカのデータ：品目の半分ほど | 4.5 | 4〜5か月に1回 | r
```
- 値段は思ったより早く変わっていた → 「値段が固い」という前提が疑われている。

## 5. 3つをくらべる
| 固いもの | 景気を動かすもの | データとの合い方 |
|---|---|---|
| 給料の額 | 買う量（総需要） | 量は合う、値段は合わない |
| 実質の給料 | 生産性 | RBC に近い |
| 品物の値段 | 買う量（総需要） | **よく合う** |

## 6. まとめ（6点）
1. 14講は、給料や値段が固くて、ちょうどよい所から外れることで景気を説明する（不均衡景気循環理論）。
2. 契約の時期がずれ、人がほかの人の給料を気にするので、給料の額はゆっくりしか動かない（テイラー）。
3. 給料の額が固い考え方は、量は合うが、実質の給料と物価の動きがデータと合わない。
4. 実質の給料が固い考え方は、生産性で景気が動き、買う量では所得が変わらない。
5. 品物の値段が固い考え方は、データによく合い、国の銀行が金利で景気を戻せる。
6. ただし、値段は思ったより早く変わるという批判がある。

## 8. 自分の暮らしにつなげる
- 給料の話をするときは、物価の上がり方と「同じ仕事の人の相場」の両方を見ると、話がしやすい。

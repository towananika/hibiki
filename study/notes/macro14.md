# 上級マクロ経済論 14講 ― 値段がすぐ変わらないと、何が起こる？

**この講で覚えること：値段や給料がすぐ下がらないと、売れ残りや失業が「数字の調整」ではなく「作る量と人手」で調整される。何が動きにくいかで、結果が3通りに分かれる。**

## 0. この講の地図（3分）

不況になると、物が売れず、働きたい人が余ります。もし値段や給料がすぐ下がれば、また売れるようになり、雇われるようになるはずです。
**では、なぜ不況は何か月も続くのか？** これが14講の問いです。答えは「値段や給料は、すぐには変わらないから」。

```flow
① 言葉をそろえる → ② 給料の額が動きにくい → ③ 給料の買える力が動きにくい → ④ 商品の値段が動きにくい → ⑤ 3つをくらべる → ⑥ 不況への手当て
```

読む前に、この3つを思い出しておくと楽です。
- **名目と実質**（0講④）：給料の額と、本当に買える量はちがう。
- **12講**：値段が自由に動くなら、お金の量を増やしても、作る量や働く人は変わらない。
- **13講**：景気の波を、「つり合う場所そのものが動く」と考える説明。

14講は、12講・13講と反対の側に立ちます。「値段がすぐ動かないから、つり合う場所に着くまでの間、作る量や人手がずれる」という考えです。

## 1. まず言葉をそろえる（5分）

この講で何度も出てくる言葉は4つだけです。

```card
14講の4つの言葉
- 硬直性：値段や給料が、変わるまでに時間がかかること（「絶対に変わらない」ではない）
- 総需要：国全体で買いたい量（消費＋投資＋政府＋外国との差）
- 本来の生産水準：働きたい人がみな働けて、値段も自由に動くときの生産（完全雇用の生産）
- 総生産ギャップ：実際の生産 − 本来の生産水準（不況ではマイナス）
```

パン屋で考えます。いつも100個売れるパンが、今日は70個しか売れない。値段をすぐ変えられないなら、翌日は作る量を減らし、必要な人手も減らすかもしれません。

```flow
買いたい量が減る → 値段はすぐ変わらない → 作る量を減らす → 人手も減らす
```

これが国全体で起これば、生産が「本来の生産水準」より少なくなります。総生産ギャップがマイナスになった状態が、不況です。

```bars
本来作れる力 | 100 | 100 | s
実際に作った量 | 90 | 90 | r
```

たとえば、国が本来100作れる力を持っているのに、実際は90しか作っていない。差の10は **使われずに余っている力**（人・機械・お店）です。総生産ギャップがマイナスというのは、この「力を出しきれていない、もったいない状態」のことです。

```quiz
Q: 硬直性の意味として正しいのは？
1: 値段や給料の調整に時間がかかること
2: 値段や給料が永久に変わらないこと
3: 値段が必ず毎日変わること
4: すべての値段が同じになること
C: 1
E: 硬直性は「調整に時間がかかる」こと。いつかは変わる。
ほかの選択肢：永久に変わらないわけではない。毎日変わるのは反対の「柔軟」。値段がそろう話ではない。
```

## 2. 型①：給料の「額」が動きにくい（10分）

**何が動きにくい？** 給料の額（名目賃金）。月給20万円は、物価が下がっても20万円のまま。

**なぜ？** 給料は1年ごとなどの契約で決まります。しかも会社ごとに更新の月がずれているので、国全体の給料は少しずつしか変わりません。ほかの人との差も気にするので、調整はさらに長引きます。
> 補足：この「更新の時期がずれる」考えを、テイラーの重複賃金契約モデルといいます。

**すると何が起こる？** たとえば会社が機械を買うのを控えた（投資が減った）とします。

```flow
投資が減る → 総需要が減る → 物価が下がる → 給料の額はそのまま → 会社にとって給料が重くなる → 雇う人が減る → 生産が減る
```

物価が下がっても給料の額が同じなら、働く人は前より多く買えます（実質賃金が上がる）。でも会社から見ると、売値が下がったのに払う給料は同じ。人を雇う負担が重くなるので、雇う人を減らします。
> 補足（式で書くと）：実質賃金 ＝ 給料の額 ÷ 物価。分母（物価）が下がると、実質賃金は上がる。

**弱点：** このモデルだと「不況で実質賃金が上がる」ことになります。でも13講で見たデータでは、実質賃金はむしろ **好況で上がる** ことが多い。データの向きと合いにくいのです。

```quiz
Q: 給料の額が動きにくいモデルで、投資が減ると実質賃金は？
1: 下がる
2: 上がる
3: 必ず変わらない
4: 給料の額と一緒に2倍になる
C: 2
E: 投資が減る→物価が下がる→給料の額はそのまま、なので実質賃金（買える力）は上がる。
ほかの選択肢：下がるのは物価のほう。給料の額は動きにくいので、変わらない・2倍にもならない。
```

## 3. 型②：給料の「買える力」が動きにくい（7分）

**何が動きにくい？** 実質賃金（給料で買える量）。会社が、わざと高めの実質賃金を保ちます。

**なぜ？** 給料が高いと、人が辞めにくく、まじめに働き、よい人が集まります。会社にとっても得になる高い給料を **効率賃金** といいます。

**すると何が起こる？**
- その高い給料で採算が合う人数しか雇わないので、働きたいのに働けない人が残る。これを **非自発的失業** という。
- 買いたい量（総需要）だけが増えても、給料と人数は変わらない。だから **生産も雇用も増えない**。需要は物価や利子率を動かすだけ。
- 生産性（同じ人手で作れる量）が上がると、1人を雇う価値が上がるので、雇用が増え、非自発的失業は減る。

> 補足：教科書の図（縦が実質利子率、横が生産）では、このモデルの総供給の線はまっすぐ縦に立つ（垂直）。「生産は需要では動かず、給料と生産性で決まる」という意味。

**弱点：** 失業が続く理由は説明できますが、「需要が減って不況になる」ことは説明できません。

```quiz
Q: 効率賃金を払う会社でも、働きたい人を全員雇うとは限らないのは？
1: 給料が高いと従業員が全員辞めるから
2: 実質賃金と名目賃金が常に同じだから
3: 会社は生産を一切考えないから
4: 高い給料では、採算が合う雇用の人数に限りがあるから
C: 4
E: 高めの給料を払うと、その給料で採算が合う人数しか雇わない。だから非自発的失業が残る。
ほかの選択肢：高い給料なら辞めにくくなる。実質と名目は物価で変わる。会社は生産を考えて雇う人数を決める。
```

## 4. 型③：商品の「値段」が動きにくい（10分）

**何が動きにくい？** 商品の値段。

**なぜ？** 値札だけでなく、メニュー・広告・契約も直す手間があります。値段を変える手間や費用を **メニューコスト** といいます。小さな手間でも、多くの店が値段を据え置くと、国全体の値段はゆっくりしか動きません。

**すると何が起こる？** 値段は同じまま、店は注文の数に合わせて作る量を変えます（作る余力がある範囲で）。

```flow
注文が増える → 作る量が増える → 雇う人手が増える → 所得が増える
```

つまり、このモデルでは **総需要（買いたい量）が生産を動かす** のがいちばん大事な点です。需要が減れば、生産も雇用も減ります。

中央銀行は、ふつう「政策金利」という利子率を目標にします。注文が増えてお金を借りたい人が増えても、金利を目標どおりに保つため、中央銀行は出回るお金の量を増やします。

### 12講とくらべる

| | 12講（値段が自由） | 14講・型③（値段が動きにくい） |
|---|---|---|
| 値段の調整 | すぐ動く | 短い間は動きにくい |
| お金や金利で、生産や雇用は？ | 変わらない | 需要を通して変わりうる |

**強み：** 好況で消費・投資・雇用・実質賃金がそろって増える動きを、ほかの2つより説明しやすいとされます。

```quiz
Q: 商品の値段が短い間変わらないモデルで、生産を動かすのは？
1: 人口
2: 天気
3: 総需要（買いたい量）
4: 税の種類
C: 3
E: 値段が据え置きなら、注文（需要）が増えると生産が増え、減ると生産が減る。
ほかの選択肢：人口・天気・税の種類は、この短期のモデルで生産を動かす中心ではない。
```

## 5. 同じ不況を、3つの型で見くらべる（7分）

3つの型を、**同じできごと** で見くらべます。
**できごと：会社が機械を買うのを控えた（投資が減った）。国全体で買いたい量（総需要）が減る。**
見るのは2つだけ。**作る量（生産）はどうなる？** と **給料で買える量（実質賃金）はどうなる？**

### 型① 給料の額が動きにくい

```flow
買いたい量が減る → 物価が下がる → 給料の額はそのまま → 買える量（実質賃金）は上がる → 会社には重いので雇う人を減らす → 生産が減る
```

- 生産：**減る**
- 実質賃金：**上がる**。給料の額は同じなのに、物価だけが下がるから。

### 型② 給料の買える力が動きにくい（効率賃金）

```flow
買いたい量が減る → 会社は給料を下げない → 雇う人数も変わらない → 生産も変わらない → 物価や利子率が下がって調整される
```

- 生産：**変わらない**
- 実質賃金：**変わらない**。理由は、会社が **自分から** 買える量を高めに保っているから。不況でも給料を下げると、よい人が辞めたり、やる気が落ちたりして、会社が損をする。だから下げない。
- 雇う人数は「給料の高さ」と「1人がどれだけ作れるか（生産性）」で決まる。どちらも変わらないので、人数も生産も変わらない。

### 型③ 商品の値段が動きにくい（メニューコスト）

```flow
買いたい量が減る → 値段はそのまま → 注文が減る → 作る量を減らす → 必要な人手が減る → 給料も下がりやすい
```

- 生産：**減る**
- 実質賃金：**下がりうる**。人手があまり要らなくなり、給料が下がりやすいのに、商品の値段は動かないから。

### まとめると

```card
不況のとき（需要が減ったとき）
- 型①：生産 減る／実質賃金 上がる
- 型②：生産 変わらない／実質賃金 変わらない
- 型③：生産 減る／実質賃金 下がる
```

実際のデータでは、**不況のとき生産も実質賃金も下がる** ことが多い。この向きに合うのは型③です。型①は実質賃金の向きが逆、型②は需要で生産が動かないので、不況そのものを説明しにくい。だから講義では、型③がいちばんデータに合いやすいとされます。

どれか1つがいつも正しいわけではありません。実際の値段は、品物によって変わる速さがちがいます。「一部の値段は数か月で変わる」としても、経済全体がすぐ調整できるとは限りません。どのくらいの動きにくさで、どれだけ長い不況を説明できるかが、いまも議論されています。

```quiz
Q: 3つの型のうち、「需要が増えても生産は増えない」のは？
1: 型① 給料の額が動きにくい
2: 型② 給料の買える力が動きにくい（効率賃金）
3: 型③ 商品の値段が動きにくい
4: どれも生産が増える
C: 2
E: 型②では、生産は給料と生産性で決まる。需要は物価や利子率を動かすだけ。
ほかの選択肢：型①と型③では、需要が増えると生産も増える。だから「どれも」はまちがい。
```

## 6. 不況への手当て：金利で注文を支える（7分）

型③のように需要が生産を動かすなら、需要を支えれば不況をやわらげられます。その道具が金利です。

```flow
中央銀行が金利を下げる → 借りやすくなる → 消費や投資が増える → 注文が増える → 生産や雇用が戻る方向
```

目安になる言葉が **自然利子率** です。値段が自由に動くとき、需要と本来の生産力がちょうどつり合う実質利子率のこと。実際の金利がこれより高いと需要が足りず、総生産ギャップはマイナスになります。金利を自然利子率まで下げると、生産は本来の水準に戻る方向へ動きます。

気をつけること：
- 自然利子率は、銀行の店頭に出ている金利ではない。直接は見えず、推計する目安。
- 中央銀行が決める政策金利は、ふつう名目の短期金利。需要に効くのは、物価の上がり方を考えた実質金利。

> 補足：金利を下げれば必ず回復するわけではありません。下げられる幅、借りる人の状態、物価の動きなどにも左右されます。

```quiz
Q: 需要不足で実際の生産が本来の水準を下回ると、総生産ギャップは？
1: マイナス
2: プラス
3: 必ずゼロ
4: 名目金利と同じ値
C: 1
E: 実際の生産 − 本来の生産水準 がマイナスになる。金利で需要を支える理由になる。
ほかの選択肢：プラスは生産が本来より多い好況のとき。ゼロはちょうどの状態。金利とは別のもの。
```

## 7. まず、この3つ

1. 値段や給料がすぐ変わらないと、売れ残りや失業は「作る量と人手」で調整される。
2. 何が動きにくいかで結果が変わる。給料の額（需要で生産が動く・実質賃金は逆向き）、給料の買える力（失業が残る・需要は効かない）、商品の値段（需要で生産が動く・データに合いやすい）。
3. 需要不足のときは、金利を自然利子率に近づけることで、生産や雇用を支えられる可能性がある。

```cloze
値段や給料が変わるまでに時間がかかることを{{硬直性}}という。
会社が人のやる気のために高めに払う給料を{{効率賃金}}という。
働きたいのに働けない失業を{{非自発的失業}}という。
値段を変える手間や費用を{{メニューコスト}}という。
実際の生産と本来の生産水準との差を{{総生産ギャップ}}という。
```

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。上級マクロは重点科目なので6問。

```quiz
Q: 値段や給料がすぐには変わらないことを何という？
1: 中立性
2: 硬直性
3: 逓減
4: 流動性
C: 2
E: 硬直性。「絶対に変わらない」ではなく、変わるのに時間がかかること。
ほかの選択肢：中立性はお金の量が実際の量に効かない話。逓減は増え方が小さくなる話。流動性は使いやすさの話。
```

```quiz
Q: 名目賃金（給料の額）が変わりにくいモデルの弱点は？
1: 失業が説明できない
2: 物価が説明できない
3: 不況で実質賃金が上がる方向になり、データと合いにくい
4: 利子率が説明できない
C: 3
E: 不況で物価が下がっても給料の額が同じなら、実質賃金が上がってしまう。
ほかの選択肢：このモデルでも失業・物価・利子率は説明できる。弱点は「実質賃金の向き」がデータと合わないこと。
```

```quiz
Q: 会社が実質の給料を高めに保ち、働きたいのに働けない人が残ることを何という？
1: 自発的失業
2: 摩擦的失業
3: 完全雇用
4: 非自発的失業
C: 4
E: 非自発的失業。高い給料で人の意欲を保つ考え（効率賃金）から生まれる。
ほかの選択肢：自発的失業は自分で選んで働かない人。摩擦的失業は仕事探しの時間。完全雇用は失業がない状態。
```

```quiz
Q: 値札やメニューを変える手間のことを何という？
1: メニューコスト
2: 機会費用
3: 使用者費用
4: 減価償却
C: 1
E: メニューコスト。だから商品の値段はすぐには変わりにくい。
ほかの選択肢：機会費用はあきらめたもの。使用者費用は機械を使う費用。減価償却は古くなる分。
```

```quiz
Q: 値段が動きにくいモデルで、中央銀行が政策金利を自然利子率まで下げると、所得は？
1: 本来の水準まで戻る方向に増える
2: さらに減る
3: まったく変わらない
4: 必ず本来の水準の2倍になる
C: 1
E: 消費や投資が増え、注文が増えるので、生産と所得は本来の水準へ戻る方向に動く。
ほかの選択肢：金利を下げて需要が減ることはふつうない。値段が動きにくいので所得は変わりうる。2倍になるわけではない。
```

```quiz
Q: 「実際の生産」と「本来の生産水準」との差を何という？
1: 自然利子率
2: 相対変動性
3: 総生産ギャップ
4: 成長会計
C: 3
E: 総生産ギャップ。不況ではマイナスになる。
ほかの選択肢：自然利子率は、需要と本来の生産力がつり合う実質利子率。相対変動性は揺れの大きさ。成長会計は成長を分ける計算。
```

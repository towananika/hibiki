# 伝統社会と生活文化 14講【会話で読む】― お葬式と先祖の祭り

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition14)」。

## 1. 長男がつぐ決まりと宗家（10分）

```talk
B: 冠婚喪祭って？
A: 大人になる儀式・結婚・葬式・先祖の祭りの4つ。13講は生まれる〜結婚、14講は葬式と祭り。
B: 朱子学は儀式をどう使った？
A: 個人の行事ではなく、父方の一族（門中）をまとめ、長男が家をつぐ社会をつくる道具にした。
B: 長男がつぐ決まりは？
A: 宗法。亡くなった人の地位や財産は、正妻の長男（嫡長子）だけがつぐ。不平等だけど、兄弟の争いがへって安定する。
B: 一族の本家は？
A: 宗家。本家の長男が宗孫、その妻が宗婦。仕事は先祖の祭りとお客のもてなし（奉祭祀・接賓客）で、祭りは年に40〜60回。地域の政治と文化の中心だった。
C: 長男1人にしぼって、一族をまとめた。
```

```card
要点
- 冠婚喪祭：大人になる儀式・結婚・葬式・先祖の祭り
- 宗法：正妻の長男（嫡長子）だけがつぐ決まり
- 宗家／宗孫／宗婦：仕事は奉祭祀・接賓客
- 息子がいなければ養子。息子が先に亡くなれば孫がつぐ（承重）
```

## 2. 朱子学式のお葬式（10分）

```talk
B: お葬式の流れは？
A: 家の部屋（正寝）で亡くなる。屋根に上がり服を持って「戻れ」と3回呼ぶ（招魂・皐復）。体を洗い、布でつつんで棺に入れる。お墓の場所と日を決め、位牌（神主）を作る。輿（喪輿）でお墓へ（発靷）。うめたあと位牌を持ち帰り、3回まつる（虞祭）。
B: 3年の喪って？
A: 三年喪。満1年が小祥、満2年が大祥、27か月目が禫祭。禫は「心がおだやか」の意味で、ここで肉も食べられるようになる。そのあとふだんの暮らしへ（吉祭）。
B: いまは？
A: お墓にうめて終わり。土葬から火葬にかわってきた。
C: 小祥 → 大祥 → 禫祭。
```

```card
要点
- 招魂（皐復）→ 体を整える → 治葬 → 発靷 → 虞祭
- 三年喪：小祥（1年）→ 大祥（2年）→ 禫祭（27か月）→ 吉祭
- いまは土葬から火葬へ
```

## 3. 朝鮮らしいお葬式の習慣（5分）

```card
先に言葉を3つ
- 洗骨（せんこつ）：骨を洗って、骨だけをうめなおすこと。沖縄にも昔あった
- ダシレギ：お葬式の夜にする、歌とおどりの劇。日本のお通夜を、にぎやかにした感じ
- 生前預修斎（せいぜんよしゅうさい）：生きているうちにする、自分のための供養。いまの「終活」に近い
```

```talk
B: 2節のお葬式は朱子学のやり方だったよね。朝鮮にしかないものもあるの？
A: あるよ。1つめは「骨を大事にする」こと。たましいの力は骨に宿ると考えたんだ。
B: え、骨を洗うってどういうこと？
A: まず体を草でおおって外に置いておく（草墳＝くさのお墓）。何年かして肉がなくなったら、骨だけを洗ってうめなおす。これが洗骨。沖縄の昔のお葬式にも同じ習慣があったよ。
B: お葬式の夜は、静かにしているものじゃないの？
A: 朝鮮では、にぎやかに遊ぶ習慣があった。南の島・珍島（チンド）のダシレギがその例。歌とおどりの劇で、最後に赤ちゃんが生まれる場面がある。
B: なんでお葬式に赤ちゃん？
A: 「1人いなくなっても、新しい命が来る」と見せて、家族の悲しみを喜びに変えるため。いまは国の無形文化財（形のない、守るべき文化）になっている。
B: 3つめの「生前…」は、死んだあとの供養じゃないの？
A: ちがうんだ。生きているうちに、お経を読んでもらい、紙のお金をささげておく。死んだあとの世界の準備を先にしておく、という考え。高麗（朝鮮の前の時代）の仏教からある。
C: 悲しみを、次の命の喜びにかえる。
```

```card
要点
- 洗骨：骨に力が宿る → 骨だけ洗ってうめなおす
- ダシレギ：お葬式の夜の歌とおどり。赤ちゃん誕生の場面で終わる
- 生前預修斎：死ぬ前に、自分の供養をすませておく
```

## 4. 先祖の祭り（10分）

```card
先に言葉を3つ
- 忌祭祀（きさいし）：命日の祭り。日本の「法事」に近い
- 節祀（せっし）：大きな祝日に、お墓でする祭り。日本の「お盆のお墓まいり」に近い
- 時祭（じさい）：一族が大勢でお墓に集まる、年1回の祭り（墓祭＝ぼさい とも言う）
```

```talk
B: 先祖の祭りって、1種類じゃないの？
A: 3種類あるよ。「いつ」「どこで」「だれが」で分けると覚えやすい。
B: 1つめは？
A: 命日の祭り（忌祭祀）。亡くなった日に毎年、家でする。まつるのは4代前まで。自分から見て、ひいおじいさんのお父さん・お母さん（高祖父母）までだね。娘も参加した。
B: 2つめは？
A: 祝日のお墓まいり（節祀）。正月、寒食（春）、端午（初夏）、秋夕（秋のお盆）に、お墓でまつる。お墓の草かりもする。
B: 3つめの時祭は、命日の祭りとどうちがうの？
A: もっと古い、5代より前の先祖のための祭り。秋（旧暦の10月）にお墓で、一族の男性だけが何百人も集まった。「うちの一族はこんなに大きい」と見せる場でもあった。
B: 朱子学のお手本どおりにやっていたんでしょ？
A: じつは、お手本よりも広げていた。お手本（朱子家礼＝朱子の書いた儀式の本）では、ふつうの人がまつるのは親まで。朝鮮では、身分の低い人（奴婢）まで4代前をまつった。お手本にない、お墓での祝日の祭りもした。
B: 祭りをするのは、ずっと長男だった？
A: 前は、息子も娘も順番に担当していた（輪回奉祀＝じゅんばんの祭り）。のちに長男だけになったんだ。
C: 命日は家で、祝日はお墓で、一族は秋に集まる。
```

```card
要点
- 忌祭祀：命日／家で／4代前まで／娘も
- 節祀：祝日（正月・寒食・端午・秋夕）／お墓で
- 時祭：旧暦10月／5代より前のお墓で／男性だけ・大勢
- 順番の祭り（輪回奉祀）→ 長男だけへ
```

> 補足：寒食（かんしょく）は4月はじめごろ、端午（たんご）は旧暦の5月5日、秋夕（チュソク）は旧暦の8月15日で、韓国のお盆のような祝日。旧暦は、月の満ち欠けで数える昔のこよみ。

## 5. 一族の力と、いまの一族（10分）

```card
先に言葉を3つ
- 族譜（ぞくふ）：一族の家系図の本
- 不遷位（ふせんい）：位牌をしまわず、ずっとまつってよい先祖。「殿堂入り」の先祖
- 宗親会（そうしんかい）：同じ名字・同じ先祖の人たちの会。いまも続く
```

```talk
B: 族譜って、ただの家系図でしょ？
A: それ以上の意味があった。「わたしはこの一族の一員だ」という証明書で、身分の証明にも使えた。だから戦争で逃げるときも、胸に抱いて持って行ったんだ。
B: ずっと同じ書き方だったの？
A: 変わっていった。16世紀ごろまでは、父方も母方も、えらい人は全部のせた（内外譜＝ないがいふ。内は父方、外は母方）。そのあと父方だけになり、19世紀には、分かれていた家どうしが「もとは同じ先祖」とまとまって、大きな族譜（大同譜＝だいどうふ。大きくまとめた家系図）を作った。
B: 4代前より古い先祖は、もうまつらないんだよね？
A: ふつうはそう。古くなった先祖の位牌（名前を書いた木の札）は、お墓にうめてしまう。
B: じゃあ、どんなにえらい先祖でも忘れられちゃうの？
A: そこで不遷位。国が「この人はえらい」と認めた先祖だけは、位牌をうめずに、家の祭りの部屋（祠堂＝しどう）でずっとまつれる。スポーツの「殿堂入り」みたいなものだね。
B: それって一族の自慢になる？
A: なる。しかも私立の学校（書院＝しょいん）にまつられると、一族だけでなく地域の学者みんなが祭りに来た。
B: いまは、こういう一族のつながりはなくなったの？
A: 儀式は小さくなった。一人ひとりを大事にする考え、女性の立場が上がったこと、身分の差がなくなったことが理由。でも宗親会は続いていて、奨学金を出したり、病院を運営したりしている。国の福祉が届かないところを助けているんだ。
C: 形を変えて、いまも残っている。
```

```card
要点
- 族譜：一族の証明書。父方も母方も → 父方だけ → 大きくまとめる（19世紀）
- 不遷位：国が認めた先祖は、ずっとまつれる（殿堂入り）
- 宗親会：奨学金・病院など、福祉のすきまを助ける
```

# 伝統社会と生活文化 14講【会話で読む】― お葬式と先祖の祭り

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition14)」。

## 1. 長男がつぐ決まりと宗家（10分）

```talk
B: 冠婚喪祭って？
A: 大人になる儀式・結婚・葬式・先祖の祭りの4つ。13講は生まれる〜結婚、14講は葬式と祭り。
B: 朱子学は儀式をどう使った？
A: 個人の行事ではなく、父方の一族（門中）をまとめ、長男が家をつぐ社会をつくる道具にした。
B: 長男がつぐ決まりは？
A: 宗法。亡くなった人の地位や財産は、正妻の長男（嫡長子）だけがつぐ。不平等だけど、兄弟の争いがへって安定する。
B: 一族の本家は？
A: 宗家。本家の長男が宗孫、その妻が宗婦。仕事は先祖の祭りとお客のもてなし（奉祭祀・接賓客）で、祭りは年に40〜60回。地域の政治と文化の中心だった。
C: 長男1人にしぼって、一族をまとめた。
```

```card
要点
- 冠婚喪祭：大人になる儀式・結婚・葬式・先祖の祭り
- 宗法：正妻の長男（嫡長子）だけがつぐ決まり
- 宗家／宗孫／宗婦：仕事は奉祭祀・接賓客
- 息子がいなければ養子。息子が先に亡くなれば孫がつぐ（承重）
```

## 2. 朱子学式のお葬式（10分）

```talk
B: お葬式の流れは？
A: 家の部屋（正寝）で亡くなる。屋根に上がり服を持って「戻れ」と3回呼ぶ（招魂・皐復）。体を洗い、布でつつんで棺に入れる。お墓の場所と日を決め、位牌（神主）を作る。輿（喪輿）でお墓へ（発靷）。うめたあと位牌を持ち帰り、3回まつる（虞祭）。
B: 3年の喪って？
A: 三年喪。満1年が小祥、満2年が大祥、27か月目が禫祭。禫は「心がおだやか」の意味で、ここで肉も食べられるようになる。そのあとふだんの暮らしへ（吉祭）。
B: いまは？
A: お墓にうめて終わり。土葬から火葬にかわってきた。
C: 小祥 → 大祥 → 禫祭。
```

```card
要点
- 招魂（皐復）→ 体を整える → 治葬 → 発靷 → 虞祭
- 三年喪：小祥（1年）→ 大祥（2年）→ 禫祭（27か月）→ 吉祭
- いまは土葬から火葬へ
```

## 3. 朝鮮らしいお葬式の習慣（5分）

```talk
B: 朝鮮らしいところは？
A: 骨を大切にする洗骨。たましいの力は骨に宿ると考え、肉がくちたあと骨だけうめた。西南の海岸では草でおおって置いた（草墳）。
B: 遊ぶ習慣もあった？
A: お葬式の夜ににぎやかに遊んだ。珍島のダシレギは、歌と踊りの劇。最後に赤ちゃんが生まれる場面があり、死の悲しみを新しい命の喜びにかえる。国の無形文化財。
B: 生きているうちの供養は？
A: 生前預修斎。高麗の仏教のころからあり、生きているうちにお経を読み、紙のお金をささげる。
C: 悲しみを、次の命の喜びにかえる。
```

```card
要点
- 洗骨：骨だけ集めてうめる（草墳）
- 珍島のダシレギ：死を楽しく送り、最後に赤ちゃんが生まれる劇
- 生前預修斎：生きているうちの供養
```

## 4. 先祖の祭り（10分）

```talk
B: 先祖の祭りは何種類？
A: 3つ。命日の祭り（忌祭祀）は家で、4代前（高祖父母）まで。お正月などの祭り（節祀）は正月・寒食・端午・秋夕にお墓で。一族の祭り（時祭・墓祭）は主に陰暦10月、5代より前のお墓で、男性だけ。
B: 朱子家礼とのちがいは？
A: 朱子家礼では、ふつうの人は親の祭りまで。朝鮮はむしろ広がり、奴婢まで4代前をまつった（四代奉祀）。お正月の祭りも朱子家礼にはないが、朝鮮はお墓を大事にして、名節にお墓でまつった。
B: 祭りをする人は？
A: 前は息子も娘も順番に（輪回奉祀）。のちに長男だけ。
C: 忌祭祀・節祀・時祭。
```

```card
要点
- 忌祭祀：命日／家／4代前まで
- 節祀：正月・寒食・端午・秋夕／お墓
- 時祭・墓祭：陰暦10月／5代より前／男性だけ
- 輪回奉祀 → 長男だけの祭りへ
```

## 5. 一族の力と、いまの門中（10分）

```talk
B: 一族の力を見せるものは？
A: 家系図の族譜。「この一族の一員だ」というしるしで、身分の証明にもなった。16世紀ごろまでは父方も母方も全部のせる内外譜。のちに父方だけになり、19世紀には大きな族譜（大同譜）が多く作られた。
B: 不遷位って？
A: 命日の祭りは4代前までで、古い先祖の位牌はうめる。でも国が認めたえらい先祖は、位牌をうめずに祠堂にずっとまつれる。それが不遷位。書院にまつられると、地域の学者みんなが祭りに来る。
B: いまは？
A: 個人主義、女性の地位の向上、身分制の廃止で、儀式は小さくなった。でも一族の会（宗親会）は続き、奨学金や病院の運営まで。福祉のすきまをうめている。
C: 形を変えて残っている。
```

```card
要点
- 族譜：一族のしるし。内外譜 → 父方だけ → 大同譜（19世紀）
- 不遷位：国が認めた先祖は位牌をうめず、ずっとまつる
- 宗親会：奨学金・投資・病院など、福祉のすきまをうめる
```

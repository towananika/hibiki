# 開かれた社会と21世紀 13講 ― まちを調べて記録する

韓国の放送大学「開かれた社会と21世紀」13講（講義資料25ページ）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
なぜ調べる？ → 何のために？（目的） → どう調べる？（数で／ことばで） → 3つの段階 → 5つの方法 → 調べる人の心がまえ
```

## 0. ひとことで
まちには、そこに住む人の **くらしと歴史** がつまっている。まちを調べて記録するのは、**目に見えるもの・見えないものの価値を見つけること**。
まちの調査は、ただの下調べではない。**調べる人とまちの人が話し合う、両方向のやりとり** でもある。

## 1. まちを調べる意味
- **まちの探究**（マウル探究）：まちの歴史・自然・人・活動・物語を見つけて、まとめて記録すること。そのスタートが **まちの調査**。
- まちの調査は、もともと人類学や地域学の **現地調査**（フィールドワーク）から始まった。いまは農村や漁村の開発、町の再生（都市再生）、まちづくり、共同体の事業にも使われる。
- まちの調査は：
  - 住民の意見を集め、物事を決めるのに **欠かせない方法**
  - 調べる人とまちが **話し合う流れ**（コミュニケーション）
  - ほかのまちとのちがいなど、**客観的な資料** が手に入る
  - 表には見えない **習慣・文化・考え方・ふるまい** や、その原因もわかる

## 2. 何のために調べる？（調査の目的）
**ふつうの調査の6つの目的**
| 目的 | ひとことで |
|---|---|
| **探る**（探索） | まちの資料がほとんどないとき、まず下調べする |
| **書き表す**（記述） | まちをもっとくわしく、きちんと整理する |
| **説明する**（説明） | まちで起きたことの **原因や背景** を明らかにする |
| **たしかめる**（検証） | 外から見たまちの考えが正しいか確かめる |
| **評価する**（評価） | まちへの政策や支援が、どれだけ効いたか測る |
| **ものさしを作る**（指標開発） | まちのようすを測る道具やものさしを作る |

**まちの政策から見た3つの目的**
| 目的 | 中身 |
|---|---|
| **まちが本当に必要なものを知る**（政策需要の把握） | 資源調査と住民の願いの調査で、必要なものと出すものを合わせる。上から一方的に決めて失敗するのを防ぐ |
| **手続きの根拠**（政策立案の手続き的根拠） | 法律で、計画の前に住民の意見を調べることが決まっている場合が多い。まちが「受けとるだけ」から「計画に参加する」側になる（民主主義に合う） |
| **情報を分け合う**（政策情報の共有） | 調べる中で、前もって情報を分け合える。そのおかげで政策を直したり足したりでき、まちの **支持** が得られる |

```quiz
Q: まちで起きたことの「原因や背景」を明らかにする調査の目的は？
1: 探る（探索）
2: 書き表す（記述）
3: 説明する（説明）
4: ものさしを作る（指標開発）
C: 3
E: 説明は、記述より一歩進んで原因や背景を明らかにする。ほかの選択肢：1は資料がないときの下調べ。2はくわしく整理すること。4は測る道具を作ること。
```

## 3. どう調べる？ 数で見るか、ことばで見るか
| | **数で見る調査**（量的調査） | **ことばで見る調査**（質的調査） |
|---|---|---|
| 結果 | 数字（年齢、住んでいる年数など）。足し算・引き算・かけ算・わり算ができる | 文章。数にしにくいことを、そのまま受けとめる |
| 時間の見方 | ある時点を切りとる（横断面調査） | 時間の流れを長く見る（時系列調査） |
| 向いている場面 | まち全体や、いくつものまちへの開発・事業の **影響を広く知る**（アンケート） | まちの物語、歴史や文化を知る（ワークショップ、インタビュー） |

- 質的調査は、量的調査の **足りないところを批判して** 生まれた別のやり方。
- でも2つは **ぶつかり合うものではなく、おぎない合うもの**。まちの調査では両方を使うことが多い。目的とだれを調べるかで選ぶ。

```quiz
Q: 数で見る調査（量的調査）と、ことばで見る調査（質的調査）の関係として、講義に合うのは？
1: どちらか一方だけを使わなければならない
2: 質的調査は、いつも量的調査より正確
3: おたがいにおぎない合い、目的と相手によって選ぶ
4: 量的調査は、まちの物語を調べるのにいちばん向いている
C: 3
E: 2つは対立ではなく補い合い。まちの調査では両方使うことが多い。ほかの選択肢：1は両方使う講義の考えに合わない。2はどちらが上ということはない。4は逆で、物語や歴史は質的調査（インタビューなど）が向いている。
```

## 4. まちの調査の中身と3つの段階
**何を調べる？**：まちの歴史と文化・伝統／まちの資源／住民の考え方やふるまい

```flow
① 計画と下調べ（企画・基礎調査） → ② 現地で調べる（現地調査） → ③ 分析してまとめる（分析・整理）
```

**① 計画と下調べの段階** がとても大事
- これまでの資料や研究を読んで、**目的・方法・日程** の大まかな設計をする。
- かかる期間・人数・お金・道具をそろえ、チームで準備をたしかめる。
- 調べる前に、まちに入れるか・資料が集まるか・調査が進められるか、**実際にできるか** をたしかめる下調べ（探索的調査）が必要。
- 調べる相手を決め、選び方（標本抽出）を決め、**質問票の下書き** を作る。ためしに使ってみて（予備調査）直す。調べる人への説明書と研修、まちとの相談もすませる。
- ここをいいかげんにすると、あとで思わぬ問題が出て、**調査全体がうまくいかなくなる**。

## 5. 5つの調べ方
| 方法 | どんなもの | よいところ・気をつけること |
|---|---|---|
| **すでにある資料**（2次資料調査） | 国や自治体などが調べてためた資料。統計庁の人口住宅総調査（5年ごと）など | お金・時間・手間がかからず、信頼できる。組み合わせ次第でいろいろ使える |
| **アンケート**（設問調査） | たくさんの人に同じ質問をする。いちばんよく使われる | 統計で分析しやすく、結果がはっきり。ただし **科学的な手順を守らないと、結果は「ごみ」** になる |
| **じっくり聞く**（深層インタビュー） | 少ない人と深く話す。まちの公式・非公式のリーダーや長老が多い | アンケートではわからない細かいことがわかる。**だれに聞くか** が大事（まちを知らない人や、かたよった見方の人だと結果がゆがむ）。紹介された人にも追加で聞く。政策のアイデアを得るのに向く |
| **みんなで地図を作る**（コミュニティマッピング） | まちの地図づくり。資源、開発の必要、交通安全地図、まちの安全地図、障害のある人の通りやすさなど | **住民がいっしょに参加できる** 調査。紙でもスマホでもでき、結果が目で見てわかる |
| **ワークショップ** | 住民が集まり、話し合って意見を出す | 開かれていて、みんなで参加できる。まちの状況・方向・優先順位などを広く知れる。**進行役しだい** で成功も失敗もするので、専門性があり **中立な進行役** が必要 |

```quiz
Q: 住民がいっしょに参加でき、紙やスマホでまちの資源や安全な道などを書きこんでいく調べ方は？
1: すでにある資料の調査（2次資料調査）
2: アンケート（設問調査）
3: みんなで地図を作る（コミュニティマッピング）
4: じっくり聞く（深層インタビュー）
C: 3
E: コミュニティマッピングは住民参加型の調査で、まちの自治や民主的な話し合いの面でも注目されている。ほかの選択肢：1は国や自治体の資料を使う方法。2はたくさんの人に同じ質問をする方法。4は少ない人と深く話す方法。
```

## 6. 調べるときのコツ（調査の技術）
- 調査の成功は **最初の出会いでほぼ決まる**。服装・話し方・表情まで、きちんと、まじめに。
- まずあいさつ。自分と訪問の目的、調査の主催者・目的・中身をかんたんに説明する。
- 「なぜ私が選ばれたの？」と不安になる人もいる。**選び方や、個人情報をどう守るか** をしっかり説明して安心してもらう。
- かかる時間を前もって伝え、事務的な話し方より **親しみのある会話** にする。
- 町では、たくさんの調査に疲れていて **断る人が多い**。できるだけお願いしてみる。その場で答えられないときは、また来る日時と場所を約束する。
- 相手の年齢に合わせて、話す速さや声の大きさを変える。
- 最後に、答えのもれがないか質問票をていねいに見直す。

## 7. 調べる人の心がまえと決まり
**心がまえ**
- 調査は **両方向のやりとり**。調べる中でできた信頼は、そのあとのまちの活動にも役立つ。
- 調べる人の態度・ことば・身なりで、まちの人の答え方が変わる。だから **前もっての研修と練習が欠かせない**。
- 調査をよく知り、**客観的で中立** な姿勢で。まちと社会の役に立ち、政策づくりに参加している **誇り** を持つ。
- はですぎる服や、かたすぎる服はさける。答える人は身がまえるのがふつうなので、困ったときの対応も準備しておく。

**守る決まり（調査の倫理）**
- まちや住民の情報は、**外にもらさない、ほかの目的に使わない**（個人情報は法律で守られ、破ると罰がある）。
- 決まった相手が留守でも、**勝手にほかの人にかえない**。
- **1つの家で2人以上を調べない**（家族の答えが影響し合って、結果がゆがむのを防ぐ）。
- **特定の答えにさそわない**、ほのめかさない。
- 答えを **勝手にちぢめたり、かえたりして書かない**。

```quiz
Q: 調べる人が守る決まり（調査の倫理）として、正しくないものは？
1: 集めた情報を、ほかの目的に使わない
2: 決まった相手が留守なら、となりの家の人に勝手にかえてよい
3: 1つの家で2人以上を調べない
4: 特定の答えにさそわない
C: 2
E: 決まった相手が留守でも、勝手にほかの人にかえてはいけない。ほかの選択肢：1、3、4はどれも講義の決まりのとおり。3は家族の答えが影響し合うのを防ぐため。
```

## まず、この3つ
1. まちの調査は、目に見えるもの・見えないものの価値を見つける、**まちとの両方向のやりとり**。
2. 数で見る調査とことばで見る調査は **おぎない合う**。段階は **計画と下調べ → 現地調査 → 分析とまとめ**。
3. 5つの方法（すでにある資料・アンケート・じっくり聞く・みんなで地図・ワークショップ）を使い分け、**中立と情報の秘密** を守る。

## ひびきの暮らしでいうと
- 住む町を知りたいときも、まず役所の統計（すでにある資料）を見て、地図に気づいたことを書きこみ、近所の長く住む人に話を聞く。この順番は、そのまま使える。
- 人に話を聞くときは、最初のあいさつと「なぜ聞くのか」の説明で、ほとんど決まる。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。

```quiz
2: 深層インタビュー
3: ワークショップ
4: 予備調査
C: 1

```

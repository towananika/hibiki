# 貨幣金融論 13講 ― 国の所得は、どう決まる？（ケインズの簡単なモデル）

韓国の放送大学「貨幣金融論」13講（スライド28枚）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

> 5〜10分で読む「[会話で読む版](view.html?n=money13t)」もあります。

```flow
国の所得（国民所得）とは → 買いたい量と作る量がつり合う所 → 民間だけの場合 → 政府を入れた場合 → 乗数効果（変化が何倍にもなる）
```

## 0. ひとことで
- 国全体の「買いたい量（需要）」と「作る量（供給）」が一致した所で、**国の所得が決まる**（ケインズの考え）。
- 支出が少し変わると、国の所得はそれより **何倍も** 変わる。これを **乗数効果** という。

## 1. 国の所得（国民所得）ってなに？
国の経済力や、人々の生活の水準を見るための、いちばんよく使われる目安。2つの言い方がある。

| 言葉 | 意味 |
|---|---|
| **国民総生産**（GNP） | その国の **国民** が、一定の期間に作った「最終の物やサービス」の価値を、市場の値段で足し合わせたもの |
| **国内総生産**（GDP） | **国内に住む人や会社** が、一定の期間に作った「最終の物やサービス」の価値を、市場の値段で足し合わせたもの |

- 「最終」とは、完成して買う人に渡るもの。途中の材料は足さない（二重に数えないため）。

## 2. 均衡国民所得 ― 買いたい量と作る量がつり合う所
**均衡国民所得**（きんこうこくみんしょとく）は、「作る量（総生産の供給）」と「買いたい量（総生産への需要）」を、ちょうど同じにする国民所得。

買いたい量は、4つの合計。
| 記号 | 言葉 | だれの支出？ |
|---|---|---|
| C（消費） | 消費支出 | 家計（民間） |
| I（投資） | 投資支出（設備や在庫に使うお金） | 会社（民間） |
| G（政府） | 政府支出 | 政府 |
| NX（純輸出） | 輸出 − 輸入 | 海外 |

```eq
作る量 Y = 買いたい量（C + I + G + NX）
```

> 補足（式で書くと）：Y は総生産量（＝国民所得）。この講では、海外（NX）は考えず、民間と政府だけで見ます。

```quiz
Q: 均衡国民所得とは？
1: 作る量と、買いたい量が一致する国民所得
2: 政府の借金がゼロになる所得
3: 全員の給料が同じになる所得
4: 輸出と輸入が同じになる所得
C: 1
E: 総生産の供給（作る量）と、総生産への需要（買いたい量）が一致する国民所得です。ほかの選択肢：2・3・4は、均衡国民所得の意味とは関係がない。
```

## 3. 民間だけの経済（政府をふくまない）
### ① 消費の決まり方（消費関数）
ケインズは、消費を決めるいちばん大事なものは **所得の大きさ** だと考えた。

```eq
消費 C = 独立消費 C0 + 限界消費性向 b × 所得
```

| 記号 | 言葉 | やさしい意味 |
|---|---|---|
| C0 | 独立消費 | 所得がなくても、生きるために使うお金。いつも0より大きい |
| b | 限界消費性向 | 所得が1増えたとき、消費が増える割合。0より大きく、1より小さい（0 < b < 1） |

- 0 < b：所得が増えれば、消費も増える。
- b < 1：増えた所得を **全部は使わない**（一部は貯金）。
- 例：消費 ＝ 1兆ウォン ＋ 0.8 × 所得。所得が100億ウォン増えると、消費は80億ウォン増える。

> 補足：この講では税金がない場合、「使えるお金（可処分所得）」と「所得」は同じ。

### ② 投資の決まり方
投資 ＝ **固定投資**（機械や工場、建物をそろえる支出）＋ **在庫投資**（会社が持つ在庫の増えた分）。

ケインズは、投資の大きさを決めるものを2つあげた。
- **金利**：金利が上がると、お金を借りて投資する費用が高くなる（機会費用が上がる）ので、投資は減る。
- **会社の将来の見こみ**：もうかりそうなら、投資は増える。

そして、**「いまの国民所得は、投資の大きさには影響しない」** と考えて、投資を一定の値（I0）とおく。

```quiz
Q: 消費関数 C = C0 + bY の限界消費性向 b について、正しいのは？
1: b は0より大きく、1より小さい
2: b はいつも1より大きい
3: b は所得がなくても使う金額のこと
4: b はマイナスの値
C: 1
E: 所得が増えれば消費も増えるが、全部は使わないので、0 < b < 1です。ほかの選択肢：2は、増えた所得より多く使うことになってしまう。3は独立消費C0の説明。4はありえない。
```

### ③ 均衡国民所得を求める（例）
消費 C ＝ 1兆ウォン ＋ 0.8Y、投資 I ＝ 2兆ウォン のとき。

```eq
Y = C + I = 3兆 + 0.8Y   →   Y = 15兆ウォン
```

> 補足（解き方）：Y − 0.8Y ＝ 3兆 なので、0.2Y ＝ 3兆、Y ＝ 15兆。

## 4. 政府を入れた経済
政府の支出 G と、税金 T が加わる。税金を引いた「使えるお金」で消費を決める。

```eq
Y = 1/(1−b) × ( C0 + I0 + G − b×T )
```

民間だけの場合とくらべると、需要の面で **政府支出が足され**、**限界消費性向 × 税金の分が引かれる**。

例：G ＝ 2兆ウォン、T ＝ 2兆ウォン（C0＝1兆、I0＝2兆、b＝0.8）のとき。
```eq
Y = 1兆 + 0.8×(Y − 2兆) + 2兆 + 2兆 = 3.4兆 + 0.8Y   →   Y = 17兆ウォン
```
政府が2兆ウォンを税金で集めて、そのまま使ったのに、国民所得は **15兆 → 17兆ウォン（2兆ふえた）**。

**なぜ？** 集めた税金のうち、家計は一部（0.8の割合）だけ消費を減らす。でも政府は、集めた2兆ウォンを **全部使う**。だから、全体の需要は、差し引きで増えるため。

```quiz
Q: 政府が2兆ウォンを税金で集めて、そのまま使ったとき、国民所得は政府なしの場合とくらべてどうなる？（b = 0.8）
1: 変わらない
2: 2兆ウォン増える
3: 2兆ウォン減る
4: 10兆ウォン増える
C: 2
E: 税金で家計の消費は減るが、政府は全額を使うので、差し引きで需要が増え、所得は15兆から17兆ウォンへ2兆増えます。ほかの選択肢：1は、政府の支出が全額使われることを見落としている。3は向きが逆。4は政府支出の乗数（5倍）だけを見て、税金で減る分（4倍）を引いていない。
```

## 5. 乗数効果 ― 変化が何倍にもなる
**乗数効果**：需要を作る支出（C・I・G）が変わったとき、国民所得が **もとの変化より大きく**（乗数ぶんだけ）変わること。

```flow
投資が1兆ふえる → 所得が1兆ふえる → そのうち0.8兆が消費にまわる → 他の人の所得が0.8兆ふえる → さらに0.64兆が消費に … → 合計5兆
```

| 数え方 | 増える額（兆ウォン） |
|---|---|
| はじめの投資の増加 | 1 |
| 1回めの消費の増加（0.8×1） | 0.8 |
| 2回めの消費の増加（0.8×0.8） | 0.64 |
| … これがずっと続く | … |
| **合計** | **5** |

### 乗数の大きさ
```eq
投資の乗数 = 政府支出の乗数 = 独立消費の乗数 = 1 ÷ (1 − 限界消費性向)
```
- b ＝ 0.8 なら、乗数は 1 ÷ 0.2 ＝ **5**。
- 投資が2兆から3兆ウォンに増えると、国民所得は 17兆 → 22兆ウォン（5兆の増加）。

> 補足：b が大きいほど（増えた所得を多く使うほど）、乗数は大きくなります。

```quiz
Q: 限界消費性向が0.8のとき、投資が1兆ウォン増えると国民所得はいくら増える？
1: 1兆ウォン
2: 0.8兆ウォン
3: 4兆ウォン
4: 5兆ウォン
C: 4
E: 乗数は 1÷(1−0.8)＝5なので、1兆の投資の増加が、国民所得を5兆ウォン増やします。ほかの選択肢：1はもとの増加分だけで、乗数効果を考えていない。2は1回めの消費の増加だけ。3は税の乗数（4）と取り違えた答え。
```

### 税金の乗数
- 税金が1兆ウォン増えると、使えるお金が1兆減り、消費が0.8兆減り、…とくり返す。
- 税金の乗数は、**マイナスで、b ÷ (1 − b)**。b＝0.8なら **−4**（1兆の増税で、所得は4兆減る）。
- 政府支出の乗数（5）より **小さい**。政府支出は全額が需要になるが、減税・増税は一部だけが消費に回るため。

### 均衡財政の乗数
政府が、税金を1兆ウォン増やして、同じ1兆ウォンを使ったら？
- 消費は 0.8兆 減る。でも政府支出が 1兆 増える。需要は差し引き **0.2兆** 増える。
- 所得は、この増加に乗数5をかけた **1兆ウォン** 増える。

```eq
均衡財政の乗数 = 5（政府支出） − 4（税金） = 1
```

つまり、**税金で集めた額と同じ額を使うと、国民所得は、その額だけ増える**。

```quiz
Q: 限界消費性向が0.8のとき、税金が1兆ウォン増えると、国民所得はどうなる？
1: 4兆ウォン減る
2: 5兆ウォン減る
3: 1兆ウォン減る
4: 変わらない
C: 1
E: 税金の乗数は b÷(1−b)＝0.8÷0.2＝4で、マイナスなので4兆ウォン減ります。ほかの選択肢：2は政府支出の乗数（5）と取り違えた答え。3は乗数効果を考えていない。4は、増税が消費を減らすことを見落としている。
```

## まず、この3つ
1. 国民所得は、作る量と買いたい量（C＋I＋G）がつり合う所で決まる。
2. 消費は所得で決まり（C＝C0＋bY）、投資は金利と将来の見こみで決まる（いまの所得とは無関係）。
3. 支出が変わると、所得は乗数（1÷(1−b)）倍に変わる。税の乗数は −b÷(1−b)、均衡財政の乗数は1。

## ひびきの暮らしでいうと
- 「所得が増えたとき、どれだけ使うか」は、人によって大きくちがう。ひびきは貯める習慣が強いので、限界消費性向は小さめ。国全体では、人がたくさん使うほど、経済は大きくまわる。
- 自分が使ったお金は、だれかの所得になり、その人がまた使う。この「お金のめぐり」が、乗数効果の考え方。

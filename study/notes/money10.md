# 貨幣金融論 10講 ― 中央銀行のお金のかじ取り

韓国の放送大学「貨幣金融論」10講（スライド40枚）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
金利を下げる → 5つの道で広がる → 投資・消費がふえる → 生産と物価が上がる
```

## 0. ひとことで
中央銀行は**金利を上げ下げしたり、お金の量を増やしたり減らしたり**して、景気と物価をちょうどよくする。
その効き目は**5つの道**を通って暮らしに届く。道具は**3つの昔ながらの道具**と、金利がほぼ0のときの**特別な道具**がある。

## 1. しくみの全体
| 使う道具（政策手段） | 途中の目印（中間目標） | 最後のゴール（最終目標） |
|---|---|---|
| 銀行への貸し出し（再割引・貸出政策） | 世の中のお金の量（通貨量） | 物価を落ち着かせる（物価安定） |
| 銀行に積ませるお金（支払準備） | 為替レート | お金の仕組みを安全に（金融安定） |
| 国債の売り買い（公開市場操作） | 物価の上がり方（インフレ率） | みんなが働ける（完全雇用）・成長 |

土台には、**政府に左右されない（独立性）**と、**説明する責任（責任性・透明性）**がある。

## 2. 効き目が届く5つの道
例：中央銀行が金利を**下げた**とき

1. **金利の道**：銀行の金利が下がる → 会社は借りて投資、家計はローンで買い物 → 生産が増え、物価も上がる
   - ただし先行きが暗いと、金利が低くても会社は投資しないし、人も家や車を買わない。
2. **財産の値段の道（資産価格経路）**：株や家の値段が上がる
   - 会社：株価が高いと安く資金を集められて投資が増える（トービンの q：会社の株の値打ち ÷ 同じ設備を新しく買う費用。1より大きいと投資が得）
   - 家計：持っている株や家の値打ちが上がると、気が大きくなってお金を使う（資産効果）
3. **為替の道**：自国の預金の利息が下がる → ドルが人気 → ウォン安 → 輸出が増え、輸入品は高くなる
4. **貸し出しの道（信用経路）**：会社の財布に余裕ができる → 銀行が貸しやすくなる → 投資と消費が増える
   - 大企業は銀行に頼らないので、この道はあまり効かない。
5. **予想の道（期待経路）**：「景気がよくなる」「物価が上がる」とみんなが思う → 給料が上がる → 物価も上がる

> 補足：株や為替は金利以外の理由でも動くので、どの道も「いつも思いどおり」には動かない。


```quiz
Q: 大企業に効きにくい道はどれ？
1: 金利の道（金利経路）
2: 貸し出しの道（信用経路）
3: 為替の道（為替経路）
4: 予想の道（期待経路）
C: 2
E: 大企業は銀行からの借り入れにあまり頼らないので、銀行の貸し出しが増えても影響が小さい。
```

## 3. 昔ながらの3つの道具
| 道具 | やり方 | よいところ | 弱いところ |
|---|---|---|---|
| 積ませるお金（法定支払準備金） | 預金の一定の割合を手元に置かせる。割合を下げるとお金が増える | 全部の銀行にすぐ強く効く | 銀行ごとの違いを見ない。細かく調整できない。銀行の力を弱める |
| 銀行への貸し出し（再割引制度） | 中央銀行が銀行に貸す量や金利を変える | 困った銀行を助けられる | 先進国ではあまり使わない |
| 国債の売り買い（公開市場操作） | **買う → お金が増え金利が下がる**／売る → お金が減り金利が上がる | 中央銀行が主導できる、細かく調整できる、まちがえてもすぐ直せる。**いちばん優れた道具** | 国債を売り買いする市場が育っていることが前提 |

韓国で積ませる割合の例：住宅のための長期の積立は0%、定期預金は2%、いつでも出せる預金は7%。


```quiz
Q: 中央銀行が国債を買うと、金利はどうなる？
1: 上がる
2: 変わらない
3: 下がる
4: 国債の値段だけ下がる
C: 3
E: 国債を買うとお金（本源通貨）が増え、国債の人気で値段が上がる。国債の値段が上がると金利は下がる。
```

## 4. 金利がほぼ0のときの特別な道具
- **先の約束（フォワードガイダンス）**：「しばらく低い金利を続けます」と前もって言う。2008年12月にアメリカの中央銀行が実際に言った。
- **お金を大量に流す（量的緩和）**：国債などをたくさん買う。アメリカは QE1〜QE4 で、持っている資産を約1兆ドルから約9兆ドルに増やした（2022年）。
  - 困った銀行への急ぎの貸し出し
  - 長期の国債や住宅ローン債券を買う
  - **組み替え（オペレーション・ツイスト）**：短い国債を売って長い国債を買い、長期金利を下げる


```quiz
Q: 短い国債を売って長い国債を買い、長期金利を下げる方法は？
1: オペレーション・ツイスト
2: 法定支払準備金
3: 再割引制度
4: フォワードガイダンス
C: 1
E: 売る国債と買う国債の期間を組み替えるので「ツイスト（ねじる）」と呼ぶ。ねらいは長期金利を下げること。
```

## ひびきの暮らしでいうと
- 住まいのローンは「金利の道」のど真ん中。中央銀行が金利を下げれば、利息の負担は軽くなりやすい。
- 金利が下がると、ウォン安で輸入品が高くなりやすい（為替の道）。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。


```quiz
Q: 中央銀行の3つの昔ながらの道具に入らないものは？
1: 銀行に積ませるお金の割合を変える（支払準備制度）
2: 銀行に貸す量や金利を変える（再割引制度）
3: 国債を売り買いする（公開市場操作）
4: 所得税の税率を変える
C: 4
E: 税率を変えるのは政府の財政政策。中央銀行の道具ではない。
```

```quiz
Q: いちばん優れた道具と言われる（公開市場操作）の長所として、正しくないものは？
1: 中央銀行が自分から動ける
2: 少しずつ細かく調整できる
3: まちがえてもすぐ逆の操作で直せる
4: 国債の市場が育っていなくても使える
C: 4
E: 国債を売り買いする市場が育っていることが前提。
```

```quiz
Q: 金利がほぼ0のとき、国債などを大量に買ってお金を流す方法は？
1: 量的緩和
2: フォワードガイダンス
3: 法定準備率の引き上げ
4: 再割引率の引き上げ
C: 1
E: 量的緩和（QE）。アメリカは QE1〜QE4 を行った。
```

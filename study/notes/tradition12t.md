# 伝統社会と生活文化 12講【会話で読む】― 奴婢の暮らし

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition12)」。

## 1. 奴婢ってだれ？（5分）

```talk
B: 奴婢って、だれのこと？
A: 奴は男の使用人、婢は女の使用人。あわせて奴婢。朝鮮王朝で、いちばん低い身分。法律では、人はふつうの民（良人）と低い身分（賤人）の2つ（良賤制）で、賤人の代表が奴婢。
B: どうして奴婢になる？
A: はじめは罪をおかした人がなった。でも大半は、親が奴婢だから生まれつき奴婢。
B: なぜ制度を続けた？
A: 国や役所は、税だけでは足りない働き手と品物を安定して得るため。両班の家は、毎日の家の仕事と品物のため。奴婢は土地と並ぶ大事な財産だった。
C: 生まれで身分が決まる。
```

```card
要点
- 奴＝男の使用人、婢＝女の使用人。良賤制（良人と賤人）
- 大半は、親が奴婢だから生まれつき奴婢
- 国や役所は働き手と品物のため、両班の家は家の仕事と品物のため
```

## 2. 国の奴婢と家の奴婢（10分）

```talk
B: 奴婢の種類は？
A: 国の奴婢（公奴婢）と、家の奴婢（私奴婢）。国の奴婢は、働きに行く奴婢（選上奴婢）と、品物を納める奴婢（納貢奴婢）。納貢奴婢は、毎年、奴は綿布2枚、婢は1枚半を納めた。かなり重い負担。
B: 家の奴婢は？
A: 2つ。主人の家に住む奴婢（率居奴婢）は、ごはん・洗たく・まき集め・使い走りなど。主人の目がいつもあり、自由が少ない。離れて住む奴婢（外居奴婢）は、決まった品物（身貢）を納め、自分の家と戸籍があり、ふつうの民とあまり変わらない。空いた時間に農業や商売で財産をふやせた。
B: 財産は持てた？
A: 持てた。朝鮮では、身分に関係なく自分の財産（私有財産）が認められた。15世紀、忠清道の奴の林福は、不作の年に穀物を2,000石出した。財産は相続もできた。お金持ちの奴婢は、たいてい離れて住む奴婢。
C: 離れて住む奴婢は、財産をふやせた。
```

```card
要点
- 公奴婢：選上奴婢（働きに行く）／納貢奴婢（品物を納める。奴は綿布2枚、婢は1枚半）
- 私奴婢：率居奴婢（主人の家に住む）／外居奴婢（離れて住み、身貢を納める）
- 奴婢も私有財産を持て、相続もできた（外居奴婢が多い）
```

## 3. 子どもの身分（5分）

```talk
B: 子どもの身分は、どう決まる？
A: 親のどちらかが奴婢なら子も奴婢（一賤則賤）。いちばん強い原則。もう1つ、母の身分に従う（従母法）。持ち主は、母（婢）の主人。
B: 奴とふつうの民の女性が結婚したら？
A: 母に従えば、子は自由な民になり、奴の主人が損をする。だから両班は、奴婢とふつうの民の結婚（良賤交婚）をわざとすすめた。夫婦2人とも自分の奴婢になるように。
B: 両班が婢に産ませた子は？
A: 主人が自由にしないかぎり、奴婢のまま。
C: 主人に都合よく決めた。
```

```card
要点
- 一賤則賤：親のどちらかが奴婢なら子も奴婢
- 従母法：子は母の身分に従う。持ち主は母（婢）の主人
- 良賤交婚：両班がわざとすすめた
```

## 4. 名前・扱い・相続（5分）

```talk
B: 扱いは？
A: 名前をぞんざいに付けて呼ばれたのは奴婢だけ（「石ころ」「庭」「子犬」など）。奴婢は、売る・相続する・贈る・借金のかたにすることができた。
B: 相続は？
A: 朝鮮の前半は、子どもに同じだけ分ける均分相続。その結果、奴婢の家族は別々の主人に分けられた。家族ごと逃げるのを防ぐねらいもあった。17世紀後半から長男中心の相続に変わり、娘は相続からも祭りの役目からも外されていった。
C: 相続で、家族がばらばらに。
```

```card
要点
- 奴婢は、売る・相続する・贈る・借金のかたにできた
- 均分相続 → 奴婢の家族が別々の主人に分けられた
- 17世紀後半から長男中心の相続へ
```

## 5. 抜け出す道、そして制度の終わり（10分）

```talk
B: 奴婢は、どうやって抜け出した？
A: 4つ。逃げる（逃亡）がいちばん多く、壬辰倭乱のあとも増えた。手柄を立てる。自由の証明書を買う（免賤帖）。主人にお金を払う（贖価）。
B: 主人は？
A: 逃げた奴婢を追った（推刷）。ドラマ「推奴」はこの話。主人を殺すなど強い反抗は、死刑になるので少なかった。
B: 制度は、どう終わった？
A: 英祖のとき、民の軍の税（軍布）を軽くする均役法。国の奴婢の負担も軽くなったけど、逃亡は止まらなかった。1801年に、王室と役所の奴婢を解放（内寺奴婢の革罷）。家の奴婢は、従母法で、奴と民の女性の子は民になる流れ。1886年に奴婢の身分を親から子へ受けつぐことを廃止、1894年の甲午改革で身分制そのものを廃止。
B: 記録は？
A: 戸籍と、財産を分ける書類（分財記）が主な記録。
C: 逃げる人の積み重ねが、制度を変えた。
```

```card
要点
- 抜け出す道：逃げる（逃亡）／手柄を立てる／免賤帖（自由の証明書を買う）／贖価（主人にお金を払う）
- 推刷：主人が逃げた奴婢を追う
- 1801年：王室と役所の奴婢を解放／1886年：身分の世襲を廃止／1894年：甲午改革で身分制を廃止
- 記録：戸籍と分財記
```

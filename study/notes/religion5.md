# 世界の宗教 5講 ― キリスト教：イエスを「救い主」と信じる

**この講で覚えること：キリスト教は、イエスを中心にした宗教。イエスは、きまりの文字よりも「心」と「人を生かすこと」を大切にした。特徴は6つ ― 唯一の神を礼拝・イエス＝キリスト・インマヌエル（神がともにいる）・すべての人へ（普遍）・聖書と秘跡・儀式。**

韓国の放送大学「世界の宗教」第5講の講義資料をもとに、日本語でまとめたノートです。資料の聖書の引用は、そのまま訳さず、要点を自分の言葉にしました。

## 0. この講の地図（3分）

```flow
① 名前の意味 → ② イエスはどんな人？ → ③ きまりとぶつかる → ④ 広がり、3回分かれる → ⑤ 特徴の6本柱
```

読み方：各節は「会話 → 図 → 要点カード → 4択」。最後に「書く準備」「言いかえ練習」「確認テスト」があります。

## 1. まず言葉をそろえる（3分）

```card
5講の4つの言葉
- キリスト：ギリシア語「クリストス」＝油を注がれた者、つまり救い主。イエスの名字ではない
- ファリサイ派：ユダヤ教のきまり（律法）をきびしく守ろうとした人びと
- 律法：神が与えたとされる、生活と信仰のきまり
- インマヌエル：「神は私たちとともにいる」という意味
```

> 補足：韓国では「キリスト」を漢字で「基督（きとく）」と書き、「キリスト教」を「基督教」と呼びます。日本語でも昔は「基督教」と書きました。

## 2. イエスはどんな人？（5分）

```talk
B: 宗教の始まりの人って、きびしいきまりを作る人じゃないの？
A: イエスは反対なんだ。講義では「水や風のような道を歩んだ人」と表されていた。どこにでも流れていき、形にしばられない、という感じ。
B: 中心は、きまりじゃなくてイエスその人？
A: そう。キリスト教は、教えの本より先に「イエスという人」が中心にある。だから名前も「キリスト（救い主）の教え」なんだ。
C: キリスト教の中心は、イエスという人。
```

```card
イエスの姿
- ユダヤ人として生まれ、ユダヤ教の中で教えた
- 病気の人、きらわれた人のそばに行った
- 形にとらわれず、水や風のように自由に動いた
- 弟子たちは、イエスを「待っていた救い主（キリスト）」と信じた
```

```quiz
Q: 「キリスト」とは？
1: イエスの名字
2: 救い主という意味の呼び名
3: イエスが生まれた町の名前
4: 教会の建物のこと
C: 2
E: 「油を注がれた者」＝救い主という意味です。だから「イエス・キリスト」は「イエスは救い主」という信仰の言葉になります。ほかの選択肢：名字や地名ではありません。
```

## 3. きまりとぶつかる ― イエスとファリサイ派（7分）

```talk
B: どうしてイエスは、ほかのユダヤ人とぶつかったの？
A: たとえば安息日。働いてはいけない休みの日に、イエスは病気の人を治したり、おなかをすかせた弟子が麦の穂をつんで食べるのを止めなかった。
B: きまりを破ったってこと？
A: ファリサイ派から見るとそう。でもイエスは「きまりは人を生かすためにある」と考えた。それに、自分を神の子と呼んだことも、強い反発を受けた。
B: じゃあ、イエスはきまりなんていらないと言ったの？
A: そこがポイント。「なくしに来たのではなく、完成させに来た」と言ったんだ。行いの形だけでなく、心の中まで問う、もっと深い守り方を求めた。
C: きまりの「形」より、きまりの「心」。
```

```flow
外の行いだけ守る（形） → 心の中まで正す（内面） → 人を生かす（愛）
```

```card
イエスの「きまり」の読み方
- 安息日でも、困っている人を助けることを優先した
- 「悪いことをしなければよい」でなく、心に悪い思いを持つことまで問うた
- 律法をなくすのではなく、完成させると言った
- 自分を神と深く結びつけたことが、反発と十字架の死につながった
```

```quiz
Q: イエスが律法について言ったことに近いのは？
1: 律法はもういらないので、すべて捨てなさい
2: 律法は形どおり守れば、心の中は問わない
3: 律法をなくすのではなく、心の中まで深めて完成させる
4: 安息日は、どんな理由でも人を助けてはいけない
C: 3
E: 「なくしに来たのではなく、完成させに来た」と言い、心の中まで問いました。ほかの選択肢：1は言いすぎ、2と4はファリサイ派の考え方に近いものです。
```

## 4. 広がり、3回分かれる（5分）

```talk
B: キリスト教って、ずっと一つだったの？
A: 講義では、大きく3回分かれたと整理していた。
B: 何でそんなに分かれるの？
A: 1回目は「イエスは神なのか、人なのか」という考え方の違い。2回目は東と西の教会の違い。3回目は教会のあり方への批判。広がるほど、考え方の違いも出てくるんだ。
C: 3回の分裂で、いまの姿になった。
```

```timeline
30年ごろ | イエスの十字架と復活 | 弟子たちが教えを広める
325年 | ニカイア公会議 | ここから約200年、イエスの理解をめぐって分かれる（1回目）
1054年 | ローマ・カトリックと正教会 | 西と東の教会が分かれる（2回目）
16世紀 | 宗教改革 | プロテスタントが生まれる（3回目）
```

> 補足：公会議は、各地の教会の代表が集まり、信仰の考えを決める会議です。

```quiz
Q: 2回目の分裂で分かれたのは？
1: カトリックとプロテスタント
2: ローマ・カトリックと正教会
3: ユダヤ教とイスラム教
4: ファリサイ派と弟子たち
C: 2
E: 西のローマ・カトリックと、東の正教会です。ほかの選択肢：カトリックとプロテスタントは3回目（宗教改革）です。
```

## 5. 特徴の6本柱（7分）

講義のまとめは、次の6つです。**課題の「特徴」の骨組み**になります。

```card
キリスト教の6つの特徴
- ① 唯一の神を礼拝：ただひとりの神だけをおがむ
- ② イエス＝キリスト：イエスこそ救い主だと信じる
- ③ インマヌエル：神は遠くにいるのではなく、人とともにいる
- ④ 普遍をめざす：一つの民族だけでなく、すべての人に開かれる
- ⑤ 聖書と秘跡：神のことばの本と、目に見える恵みのしるし（洗礼など）
- ⑥ 儀式：礼拝やミサで、信仰をいっしょに表す
```

```talk
B: ④の「普遍」って？
A: ユダヤ教は、主にユダヤの民の宗教だった。キリスト教は、民族や身分に関係なく「だれでも」と開いた。それで世界中に広がったんだ。
B: ③のインマヌエルは、①の唯一神とどうつながる？
A: ただひとりの大きな神が、イエスを通して人のすぐそばに来た、と考える。遠い神と近い神が、イエスでつながる感じだね。
C: ひとりの神が、イエスを通して、すべての人のそばに。
```

```quiz
Q: 「普遍をめざす」の意味は？
1: 一つの民族だけの宗教であること
2: 民族や身分に関係なく、すべての人に開かれていること
3: 毎日同じ食事をすること
4: 儀式をしないこと
C: 2
E: 一つの民族をこえ、すべての人に向かうという意味です。ほかの選択肢：1はその反対です。
```

```quiz
Q: 「秘跡（サクラメント）」の例は？
1: 洗礼
2: ラマダーンの断食
3: 八正道
4: メッカ巡礼
C: 1
E: 洗礼は、目に見えない神の恵みを目に見える形で表す儀式（秘跡）の一つです。ほかの選択肢：断食と巡礼はイスラム教、八正道は仏教です。
```

## 7. 言いかえ練習：写さずに、自分の文にする（5分）

課題のきまり：教材や講義の文をそのまま写すのは剽窃。「〜であること。」「〜する。」と並べる書き方はだめで、完結した文で書く。

```quiz
Q: 講義ふうの文「イエスは律法を廃止するのではなく完成するために来た」。いちばん良い言いかえは？
1: イエスは律法を廃止するためでなく、完成するために来た。
2: 律法の完成のために来たこと。
3: イエスは、安息日のような古いきまりを捨てたのではなく、その目的である「人を生かすこと」まで深めて守ろうとした。
4: イエスは、律法はすべて意味がないと教えた。
C: 3
E: 3は意味を保ち、安息日の例も入った自分の文です。ほかの選択肢：1は語順を少し変えただけの写し、2は「〜こと。」の箇条書きふう、4は意味が変わっています。
```

```card
言いかえのコツ（3つ）
- 本を閉じて、友だちに話すように書く
- 自分で選んだ例を1つ入れる（安息日・心の中の罪・普遍など）
- 「〜である。なぜなら〜」と、理由までつなげて文を書き切る
```

## 8. まず、この3つを覚える

1. **イエス＝キリスト**：イエスを救い主と信じる。中心は「イエスという人」。
2. **律法の完成**：形より心。人を生かすことを優先する。
3. **6つの特徴**：唯一神・イエス＝キリスト・インマヌエル・普遍・聖書と秘跡・儀式。

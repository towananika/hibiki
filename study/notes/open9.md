# 開かれた社会と21世紀 9講 ― まちを変える法と制度

**住民が自分たちで始めたまちづくりを、ルール（法律や条例）で支えて長続きさせる。ただし、ルールが住民の自由をうばってはいけない。**

添付の第9講講義録をもとに整理しました。（　）の中は試験に出る正式な言い方です。

```flow
みんなで話し合う（社会化） → 議会と調整（政治化） → きまりにする（制度化） → 施策にする（政策化）
```

## 1. 住民の活動をルールにする
- 各地で、住民が中心のまちづくりが広がっている（協同組合、地域通貨、エネルギー自立のまち など）。
- 古い建物を壊して新しくする開発に対して、**住む人が中心の再生**（住居・都市再生）も増えた。
- それを国や自治体がルールにして支えることを **制度化** という。
  - 国際的な約束、国の法律、自治体のきまり（条例）だけでなく、「みんなの当たり前」になることも含む。

```quiz
Q: 住民のまちづくりがルールになるまでの順番として正しいのは？
1: 制度化 → 政策化 → 社会化 → 政治化
2: 社会化 → 政治化 → 制度化 → 政策化
3: 政治化 → 社会化 → 政策化 → 制度化
4: 政策化 → 制度化 → 政治化 → 社会化
C: 2
E: まず地域で話し合い（社会化）、議会と調整し（政治化）、きまりにして（制度化）、実際の施策にする（政策化）。
```

## 2. ルールが必要なわけ、気をつけること
**必要なわけ**
- 市長や担当者が交代しても、活動が止まらないようにする。
- 住民と支援する組織の役割と責任（権限と責任）をはっきりさせる。

**気をつけること**
- 国が全国同じ点数表（評価指標）で評価すると、まちに順位がついて個性が消える。
- 補助金が、役所寄りの団体の力になってしまった例もある。
- 国の役所どうしが成果を競う（成果主義）と、住民の話し合いという「過程」が軽く見られる。

```quiz
Q: 住民がまちづくりの制度化を求めた理由に合うのは？
1: 補助金をできるだけ多くもらうため
2: 全国のまちに順位をつけるため
3: 市長や担当者が替わっても、活動を安定して続けるため
4: 住民の参加を減らすため
C: 3
E: 担当者の交代や世論に左右されず、計画的に続けるため。役割と責任をはっきりさせる目的もある。
```

## 3. 良い条例の中身
- 年齢・性別・心身の状態・出身・暮らし向きで、だれも差別しない。
- **18歳未満の子どもにも**、年齢に合った参加の権利がある。
- 住民票の住所ではなく、**そこで暮らしている人**（生活者）の目で住民を考える。
- 住民にも責任がある：自分の発言と行動、まちの決定に責任を持ち、参加を広げる努力をする。
- 行政と住民をつなぐ **支援センター**（中間支援組織）を置き、民間に任せる道も開く。
- 住民が中心となって開く**まちのお祭り**も支える（常設のお祭り委員会）。

```quiz
Q: 講義が勧める「住民」の考え方は？
1: 住民票に登録された人だけ
2: 家や土地を持っている人だけ
3: 18歳以上の人だけ
4: そこで暮らし、活動している人（生活者）
C: 4
E: 住民登録の住所ではなく、生活者の目で考える。子どもも年齢に合った参加の権利を持つ。
```

## 4. ソウル市の例
- 支援センターに窓口を一つにまとめ、住民がいつでも提案できるようにした。
- まちの育ち具合で支援を変える：

```flow
たね（つながりが弱い） → 新芽（つながりができた） → 希望（活動が活発）
```

**まちづくりの始まりと終わりは、住民とまち。** 建物中心から、人と、今と未来の世代を大切にする暮らしの場づくりへ。

> 補足：日本の「まちづくり条例」とほぼ同じ考え方です。

## 1. 通勤の費用を比べる（5分）

```talk
B: 車と電動の乗り物と公共交通を比べるとき、買う値段だけ見ればいい？
A: それだけでは足りない。使う間の費用も見る。総保有費用 ＝ 購入後の値下がり ＋ 燃料・電気 ＋ 保険・税・整備など。
B: ほかには？
A: 同じ年数・距離で比べる。時間（運転・乗換え・待ち時間）と、生活への適合（荷物・天候・駐車・充電）も見る。
B: 数え方の注意は？
A: 購入額全部を数える方法なら、最後に売って戻る金額を引く。購入額と値下がりを二重に数えない。
C: お金・時間・生活への適合の3つ。
```

```eq
総保有費用 = 購入後の値下がり + 燃料・電気 + 保険・税・整備など
```

```card
要点
- 総保有費用 ＝ 値下がり ＋ 燃料・電気 ＋ 保険・税・整備など
- 比べるもの：お金（同じ年数・距離）／時間／生活への適合
- 購入額と値下がりを二重に数えない
```

## 2. 電動化と自動運転（10分）

```talk
B: 電動化って？
A: 動力を電気モーターへ移すこと。3つの型がある。バッテリー式（BEV）は外から充電した電池で走る。PHEV は外からも充電できて、エンジンと電気を使う。燃料電池式（FCEV）は水素などから電気を作って走る。
B: 課題は？
A: 静かさや、走行時の排気の少なさが利点。一方、価格・充電設備・電池の寿命が課題。電気で走ることと、自動で運転することは別。
B: 自動運転のレベルは？
A: レベル0〜2は人が運転を担当・監視。レベル3は条件内ではシステムが運転し、求められたとき人が引き継ぐ。レベル4は決められた運行条件内でシステムが対応。レベル5は広い条件に対応する完全自動運転。
C: レベル3は引継ぎ、レベル4は条件内、レベル5は完全。
```

```card
要点
- BEV：電池で走る／PHEV：エンジン＋電気（外から充電可）／FCEV：水素などから電気を作る
- 電気で走る ≠ 自動で運転する
- レベル0〜2：人が担当／3：条件内はシステム、引継ぎが必要／4：運行条件内でシステム／5：完全自動
```

## 3. 移動を組み合わせる（5分）

```talk
B: 乗り物を持たなくても、移動できる？
A: 自転車を借り、バスへ乗り、必要ならタクシーを使う。出発から到着までの移動を、連続したサービスとして組み合わせる。
B: サービスの違いは？
A: 車両の共有は、借りた人が運転する。相乗りは、同じ車を複数の利用者で使う。配車サービスは、車と運転者を呼んで利用する。
B: 大事なのは？
A: 乗換え・予約・料金やデータの連携。1つのアプリに並べるだけでは、すべての移動が便利になるとは限らない。
C: 共有・相乗り・配車の3つ。
```

```card
要点
- 車両の共有：借りた人が運転／相乗り：同じ車を複数の利用者で／配車：車と運転者を呼ぶ
- 大事なのは、乗換え・予約・料金・データの連携
```

## 4. 渋滞は誰が負担する？（10分）

```talk
B: 渋滞は、自分の問題だけ？
A: ちがう。自分の車が混む道へ入ると、ほかの人の待ち時間も増える。その負担を、自分の判断に十分含めていないことがある。
B: 道路を増やせば？
A: 便利になって車の利用が増え、混雑が戻ることがある。混む時間や場所に料金をかける、時間を変える、相乗りや公共交通と組み合わせる、などを考える。
B: 新技術で混雑は消える？
A: 自動運転で移動中に休めるなら、長い移動を選ぶ人もふえるかもしれない。1台が賢くなることと、街全体が混まなくなることは別。
C: 自分の費用と、周囲への負担は別。
```

```card
要点
- 渋滞：自分が入ると、ほかの人の時間・環境にも負担
- 道路を増やしても、利用が増えて混雑が戻ることがある
- 対策：混む時間や場所への料金／時間の変更／相乗り／公共交通との組合せ
- 1台が賢い ≠ 街全体が混まない
```

## 5. 電動車に補助金を出す理由（5分）

```talk
B: 電動車に、なぜ補助金を出すの？
A: 社会にとっての利益が、買う人や作る人だけの利益より大きい場合。汚染を減らすことが、周囲の人の健康などにも役立つ。それと、生産経験から得た知識が、ほかの会社にも広がる（学習の波及）。
B: 必ず必要？
A: 「新しい」「量が増えると安い」だけでは決まらない。どの市場の失敗を直したいのかを考える。効果が薄れたり条件が変わったりしたら、対象や金額を見直す。
C: 汚染の減少と、学習の波及。
```

```card
要点
- 補助の理由：汚染を減らす利益／学習の波及（知識がほかの会社にも広がる）
- 補助が必ず必要とは決まらない。条件が変われば見直す
```

# 世界の宗教 11講 ― 日本の宗教：神さまと仏さまがいっしょにいる国

**この講で覚えること：日本では、ひとりの人が神社にも、お寺にも行く。神道と仏教は、長い時間をかけて重なり合ってきた。**

```flow
儒教・仏教が伝わる → 神さま（カミ）の信仰と重なる → 仏教が日本流に変わる → 新しい宗教も生まれる
```

## 1. 日本の宗教は、ひとつの箱に入らない

講義の資料は、次の4つを取り上げています。
- 中国や朝鮮から伝わった **儒教と仏教**
- 16世紀に伝わった **キリスト教**
- 日本にもとからある **神道**

日本の宗教は「どれかひとつ」で説明できません。**伝わってきたものと、もとからあるものが出会い、まざり合った**と見ると、わかりやすくなります。

## 2. 神道の「カミ」ってなに？

神道でいう **カミ** は、世界をつくったひとりの全能の神さまではありません。
- **ご先祖さま**（祖先神）
- **山・川・大きな木・岩などの自然**（自然物）

など、特別な力を感じるもの、おそれ敬う気持ちがわくものが、カミになります。

資料のポイントは3つ：
1. **人間とまったく別の存在ではない**（人もカミとしてまつられることがある）
2. **よい・わるいの教え（道徳）とは直接むすびつかない**（カミは「正しさの先生」ではない）
3. **とても身近で具体的**（この山、この祖先、というように）

```quiz
Q: 神道の「カミ」の説明として、近いものは？
1: 世界をつくった、ただひとりの全能の神
2: 道徳を教える先生
3: 祖先や山・川など、身近で具体的なものにやどる特別な力
4: 外国から伝わった仏さま
C: 3
E: カミは、祖先や自然など、身近で具体的なものと結びついている。
```

## 3. 神さまと仏さまが重なる（神仏習合）

仏教が伝わってから、日本では **カミへの信仰と仏教がむすびついて** いきました。これを **神仏習合**（しんぶつしゅうごう）といいます。
- たとえば「日本のカミは、じつは仏さまが姿を変えて現れたもの」という考え方が生まれた。
- 神社とお寺が、同じ場所にいっしょに建っていることも多かった。

> 補足：明治時代（1868年〜）に、国の方針で神社とお寺が分けられました（神仏分離）。それでも、今の暮らしには重なりが残っています。

## 4. 「今の暮らしは神社、死んだあとはお寺」

資料は、神道と仏教の役割を、こんなふうに分けて見せています。

| | 神道 | 仏教 |
|---|---|---|
| 主に関わること | **今の暮らし**（現世）：安産、合格、商売繁盛、お宮参り、初もうで | **死んだあと**（来世）：お葬式、お墓、法事 |

> 補足：これは覚えやすくするための大まかな分け方です。お寺で今の幸せを願うこともあり、いつもきっちり分かれるわけではありません。

```quiz
Q: 「現世は神道、来世は仏教」の説明として正しいのは？
1: 今の暮らしの願いは神社、お葬式やお墓はお寺、という大まかな役割分担
2: 神道の人は、死んだあとのことを考えない
3: 仏教は、今の暮らしにまったく関係ない
4: 法律でこう決まっている
C: 1
E: 役割をつかむための大まかな分け方。例外もある。
```

## 5. 仏教が日本流に変わる・新しい宗教

伝わった仏教は、日本の人々の暮らしに合わせて形を変えていきました（**仏教の日本化**）。お経をむずかしく学ぶより、「念仏をとなえる」「題目をとなえる」など、ふつうの人にもできるやり方が広まりました。

さらに近代には、**新しい宗教**（新宗教）も生まれました。資料に出てくるのは2つ。

| 名前 | ひとことで |
|---|---|
| **創価学会** | 日蓮という僧の仏教をもとにした、お坊さんではない人たち（在家）の団体 |
| **天理教** | 19世紀に中山みきが始めた宗教。「みんなで明るく楽しく暮らす」（陽気ぐらし）を大事にする |

> 補足：創価学会は仏教系、天理教は神道に近い流れから生まれた別の宗教です。同じ仲間ではありません。

## 6. キリスト教

16世紀にキリスト教が伝わりましたが、江戸時代には **禁止** されました。明治時代に再び認められましたが、今も信じる人は人口の約1%と少数です。
> 補足：学校や結婚式など、キリスト教の文化に触れる機会は多くあります。

## 7. まず、この3つ

1. 神道のカミは、祖先や自然など、身近で具体的なもの。
2. 神道と仏教は重なり合ってきた（神仏習合）。大まかには「今の暮らしは神社、死んだあとはお寺」。
3. 仏教は日本流に変わり、創価学会や天理教などの新しい宗教も生まれた。

# デジタル経済 7章【会話で読む】― 人工知能（AI）

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=ch7)」。

## 1. 汎用技術とダ・ヴィンチ問題（5分）

```talk
B: 汎用技術って、何？
A: 多くの産業で広く使われ、どんどん良くなり、ほかの発明を呼び込む技術。蒸気機関、電気、そして今はAIとブロックチェーンが候補。
B: すぐ効くの？
A: すぐには効かない。ダ・ヴィンチは1493年にヘリコプターを描いたけど、まわりの技術がなくて作れなかった。これがダ・ヴィンチ問題。
B: 電気モーターの例は？
A: 1880年代に入れても、すぐには生産性が上がらなかった。工場の作り直しと教育が必要で、約30年後、管理職が替わってからやっと上がった。
C: まわりの発明（補完的な革新）が必要。
```

```card
要点
- 汎用技術：多くの産業で使われ、改良が続き、ほかの発明を呼ぶ（蒸気機関・電気・AI）
- ダ・ヴィンチ問題：効くには、まわりの技術・組織・人の変化が必要で、時間がかかる
- 電気モーター：約30年後に生産性が上がった
```

## 2. AIの歩み（10分）

```talk
B: AIは、いつ始まったの？
A: 1956年のダートマス会議。マッカーシーが「人工知能」と名づけた。
B: 最初のやり方は？
A: 記号主義。専門家の判断を規則にするエキスパートシステム（例：医療診断のMYCIN）。でも一般的な領域には広げられず、行きづまった。これがAIの冬。
B: 「簡単なことが難しい」って？
A: モラベックのパラドックス。高度な推論は計算が少なくてすむけど、手書きの数字を読む、ボールを取るなどは膨大な計算が要る。
B: その後は？
A: 機械学習。データから学ぶ。教師あり（答えつき）、教師なし（答えなしでパターンを見つける）、強化学習（目標と環境から学ぶ）の3つ。
C: 暗黙知（言葉にできない）が、明示知になりつつある。
```

```timeline
1956 | ダートマス会議 | 「人工知能」の名前
1997 | ディープ・ブルー | チェスで世界王者に勝つ
2011 | ワトソン | クイズ番組で人間に勝つ
2012 | ディープラーニング | 画像認識が急に良くなる
2016 | アルファ碁 | イ・セドルに4勝1敗
2022 | ChatGPT | 生成AIが広がる
```

```card
要点
- 暗黙知：言葉にできない／明示知：言葉や式で伝えられる
- 記号主義 → AIの冬 → 機械学習 → ディープラーニング → 生成AI
- 機械学習：教師あり／教師なし／強化学習
- 完全情報ゲーム（チェス・碁）も不完全情報ゲーム（ポーカー）も、機械が人を上回った
```

## 3. いまのAIの課題（5分）

```talk
B: 生成AIは、理解して答えているの？
A: 「確率のオウム」と言われる。学んだ言葉から、次に来る言葉を確率で並べているだけ。いつも正しいとは限らず、学習データによる偏りもある。
B: ほかの課題は？
A: 学習の費用が上がり続ける。2016年から毎年約2.4倍。だから普通のベンチャーでは足りず、大企業が投資する（マイクロソフト→OpenAI、アマゾン→Anthropic）。
B: 汎用AIは？
A: 今のAIは、碁は強くてもチェスはできないような、狭いAI。汎用の知能をどう定義するかも難しい。
C: 確率のオウム／費用の上昇／狭いAI。
```

```card
要点
- 確率のオウム：次に来る言葉を確率で並べている。いつも正しいとは限らない
- 学習の費用：2016年から毎年約2.4倍 → 大企業が投資
- 狭いAI：特定の分野に強いが、ほかはできない
```

## 4. 職場での効果（10分）

```talk
B: AIを使うと、仕事はどうなる？
A: 3つの研究がある。コンサル（BCG、758人）、電話相談（5,179人）、プログラミング（アントグループ、1,219人）。
B: コンサルは？
A: 「でこぼこの境界」。AIが得意な仕事（言葉中心）では、点数が上がった。でも苦手な仕事（数字中心）では、正答率が84.5%から60%に下がった。
B: 電話相談とプログラミングは？
A: 電話相談は、1時間に解決する件数が平均13.8%増。新人ほど伸びた。プログラミングは、コードが平均55%増。技能の低い人は67%増。
B: 共通点は？
A: 平均で生産性は上がる。特に初心者・技能の低い人で効果が大きい。ただし今わかっているのは、一部の仕事だけ。
C: いつ、どこまでAIを信じるかが大事。
```

```card
要点
- 得意な仕事：点数↑（もと下位43%、上位17%）／苦手な仕事：正答率84.5% → 60%
- 電話相談：+13.8%、新人ほど伸びた
- コード：+55%、技能の低い人は+67%
- 共通点：平均で上がり、初心者ほど効果が大きい
```

## 5. 経済学から見たAI：予測と判断（10分）

```talk
B: 経済学では、AIをどう見る？
A: 予測の技術。予測は、持っている情報から、持っていない情報を作ること。確率で表す。
B: 予測と決定は同じ？
A: ちがう。午後に雨の確率80%（予測）でも、傘を持っていくか（決定）は別。決定には、得と損の見積もり（判断）が要る。予測 ＋ 判断 ＝ 決定。人の役目は判断。
B: 予測が安くなると？
A: 予測を材料に使う場面がふえる。代わりになるもの（運転すること）は価値が下がる。補うもの（データと判断）は価値が上がる。
B: 会社全体の変化は？
A: AIを使うには、部署ごとに決められる分け方と、部署どうしの協力の両方が要る（ダ・ヴィンチ問題ふたたび）。
C: 予測が安くなる → データと判断の価値が上がる。
```

```eq
予測 + 判断 = 決定
```

```card
要点
- AI ＝ 予測の技術。予測 ＋ 判断（得と損の見積もり）＝ 決定
- 予測が安くなる：代わるものは価値↓、補うもの（データ・判断）は価値↑
- 経済学がAIに役立つこと：因果推論／顕示選好／しくみの設計と評価
```

## 6. AIの社会の課題（5分）

```talk
B: AIには、どんな社会の問題がある？
A: 5つ。独占（大量のデータを持つ巨大IT企業がさらに強くなる）、著作権（学ぶデータと作ったものの権利）、プライバシー、教育と訓練、格差。
B: 格差は？
A: 国の中では、技術の変化が仕事と所得を変えて、所得の格差になる。国どうしでは、途上国の強み（人手に頼る技術）をAIが代わると、格差が広がるかもしれない。
C: 独占・著作権・プライバシー・教育と訓練・格差。
```

```card
要点
- 独占：データが多い巨大IT企業がさらに強くなる
- 著作権：学ぶデータと、作られたものの両方の権利
- プライバシー／教育と訓練／格差（国の中・国どうし）
```

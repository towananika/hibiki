# 開かれた社会と21世紀 14講【会話で読む】― まちの物語をつくる

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=open14)」。

## 1. なぜ物語が必要？（10分）

```talk
B: ストーリーテリングって？
A: 物語を伝える、五感に届く伝え方全体のこと。その場にいる感じ（現場性）と、くり返し体験できる感じ（再演性）を持つ。
B: なぜまちに必要になった？
A: 工場がへって町がさびれた欧米の町が、文化で地域を元気にする作戦を始めた。例はバルセロナのカサ・ミラ。インターネットで場所をくらべやすくなり、5都2村の暮らしやグリーンツーリズムも広がった。
B: 課題は？
A: ハーバート・サイモン「情報はありふれ、関心はどんどん貴重になる」。これまでのまちは成長と成果第一の犠牲になってきた。見た目の成長や建物中心の開発を乗りこえる必要がある。
C: 関心が貴重な時代。
```

```card
要点
- ストーリーテリング：五感に届く伝え方。現場性と再演性
- 欧米の町が文化で地域再生（カサ・ミラ）
- サイモン：情報はありふれ、関心は貴重
```

## 2. 場所マーケティングとテーマ（10分）

```talk
B: 場所マーケティングって？
A: ある場所のそこだけのイメージを作り、新しい価値を生む作戦。宣伝・販売、文化の建物、イベント（華川のやまめ祭り、加平のジャズ祭り）、文化の通り、歴史の建物を守る、スポーツ行事の6種類。アメニティは、暮らしに必要な全体としての心地よさ。
B: まちのテーマは？
A: まちを育てる作戦の中心。1つのことばや文で言えて、イメージがすぐ浮かぶ短いしるし。よそのまね（まねベンチマーキング）には限界がある。
B: 大事なことは？
A: しぼって集中する（選択と集中）。多すぎるとまちらしさがぼやける。
C: 1つだけ選ぶ。
```

```card
要点
- 場所マーケティング6種：宣伝／文化の建物／イベント／文化の通り／歴史を守る／スポーツ
- アメニティ：暮らしの全体としての心地よさ
- テーマ：短いしるし。選択と集中
```

## 3. 4つの段階と実例（10分）

```talk
B: 物語を育てる段階は？
A: 4つ。準備（住民が主役）→ 物語を掘り起こす（中心の段階。文化・自然・産業・場所に分けて一覧）→ 体験できるようにする（OSMU：1つのテーマをいろいろな形で使う）→ 物語を分け合う。
B: 実例は？
A: 統営のトンピランは壁画コンテストで元気に。任実チーズ村は、ベルギーの池正煥神父がやぎ2頭から始めた。加平はジャズ。日本の境港は水木しげるロード。
B: 気をつけることは？
A: 成功の保証はない。何でも治る薬ではない。まず記録庫（マウルアーカイブ）から。「お年寄りが1人亡くなると、まちから博物館が1つ消える」。
C: 作るより、見つけて守る。
```

```card
要点
- 準備 → 掘り起こす → 体験できるように（OSMU）→ 分け合う
- 実例：統営・トンピラン／任実チーズ村／加平ジャズ祭り／境港・水木しげるロード
- 何でも治る薬ではない。作るより見つけて守る
```

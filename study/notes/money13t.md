# 貨幣金融論 13講【会話で読む】― 国の所得は、どう決まる？

1つの節が5〜10分。きょうは **1節だけ** でOK。会話に出る3人は、日替わりで入れかわります（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money13)」。

## 1. 国の所得ってなに？（5分）

```talk
B: 「国民所得」って、つまり国の稼ぎのこと？
A: そう。国の経済力や生活の水準を見る、いちばんよく使う目安だよ。
B: GNPとGDPがあるよね。どうちがうの？
A: 数える人がちがう。GNPは「その国の国民」、GDPは「国内に住む人や会社」が作ったものの合計。
B: 何を数えるの？
A: 「最終」の物やサービスだけ。完成して買う人に渡るもの。材料まで足すと、二重に数えちゃうから。
C: 国籍のGNP、場所のGDP、と覚えよう。
```

```card
要点
- GNP＝国民が作った最終の物やサービスの合計
- GDP＝国内で作った最終の物やサービスの合計
- 途中の材料は足さない（二重に数えない）
```

## 2. 均衡国民所得（5分）

```talk
B: 「均衡国民所得」って、むずかしそう…。
A: 作る量と、買いたい量が、ちょうど同じになる所得のこと。
B: 買いたい量って、だれが買うの？
A: 4人。家計（C：消費）、会社（I：投資）、政府（G）、海外（NX：輸出−輸入）。この講では、海外は考えないよ。
C: 作る量 ＝ 買いたい量。これだけ。
```

```card
要点
- 均衡国民所得：作る量 ＝ 買いたい量 になる所得
- 買いたい量 ＝ 消費 C ＋ 投資 I ＋ 政府 G（＋ 純輸出 NX）
```

```cloze
作る量と買いたい量が同じになる国民所得を、{{均衡国民所得}}という。
買いたい量は、家計の{{消費}}、会社の{{投資}}、{{政府}}の支出（と純輸出）の合計。
```

## 3. 消費と投資の決まり方（10分）

```talk
B: 所得が増えたら、人は増えた分を全部使う？
A: 全部は使わない。一部は貯金する。使う割合を「限界消費性向（b）」というよ。0より大きくて、1より小さい。
B: 所得がゼロでも、使うお金はあるよね。
A: うん、それが「独立消費（C0）」。生きるために必要な分だから、いつも0より大きい。
C: 消費 ＝ C0 ＋ b × 所得。
B: 投資は、何で決まるの？
A: ケインズは2つ。金利と、会社の将来の見こみ。金利が上がると、借りる費用が高くなって、投資は減る。
B: いまの所得は関係ないの？
A: この簡単なモデルでは、関係ないとして、一定の値（I0）とおくんだ。
```

```card
要点
- 消費 C ＝ C0（独立消費）＋ b（限界消費性向）× 所得
- 0 ＜ b ＜ 1：所得が増えれば消費も増えるが、全部は使わない
- 投資は、金利（上がると減る）と将来の見こみで決まる
```

```cloze
所得が1増えたとき消費が増える割合を、{{限界消費性向}}という。
所得がなくても使う、生きるために必要な消費を、{{独立消費}}という。
金利が上がると、投資は{{減る}}。
```

### 計算してみよう
C ＝ 1兆ウォン ＋ 0.8Y、I ＝ 2兆ウォン のとき。

```eq
Y = C + I = 3兆 + 0.8Y → Y = 15兆ウォン
```

> 補足：Y − 0.8Y ＝ 3兆 なので、0.2Y ＝ 3兆、Y ＝ 15兆。

## 4. 政府を入れると（5分）

```talk
B: 政府が入ると、どうなるの？
A: 政府は税金（T）を集めて、使う（G）。家計は税金を引いた残りで消費を決めるよ。
B: 例は？
A: G＝2兆、T＝2兆ウォンなら、国民所得は15兆から17兆ウォンに増える。2兆増えた。
B: 税金で集めて使っただけなのに、なんで増えるの？
A: 家計は、税金の分のうち、消費を減らすのは8割だけ。でも政府は、集めた2兆を全部使う。差し引きで、買いたい量が増えるんだ。
C: 家計は全部は使わない。政府は全部使う。
```

```card
要点
- 例：G＝2兆、T＝2兆（b＝0.8）→ 所得は 15兆 → 17兆ウォン
- 理由：税金で減る家計の消費は一部だけ。政府は全額使う
```

## 5. 乗数効果（10分）

```talk
B: 「乗数効果」って？
A: 支出が1兆ウォン増えると、国民所得はそれより何倍も増える、ということ。
B: どうして何倍にもなるの？
A: 使ったお金は、だれかの所得になるよね。その人が、また8割を使う。
B: 1兆 → 0.8兆 → 0.64兆 …と続く？
A: そう。合計すると5兆になる。倍率は 1÷(1−b)。b＝0.8なら 1÷0.2＝5。
B: bが大きいほど、倍率も大きい？
A: うん。たくさん使う人が多いほど、お金がぐるぐる回って、大きくなる。
C: 投資・政府支出・独立消費は、みんな同じ乗数。
```

```eq
乗数 = 1 ÷ (1 − b) → b＝0.8 なら 5
```

```card
要点
- 乗数効果：支出の変化より、所得が何倍も変わる
- 乗数 ＝ 1 ÷（1 − 限界消費性向）。b＝0.8 なら 5
- 投資・政府支出・独立消費の乗数は、すべて同じ
```

```cloze
限界消費性向が0.8のとき、乗数は 1÷(1−0.8)＝{{5}}。
投資が1兆ウォン増えると、国民所得は{{5兆}}ウォン増える。
限界消費性向が大きいほど、乗数は{{大きく}}なる。
```

## 6. 税金と、均衡財政（5分）

```talk
B: 税金が増えたら、所得はどうなる？
A: 減る。税の乗数は −b÷(1−b)。b＝0.8なら −4。1兆の増税で、所得は4兆減る。
B: 政府支出の乗数（5）より小さいのは、なんで？
A: 政府支出は全額が需要になる。でも増税は、家計が消費を減らす分（8割）だけが効くから。
B: 税金を1兆集めて、同じ1兆を使ったら？
A: 5 − 4 ＝ 1。所得は、その額だけ増える。これを「均衡財政の乗数」といって、いつも1。
C: 集めた分を使うと、所得はその分だけ増える。
```

```card
要点
- 税の乗数 ＝ −b ÷ (1 − b)。b＝0.8 なら −4
- 政府支出の乗数（5）より小さい（絶対値で）
- 均衡財政の乗数 ＝ 5 − 4 ＝ 1（集めた額と同じだけ使うと、所得はその額だけ増える）
```

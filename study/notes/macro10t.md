# 上級マクロ経済論 10講【会話で読む】― 働く時間と給料は、どう決まる？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro10)」。

## 1. 働く？ 休む？（5分）

```talk
B: 休日に、あと1時間働くか迷うことがあるよね。
A: 休みを1時間減らして得られる物と、休みの大事さを比べているんだ。1時間働けば、好きなランチ1回分が買える、とするよ。
B: ランチより休みが大事なら？
A: 休む。ランチのほうが大事なら、働く。
B: 式にすると？
A: MRS ＝ w。MRS（限界代替率）は、休みと消費の交換の目安。w は物価を考えた給料（実質賃金）。
C: 休む1時間の価値 ＝ 働く1時間で買える物。
```

```card
要点
- 休む1時間の価値 ＝ 働く1時間で買える物（MRS ＝ w）
- MRS（限界代替率）：休みと消費の交換の目安
- w（実質賃金）：物価を考えた給料
```

## 2. 給料が上がったら、必ず多く働く？（5分）

```talk
B: 給料が上がったら、もっと働くよね？
A: 気持ちは2つの方向に動く。休むと、もらい損ねる給料が大きくなるので、働きたい（代替効果）。でも、前より少ない時間でも生活できるので、減らしたい（所得効果）。
B: どっちが強い？
A: 結果は変わる。この講では、給料が上がると働く量が増える場合を考える。
B: 配当が増えたら？
A: もっと休めるので、働く量を減らす方向。
B: 利子が上がったら？
A: 今働いて貯めたお金が将来増えやすいので、「今働き、休みは将来に回そう」となる。これが労働の異時点間代替。
C: 代替効果は働く方向、所得効果は休む方向。
```

```card
要点
- 代替効果：休むと損 → 働く時間を増やしたい
- 所得効果：少ない時間でも生活できる → 減らしたい
- 配当などの給料以外のお金が増える → 働く量は減る方向
- 利子↑ → 今働いて、休みを将来に回す（労働の異時点間代替）
```

## 3. 会社は、人手を雇う？（5分）

```talk
B: 会社は、人手を雇うかどうか、どう決める？
A: 人手を1時間分増やすと、パンが追加で8個できるとする。給料がパン5個分なら、雇うと得。
B: 人手をどんどん増やすと？
A: オーブンが混み合うから、追加の生産はだんだん小さくなる。だから、追加の生産と給料がつり合う所までにする。
B: 式は？
A: MPL ＝ w。MPL（労働の限界生産）は、人手をもう1単位足したときに増える生産。
B: 給料が上がると？
A: 雇いたい量は減る。技術が進むと、同じ人手で多く作れるので、雇いたい量は増える方向。
C: 追加の人手が増やす生産 ＝ 実質の給料。
```

```card
要点
- 会社の判断：MPL（労働の限界生産）＝ w（実質賃金）
- 給料が上がる → 雇いたい量は減る
- 技術が進む → 雇いたい量は増える方向
```

## 4. 働きたい量と雇いたい量（5分）

```talk
B: 給料と雇用は、どうやって決まる？
A: 給料が自由に動くモデルでは、働きたい量と雇いたい量が同じになる所で決まる（労働市場の均衡）。
B: 完全雇用は、失業者ゼロ？
A: ちがう。転職のために探している人などは残りうる。
B: 古典派とケインズ派は？
A: 古典派の基本モデルは、給料が動いて量を合わせる。ケインズ派は、給料がすぐ動かず、働きたいのに働けない場合がある。
B: 利子が上がると？
A: 今の労働供給が増えて、雇用と生産が増える。縦軸が実質利子率、横軸が生産の図では、実質総供給曲線は右上がり。
C: 技術が進む・政府の購入が増える（将来の増税を見こんで働く）と、線は右へ。
```

```card
要点
- 労働市場の均衡：働きたい量 ＝ 雇いたい量 で、給料と雇用が決まる
- 完全雇用 ≠ 失業者ゼロ
- 実質総供給曲線は右上がり（利子↑ → 労働供給↑ → 生産↑）
- 技術の進歩・政府の購入の増加で、線は右へ
```

## 5. なぜ、仕事探し中の人が残る？（10分）

```talk
B: 失業率が一定のときは、同じ人がずっと失業してるの？
A: ちがう。仕事を辞める人と、新しく仕事に就く人が、毎期いるから（労働探索モデル）。
B: 仕事は、どう選ぶ？
A: 「この給料以上なら受けたい」という最低の給料を、留保賃金という。誘いの給料がそれ未満なら、探し続ける。
B: 失業率が落ち着くのは？
A: 仕事を辞める人数 ＝ 新しく仕事に就く人数 のとき。働く90人のうち毎月2人が辞め、失業中の10人のうち毎月2人が就職すれば、失業者は10人のまま。
B: 試験の式は？
A: s(1−U) ＝ U×p×H(w*)。U は失業率、1−U は働いている人の割合、s は辞める割合、p は失業中の人に誘いが来る確率、w* は留保賃金、H(w*) は誘いの給料が基準以上である確率。
C: 左は辞める人、右は就職する人。
```

```eq
仕事を辞める人数 = 新しく仕事に就く人数
```

```card
要点
- 留保賃金：「この給料以上なら受けたい」という最低の給料
- 失業率が一定 ＝ 辞める人数 ＝ 就職する人数（同じ人がずっと失業とは限らない）
- s(1−U) ＝ U×p×H(w*)。仕事探しに時間がかかる失業は摩擦的失業
- 失業手当が増えると、単純なモデルでは留保賃金が上がる
```

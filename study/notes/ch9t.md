# デジタル経済 9章【会話で読む】― ゲーム産業

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=ch9)」。

## 1. 遊ぶ場所と、売り方（5分）

```talk
B: ゲームの売り方は、どう変わってきた？
A: 1970年代以降は、ゲームセンター（1回ずつ払う）と家庭用ゲーム機（本体・ソフトを買う）。2000年代以降はオンラインで、月額・ダウンロード・追加コンテンツ。スマホの普及で、いつでも遊べて、広告やアプリ内購入も広がった。
B: 古い方式は消えた？
A: 消えていない。買い切りも、月額も、無料プレイも併存している。
C: 遊ぶ場所が変わると、売り方も変わる。
```

```card
要点
- ゲームセンター（1回ずつ）→ 家庭用ゲーム機（本体・ソフト）→ オンライン（月額・DL）→ スマホ（広告・アプリ内購入）
- 古い方式も併存している
```

## 2. ゲーム機とソフトは、互いを必要とする（5分）

```talk
B: 本体と作品は、どんな関係？
A: 本体だけでは、遊びたい作品がなければ買いたくない。作る側も、利用者が多い本体向けに出したい。魅力的な作品がふえる → 遊ぶ人がふえる → 作る会社が集まる → さらに作品がふえる。
B: 名前は？
A: 本体と作品のように、一緒に使うと価値が高まる物を補完財という。遊ぶ人と作る人をつなぐ構造は、プラットフォーム。
C: 補完財とプラットフォーム。
```

```card
要点
- 補完財：一緒に使うと価値が高まる物（本体と作品）
- プラットフォーム：遊ぶ人と作る人をつなぐ構造
- 作品↑ → 遊ぶ人↑ → 作る会社↑ の好循環
```

## 3. 本体を安くして、どこで稼ぐ？（10分）

```talk
B: 本体は、安く売っていいの？
A: 本体の利益を低くして利用者をふやし、ソフト販売や利用料で稼ぐ考えがある（かみそりと替え刃の考え）。
B: 売り方は？
A: 3つ。買い切りは最初に払う。月額は遊べる期間に払う。無料プレイは広告や追加購入で稼ぐ。
B: 売上と利益は同じ？
A: ちがう。利益 ＝ 売上 − 開発や運営の費用。サーバー、更新、問い合わせ対応などの費用もかかる。
C: 続けるには、費用も見る。
```

```eq
利益 = 売上 − 開発や運営の費用
```

```card
要点
- かみそりと替え刃：本体は安く、ソフト販売や利用料で稼ぐ
- 買い切り／月額／無料プレイ（広告・追加購入）
- 売上 ≠ 利益。継続運営の費用もかかる
```

## 4. 独占作品と移植（5分）

```talk
B: 1つの機種でしか遊べない作品があるよね。
A: 独占供給。その機種を選ぶ理由になるけど、移りにくさにもつながる。
B: 移植って？
A: 別の機種で動くように作り直すこと。操作・性能・画面の違いへの対応に、費用と時間がかかる。
B: 問題は？
A: 独占は魅力を作る手段でもあるけど、競争相手が参入しにくくなる問題もある。
C: 独占は魅力でもあり、参入の壁でもある。
```

```card
要点
- 独占供給：その機種を選ぶ理由になるが、移りにくさにもなる
- 移植：別の機種向けに作り直す（費用と時間）
- 独占は競争相手の参入を難しくする問題もある
```

## 5. 無料と新技術（10分）

```talk
B: 無料なら、安く遊べる？
A: 同じではない。広告を見る時間や追加購入がありうる。ランダムな報酬を得る有料の仕組みは、確率型アイテム。何に払うか、上限はいくらかを、遊ぶ側が考える。
B: 新技術は？
A: クラウドゲームは、遠くのサーバーでゲームを動かし、映像を受け取って遊ぶ。高性能な本体の負担を減らせるけど、通信の速さや遅延が課題。クロスプレイは、異なる機種の人が一緒に遊べる仕組み。
B: ほかには？
A: eスポーツ（観戦）、VR（仮想空間）、AR（現実に情報を重ねる）、AI（制作を助ける）、キャラクターなどの知的財産の展開も論点。
C: 技術は、誰のどの負担を減らすかで選ぶ。
```

```card
要点
- 無料 ≠ 安く遊べる（広告・待ち時間・追加購入）
- クラウドゲーム：サーバーで動かし映像を受け取る。課題は通信の速さ・遅延
- クロスプレイ：異なる機種の人が一緒に遊べる
- 市場規模は、何を含む数字か（本体・広告・ハード）と、予測か実績かを確かめる
```

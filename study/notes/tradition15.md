# 伝統社会と生活文化 15講 ― 村の祭りと家の神さま

韓国の放送大学「伝統社会と生活文化」15講（最終回、対談の講義、約45分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名や数字は聞き取りなので、少しずれているかもしれない。

```flow
国の祭り（三壇一廟） → 村の祭り（洞祭）：祭りの形と巫女の儀式の形 → 家の神さま（家庭信仰）：柱・土地・台所・子ども・財産・風
```

## 0. ひとことで
昔の人にとって **村は世界のすべて**。だから村みんなで **村の安全と豊作を祈る祭り（洞祭）** をした。
家の中にも、場所ごとに役目のちがう **家の神さま（家神）** がいて、春と秋にまつった。
願うことはいつも同じ。**家族が無事で（安寧）、豊かであること（豊饒）**。いまの私たちの願いとも、あまり変わらない。

## 1. 昔の村ってどんなところ？
村は、いくつもの顔を持っていた。
- **国から見た一番小さい単位**：税を集める単位
- **血のつながる人の集まり**（血縁共同体）
- **いっしょに働く仲間**（生産共同体）：田植えなどで手を貸し合う

一生その村から出ない人も多く、**村がその人の世界のすべて** だった。家族の幸せは「まず村が安全であること」の上にある。だから村の祭りは、みんなの心の **よりどころ** になった。

## 2. 国の祭りが、村の祭りのお手本に
朝鮮王朝は朱子学（儒教）の国。都の祭りのしくみを、地方の役所でもくり返した（**三壇一廟**）。
| 場所 | まつるもの |
|---|---|
| 学校の廟（文廟、郷校） | 孔子 |
| 社稷壇 | 土地と穀物の神 |
| 厲壇 | 事故・戦争で亡くなった人、まつってくれる子孫がいない人など、うらみを残した死者 |
| 城隍壇 | 中国では町の城壁を守る神。朝鮮では **その土地の大事な山の神** に変わった |

これが、村の祭りの場所・やり方・日にちの **お手本** になったと考えられている。

```quiz
Q: 朝鮮の地方で、城隍壇（じょうこうだん）でまつられたのは？
1: 孔子
2: 土地と穀物の神
3: その土地の大事な山の神
4: まつってくれる子孫のいない死者
C: 3
E: 城隍神は、中国では町の城壁を守る神。朝鮮に来て、その土地の大事な山の神をまつる形に変わった。
ほかの選択肢：1は文廟、2は社稷壇、4は厲壇でまつるもの。
```

## 3. 村の祭り（洞祭）の2つの形
| | 祭りの形（祭祀） | 巫女の儀式の形（クッ） |
|---|---|---|
| だれが | 村から選ばれた男性の代表（祭官） | 村人の楽器隊（風物）や、専門の巫女（巫堂） |
| やり方 | 儒教式。祝いのことば（祝文）を読み、お酒を3回ささげる | 歌・踊り・楽器で神をよぶ |
| どれくらい | 毎年など | お金がかかるので **3年に1回** ほど。貧しい村は10年に1回 |

- ふつうは、まず代表が祭りの形で祈り、そのあと巫女が儀式をする。
- 巫女の儀式でいちばん多い名前は **別神クッ**（べっしん）。「いつもの祭りとは **別に、特別に** する祭り」という意味。村に悪いことが起きたとき、日を選び直してもう一度まつることも別神祭という。

> 補足：クッは、巫女（巫堂）が歌や踊りで神をよび、願いを伝える儀式のこと。風物は、いまの「サムルノリ」のような、たいこやかねの演奏。

**名前はいろいろ**
- 学問では **洞祭**（どうさい、村の祭り）と呼ぶことが多い。
- まつる神やお堂の名前で呼ぶことも：山の神なら山神祭、城隍堂なら城隍祭、京畿道では都堂祭など。
- いくつかの小さな村が1つにまとまると、中心の村の神を「都城隍」と呼び、まわりの村も祭りに参加した。

```quiz
Q: 村の祭りで「別神クッ」の「別神」の意味として、いちばん一般的な説明は？
1: 別の国から来た神
2: いつもの祭りとは別に、特別にする祭り
3: 家族と別れる祭り
4: 別の村の神
C: 2
E: 漢字の意味どおり「特別に、別にささげる祭り」と考えるのが一般的。費用が大きく3年に1回ほど。
ほかの選択肢：1、3、4は講義の説明と合わない。
```

## 4. 3つの村の例
| 村 | 特徴 |
|---|---|
| ソウル・弘智洞の山神祭 | 陰暦8月1日。高いビルの都会でも続く。紙に名前と願いを書いて燃やす（焼紙）。**豚の頭** をそなえる。この辺りの村はみな山の神をまつる（北漢山や仁王山のふもとだから） |
| 京畿道・義王市旺南洞の堂祭 | 300年以上続く。陰暦10月1日、2年に1回。体も家も元気な人を **堂主** に選び、1日前に地中にうめた酒を使う。**牛の頭**（牛1頭をまるごとささげる意味）。昔は村の宴会の日 |
| 京畿道・龍仁市の村 | 家ごとに同じ額を出し（契のように運営）、陰暦9月の村の会議で何でも決めた。約150年前からのお金の記録、祝文、**そなえ物の並べ方の図（陳設図）** が残る |

- 陳設図を見ると、村の山の神が **いちばん上の席**、残りは5つの方角の神（五方神）。山の神にだけ牛の頭をそなえた。
- いまの村の祭りは、村全体の行事ではなくなった。それでも **村の歴史を大事に思う人たちが、自分たちらしさを確かめ合う場** になっている。

> 補足：「契」（けい）は、メンバーがお金を出し合って運営する会のこと。

## 5. 家の神さま（家庭信仰）
家の中の **場所ごとに、役目のちがう神さま（職能神）** がいると考えた。

| 神さま | 守るもの | ポイント |
|---|---|---|
| **成造（ソンジュ）** | 家そのもの・一家の主 | 最初に家を建てた大工の神。家の柱の上の大きな梁（はり）を上げた日が「成造の誕生日」。紙を折って梁にむすぶ |
| **土主（トジュ）** | 家の土地 | 山の神とつながることが多い。土地の力が強い家ほど、ていねいにまつる |
| **竈王（チョワン）** | 台所・火 | 名前は道教から。はじめは食べ物と火、のちに家族全体を守る神に |
| **三神おばあさん** | 子ども | 子をさずけ、元気に育てる。生まれて7日ごとに3回（21日まで）まつる。産室には家族でも入れない |
| **業（オプ）** | 家の財産 | ヒキガエルやヘビの姿で考えられた。人のこともあり、その人が出ていくと家がかたむくと信じた |
| **霊登（ヨンドゥン）** | 風と雨 | 陰暦2月1日に天から下りて、15日に帰る。嫁と来ると雨、娘と来ると風が吹くという |

- **家長が変わると、成造も新しくする**。父が亡くなり息子が家をつぐと、古い成造の紙を燃やすなどして、新しい成造をむかえた（「成造と家長は1つ」）。
- まつる時期は主に2回：**お正月（小正月の15日まで）** は1年の無事と豊作を願い、**秋（陰暦10月）** は収穫に感謝して、もちを分け合う。

```quiz
Q: 家を建てた最初の大工とされ、家長が変わると新しくむかえ直した家の神さまは？
1: 成造（ソンジュ）
2: 竈王（チョワン）
3: 三神おばあさん
4: 霊登（ヨンドゥン）
C: 1
E: 成造は家と一家の主を守る神。「成造と家長は1つ」とされ、家長が変わると新しくした。
ほかの選択肢：2は台所と火、3は子ども、4は風と雨の神。
```

## 6. まず、この3つ
1. 昔の村は世界のすべて。村の祭りには **祭りの形（儒教式）** と **巫女の儀式の形（クッ）** がある。
2. 家の中には、場所ごとに役目のちがう神さまがいる（成造・土主・竈王・三神・業・霊登）。
3. 願いはいつも **無事（安寧）と豊かさ（豊饒）**。伝統は固まったものではなく、社会とともに変わり続ける。

## ひびきの暮らしでいうと
- 都会でも、村の祭りは「自分たちらしさを確かめる場」として残っている。住む町の行事や歴史を知ると、その町が **自分の場所** になっていく。
- 家長が変わると神さまも新しくむかえた。暮らしの節目に **家の決まりを見直す** のは、いまも役に立つ考え方。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。

```quiz
Q: 朝鮮の村の祭り（洞祭）について、正しくないものは？
1: 祭りの形（祭祀）と、巫女の儀式の形（クッ）に大きく分けられる
2: 巫女の儀式はお金がかかるので、3年に1回ほどが多い
3: どの地方でも、名前とやり方はまったく同じだった
4: 地方の国の祭り（三壇一廟）が、お手本になったと考えられている
C: 3
E: 村の祭りは、地方・村・家ごとに名前もやり方もちがう。とても多様なのが特徴。
ほかの選択肢：1、2、4はどれも講義のとおり正しい。
```

```quiz
Q: 地方の役所で、孔子をまつる文廟と、社稷壇・厲壇・城隍壇の3つの壇で祭りをするしくみを（　）という。
1: 三壇一廟
2: 四代奉祀
3: 三年喪
4: 五方神
C: 1
E: 三壇一廟。都の祭りのしくみを地方でもくり返したもの。
ほかの選択肢：2は4代前まで先祖をまつること。3は3年かけるお葬式。4は5つの方角の神。
```

```quiz
Q: 家の財産を守る神で、ヒキガエルやヘビ、ときには人の姿で考えられたのは？
1: 土主（トジュ）
2: 業（オプ）
3: 成造（ソンジュ）
4: 三神おばあさん
C: 2
E: 業（オプ）は財産の神。その「業」が出ていくと家がかたむくと信じ、大きな儀式でよびもどそうとした。
ほかの選択肢：1は家の土地、3は家そのものと家長、4は子どもを守る神。
```

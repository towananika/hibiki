# 世界の宗教 8講 ― 仏教：苦しみを、どう軽くする？

**「思いどおりにならない苦しみは、なぜ生まれるのか。そこから離れるには、どう生きるのか」。** この講では、仏教の教えを、この問いから学びます。

韓国の放送大学「世界の宗教」第8講の配布資料を、日本語でまとめたノートです。日常の例は、理解を助けるために加えたものです。信じることを求めるのではなく、仏教の考え方を学びます。

## 1. まずは、4つの問いだけ

たとえば、友だちから返事が来なくて、何度もスマホを見てしまうとします。

- **何がつらい？** → 返事が来ないことが気になり、落ち着かない。
- **何が苦しさを強める？** → 「今すぐ返事がほしい」という強いこだわり。
- **そのこだわりが静まったら？** → 返事を待つ間も、落ち着いて過ごしやすくなる。
- **どう練習する？** → 自分の気持ちに気づき、考え方や行動を整える。

この4つの見方が、仏教の基本となる **四聖諦（ししょうたい）** です。「諦」は、ここでは「あきらめる」ではなく「真理」という意味です。

```flow
苦しみを知る → 原因を知る → 原因が静まることを知る → そのための道を歩む
```

> 補足：スマホの例は、教えの一部をイメージするためのものです。仏教の「苦」は、日常の不安だけでなく、生・老い・病・死などにも関わる、もっと広い考えです。

```quiz
Q: 四聖諦の4つは、何を表す？
1: 苦しみ・原因・解放・そのための道
2: 過去・現在・未来・永遠
3: 体・お金・仕事・友人
4: 生まれる・育つ・働く・休む
C: 1
E: 苦諦は苦しみ、集諦はその原因、滅諦は原因が静まった解放、道諦はそこへ向かう実践の道です。
```


## 2. 四聖諦を、試験の言葉につなぐ

| 名前 | 読み方 | 何を考える？ |
|---|---|---|
| 苦諦 | くたい | 思いどおりにならない苦しみがある |
| 集諦 | じったい | 苦しみが生まれる原因がある |
| 滅諦 | めったい | その原因が静まり、苦しみから離れられる |
| 道諦 | どうたい | そこへ向かう実践の道がある |

ここで「人生には楽しさが一切ない」と言っているわけではありません。**楽しい経験も、ずっと同じままには続かない。** それを「変わらず続いてほしい」と握りしめると、苦しみにつながる、と考えます。

変わり続けることを **無常（むじょう）**、強くこだわって離れられないことを **執着（しゅうちゃく）** といいます。

**「変わると知らないこと」と「変わると知っていても手放せないこと」は違います。** 前者は無常の理解に、後者は執着に関係します。

「将来、人が死ななくなるかもしれない」と考えること自体は、関心や希望でもあり、執着とは限りません。「そうならなければ絶対に受け入れられない」と、とらわれることとは分けます。仮に死ななくても、体・記憶・気持ちが変わるなら、無常とは矛盾しません。

```quiz
Q: 無常とは、何もかも無意味ということ？
1: 何もかも無意味だということ
2: 物事が同じままにはとどまらないこと
3: 変化を止めれば幸福になること
4: 気持ちを持ってはいけないということ
C: 2
E: 違います。物事が変わり続け、同じままにはとどまらないということです。
```

```quiz
Q: 「将来、人が死ななくなるかもしれない」と考えること自体は、執着？
1: 未来を考えたら必ず執着になる
2: 科学に希望を持つことはすべて執着
3: 考えるだけで、執着とは決められない
4: 体が変わると知っていれば執着は絶対に起こらない
C: 3
E: 可能性への関心や希望と、「そうでなければ絶対に受け入れられない」というとらわれは区別します。変化を知っていても、執着は起こりえます。
```


## 3. 「私」を、5つの働きに分けて見る

講義には **五蘊（ごうん）** という言葉が出ます。私たちの心身の経験を、5つのまとまりとして見る考えです。

| 名前 | やさしく言うと | スマホの例なら |
|---|---|---|
| 色（しき） | 体や、物質的なもの | 目や体、画面など |
| 受（じゅ） | 快い・不快・どちらでもないという感じ | 返事がなくて不快に感じる |
| 想（そう） | 特徴を見分け、意味づける働き | 「まだ返事がない」と見分ける |
| 行（ぎょう） | 意志や、心のさまざまな働き | また確認しようとする気持ち |
| 識（しき） | 見る・聞くなど、対象を知る働き | 画面を見ている意識 |

五蘊は、順番に起こる5段階というより、**経験を分けて観察する見方**です。

講義では、五蘊への執着が苦しみになると説明されます。体や気持ちを「絶対に変わってほしくない私のもの」と握りしめることに注目します。体や感情を大切にしてはいけない、という意味ではありません。

```quiz
Q: 五蘊は、順番に進む5つの段階？
1: 修行で順に進む5つの段階
2: 守らなければならない5つの職業
3: 心身の経験を5つのまとまりで見る
4: 人間の体だけを5つに分ける
C: 3
E: そうではありません。色・受・想・行・識という、心身の経験を5つのまとまりに分ける見方です。
```


## 4. 苦しみは、条件がつながって生まれる

講義は、苦しみの原因をたどる **十二因縁（じゅうにいんねん）** に触れています。これは、無明から老死までのつながりを、12の項目で示す教えです。

**無明（むみょう）** は、単に知識が少ないことではなく、物事のあり方を見通せないこと。**渇愛（かつあい）** は、「どうしてもほしい」「こうであってほしい」と求めてやまない心です。

日常の例で、条件のつながりだけを考えると、こうなります。

```flow
気になる出来事 → 不快な感じ → すぐ安心したくなる → 何度も確認する → さらに気になる
```

> 補足：この図は十二因縁そのものの一覧ではありません。原因と条件がつながる、という考え方を理解するための例です。配布資料には12項目の詳しい列挙はありません。

仏教では、生まれては死ぬことを繰り返す **輪廻（りんね）** と、無明や渇愛を結びつけて考えます。これは仏教の宗教的な教えとして読む部分です。

```quiz
Q: 渇愛とは？
1: 水を飲む必要だけを指す言葉
2: 何にも関心を持たない心
3: すべてを正確に理解している状態
4: こうであってほしいと求めてやまない心
C: 4
E: 「どうしてもほしい」「こうであってほしい」と求めてやまない心です。この講では、苦しみの原因として考えます。
```


## 5. 涅槃は、「何も感じなくなる」こと？

この講では、渇愛や執着が静まり、苦しみから解放されたあり方を **涅槃（ねはん）** と説明します。

```eq
涅槃 = 渇愛が静まった解放
```

何でも我慢することや、感情を押し殺すことと同じではありません。「こうでなければ絶対にだめ」というとらわれから離れる、と考えると入口がつかみやすくなります。

> 補足：「返事を気にしなくなった」だけで涅槃に達した、という意味ではありません。日常の例と、仏教が目指す解放は区別します。

```quiz
Q: 涅槃とは、感情を押し殺すこと？
1: 渇愛や執着が静まった解放
2: 感情を無理に消すこと
3: 楽しいものをもっと集めること
4: 体が一切変化しなくなること
C: 1
E: 違います。この講では、渇愛や執着が静まり、苦しみから解放されたあり方です。
```


## 6. そのために、どう生きる？ ― 八正道

**八正道（はっしょうどう）** は、苦しみから離れるための8つの実践です。1つ終えたら次へ進むだけの手順ではなく、互いに支え合う道です。

| 名前 | 読み方 | やさしく言うと |
|---|---|---|
| 正見 | しょうけん | 苦しみや、その原因について適切に理解する |
| 正思惟 | しょうしゆい | 欲や悪意、人を傷つける思いから離れる方向で考える |
| 正語 | しょうご | うそや、人を傷つける言葉を慎む |
| 正業 | しょうごう | 人を害する行いを慎む |
| 正命 | しょうみょう | 他者を害する生業を避け、生計を立てる |
| 正精進 | しょうしょうじん | よくない心を減らし、よい心を育てる努力をする |
| 正念 | しょうねん | 体や心に起こっていることを、気づいて観察する |
| 正定 | しょうじょう | 心を落ち着け、集中を育てる |

たとえば、腹が立ったとき。「絶対に嫌われた」と決めつけず、今の怒りに気づく。勢いで相手を傷つけるメッセージを送らず、いったん落ち着く。こうした例で、考え・言葉・心の関係を思い浮かべられます。

理解のために大きく分けると、次の3つです。

```flow
理解や考えを整える → 言葉や行動を整える → 注意や集中を育てる
```

> 補足：この3つは、知恵（慧）・行動の規律（戒）・心の集中（定）という、一般的な整理を補ったものです。正念は「何も考えない」、正定は「無理に考えを消す」という意味ではありません。

```quiz
Q: 正語と正命は、何を整える実践？
1: 正語は食事、正命は睡眠の取り方
2: 正語は言葉、正命は生計の立て方
3: 正語は集中、正命は呼吸の速さ
4: 正語は姿勢、正命は記憶力
C: 2
E: 正語は言葉、正命は生計の立て方です。仏教の実践は、集中することだけでなく、日々の生き方にも関わります。
```


## 7. 集中を妨げる、5つのもの

講義は、心の集中を妨げる5つの状態も挙げています（**五蓋・ごがい**）。

| 妨げ | 日常の言葉でいうと |
|---|---|
| 感覚的な欲望 | 楽しそうなものを追いかけ続ける |
| 悪意・憎しみ | 怒りで頭がいっぱいになる |
| 怠け・無気力 | だるさや眠気に沈む |
| 落ち着かなさ・心配 | 気が散り、後悔などが巡る |
| 疑い | 修行の道などへの迷いで、進めなくなる |

「疑い」とあるからといって、質問や、自分で確かめることが全部悪いという意味ではありません。ここでは、実践を妨げる心の状態についての説明です。

```quiz
Q: 五蓋は何を妨げる？
1: 体の成長
2: 暦の季節の変化
3: 心の集中
4: 言葉を覚える年齢
C: 3
E: 心の集中です。感覚的欲望、悪意、怠けや無気力、落ち着かなさや心配、実践への疑いが挙げられています。
```


## 8. まず、この3つを覚える

1. **四聖諦**：苦しみ・原因・解放・そこへ向かう道。
2. **執着**：変わるものを、変わらないでほしいと握りしめること。
3. **八正道**：考え、言葉、行動、注意、集中などを整える実践。

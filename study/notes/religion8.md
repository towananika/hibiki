# 世界の宗教 8講 ― 仏教：苦しみを知り、執着をほどく道

**この講で覚えること：仏教は「神を信じる」より「苦しみから離れる道」を説く。苦しみ・原因・解放・道の4つ（四聖諦）が土台。苦しみの元は、変わるものへの執着（渇愛）。それが静まった状態が涅槃で、そこへ向かう実践が八正道。**

韓国の放送大学「世界の宗教」第8講の講義資料（全21ページ）をもとに、日本語でまとめたノートです。経典の引用は、そのまま訳さず、要点を自分の言葉にしました。信じることを求めるのではなく、仏教の考え方を学びます。

## 0. この講の地図（3分）

```flow
① 仏教って何？ → ② 四聖諦 → ③ 苦しみの正体（五蘊と執着） → ④ 原因をたどる → ⑤ 涅槃 → ⑥ 八正道 → ⑦ 集中のじゃまもの
```

読み方：各節は「会話 → 図 → 要点カード → 4択」。最後に「3つの宗教くらべ」「書く準備」「言いかえ練習」「確認テスト」があります。

## 1. まず言葉をそろえる（3分）

```card
8講の4つの言葉
- 四聖諦（ししょうたい）：苦しみ・原因・解放・道の、4つの真理。「諦」は「あきらめ」ではなく「真理」
- 執着（しゅうちゃく）：変わるものを、変わらないでほしいと握りしめること
- 涅槃（ねはん）：欲望と執着が静まり、苦しみから解放されたあり方
- 八正道（はっしょうどう）：涅槃へ向かう、8つの正しい実践
```

## 2. 仏教って、何をする宗教？（4分）

```talk
B: 宗教って、まず神さまを信じるものでしょ？
A: 講義は「仏教とは、いったい何か？」という問いから始まった。仏教の中心は、神を信じることより、「なぜ苦しいのか、どうすれば離れられるのか」を見つめることなんだ。
B: お医者さんみたいだね。
A: よく言われるたとえだよ。症状を知る → 原因を知る → 治った状態を知る → 治し方を実行する。これが次の四聖諦。
C: 仏教は、苦しみから離れる「道」。
```

```quiz
Q: 仏教の中心にある問いに近いのは？
1: 世界をつくった神はだれか
2: 苦しみはなぜ生まれ、どうすれば離れられるか
3: どの民族がいちばんすぐれているか
4: どうすればお金持ちになれるか
C: 2
E: 苦しみの原因と、そこから離れる道を見つめるのが仏教の中心です。ほかの選択肢：創造の神を中心にするのはキリスト教やイスラム教です。
```

## 3. 四聖諦 ― 4つの真理（6分）

```talk
B: 四聖諦って、むずかしそう。
A: 講義では「地上のすべての動物の足あとが、ゾウの大きな足あとに入るように、四聖諦はよい教えをすべてふくむ」というたとえが出た。つまり、仏教のいちばん大きな土台なんだ。
B: 「人生は苦しい」ってこと？ 暗くない？
A: 楽しいことがないという意味じゃない。楽しいことも、ずっとは続かない。それを「ずっと続いて」と握りしめると苦しくなる、という見方だよ。
C: 4つ全部で一つの道。
```

```flow
苦諦：苦しみがある → 集諦：原因がある → 滅諦：原因が静まれば苦しみも静まる → 道諦：そのための道がある
```

```card
四聖諦
- 苦諦（くたい）：思いどおりにならない苦しみがある
- 集諦（じったい）：苦しみには原因（欲望・執着）がある
- 滅諦（めったい）：原因が静まれば、苦しみから離れられる
- 道諦（どうたい）：そこへ向かう実践の道（八正道）がある
```

変わり続けることを **無常（むじょう）** といいます。楽しさも続かないと知ると、人は感覚の楽しみに飽き、とらわれなくなり、心が清らかになる ― 講義はそう説明します。

```quiz
Q: 四聖諦の4つは、何を表す？
1: 苦しみ・原因・解放・そのための道
2: 過去・現在・未来・永遠
3: 体・お金・仕事・友人
4: 生まれる・育つ・働く・休む
C: 1
E: 苦諦は苦しみ、集諦は原因、滅諦は解放、道諦はそこへ向かう道です。
```

```quiz
Q: 無常とは？
1: 何もかも無意味だということ
2: 物事が同じままにはとどまらないこと
3: 変化を止めれば幸福になること
4: 気持ちを持ってはいけないということ
C: 2
E: 物事が変わり続けるということです。ほかの選択肢：「無意味」や「気持ちを持つな」という意味ではありません。
```

## 4. 苦しみの正体 ― 五蘊と執着（5分）

```talk
B: 「苦しみとは何か」に、仏教はどう答えるの？
A: 講義では「苦しみとは、五蘊への執着だ」と答えていた。五蘊は、「私」を5つのまとまりに分けて見る見方。
B: 体や気持ちを大切にしちゃだめってこと？
A: ちがう。「これは絶対に変わらない私のもの」と握りしめることが問題なんだ。経典では、五蘊は重い荷物で、それを下ろすことが幸せだ、と言っている。
C: 「私」を5つに分けて、握りしめた手をゆるめる。
```

```card
五蘊（ごうん）＝「私」を5つに分けて見る
- 色（しき）：体や物＝物質
- 受（じゅ）：快い・いや、という感じ＝感覚
- 想（そう）：「これは〇〇だ」と見分ける＝知覚
- 行（ぎょう）：こうしよう、という心の動き＝行為
- 識（しき）：見たり聞いたりして知る＝意識
```

```quiz
Q: 講義で、苦しみとは何と説明された？
1: 体があること
2: 五蘊への執着
3: 神を信じないこと
4: お金がないこと
C: 2
E: 五蘊（体や心の働き）を「変わらない私のもの」と握りしめることが苦しみだ、と説明されます。ほかの選択肢：体があること自体が苦しみなのではありません。
```

## 5. 原因をたどる ― 欲望・無知・輪廻（5分）

```talk
B: どうして握りしめちゃうの？
A: 原因は2つ。物事のあり方が見えていない無知（無明）と、「どうしてもほしい」という欲望（渇愛）。講義では、欲望ほど長く人をしばる「足かせ」はない、と言っていた。
B: しばられると、どうなるの？
A: 生まれては死ぬ、をくり返す輪廻（りんね）の輪から出られない、と仏教は考える。苦しみの原因を12の段階でたどる「十二因縁」という教えもある。
C: 無知と欲望が、苦しみの輪を回す。
```

```flow
無知（無明） → 欲望（渇愛） → 執着 → 苦しみ → 輪廻をくり返す
```

```card
輪から出るには（講義の要点）
- 無知をなくす
- 知恵を育てる
- 欲望を静める
- → そうすれば、もう輪廻しない
```

```quiz
Q: 講義で、輪廻しないために必要とされたのは？
1: 無知をなくし、知恵を育て、欲望を静める
2: たくさんの財産を集める
3: 毎日、肉をたくさん食べる
4: 何も考えずに眠る
C: 1
E: 無知を消し、知恵を育て、欲望を静めることです。ほかの選択肢：財産を集めることは、かえって欲望を強めます。
```

## 6. 涅槃 ― 何も感じなくなること？（3分）

```talk
B: 涅槃って、感情を全部消すこと？
A: よくある誤解。講義では「欲望が完全に消え、手放し、解き放たれた状態」と説明していた。感情を無理におさえこむのとはちがう。
C: 涅槃＝欲望が静まった、自由な状態。
```

```eq
欲望が静まる = 涅槃
```

```quiz
Q: 涅槃とは、感情を押し殺すこと？
1: 欲望や執着が静まり、苦しみから解き放たれたあり方
2: 感情を無理に消すこと
3: 楽しいものをもっと集めること
4: 体が一切変化しなくなること
C: 1
E: 欲望が静まり、とらわれから解き放たれたあり方です。ほかの選択肢：無理に感情を消すことではありません。
```

## 7. 八正道 ― 8つの正しい実践（6分）

```talk
B: どうすれば、そこへ行けるの？
A: それが四聖諦の4つ目「道」で、八正道という。8つは順番にクリアする手順じゃなくて、いっしょに支え合う。
B: 修行するお坊さんだけのもの？
A: 正しい言葉、正しい仕事（生計）もふくむから、ふだんの生活とつながっている。たとえば腹が立ったとき、自分の怒りに気づいて、相手を傷つけるメッセージを送らない。それも実践だよ。
C: 考え・言葉・行い・暮らし・心を整える8つ。
```

```card
八正道
- 正見（しょうけん）：苦しみと原因を正しく見る
- 正思惟（しょうしゆい）：欲や悪意から離れて考える
- 正語（しょうご）：うそや人を傷つける言葉を使わない
- 正業（しょうごう）：人を害する行いをしない
- 正命（しょうみょう）：人を害さない仕事で暮らす
- 正精進（しょうしょうじん）：よい心を育てる努力
- 正念（しょうねん）：いまの体と心に気づく
- 正定（しょうじょう）：心を落ち着け、集中する
```

```flow
知恵：正見・正思惟 → 行い：正語・正業・正命 → 心：正精進・正念・正定
```

> 補足：この3つの分け方（知恵・戒め・集中）は、一般的な整理を足したものです。

```quiz
Q: 正語と正命は、何を整える実践？
1: 正語は食事、正命は睡眠
2: 正語は言葉、正命は生計（暮らしの立て方）
3: 正語は集中、正命は呼吸
4: 正語は姿勢、正命は記憶力
C: 2
E: 正語は言葉、正命は人を害さない仕事で暮らすことです。仏教の実践は、ふだんの生き方にも関わります。
```

## 8. 集中をじゃまする5つ（3分）

```card
五蓋（ごがい）＝集中のじゃまもの
- 感覚の欲望：楽しそうなものを追いかけ続ける
- 悪意・憎しみ：怒りで頭がいっぱい
- 怠け・無気力：だるさや眠気に沈む
- 落ち着かなさ・心配：気が散り、後悔がめぐる
- 疑い：道への迷いで進めない
```

> 補足：「疑い」は、質問や自分で確かめることが悪いという意味ではありません。実践を止めてしまう迷いのことです。

```quiz
Q: 五蓋は何を妨げる？
1: 体の成長
2: 季節の変化
3: 心の集中
4: 言葉を覚える年齢
C: 3
E: 心の集中です。正定（集中）を育てるために、この5つに気づくことが大切とされます。
```

## 9. 3つの宗教をくらべる（5分）

5講・6講・8講を並べると、それぞれの特徴がはっきりします。

```card
キリスト教（5講）
- 信じる：ただひとりの神。イエスは救い主（神の子）
- 問題と救い：神から離れた人が、イエスを通して神とつながる
- 生き方：神と隣人を愛する。すべての人に開かれる
```

```card
イスラム教（6講）
- 信じる：ただひとりの神。ムハンマドは最後の預言者（人間）
- 問題と救い：神にゆだね、最後の審判にそなえる
- 生き方：五行で毎日を形づくる。きまり（シャリーア）が生活全体へ
```

```card
仏教（8講）
- 信じる：創造の神を中心にしない。ブッダは目ざめた人
- 問題と救い：苦しみの原因（執着）を静め、涅槃へ
- 生き方：八正道で、考え・言葉・暮らし・心を整える
```

```quiz
Q: 3つの中で、「創造の神を中心にしない」のは？
1: キリスト教
2: イスラム教
3: 仏教
4: 3つとも
C: 3
E: 仏教は、神を信じることより、苦しみから離れる道を中心にします。キリスト教とイスラム教は、ただひとりの神を信じる一神教です。
```

## 11. 言いかえ練習：写さずに、自分の文にする（5分）

```quiz
Q: 教科書ふうの文「苦は五蘊に対する執着に起因する」。いちばん良い言いかえは？
1: 苦は、五蘊に対する執着に起因する。
2: 五蘊への執着が苦の原因であること。
3: 体や気持ちは変わっていくのに、それを「ずっとこのままの私」と握りしめるから苦しくなる、と仏教は考える。
4: 仏教では、体があること自体が苦しみだと考える。
C: 3
E: 3は意味を保ち、ふだんのことばで説明した自分の文です。ほかの選択肢：1は写し、2は「〜こと。」の箇条書きふう、4は意味が変わっています。
```

```card
言いかえのコツ（3つ）
- 漢字の用語（四聖諦・五蘊）は使ってよいが、すぐ後に自分のことばで説明する
- 身近な例を1つ入れる（返事を待つ不安、怒ったときなど）
- 「〜と考える。なぜなら〜」と、文を書き切る
```

## 12. まず、この3つを覚える

1. **四聖諦**：苦しみ・原因・解放・道。
2. **執着**：変わるもの（五蘊）を、変わらないでほしいと握りしめること。
3. **涅槃と八正道**：欲望が静まった自由と、そこへ向かう8つの実践。

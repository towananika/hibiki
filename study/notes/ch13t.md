## 1. 生産の大きさと、暮らしの満足は別（5分）

```talk
B: GDPが大きければ、暮らしも満足？
A: GDPは、一定期間に国内で生み出した付加価値などから、生産の大きさを測る指標。幸福や便利さそのものではない。
B: 無料の地図は？
A: 道探しの時間を減らしても、その便利さ全体が購入額として現れるわけではない。便益全体を、GDPだけでは測れない。
B: 品質は？
A: 昔と同じ価格のパソコンでも、今は多くのことができる。品質向上を十分に考慮しないと、変化を読みちがえる。
C: 払う金額がゼロでも、価値がゼロとは限らない。
```

```card
要点
- GDP：国内で生み出した付加価値から、生産の大きさを測る指標（幸福そのものではない）
- 無料サービスの便利さ全体は、GDPだけでは測れない
- 同じ価格でも、品質（性能）は変わる
```

## 2. 生産性の謎（5分）

```talk
B: 便利な道具があるのに、生産性が伸びないことがある？
A: 労働生産性 ＝ 生み出した量や付加価値 ÷ 働いた時間など。技術が進んでも、統計の生産性の伸びが小さいことがある。これが生産性の謎。
B: 理由は？
A: 測定の問題だけではない。道具を入れて、仕事の流れや教育を整えるまで、効果が出るのに時間がかかることもある。
C: AIを入れた事実と、仕事が改善した結果は別。
```

```eq
労働生産性 = 生み出した量や付加価値 ÷ 働いた時間など
```

```card
要点
- 労働生産性 ＝ 生み出した量や付加価値 ÷ 働いた時間など
- 生産性の謎：技術が進んでも、統計の生産性の伸びが小さい
- 道具を入れて、仕事の流れや教育を整えるまで時間がかかる
```

## 3. 利用者の得（消費者余剰）（10分）

```talk
B: 無料サービスの得は、どう考える？
A: 払ってもよい額から、実際の支払いを引いた差が、消費者余剰。月1,000円まで払ってもよいと思い、実際は300円なら、700円が余剰。
B: 価格がゼロなら？
A: 価値があるなら、余剰はありえる。ただし、支払ってもよい額は、実際に口にした金額とは限らない。
B: 別の測り方は？
A: 使えない期間に、どれだけ補償が必要かを聞く方法（受取補償額・WTA）。GDP-Bなどは、こうした便益を見て、GDPを補う試み。
B: 測り方の注意は？
A: 減った時間を換算する（時間にどんな価値を置くか）。使えない場合の補償を聞く（大きく答える動機や質問の条件）。サービス間を比較する（代替手段や人・国による違い）。
C: 無料の価値を足せば、幸福の正解が出る、とは言えない。
```

```eq
消費者余剰700円 = 払ってもよい1,000円 − 実際の支払い300円
```

```card
要点
- 消費者余剰 ＝ 払ってもよい額 − 実際の支払い
- 受取補償額（WTA）：使えない場合にいくら必要かを聞く
- GDP-Bなど：便益を見てGDPを補う試み
- 測り方ごとに、注意点がある
```

## 4. 大企業と競争（5分）

```talk
B: 便利な大企業なら、競争の問題はない？
A: 利用者・データ・関連サービスが集まると、大きい企業がさらに有利になりうる。便利になる面と、参入の壁になる面がある。
B: 例は？
A: マイクロソフトのOSとブラウザーの組合せをめぐる競争問題。
B: 大きいだけで違法？
A: ちがう。大きいことだけで、直ちに違法と決めるわけではない。新しい参入、乗換え、革新への影響を見る。
C: 利用者が集まる → データが充実 → 参入の壁にもなりうる。
```

```card
要点
- 利用者・データ・関連サービスが集まる → 大企業がさらに有利になりうる
- 便利になる面と、参入の壁になる面の両方がある
- 大きいことだけで、直ちに違法とは決めない
```

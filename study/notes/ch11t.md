## 1. 共有は、無料であげることではない（5分）

```talk
B: 共有経済って、無料であげること？
A: ちがう。普段は自分が持つ物でも、使わない時間に誰かへ貸せる。部屋や車の所有権を移さず、一定の時間だけ使ってもらう。使われていない時間が、役に立つ時間にかわる。
B: 言葉の範囲は？
A: 共有経済（シェアリングエコノミー）の範囲は、論者によって違う。
C: 所有を変えずに、使い方を変える。
```

```card
要点
- 共有経済：持つ物を、使わない時間に貸す（所有権は移さない）
- 使われていない時間 → 役に立つ時間
- 言葉の範囲は、論者によって違う
```

## 2. なぜアプリを使う？（5分）

```talk
B: アプリがなくても貸せるのに、なぜ使う？
A: 知らない相手を探す、空き時間を合わせる、料金を決める、支払いと評判を確認する。その手間を減らすのが、プラットフォーム。
B: 仲介会社は物を持ってる？
A: 持っていない場合もある。ただし、アプリ上で評価があっても、すべての危険がなくなるわけではない。
C: 探す・決める・払う・評判の手間を減らす。
```

```card
要点
- プラットフォーム：検索・評価・料金・支払いの手間を減らす
- 仲介会社が部屋や車を持っていない場合もある
- 評価があっても、すべての危険がなくなるわけではない
```

## 3. みんなで作るソフト（オープンソース）（10分）

```talk
B: オープンソースって？
A: 中身の設計図に当たるソースコードを、ライセンスの条件に従って利用・変更・再配布できるソフト。誰かが使っても、ほかの人が同じコードを使える。
B: なぜ続くの？
A: 作ることや修正、運営には手間がかかる。参加する動機は、親切心だけではなく、自分の問題を解く、腕を示す、学ぶ、仲間と楽しむなどが混ざる。
B: 企業は、無料の物になぜ協力する？
A: 共有の土台がよくなると、自社の製品や保守サービスにも役立つ。自社だけで全部作らず、ほかの参加者の力も使える。
B: 有料ソフトとの競争は？
A: 価格だけでなく、機能・対応・使い慣れ・移行の手間も重要。
C: 無料でも、使いやすさや手間が勝負。
```

```card
要点
- オープンソース：ソースコードを、条件に従って利用・変更・再配布できる
- 参加の動機：自分の問題を解く／腕を示す／学ぶ／仲間と楽しむ
- 企業も、共有の土台が良くなると、自社の製品や保守サービスに役立つ
```

## 4. ライセンス（5分）

```talk
B: 自由に使えるって、ルールがないこと？
A: ちがう。ライセンスの型がある。MIT・BSDなどは、広い再利用を認め、表示などの条件を守る。GPLなどは、配布時に、対応するコードや同じ自由を守る条件がある。
B: 有料で売れる？
A: オープンソースは有料で販売することもできる。GPLも、あらゆる社内変更を常に世界へ公開せよという意味ではない。
C: 自由に使える ≠ ルールがない。
```

```card
要点
- MIT・BSDなど：広い再利用を認め、表示などの条件を守る
- GPLなど：配布時に、対応するコードや同じ自由を守る条件がある
- オープンソースは有料で販売することもできる
```

## 5. 広げるときに確かめること（5分）

```talk
B: 共有を広げるときは、何を見る？
A: 4つ。技術（作業を分け、成果を確認できるか）、運営（誰が何を担当し、変更をどう決めるか）、動機（貢献が続く理由があるか）、社会のルール（安全・働く条件・個人情報・税を守れるか）。
B: 新サービスで誰かが損することは？
A: 利用者が得をしても、既存の提供者の利益が減る場合がある。反対に、古い提供者を守るだけでもよくない。
C: 技術・運営・動機・社会のルール。
```

```card
要点
- 確かめる4つ：技術／運営／動機／社会のルール
- 新しい貸し借りで、利用者は得をしても、既存の提供者の利益が減る場合がある
```

# 開かれた社会と21世紀 11講 ― まちと人をつなぐ（組織化）

韓国の放送大学「開かれた社会と21世紀」11講（講義資料28ページ）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

```flow
同じ困りごとに気づく → 目標をそろえる → 役わりを分けて動く → 人どうしのつながりと力が育つ
```

## 0. ひとことで
**組織化** とは、会の名前や名簿を作ることではない。
近所の人どうしが **「いっしょに考え、学び、動ける関係」を育てること**。
行事が1回うまくいったかより、その準備の中で **話せる・助け合える関係ができたか** が大事。

## 1. 「会」と「会を育てること」はちがう
| 言葉 | 意味 | 例 |
|---|---|---|
| **組織** | 人が集まって役わりを持つ会 | 自治会、青年会、お年寄りの会、商店会、協同組合 |
| **組織化** | 同じ困りごとや目標を見つけて、協力して動けるようにしていく **流れ** | 防災の集まりを、みんなで話し合いながら育てる |

- 仲よくおしゃべりするだけ、人数を集めるだけ、では組織化ではない。
- 住民が自分で参加し、自分たちで決め（自治）、意見のちがいを話し合い、別の案（代案）を考えるところまで入る。

```quiz
Q: 講義でいう「組織化」にいちばん近いものは？
1: 会の名前と名簿を作れば終わり
2: 専門家だけで計画を決める
3: 住民が同じ目標に向かって、学び、協力して動ける関係を育てる
4: 人数の多い会を、必ず新しく作る
C: 3
E: 組織化は、参加・学び・協力を育てていく、終わりのない流れ。ほかの選択肢：1は形だけ。2は住民が自分で決める力を育てない。4は、いまある会を生かす道を捨てている。
```

## 2. なぜ必要？
- 共働きの家や一人暮らしがふえ、まちで必要なことも変わってきた。
- だから新しい会を作る前に、**いまある会と、物事の決め方** を調べる。いまある会を使う、学び直して作り直す、という道もある。

> 補足（たとえ話）：防災の集まりを始めるなら、まず自治会や商店会が何をしているか、ふだん来られない人にどんな事情があるかを聞く。「新しい会を作る」がいつも最初の答えとは限らない。

## 3. 組織化の4つのはたらき
| はたらき | ひとことで |
|---|---|
| **参加をうながす**（参加の促進） | 住民が集まり、まちの将来の姿をいっしょに思いえがく |
| **学ぶ**（学習） | 協力すること、みんなの得、信頼のつながり、長く続けることを学ぶ |
| **人や物をつなぐ**（資源のネットワーク化） | 人・物・知識・経験・場所をつないで、1人ではできないことをする |
| **自分たちで決める力がつく**（能力と影響力の向上） | 会議・意見まとめ・もめごとの調整を経験し、まちのことを決める場に加われるようになる |

```flow
参加する → いっしょに学ぶ → 人と物をつなぐ → 決める力がつく → また参加する
```

- 4つはばらばらではなく、**ぐるぐる回って、おたがいを強くする**。
- **信頼のつながり**（社会関係資本）は、「困ったときに助け合える関係」のこと。

```quiz
Q: 組織化の4つのはたらきについて、正しいのは？
1: 参加・学び・つなぐこと・決める力が、おたがいに影響し合う
2: 参加する人数をふやすことだけがはたらき
3: 学びは、活動がぜんぶ終わってから始まる
4: つなぐもの（資源）は、建物とお金だけ
C: 1
E: 4つはつながって、ぐるぐる回る。ほかの選択肢：2は人数だけを見ている。3は、活動の途中でも学んでいる。4は、人・知識・経験も大事な資源。
```

## 4. 住民・リーダー・手伝う人の役わり
| だれ | 役わり |
|---|---|
| **住民** | 主役。動きながら、自分も学んで変わっていく |
| **まちのリーダー** | 住民の一人として話し合いを進める。えらい人ではない。意見を聞き、会議をまわし、もめごとをまとめる |
| **手伝う人**（専門家・支援の団体） | 経験と知識で、住民が **自分たちで動けるように** 手伝う。代わりに決め続けない |

- これは上下の命令の順番ではない。
- 手伝う人に **たよりすぎると、まちの力が育たない**。ただ、まちの中にリーダーが見つからないときは、外から迎えることもある。

```quiz
Q: 手伝う人（専門家・支援の団体）の、のぞましい役わりは？
1: 住民の意見に関係なく、自分の理想を実現する
2: いつまでも自分がいないと決められない状態にしておく
3: どのまちにも同じリーダー像をおしつける
4: まちの力を見きわめ、住民とリーダーが自分で動けるように支える
C: 4
E: 手伝う目的は、まち自身の力を育てること。ほかの選択肢：1は住民を主役にしていない。2は、たよる状態を続けてしまう。3は、まちごとのちがいを見ていない。
```

## 5. 理想より先に「いまのまち」から
アメリカの住民運動家 **アリンスキー** は、**ちゃんと話が通じ合うこと** と、**ありのままの現実から始めること** を大事にした。
いまを知るのは、理想をあきらめることではない。いまの事情・人間関係・決まりがわかって、はじめて変え方が見えてくる。

> 補足（たとえ話）：「みんな毎週来るべき」と決める前に、仕事・子育て・移動など、来られない理由を聞く。来ない人を「やる気がない」と決めつけない。

## 6. 4つの段階で進めて、見直す
```flow
調べる・準備する → 話し合って計画する → やってみる → ふり返って作り直す
```
| 段階 | すること |
|---|---|
| 調べる・準備（調査・準備） | まちにある人・物・知識、住民の困りごと、人間関係、決め方を調べる |
| 計画（組織化・計画） | 情報と将来の姿を共有し、話し合いの力を育てて、計画を作る |
| 実行 | 分けた役わりを果たす。手伝う人は記録をとって共有する |
| ふり返り（評価・再組織化） | 結果だけでなく、**進め方と、それぞれの動き** もふり返り、次に生かす |

- どのまちも、必ずこの順番で一から始めるわけではない。いまある会を使って途中から進めることもある。

```quiz
Q: 活動のあとのふり返り（評価）で大事なことは？
1: 結果の数字だけを記録して、会を解散する
2: 進め方と、参加した人の動きをたしかめ、次に生かす
3: もめごとがあったことは記録から消す
4: 最初の計画は、ぜったいに変えない
C: 2
E: ふり返りは「次をよくする」ためのもの。ほかの選択肢：1は進め方を見ず、続けることも考えていない。3は学びの材料をなくす。4は、現実に合わせた見直しができない。
```

## 7. 3つのやり方を見分ける
| やり方 | 何を中心にする？ | 例 |
|---|---|---|
| **困りごと中心**（課題中心の方法） | いま目の前にある、はっきりした問題 | 再開発、住まい、環境、暴力、働き方、人権 |
| **分野ごとの事業**（社会経済プロジェクトの方法） | 1つの分野の活動で人をつなぐ | 教育、医療・健康、自立の手伝い、文化 |
| **まち全体を育てる**（統合的地域社会開発の方法） | 分野にかたよらず、まち全体の力と資源をつなぐ | 急に変えるより、長く続くまちに |

> 覚え方：「いまの問題」／「分野ごと」／「まち全体を長く」。実際は重なることもある。

```quiz
Q: 教育・健康・文化などをつなぎ、1つの分野にかたよらず、まち全体を長く育てるやり方は？
1: 困りごと中心のやり方
2: 分野ごとの事業のやり方
3: まち全体を育てるやり方（統合的地域社会開発）
4: 外の人にぜんぶまかせるやり方
C: 3
E: 「いくつもの分野」と「まち全体を長く」が手がかり。ほかの選択肢：1は目の前の1つの問題が中心。2は1つの分野の事業が中心。4は講義の3つの分け方に入っていない。
```

## 8. 会の形も、集まる場所も、まちに合わせる
- 新しい活動は、まず **いまある会でできないか** を考える。だめなら、新しい会を作る。
- 役わり・ほかの会との関係・もうけの分け方を、**みんなの合意と決まり（規約）** ではっきりさせておくと、むだなもめごとを防げる。
- 講義は映画「ジミー、野を駆ける伝説」から、広場や集会所は人が集まる場所になるけれど、**集まる人も話し方もまちごとにちがう** と話す。場所だけまねしてもうまくいかない。
- 結論：どのまちにも使える手順書はない。**住民の願いと、まちの特徴・力に合うやり方を選ぶ**。

## まず、この3つ
1. 組織化は「会を作ること」ではなく、「いっしょに考え・学び・動ける関係を育てること」。
2. 4つのはたらき（参加・学び・つなぐ・決める力）はぐるぐる回る。手伝う人は、住民が自分で動けるように支える。
3. 進め方は「調べる→計画→実行→ふり返り」。やり方は「困りごと中心／分野ごと／まち全体」。どれも、まちに合わせて選ぶ。

## ひびきの暮らしでいうと
- 会社や勉強会で何かを変えたいときも、まず1人に困りごとを聞く。目標を1つ決め、役わりを分けてためし、何が変わったかふり返る。
- 人を「動かす」のと、その人が「自分で決めて動けるように支える」のは、ちがう。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。

```quiz
Q: 新しい活動を始めるとき、講義に合う考え方は？
1: いまある会を調べ、役わり・関係・もうけの分け方を合意しておき、必要なら会を作り直す
2: いまある会は、必ずなくす
3: もうけの分け方は、もめごとが起きてから決める
4: うまくいったまちの施設を、どのまちにも同じ形で作る
C: 1
E: まちに合わせて選び、先に合意しておくことが大事。ほかの選択肢：2は使える会を捨ててしまう。3はもめごとを防げない。4は、集まる人や話し方のちがいを見ていない。
```

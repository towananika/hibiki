# 伝統社会と生活文化 8講 ― 困ったら役所に訴える

韓国の放送大学「伝統社会と生活文化」8講（対談の講義）を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。音声から文字を起こしてまとめたので、人名などの漢字は分かる範囲で書いた。

**この回の答え：朝鮮時代の人は、村で解決できない困りごとを、紙に書いて役所に訴えた（民状）。だれでも訴えられ、上の役所や王にまで訴える道があった。それでも解決しないと、農民の反乱になった。**

```flow
困りごと → 村で話し合う → だめなら役所に訴え状（民状） → 上の役所 → 王へ → それでもだめなら反乱
```

## 1. 民の訴え状とは
- 民が役所に出す訴えの書類 ＝ **訴え状**（民状）。書類の形は（所志）とよばれた。
- 何人もが名前を並べて出す訴え状 ＝（等状）。
- 国が訴えを大事にした理由は儒教の考え：
  - 民の心は天の心（民心は天心）。民の心を失うと、王は王でいられない。
  - 民は国のもと（民本思想）。

### 1.1 例：背負い商人の訴え（1872年）
- 鉄原（チョロン）に住む、荷を背負って売り歩く商人が、役所から「穀物を借りなさい」と割り当てられた。
- その制度 ＝ 春に穀物を貸し、秋に利子をつけて返させる（還穀）。
- 仕事もなく利子を払えない彼は、「わたしを外してください」と訴え状を出した。
- 「あちこち渡り歩く身」と書いたのがポイント。よそへ行かれたら役所は取り返せない → 外してもらえた。

```flow
もとは 貧しい人を助ける制度 → 朝鮮後期 国のお金が足りない → 役所のかせぎの道具に → むりやり割り当て → 訴えがふえる
```

## 2. 朝鮮後期、訴えがどっとふえた
- 物を売り買いし、お金を使う暮らしが広がった（商品・貨幣経済の発展）→ もめごともふえた。
- 19世紀の全羅道のある郡では、1日に数十通の訴え状が郡の長に届いた。「訴え状の洪水」の時代。

### 2.1 書き方の手本の本（儒胥必知）
- 名前の意味：学ぶ人（儒生）と役所の下役（胥吏）が必ず知るべき本。19世紀の本。
- 中身：王への訴え（上言）から売り買いの契約書（文券）まで、7種類の書類の手本。中心は訴え状。

| 訴え状の順番 | 書くこと |
|---|---|
| はじめ | 住んでいる所・身分・名前 |
| 書き出し | 「つつしんで申し上げます」 |
| 本文 | 困りごとを自由に書く |
| むすび | 「どうかお取り計らいください」 |
| 最後 | あて先（郡の長）と日付 |

- 役所は訴え状の**左下に答え（処分）を書いて**、本人に返した。この答え ＝（題辞）。
- いちばん大事なのは、本文と答え（題辞）。

### 2.2 役所の控え帳（民状置簿冊）
- 訴え状は本人に返すので残りにくい。役所は、訴えと答えを**短くまとめた帳面**を残した。
- 19世紀の慶尚道・全羅道・忠清道のものが多く、ソウル大学の奎章閣にある。
- よい点：ある時・ある土地の訴えがまとめて分かる。弱い点：まとめなので細かい中身は分からない。

## 3. だれが訴えられた？
- **だれでも**。身分に関係なかった。
  - 女の人、奴婢（召し使いの身分）、牢屋にいる人まで訴えた。
  - 元の役人・今の役人も。村みんなの代わりに訴えることが多かった。
  - 役所の下役は、休みや辞めることを願い出るのに使った。
- 「昔の人は裁判をいやがった」というのは思いこみ。ほかの国とくらべても、とても開かれていた。

## 4. だれが裁いた？
- 今のような裁判所はない。**役所の仕事と裁判が分かれていなかった**。
- ソウル：裁判の役所が集まっていた。
  - 3つの大きな役所（三法司：刑曹・司憲府・漢城府）。
  - お金や土地のもめごと（今の民事）を扱う役所（詞訟衙門）、人をつかまえて閉じこめられる役所（直囚衙門）。
- 地方：**郡の長（守令）**と**道の長（観察使）**が、両方の役をかねた。
- 郡の長の力はとても強く、裁きは郡の長の思いのままになりやすかった（「お役人さまの裁き」という言い方が今も残る）。
  - 補足：郡の長の大事な仕事は、裁判と税集め。税を出さない人を裁いて罰する力が、その力のもとだった。
- いくつかの郡にまたがるもめごと：訴えられた側の郡の長に出す。郡の長がいないとき：となりの郡の長が代わりに処理（兼官）。

### 4.1 裁判の進み方
```flow
本人が訴え状を出す（代わりはだめ） → 訴えた人が 相手を自分で連れてくる → 簡単に話を聞く → 答え（題辞）を書いて返す → 控え帳に残す
```
- 門番や下役は、訴え状を勝手に追い返してはいけない決まり。
- 訴えた人が相手を連れてくる決まり（当事者主義）。でも力がないと連れて来られず、「連れて来てください」ともう一度訴えることもあった。

## 5. 上へ、上へと訴える道
- 法律の本（経国大典）に、上に訴える道が書いてあった。

```flow
郡の長（守令） → 道の長（観察使）※この訴えは（議送） → 役人を見張る役所（司憲府） → 王（申聞鼓）
```

### 5.1 王に直接訴える
- **申聞鼓**：宮殿の門の大きな太鼓をたたいて、王に聞いてもらう。でも使うのはソウルの両班（上の身分）ばかりで、あまり広まらなかった。
- 15世紀後半から、代わりに次の2つ。いちばん多かったのは18世紀の**正祖王**のころ。

| | 書いて訴える（上言） | 鳴らして訴える（撃錚） |
|---|---|---|
| やり方 | 王の行列の道で、書いた訴えを係の役人に出す | 行列の前に出たり宮殿に入ったりして、どらや鐘を鳴らす |
| 好んだ人 | 学のある上の人たち（士大夫） | 字が読めない下の身分の人たち |
| ひとこと | 書類なのでおだやか | まず「さわいだ罪」で罰を受けてから、口で訴える |

- 正祖のころの訴えの中身：税や郡の悪いやり方（民隠）がいちばん多い。ほかに、お墓の土地あらそい（山訟）、先祖をほめてほしい、養子をとる許しがほしい。

## 6. 何を訴えた？（6つ）
### 6.1 税（いちばん大事）
- 朝鮮後期の3つの大きな税 ＝（三政）：
  - 土地の税（田政）：土地を持つ人の訴え。災害で作れなかったから減らして、まちがって高くされた、など。
  - 兵役のかわりに出す布（軍政・軍布）：両班が抜けて、ふつうの民だけの負担になった。
  - 春に借りて秋に返す穀物（還穀）。
- 貧しい農民の訴えは、軍布と還穀が中心（土地を持たないので）。
- 軍布のひどい取り立ての例：赤ちゃんを兵役の名簿にのせる（黄口簽丁）、死んだ人からも取る（白骨徴布）、となりや親族から取る（隣徴・族徴）。
- 解決はむずかしかった：郡ごとに**税の合計が決まっていた**ので、1人を外すと、ほかの人の負担がふえる。→「今年はもう終わり、来年を待て」という答えが多い。

### 6.2 土地と奴婢
- 土地を持つ権利のあらそいが多い（農業の社会だから）。
- 「期限内なら買いもどせる」という条件つきの売り買い（還退）で、返してくれないともめた。
- 力のある家や役所が、新しく開いた土地をうばうこともあった。
- 奴婢は財産として売り買い・相続された。ふつうの民と奴婢が結婚して生まれた子（良賤交婚）は、だれのものか・どの身分か、でもめた。

### 6.3 お墓の土地あらそい（山訟）
- 原因：お墓の場所のよしあし（風水）と、山の持ち主の問題。
- 19世紀、丁若鏞（茶山）は「なぐり合いや殺人の半分近くは山訟が原因」と書いたほど。

```flow
1807年 お墓をめぐりあらそい開始 → 郡の長・道の長・暗行御史 → 1808〜1811年 王へ（上言5回・撃錚2回） → 訴えすぎの罪で牢屋へ
```
- 例：慶尚道の善山。盧（ノ）家の山に、朴（パク）家の人が母のお墓をつくった。郡の長は「移せ」と命じたが、朴家は何か月も牢屋に入れられても従わない。盧家は王にまで訴えたが、最後は「筋の通らない訴えをくり返した罪」（非理健訟）で牢屋に入れられ、負けてしまった。
- 例：坡平尹氏と青松沈氏の山訟（英祖のころ）。王も決められず、**約250年**つづき、最近になって子孫どうしの話し合いで解決した（京畿道 坡州）。

### 6.4 借金
- 高い利子の借金（高利貸）を返せない。
- 薬や木材を買って代金を払わない → 物の売り買いがさかんだったしるし。
- 牢屋に入ると、家族が食事などの世話をする（獄バラジ）。裁判が長びくと借金になった。
- 殺人事件の調べの費用を、加害者の家族が負担することも多く、借金になった。

### 6.5 田畑を借りて作る権利と水
- 小作の人が作る権利は守られる決まり（種をまいたあとは取り上げない）。でも守られず、もめた。
- 田んぼの水（ため池や堰）を、村と村で取り合った。村の中では解決できないので役所へ。

### 6.6 村の秩序
- 親孝行な人や貞節な女の人をほめてほしい、という村みんなの訴え。
- 酒におぼれる人・どろぼう・乱暴者をつかまえてほしい、という訴え。
- 日照りや水害のとき、税を軽くしてほしい、という訴え。

## 7. 訴えから反乱へ
- 村みんなで出す訴え（等訴）は、**法にかなったお願い**。反乱とは別のもの。
- でも19世紀、国の仕組みがゆらぎ、ひどい取り立て（苛斂誅求）がふえると、訴えでは解決できなくなった。
- 最後の手段が、農民の反乱（農民抗争）。

```flow
村みんなで訴える（等訴） → 聞いてもらえない → 1862年 壬戌農民抗争 → 1894年 甲午農民戦争
```

## 8. まとめ（6点）
1. 民の訴え状（民状・所志）で、村で解決できない困りごとを役所に訴えた。もとにあるのは儒教の「民は国のもと」。
2. 朝鮮後期、物とお金の暮らしが広がり、訴えがどっとふえた。書き方の手本（儒胥必知）、役所の控え帳（民状置簿冊）がある。
3. 訴えられるのは、女の人・奴婢・牢屋の人までだれでも。
4. 地方では郡の長（守令）が裁判もした。役所の仕事と裁判は分かれていない。
5. 上へ訴える道：郡の長 → 道の長 → 司憲府 → 王。王へは書いて（上言）か、鳴らして（撃錚）。正祖のころがいちばん多い。
6. 中身は税（三政）・土地と奴婢・お墓（山訟）・借金・小作と水・村の秩序。訴えで解決できないと、農民の反乱になった。

## 10. 自分の暮らしにつなげる
- 今の役所への苦情や要望も同じ。「だれが・何に困っていて・どうしてほしいか」を書くと伝わりやすいのは、昔の訴え状の書き方と同じ。

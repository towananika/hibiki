# 伝統社会と生活文化 11講【会話で読む】― 女性の結婚・愛・仕事

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition11)」。

## 1. 結婚は「家と家」（5分）

```talk
B: 朝鮮の結婚は、どんなもの？
A: 両班にとって、結婚は家と家のむすびつき（二姓之合）。だから両班の男性の妻は、必ず同じ身分から。
B: 国はどんな結婚をすすめた？
A: 仲人を通す。同じ名字どうしは結婚しない（同姓不婚）。喪の間は結婚しない。ぜいたくをしない。30歳をこえても結婚できない女性は、国がお世話して結婚させた。苦労をともにした妻（糟糠の妻）を捨てない、も大事にされた。
B: 「春香伝」は？
A: 李夢龍と春香は、身分がちがうので、本当は結婚の相手にはなれない。
C: 結婚は家と家のむすびつき。
```

```card
要点
- 結婚は家と家のむすびつき（二姓之合）。妻は同じ身分から
- 同姓不婚：同じ名字どうしは結婚しない
- 30歳をこえて結婚できない女性は、国がお世話
- 糟糠の妻を捨てない
```

## 2. 結婚の年齢と、再婚（10分）

```talk
B: 何歳で結婚した？
A: 法律（経国大典）では、両班の男性15歳・女性14歳から。でも戸籍などの研究では、実際は女性17.5歳・男性18歳ごろ。
B: 「年上の花嫁と小さな花婿」のイメージは？
A: 研究では、ちがった。同い年や、花嫁が年上は少ない。結婚は早いのに、1人目の子は遅い。花嫁が結婚後しばらく実家にいた（于帰）から。
B: 再婚は？
A: 男性は、できた。出産で亡くなる妻が多く、「跡つぎの息子が必要」と再婚、3回目もめずらしくなかった。でも相手は初婚の女性だけ。
B: 女性は？
A: 高麗までは再婚する女性も多かった。儒教が広まると「再婚は貞節を失うこと」と考えられた。国は再婚を直接禁止せず、再婚した女性の名を名簿（恣女案）にのせて、子や孫が役人になるのを難しくした。朝鮮の後半には、両班の女性の再婚はほぼ不可能になった。
C: 男性は再婚できて、女性は難しい。
```

```card
要点
- 実際の結婚年齢：女性17.5歳・男性18歳ごろ（法律は女性14歳・男性15歳から）
- 結婚は早いが、1人目の子は遅い（于帰：花嫁がしばらく実家にいる）
- 男性（両班）は再婚できたが、相手は初婚の女性だけ
- 女性は再婚がほぼ不可能に。再婚した女性の名は恣女案にのせ、子孫の役人への道を難しくした
```

## 3. 旌表政策（5分）

```talk
B: 国は、女性にどんな働きかけをした？
A: 旌表政策。夫に尽くした妻（烈女）・忠臣・孝行者を表彰し、家の門（旌閭門）を建て、税を軽くした。
B: 影響は？
A: 表彰されると家の名誉になり、税も軽くなった。そのため、両班でないふつうの家の女性まで、まねするようになった。さらに後の時代には、夫が死ぬと妻も自分で命を絶つ（殉死）ことまで「りっぱなこと」と見られるようになった。
C: 表彰が、考え方を広げた。
```

```card
要点
- 旌表政策：烈女・忠臣・孝行者を表彰し、旌閭門を建て、税を軽くした
- 表彰は家の名誉と税の軽減につながり、ふつうの家にも広がった
- 後の時代には、殉死まで「りっぱなこと」と見られるようになった
```

## 4. 結婚式とすまいの変化（10分）

```talk
B: 結婚式は、どこでやった？
A: もとの朝鮮のやり方（男帰女家）は、花婿が花嫁の家に入って式をし、そこで暮らす。中国式（親迎）は、花婿が花嫁を自分の家に連れてきて式をし、そこで暮らす。
B: 間は？
A: 16世紀の折衷（半親迎）は、花嫁の家で、その日のうちに式をする。すまいはもとのやり方。朝鮮の後半（于帰）は、式は花嫁の家で、花嫁はしばらく実家にいて、年が明けたころ夫の家に行く。
B: 儒学者はどう考えた？
A: 建国のころから中国式をすすめた。男（陽）が女（陰）に従うのが正しいから。
B: 記録は？
A: 16世紀の学者・柳希春の日記（眉巌日記、1567〜1577年の11年分）に、孫の結婚の様子がくわしい。500年かけて、花嫁が夫の家で暮らす形に変わった。
C: 男帰女家 → 半親迎 → 于帰 → 夫の家で暮らす。
```

```card
要点
- 男帰女家：花婿が花嫁の家に入って暮らす（もとの朝鮮）
- 親迎：花嫁を自分の家に連れてくる（中国式）
- 半親迎：花嫁の家で、その日のうちに式（16世紀の折衷）
- 于帰：式は花嫁の家、花嫁はしばらく実家にいてから夫の家へ
- 眉巌日記（柳希春）：結婚の様子の記録。500年かけて変わった
```

## 5. 妻と妾、身分の低い女性の仕事（10分）

```talk
B: 夫は、1人の妻だけ？
A: 正しくは、1人の妻と、何人もの妾（一夫一妻多妾）。高麗の終わりには妻を何人も持つ人もいたけど、李芳遠（のちの太宗）の「王子の乱」をきっかけに、妻は1人と決まった。
B: 妻と妾のちがいは？
A: 妻は、家の跡つぎのため、同じ身分から選ぶ。社会に認められ、結婚は続く。妾は、夫の好みで選ばれ、家族の中のいちばん下。
B: 家の仕事は？
A: 実際に担ったのは、身分の低い女性。そばで仕える仕事、乳母、台所の仕事（実際に作るのは廚婢）、機織りと養蚕（布は税にも使えた。いちばん生産的）、市場で売る仕事。
B: 養蚕は？
A: かいこを育てて絹をとる。王妃が自分でかいこを育てる儀式（親蚕礼）でお手本を見せた。
C: 家の仕事は、多くが身分の低い女性。
```

```card
要点
- 一夫一妻多妾：1人の妻と、何人もの妾（王子の乱をきっかけに妻は1人）
- 妻：同じ身分から選び、社会に認められる／妾：夫の好みで選ばれ、家族の中のいちばん下
- 身分の低い女性の仕事：そばで仕える／乳母／台所（廚婢）／機織り・養蚕／市場で売る
- 布は税にも使えた。親蚕礼：王妃が自分でかいこを育てる儀式
```

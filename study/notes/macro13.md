# 上級マクロ経済論 13講 ― 景気はなぜ波打つ？（均衡景気循環理論）

韓国の放送大学「上級マクロ経済論」13講の講義資料を、試験に向けて覚えやすくまとめたもの。

**この回の答え：景気の波を「いつも均衡のまま動くもの」と見る理論は2つ。ルーカスは「思いがけないお金の変化で人が値段を見まちがえる」こと、実物的景気循環理論（RBC）は「ずっと続く生産性のショック」が原因だと考える。データにより合うのは RBC。**

```flow
景気の動きの特徴（データ） → 貨幣的均衡景気循環理論（ルーカス） → 実物的景気循環理論（RBC）
```

## 1. 景気の動きを見る2つの物さし
| 物さし | 見方 |
|---|---|
| **同じ向きに動くか（共動性）** | GDP との相関係数。プラスなら**景気順応的**、マイナスなら**景気逆行的**、0 に近ければ**無循環的** |
| **ゆれの大きさ（相対変動性）** | その変数の標準偏差 ÷ GDP の標準偏差。1 より大きければ GDP よりよくゆれる |

## 2. 韓国のデータ（1970〜2019年）の特徴
| 変数 | 向き | ゆれ・ひとこと |
|---|---|---|
| 消費 | 順応的 | 通貨危機（1997年）のあと、消費のゆれが所得より大きい（消費変動性のパズル） |
| 投資 | 順応的 | GDP よりずっと大きくゆれる |
| 雇用 | 順応的 | 2000年代半ばから弱まる。ゆれは小さい |
| 実質賃金 | **順応的** | 雇用よりゆれが大きい（会社は人数より賃金で調整） |
| 実質利子率 | **逆行的** | 危機のときに急に上がる |
| 物価 | **逆行的** | 需要が引く物価上昇と、費用が押す物価上昇がかわるがわる |
| 通貨（M1） | 順応的 | GDP より**先に**動き、ゆれも大きい → お金は中立ではない |

```bars
投資のゆれ | 100 | とても大きい | r
GDP のゆれ | 40 | 基準 | m
雇用のゆれ | 25 | 小さい | s
```

> 補足：「景気順応的」は景気がよいときに上がる、「景気逆行的」は景気がよいときに下がる、という意味。

## 3. 貨幣的均衡景気循環理論（ルーカス）
- **不完全情報モデル**：自営の生産者は、自分の品物の値段はすぐ分かるが、物価全体はすぐには分からない。
- 思いがけずお金がふえて値段が上がると、「自分の品物が**相対的に**高く売れる」と見まちがえ、もっと働き、もっと作る。

```flow
予想外の M↑ → 自分の品物の値段↑ → 相対価格が上がったと見まちがえる → 働く量↑・生産↑
```

| 変数 | モデルの答え | データ |
|---|---|---|
| 所得・雇用・消費・投資 | ↑ | 合う |
| 実質利子率 | ↓ | 合う（逆行的） |
| 実質賃金 | ↓（逆行的） | **合わない**（データは順応的） |
| 物価 | ↑（順応的） | **合わない**（データは逆行的） |

### 3.1 政策への答え：政策無力性の命題
- **予想された**お金の変化は、人がすぐ物価に読みこむので、実質の量に効かない。効くのは**予想外**の変化だけ。
- だから政府が景気を安定させようとしても、くりかえし予想されて効かなくなる。

### 3.2 弱いところ
1. 物価の情報は毎月すぐ出るので、見まちがえは小さく、大きな景気の波は説明しにくい。
2. 見まちがえはすぐ直るので、波が**長く続く**ことを説明できない（韓国の景気の波は平均約50か月）。

## 4. 実物的景気循環理論（RBC）
- キドランドとプレスコット、ロングとプロッサー。
- 景気の波の原因は、**ずっと続く全要素生産性（技術）のショック**。今の生産性が上がると、未来の生産性も上がると予想される。

```flow
生産性↑（今も未来も） → 労働需要 右へ・総供給 右へ ＋ 投資↑で総需要 右へ → 所得↑・雇用↑
```

| 変数 | RBC の答え | データ |
|---|---|---|
| 所得・雇用・消費・投資 | ↑ | 合う |
| 実質賃金 | ↑（労働需要が右へ動くから） | **合う** |
| 実質利子率 | ↓（たぶん） | 合う |
| 物価 | ↓ | **合う** |
| 通貨 | モデルの中では無循環 | 合わない → 次の説明 |

### 4.1 お金が景気より先に動くのはなぜ？（内生的な通貨供給）
- 景気がよくなりそうだと、銀行の**信用創造**が先にふえる。
- 中央銀行も、景気に合わせてお金を出す（受け身）か、先回りして出す。
- だから、お金が原因でなくても、**お金が景気より先に動く**ように見える。

### 4.2 RBC の強いところと政策の見方
- ショックがずっと続く・設備が完成するまで時間がかかる（**建設期間**）ので、波が長く続くことを説明できる。
- 景気の波 ＝ 完全雇用の均衡そのものが動いたもの → **損ではなく、安定化政策はいらない**。
- くらべる：ルーカス「政策は**効かない**」、RBC「政策は**いらない**」。

### 4.3 RBC への批判
1. 生産性のショックは測りにくい：設備の稼働率や働く強さの変化がまざる。
2. 不況を「技術がマイナスになった」と説明するのは不自然。
3. 「技術ショック」の中身を広げすぎると、何でもあてはまってあいまいになる。

## 5. まとめ（6点）
1. 物さしは、GDP との相関（向き）と標準偏差の比（ゆれ）。
2. 韓国：消費・投資・雇用・実質賃金・通貨は順応的、利子率と物価は逆行的。投資はとてもよくゆれる。
3. ルーカス：予想外のお金で相対価格を見まちがえる。賃金と物価の向きがデータと合わない。
4. ルーカスの政策の答え：予想された政策は効かない（政策無力性）。
5. RBC：続く生産性ショック。賃金↑・物価↓でデータとよく合う。お金は内生的に先に動く。
6. RBC の政策の答え：波は均衡なので、安定化政策はいらない。ただし生産性ショックの測り方に批判。

## 7. 自分の暮らしにつなげる
- 景気がよくなると、人数より先に給料やボーナスが動きやすい（実質賃金は順応的）。景気の波は、給料の動きからも感じられる。

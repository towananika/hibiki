# 上級マクロ経済論 13講 ― 景気はなぜ波打つ？

韓国の放送大学「上級マクロ経済論」13講を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

**この回の答え：景気の波には2つの説明がある。ルーカスは「思いがけないお金の変化で、人が値段を見まちがえるから」、もう1つは「技術の変化が長く続くから」と考える。データによく合うのは後のほう。**

```flow
データで景気の動きを見る → ルーカスの考え → 技術の変化の考え（RBC）
```

> 補足：どちらも「景気はいつもつりあったまま動く」と見る（均衡景気循環理論）。

## 1. 景気の動きを見る2つの物さし
| 見ること | やさしく言うと | 試験での言い方 |
|---|---|---|
| 向き | 景気と同じ向きに動く | 景気順応的 |
| 向き | 景気と逆の向きに動く | 景気逆行的 |
| ゆれ | GDPよりどれだけ大きくゆれるか | 相対変動性 |

- 向きは、GDPとの相関でみる。プラスなら同じ向き、マイナスなら逆。
- ゆれは「その変数の標準偏差 ÷ GDPの標準偏差」。1より大きいとGDPよりよくゆれる。

## 2. 韓国のデータ（1970〜2019年）
| 景気と同じ向き | 景気と逆の向き |
|---|---|
| 消費・投資・雇用・給料（実質賃金）・お金の量（M1） | 利子率（実質利子率）・物価 |

- 投資は、GDPよりずっと大きくゆれる。
- 給料は、雇う人数よりよくゆれる。会社は人数より給料で調整する。
- お金の量は、GDPより**先に**動く。お金は景気に効いているように見える。

## 3. ルーカスの考え（貨幣的均衡景気循環理論）
- 作る人は、自分の品物の値段はすぐ分かる。でも、全体の物価はすぐ分からない（不完全情報モデル）。

```flow
思いがけずお金がふえる → 自分の品物の値段↑ → 「自分のだけ高く売れる」と見まちがえる → 多く働き多く作る
```

| | ルーカスの答え | データ |
|---|---|---|
| 収入・雇用・消費・投資 | ふえる | 合う |
| 利子率 | 下がる | 合う |
| 給料 | 景気と逆 | **合わない** |
| 物価 | 景気と同じ向き | **合わない** |

### 3.1 予想された政策は効かない
- 人は、予想できるお金の変化をすぐ物価に読みこむ。だから効くのは思いがけない変化だけ（政策無力性の命題）。

### 3.2 弱いところ
1. 物価は毎月すぐ発表されるので、見まちがえは小さい。大きな波は説明しにくい。
2. 見まちがえはすぐ直る。波が長く続くこと（韓国では平均約50か月）を説明できない。

## 4. 技術の変化の考え（実物的景気循環理論・RBC）
- キドランドとプレスコットなど。
- 波の原因は、長く続く技術の変化（全要素生産性のショック）。今よくなると、未来もよくなると予想される。

```flow
技術がよくなる → 雇いたい人がふえる・投資がふえる → 収入↑・雇用↑
```

| | RBCの答え | データ |
|---|---|---|
| 収入・雇用・消費・投資 | ふえる | 合う |
| 給料 | 上がる（景気と同じ向き） | **合う** |
| 物価 | 下がる（景気と逆） | **合う** |
| お金の量 | 景気と関係なし | 合わない → 4.1 |

### 4.1 お金が景気より先に動くわけ
- 景気がよくなりそうだと、銀行が先に貸し出しをふやす。国の銀行もそれに合わせてお金を出す。
- お金は原因ではなく、景気につられて動いている（内生的な通貨供給）。

### 4.2 政策の見方
- 技術の変化が続き、工場や設備ができるまで時間がかかる（建設期間）ので、波は長く続く。
- 波はつりあいそのものが動いたもの。損ではないので、景気をならす政策はいらない。

| | 政策について |
|---|---|
| ルーカス | 政策は**効かない** |
| RBC | 政策は**いらない** |

### 4.3 RBCへの批判
1. 技術の変化は測りにくい。機械の動かし方や働く強さの変化がまざる。
2. 不況を「技術が悪くなった」と説明するのは不自然。

## 5. まとめ（6点）
1. 物さしは、景気との向きと、GDPとくらべたゆれの大きさ。
2. 韓国：利子率と物価だけが景気と逆。投資はとてもよくゆれる。
3. ルーカス：思いがけないお金で値段を見まちがえる。給料と物価の向きがデータと合わない。
4. ルーカスの政策の答え：予想された政策は効かない。
5. RBC：長く続く技術の変化。給料と物価の向きがデータと合う。
6. RBCの政策の答え：政策はいらない。でも技術の変化は測りにくい。

## 7. 自分の暮らしにつなげる
- 景気がよくなると、人数より先に給料やボーナスが動きやすい。景気の波は、給料の動きからも感じられる。

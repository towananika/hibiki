# 上級マクロ経済論 13講 ― 景気の波は、なぜ起こる？

**同じ「生産が増えた」という結果にも、違う理由が考えられます。** この講では、「値段の受け取り違い」と「生産性の変化」という2つの説明を比べます。

## 1. パンの売値が上がった。なぜ？

あなたがパン屋なら、2つの場合を区別したいはずです。

- **自分のパンだけ**人気が出て高く売れる → もっと作ると得になりそう。
- **世の中の物価全体**が上がった → 材料も高くなるなら、得が増えたとは限らない。

この違いがすぐにはわからない、という所から始めるのが、ルーカスの説明です。

```flow
自分の売値が上がる → 自分の商品だけ人気だと思う → 生産を増やす
```

予想外にお金が増えて全体の物価が上がっても、初めは自分の商品だけの値上がりだと受け取る場合があります（不完全情報モデル）。**合理的な人でも、情報が足りなければ見分けられない**という話です。

```quiz
Q: 自分のパンだけの値上がりと、全体の物価上昇は何が違う？
1: 自分のパンだけなら相対的に有利になる
2: 全体の物価上昇なら材料費は必ず下がる
3: どちらも必ず同じだけ利益が増える
4: 自分のパンだけ高くなっても有利にはならない
C: 1
E: 自分のパンだけなら、ほかの物と比べて有利です。全体の物価上昇なら、材料なども高くなり、同じように得とは限りません。
```

```quiz
Q: ルーカスのモデルで、生産が一時的に増える理由は？
1: 全員が全体の物価を完全に知っている
2: 全体の値上がりを、自分の商品が有利だと受け取る
3: お金が増えるとオーブンの性能が直接上がる
4: 生産の増加を政府が必ず命令する
C: 2
E: 全体の値上がりを、自分の商品が有利になったと受け取り、生産を増やすためです。
```


## 2. 予想できる変化と、できない変化

みんなが物価上昇を予想していれば、自分の売値が上がっても「全体が上がったのだろう」と判断できます。

ルーカスの単純なモデルでは、**予想された金融政策は、生産を持続的には増やせない**と考えます（政策無力性の命題）。予想外の変化なら、一時的に生産が動きます。

弱点は、全体の物価がわかれば受け取り違いが直ることです。何年も続く景気の波を、これだけで説明するのは難しくなります。

```quiz
Q: ルーカスのモデルで、予想された金融政策の効果は？
1: どんな政策でも生産を永久に増やす
2: 予想されるほど見分け違いが必ず増える
3: 実質の生産を持続的には増やせない
4: 予想外の政策も生産に全く影響しない
C: 3
E: 予想できれば、値上がりを自分の商品だけの有利さと受け取りにくくなります。このモデルでの条件つきの結果です。
```


## 3. もう1つの説明：同じ人手で、多く作れる

新しい製法で、同じ人手と設備からパンを多く作れるようになったとします。これは売値の受け取り違いではなく、**実際に作る力が変わった**例です。

```flow
生産性がよくなる → 人手や設備を使う価値が上がる → 雇用や投資が増える → 生産が増える
```

このような変化を中心に景気を説明するのが、**実物的景気循環理論（RBC）** です。キドランドやプレスコットらが発展させました。

- 「実物的」：お金の数字ではなく、生産性などに注目する。
- 「ショック」：モデルの外から起こる変化。悪い出来事だけを指す言葉ではない。
- 生産性の改善が将来も続くと予想されると、設備投資にもつながる。

工場の建設にも時間がかかるので、影響が長く続きえます。

```quiz
Q: RBCの「実物的」は、何に注目する意味？
1: 紙幣に印刷された数字の形
2: 中央銀行が保管する金貨の重さだけ
3: 生産性など、実際の作る力
4: 商品の見た目だけ
C: 3
E: お金の数字より、生産性など実際の作る力に注目する意味です。
```


## 4. データとは、何を比べる？

生産・雇用・物価などが、一緒にどう動くかを見ます。

| 言葉 | 日本語でいうと | 例 |
|---|---|---|
| 景気順応的 | GDPと同じ向きに動く | 好況で投資が増える |
| 景気逆行的 | GDPと逆の向きに動く | 好況である変数が下がる |
| 相対変動性 | GDPと比べた、揺れの大きさ | 投資は消費より大きく揺れやすい |

相対変動性は **その変数の標準偏差÷GDPの標準偏差**。標準偏差は、変動の大きさを測る数字です。同じ方法で処理したデータどうしを比べます。

元のノートで扱う韓国の1970〜2019年の整理では、消費・投資・雇用・実質賃金・M1はGDPと同じ向き、実質利子率・物価は逆向きでした。**どの国・時期にも必ず同じ関係がある、という意味ではありません。**

> 補足：このノートでは講義の元データを再集計していません。方向の比較は、ここで扱う期間とモデルの整理として読みます。

```quiz
Q: 景気順応的とは、どんな動き？
1: GDPと逆の向き
2: GDPと同じ向き
3: 全く変動しない
4: GDPより必ず先に動く
C: 2
E: 向きが同じことと、動く時期が先であることは違います。変動の大きさも別の物差しです。
```


## 5. 2つの説明を比べる

| 注目点 | ルーカスのモデル | ここで扱うRBC |
|---|---|---|
| 波の出発点 | 予想外のお金と、不完全な情報 | 生産性の変化 |
| 生産が増える理由 | 自分の商品が有利だと受け取る | 実際に作る力が高まる |
| 実質賃金・物価の方向 | この講のデータと合いにくい | 合う部分がある |
| 苦手な点 | 波が長く続く理由 | 生産性の変化の測定、不況の説明 |

どちらも、**つり合う場所そのものが動く**と考えます（均衡景気循環理論）。第14講では、値段がすぐ動かず、つり合いから外れる説明を学びます。

### お金が先に増えたら、お金が原因？

そうとは限りません。景気がよくなる見通しを受けて、会社が先に借り、銀行が貸し出しを増やすこともあります。

```flow
景気改善の予想 → 先に借入れと預金が増える → 後で生産が増える
```

「先に動いた」ことだけでは、原因までは決められません。これがRBC側のお金の動きの説明の1つです。

```quiz
Q: お金の量がGDPより先に増えたら、お金が景気の原因といえる？
1: 先に動けば必ず原因といえる
2: GDPより先なら必ず無関係といえる
3: 通貨量とGDPはどの期間でも同じ動きをする
4: それだけでは原因とはいえない
C: 4
E: それだけではいえません。景気改善の予想に反応して、借入れや預金が先に増えた可能性もあります。
```


## 6. 政策については、条件をつけて読む

- ルーカス：このモデルでは、**予想された金融政策**で実質の生産を増やし続けることはできない。
- 基本的なRBC：市場のゆがみがないなどの条件では、人々が変化に最適に対応しているため、波を消す政策が望ましいとは限らない。

**不況で誰も困らない、どんな政策も不要、という意味ではありません。** 失業や金融の問題などを加えると、結論も変わりえます。

```quiz
Q: 基本的なRBCで政策が不要とされるのは、無条件？
1: 市場にゆがみがないなどの条件つき
2: どんな現実でも無条件に不要
3: 不況で困る人がいないから不要
4: 政策を実行する方法が存在しないから不要
C: 1
E: 違います。市場のゆがみがないなどの条件での結論です。現実の問題を加えれば、政策の役割も変わりえます。
```


## 7. まず、この3つ

1. ルーカスは、情報が足りずに値段の変化を見分けられない場合を考える。
2. RBCは、実際の生産性の変化から景気を説明する。
3. 一緒に動く・先に動く、だけで原因を決めない。

# 開かれた社会と21世紀 12講【会話で読む】― まちづくりの計画と実行

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=open12)」。

## 1. まちの約束と計画（5分）

```talk
B: まちづくりの計画って？
A: 住民が自分で参加し、決め、動く計画。上から専門家が決めるのとはちがう（住民主導型）。まちの議題（マウル議題）は、長く続くまちのために何をするかを書いたもの。目標は「幸せに、元気に、ずっと暮らすこと」。
B: 企画と計画は？
A: 企画は「こうなりたい未来」を決めて道すじを選ぶ流れ。計画は、そこから生まれたくわしい実行の中身。
C: 住民が主役。
```

```card
要点
- 住民主導型：住民が参加し、決め、動く
- 目標：幸せに、元気に、ずっと暮らす
- 企画＝未来と道すじを決める／計画＝くわしい実行の中身
```

## 2. 5つの段階（10分）

```talk
B: 段階は？
A: 5つ。準備 → 調査・分析 → 目標の姿と作戦 → くわしい実行計画 → 実行とふり返り。
B: 準備は？
A: 「必要だ」と感じて仲間を広げる。調べて理解する、情報を分け合う、やる気を引き出す（動機づけ）の3つが大事。
B: 調査・分析は？
A: 資源調査（資源の図鑑）、まちの環境分析（まち歩き、地図づくり、SWOT分析）、住民の願いの調査（アンケート、インタビュー、マインドマップ）。いちばん大事なのは、たくさんの住民の参加。
C: 準備と調査で土台をつくる。
```

```card
要点
- 準備 → 調査・分析 → ビジョンと作戦 → 実行計画 → 実行とふり返り
- 準備：調べる・分け合う・動機づけ
- 調査：資源調査／環境分析（SWOT）／願いの調査（マインドマップ）
```

## 3. 目標・計画・実行（10分）

```talk
B: 目標の姿は？
A: 未来の姿（ビジョン）と方向を決め、まちのテーマから作戦（実践戦略）を立てる。作戦は道しるべ（ガイドライン）。だれか1人が勝手に、あせって決めない。
B: くわしい計画は？
A: だれが・いつ・どうやって・だれとやるか。優先順位をつけ、実行する組織とルール（まち規約、まちの会社なら定款）を作る。ストーリーテリングで、まちの物語を伝える。
B: 実行とふり返りは？
A: 住民・専門家・自治体が協力して進める。ふり返り（評価）では、目標の達成・住民の参加・お金の使い方・住民の満足を見る。思わぬ問題は早めに見つけて解決。
C: ゆっくり、みんなで（のろのろの哲学）。
```

```card
要点
- ビジョン → 実践戦略（ガイドライン）
- 実行計画：優先順位／まち規約・定款／ストーリーテリング
- 評価：達成・参加・お金・満足
- のろのろの哲学：ゆっくり、みんなで。段階は重なってもよい
```

## 4. 手順の例（5分）

```talk
B: 手順の例は？
A: 日本建築学会（2002年）の「まちづくりデザインの流れ」は5段階。まちを調べる → 分析して評価 → 未来の姿 → 空間のデザイン → ルール作り。釜山のマニュアルは7段階で、仲間づくり（パートナーシップ）から始まる。
B: どれが正しい？
A: まちに合う手順を選ぶ。段階は重なり、現場では2つを同時に進めることも多い。
C: 同じマニュアルを使うより、まちに合わせる。
```

```card
要点
- 日本建築学会（2002）：調べる → 分析 → 未来の姿 → 空間デザイン → ルール
- 釜山：7段階（仲間づくりから）
- まちに合う手順を選ぶ
```

# 上級マクロ経済論 9講【会話で読む】― 会社は、いつ機械を買う？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro9)」。

## 1. パン屋とオーブン（5分）

```talk
B: 会社は、機械を買うかどうか、どう決めるの？
A: 新しい機械で増える稼ぎが、使う費用より大きければ買う。パン屋のオーブンで考えよう。値段100万円、1年で稼ぎが20万円増える。
B: 費用は？
A: 1年使う費用は、利子5万円＋古くなる分（値下がり）10万円＝15万円。
B: 差し引きは？
A: 20万 − 15万 ＝ 5万円の得。だから買う。
C: 稼ぎの増加 ＞ 使う費用 なら買う。
```

```eq
使う費用15万円 = 利子5万円 + 値下がり10万円
```

```card
要点
- 買う条件：その機械で増える稼ぎ ＞ 使う費用
- 使う費用 ＝ 利子 ＋ 値下がり（減価償却）
- 自分のお金で買う場合も、運用すれば得られた利子（機会費用）を考える
```

## 2. 次の1台で考える（5分）

```talk
B: 得なら、何台でも買う？
A: 買わない。お客さんや働く人が同じなら、オーブンだけ増やしても使い切れない。見るのは「次の1台」で増える分。
B: 例は？
A: 1台目は稼ぎ20万、2台目は17万、3台目は12万。費用は15万だから、3台目は買わない。
B: 試験の言葉では？
A: 資本は機械や建物。資本の限界生産（MPK）は、資本をもう1つ足すと増える生産。使う費用は資本の使用者費用。単純なモデルでは MPK ＝ r ＋ d。
B: r と d は？
A: r は実質利子率（物価の変化を考えた利子）、d は減価償却率（古くなる割合）。パン屋の費用15万円は、100万円に対して 15％＝5％＋10％。
C: 次の1台の稼ぎ ＝ 費用 になる所まで増やす。
```

```card
要点
- 次の1台で増える稼ぎと、使う費用を比べる
- MPK（資本の限界生産）＝ r（実質利子率）＋ d（減価償却率）
- 3台目が12万 ＜ 費用15万 → 買わない
```

## 3. 何が変わると買う量が変わる？（5分）

```talk
B: 利子が上がったら？
A: 使う費用が増える。利子が5万から10万に上がると、費用は15万から20万。得だった計画が、得でなくなる。投資は減る。
B: 投資って？
A: 生産のために機械や建物を増やすこと。株を売り買いする話とは別。
B: ほかは？
A: 将来の生産性が上がると、同じ機械で多く作れるので、投資は増える。機械が早く古くなるのは、一方向には決まらない。
C: 利子↑ → 投資↓。将来の生産性↑ → 投資↑。
```

```card
要点
- 利子が上がる → 費用が増える → 投資は減る
- 将来の生産性が上がる → 投資は増える
- 機械が早く古くなる → 一方向には決まらない（費用は増えるが、買い替えも必要）
```

## 4. 将来の見通しと、資本の限界効率（5分）

```talk
B: 将来の稼ぎは、わからないよね。
A: そう。「来年も売れる」と思えば買いやすく、「売れないかも」と思えば買い控える。ケインズは、こうした見通しや気持ちを重く見た。
B: 試験に出る言葉は？
A: 資本の限界効率（MEC）は、設備の購入費と、将来得られると予想する収益から求める収益率。借りる利子率より高ければ、投資する理由になる。
B: 投資の限界効率（MEI）は？
A: 投資を増やしたときの設備価格の変化も考えた収益率。みんなが一度に買って値上がりすると、同じ稼ぎでも収益率は下がる。
C: MEC ＞ 利子率 なら投資。
```

```card
要点
- MEC（資本の限界効率）：購入費と予想収益から求める収益率。利子率より高ければ投資
- MEI（投資の限界効率）：設備価格の変化も考えた収益率
- 将来の設備 ＝ 今の設備の残り ＋ 今の投資
```

## 5. 銀行の上乗せと、トービンの q（10分）

```talk
B: 銀行が貸すとき、利子を上乗せするのは？
A: 返してもらえない危険があるから。銀行は、会社が返せるかを完全には見分けられない（情報の非対称性）。上乗せを債務不履行プレミアム（x）という。
B: 費用は？
A: 借りて買う費用 ＝ r ＋ d ＋ x。金融危機で x が大きくなると、投資は減る方向。
B: トービンの q は？
A: q ＝ 市場で評価された資本の価値 ÷ 同じ資本をそろえ直す費用。100万円でそろえた設備が市場で150万円と評価されれば q＝1.5。
B: 読み方は？
A: q＞1なら、設備を増やす方向。q＜1なら、増やすのを控える方向。投資に直接関係するのは、次の1単位を比べる限界 q。
C: 限界 q＝1 が MPK＝r＋d に対応する。
```

```eq
借りて買う費用 = r + d + x
```

```card
要点
- x（債務不履行プレミアム）が大きくなる → 借りて投資する費用が増える
- トービンの q ＝ 市場で評価された資本の価値 ÷ そろえ直す費用
- q＞1：増やす方向／q＜1：控える方向（限界 q＝1 が MPK＝r＋d に対応）
```

## 6. 会社の話から国全体の話へ（5分）

```talk
B: 会社の投資は、国全体では何？
A: 買いたい量（総需要 Yd）の一部。Yd ＝ 家計の消費 C ＋ 会社の投資 I ＋ 政府の購入 G。輸出入のない経済で考える。
B: 利子が上がると？
A: 投資が減り、国全体の需要が減る。縦に実質利子率、横に生産・所得を取ると、需要の線は右下がり（実質総需要曲線）。
B: 線が動くのは？
A: 政府の購入が増えたり、将来の技術に期待して投資が増えたりすると、同じ利子率でも需要が増えるので、右へ動く。
C: 需要の線は右下がり。
```

```card
要点
- 総需要 Yd ＝ C（消費）＋ I（投資）＋ G（政府の購入）
- 実質総需要曲線は右下がり（利子↑ → 投資↓ → 需要↓）
- 政府の購入↑・将来の技術への期待↑ → 線が右へ
```

# 伝統社会と生活文化 10講【会話で読む】― 役人と両班の暮らし

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition10)」。

## 1. 両班ってだれ？ 役人になる3つの道（10分）

```talk
B: 両班って、だれのこと？
A: もとは役人の2つのグループ、文の役人（文班）と武の役人（武班）のこと。役人の子や孫が代々役人になるうちに、その一族ぜんぶが特別あつかいされて、「両班」と呼ばれるようになった。
B: 法律の上の身分は？
A: ふつうの民（良人）と、低い身分（賤人、代表は奴婢）の2つ。
B: 役人になる道は？
A: 3つ。文の試験（文科）はいちばん確かだけど、合格は1年に約30人。武の試験（武科）は軍の役人で、有名な人は李舜臣。家柄・推薦（蔭官）は、高い役人の子や孫が簡単な試験で入れる道。
C: 文科・武科・蔭官。
```

```card
要点
- 両班：もとは文班・武班（役人の2グループ）。のちに一族ぜんぶを指す
- 法律の上では、良人と賤人（奴婢など）の2つ
- 役人になる道：文科／武科（李舜臣）／蔭官（家柄・推薦）
```

## 2. 役人になってからの苦労（5分）

```talk
B: 役人になれば、楽？
A: 意外と大変。ひとり暮らしの赴任（他郷暮らし）は、交通も連絡も不便で、遠い国境では風土病にかかることもある。
B: お金は？
A: 官服（帽子・上着・帯・革の靴）がとても高くて、月給の半分以上かかった。新人いじめ（免新礼）は、何か月も続いて、宴会代で破産する人もいた。
C: 赴任・官服・免新礼の3つが苦労。
```

```card
要点
- 他郷暮らし：ひとり暮らしの赴任（遠い国境は風土病も）
- 官服が高い：月給の半分以上
- 免新礼：新人歓迎の儀式（いじめ）。宴会代で破産する人も
```

## 3. 都の役所街と働き方（10分）

```talk
B: 役所は、どこにあった？
A: 宮殿（景福宮）の門の前の大通りに、6つの省（六曹）などが並ぶ役所通り（六曹通り）。王のすぐそばで働く役所は、宮殿に合わせて引っこす。
B: 1つの役所の人は？
A: 高い役人（堂上官）、その下の役人（堂下官）、事務係（胥吏）、使い走り。
B: 勤務時間は？
A: 決まりは朝6時〜夕方6時（冬は8時〜4時）。でも実際は交代制でかなり自由。決まった休日はなく、5日出て2日休み、などの交代制。当番は泊まる（宿直）。
C: いまのフレックス制（時差出勤）に近い。
```

```card
要点
- 六曹通り：宮殿の門の前の大通りに6つの省が並ぶ
- 役所の人：堂上官／堂下官／胥吏（事務係）／使い走り
- 決まりは朝6時〜夕方6時（冬は8時〜4時）。実際は交代制で自由
```

## 4. 休み・給料・定年（5分）

```talk
B: 休みはあった？
A: 理由ごとに日数が決まっていた。親に会いに行く・お墓参りは7日、妻のお葬式は15日、親の病気は遠い地方70日・中くらい50日・都の近く30日。
B: 昇進は？
A: 出勤日数が必要（6品以上は900日、7品以下は450日）。休みは数えないので、みんな日数を数えた。
B: 給料は？
A: 俸禄は、家族が暮らせる額ではなかった。仕事のお礼より、国の役目を果たすための活動費に近い考え方。地方の長（守令）は、税を国に納めた残りを使えたので、比べると豊か。
B: 定年は？
A: 決まった定年はない。地方の長は65歳まで任命で、任期があるので実際は約70歳まで。
C: 給料だけでは暮らせず、家の収入で支えた。
```

```card
要点
- 休暇は理由ごとに日数が決まる（お墓参り7日、妻のお葬式15日、親の病気30〜70日）
- 昇進には出勤日数が必要（6品以上900日、7品以下450日）。休みは数えない
- 俸禄は、家族が暮らせる額ではない。活動費に近い
- 決まった定年はない
```

## 5. 役人になれなかった両班（10分）

```talk
B: 両班は、みんな役人になれた？
A: 大半はなれなかった。とくに地方は、推薦してくれる人が少なかった。
B: どう暮らした？
A: 農業の経営者（自分では田んぼに入らず、農作業を動かす）、子どもの先生、祭りと客のもてなし（奉祭祀・接賓客）、受験生（何十年も受け続ける。家柄を守るため）、村の役目、儒教の正しさを守る（兵役を免除され、王に意見書＝上疏を出す）。
B: 両班の名簿は？
A: 16世紀後半、地元の両班名簿（郷案）を作って村の運営に加わった。書院と名簿は、推薦と全員の投票で入れた。入れない両班も多く、名簿をめぐる争いも起きた。
B: 両班とふつうの人のちがいは？
A: 考え方の上では、儒教を学び、実行する人が両班。でも、それは両班でなくてもできる。
C: 役人になれなかった両班が大多数。
```

```card
要点
- 両班の大半は役人になれなかった（特に地方）
- 暮らし：農業の経営／子どもの先生／祭りと客のもてなし／受験生／村の役目／上疏
- 郷案：地元の両班名簿。推薦と全員の投票で入る
```

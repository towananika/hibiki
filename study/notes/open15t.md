# 開かれた社会と21世紀 15講【会話で読む】― まちの記録庫（アーカイブ）をつくる

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=open15)」。

## 1. まちのアーカイブとは（10分）

```talk
B: まちのアーカイブって？
A: まちの歴史といまのようすを残した記録と、それを集めた場所の両方。役所中心の記録は偏っているという批判から、隠れた人たちに光を当てようと広がった。住民自身が記録を残す人（アーキビスト）でもあり、使う人でもある。
B: 記録の種類は？
A: 紙（文書、写真、会議の記録）、電子（写真・動画・音声）、古い木やアート作品まで、意味があれば何でも。場所の記録（空間記録物）と、場所でない記録（非空間記録物。生活史やインタビュー）がある。
B: 特徴は？
A: 作り手がいろいろで種類は広がる。決まった形（標準化）で管理する必要がなく、やり方が自由。
C: 住民みんなが作り手。
```

```card
要点
- まちのアーカイブ＝まちの記録＋集めた場所
- 住民が記録を残す人（アーキビスト）で使う人
- 空間記録物（地図・写真）／非空間記録物（生活史・インタビュー）
- 標準化の必要がなく、自由
```

## 2. 役所の記録管理とのちがい、実例（10分）

```talk
B: 役所の記録管理とのちがいは？
A: 役所は法律で決められ、役目は説明責任を果たすこと。記録は移管が中心。まちのアーカイブは共同体の共通の思いにもとづく自主的なもの。役目は話し合いの道具・文化を楽しむ・共同体をとりもどすこと。集めることと、わざわざ作ることが大事で、サービスは展示・イベントが中心。
B: 実例は？
A: 洪城のパルマル図書館、まちの新聞（マウル新聞）、聞き取り（口述インタビュー）、416記憶貯蔵所はSNSでも保存している。
C: 自主・話し合い・共同体。
```

```card
要点
- 役所：法律・説明責任・移管／まち：自主・話し合いと共同体・集めて作る
- 実例：パルマル図書館／マウル新聞／口述インタビュー／416記憶貯蔵所
```

## 3. 進め方（10分）

```talk
B: 進め方は？
A: ①まちの成り立ちを知る（自然、人の空間、歴史、共同体の会、行事、暮らし、各家、つながり）。②全体の計画：目標と範囲、参加できる人、お金、技術、最後の形。③集める：団体から、個人から、イベント（コンテスト）で。④使う：展示、本や案内（出版物）、学びのプログラム。
B: 続けるには？
A: 計画 → 集める → 整理 → 形にする → 使って足し続ける。お金と技術の支援、もとの資料を公開するか、著作権も考える。自治体と協力し、いろいろなつながりと結びつく。
C: 何のために、どこまで残すかを先に決める。
```

```card
要点
- 成り立ちを知る → 全体の計画（目標と範囲）→ 集める（団体・個人・イベント）→ 使う（展示・本・学び）
- 続けるために：お金・公開・著作権・自治体との協力
```

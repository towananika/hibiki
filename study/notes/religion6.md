# 世界の宗教 6講 ― イスラム教：唯一の神にゆだね、毎日の行いで表す

**この講で覚えること：イスラム教は、預言者ムハンマドが受けた神のことば（クルアーン）から始まった一神教。「イスラーム」は「神にゆだねること」。信じること（唯一の神・天使・預言者・啓典・最後の審判）と、行うこと（五行）が、毎日の生活を形づくる。**

韓国の放送大学「世界の宗教」第6講の講義資料をもとに、日本語でまとめたノートです。資料のクルアーンの引用は、そのまま訳さず、要点を自分の言葉にしました。

## 0. この講の地図（3分）

```flow
① 身近なムスリム → ② 名前の意味 → ③ ムハンマドとクルアーン → ④ 何を信じる？ → ⑤ 何を行う？ → ⑥ 命と自由
```

読み方：各節は「会話 → 図 → 要点カード → 4択」。最後に「書く準備」「言いかえ練習」「確認テスト」があります。

## 1. まず言葉をそろえる（3分）

```card
6講の4つの言葉
- イスラーム：「神にゆだねる・従う」という意味。信じる人はムスリム（ゆだねる人）
- アッラー：アラビア語で「神」。ただひとりの神のこと
- クルアーン：ムハンマドに下された神のことば（啓示）をまとめた聖典
- シャリーア：クルアーンとハディース（ムハンマドの言行）をもとにした生き方のきまり
```

## 2. 身近なムスリムと、名前の意味（4分）

```talk

A: 講義は、ボクサーのムハマド・アリやマイク・タイソン、バスケットボールのカリーム・アブドゥル＝ジャバー、歌手、人権運動家マルコムX、サッカー選手の写真から始まった。みんなムスリムなんだ。
B: 意外と身近なんだね。
A: 世界でキリスト教の次に信じる人が多い宗教だよ。まず、名前から整理しよう。
C: イスラームは「教え」、ムスリムは「人」。
```

```card
名前の整理
- イスラーム：神にゆだねること（宗教の名前）
- ムスリム：ゆだねる人（信じる人の呼び名）
- 「回教」：中国を通じた古い呼び名。いまは「イスラム教」「イスラーム」を使う
```

> 補足：韓国でも、昔は漢字で「回教」と呼ばれていました。

## 3. ムハンマドとクルアーン（6分）

```talk
B: ムハンマドは神さまなの？
A: ちがう。ムハンマドは人間で「預言者」。神のことばを預かって人に伝える役。アブラハム、モーセ、イエスも預言者で、ムハンマドが最後の預言者とされる。
B: クルアーンは、ムハンマドが書いた本？
A: イスラム教では「ムハンマドの考え」ではなく「神のことばそのもの」とされる。だから、だれも変えられない、とクルアーン自身が言っている。
C: ムハンマドは人間の預言者。クルアーンは神のことば。
```

```flow
神 → 天使ジブリール → 預言者ムハンマド → クルアーン（神のことば） ＋ ハディース（ムハンマドの言行） → シャリーア（生き方のきまり）
```

```card
ことばと、きまり
- 610年ごろ、メッカ近くの洞窟でムハンマドが最初の啓示を受けた
- クルアーン：神のことば。だれも書きかえられない
- ハディース：ムハンマドが言ったこと・したことの記録
- シャリーア：この2つをもとに、祈り・食事・家族・商売まで導くきまり
```

```quiz
Q: ハディースとは？
1: 神のことばそのもの
2: ムハンマドの言ったこと・したことの記録
3: 1年に1か月の断食
4: 天使の名前
C: 2
E: ムハンマドの言行の記録で、クルアーンとともにシャリーアのもとになります。ほかの選択肢：神のことばはクルアーンです。
```

## 4. 何を信じる？（6分）

```talk
B: いちばん大事な考えは？
A: 「神はただひとり」。神には子も仲間もいない。だから神の姿を絵や像にしない。
B: キリスト教も一神教だよね。何がちがうの？
A: キリスト教はイエスを「神の子」で救い主と考える。イスラム教では、イエスは大切な預言者だけど人間。神に並ぶものは何もない、とはっきり言うんだ。
C: 神はただひとり。何も神に並べない。
```

```card
講義で出てきた「信じること」5つ
- 唯一の神アッラー：ただひとり、何にも並ばない
- 天使：神のことばを運ぶ存在
- 預言者：アブラハム・モーセ・イエス…最後がムハンマド
- 啓典：神のことばの書物。最後で完全なのがクルアーン
- 最後の審判：この世の終わりに、生き方が神に裁かれる
```

> 補足：一般には、ここに「定命（すべては神の意志のもとにある）」を足して「六信」と呼びます。講義のスライドには5つが出ていました。

```quiz
Q: イスラム教とキリスト教のちがいとして正しいのは？
1: イスラム教は多神教である
2: イスラム教は、イエスを神ではなく人間の預言者と考える
3: イスラム教は、預言者をまったく認めない
4: イスラム教には聖典がない
C: 2
E: どちらも一神教ですが、イスラム教はイエスを預言者のひとりとし、神の子とはしません。ほかの選択肢：イスラム教は一神教で、預言者も聖典もあります。
```

## 5. 何を行う？ ― 五行とジハード（7分）

```talk
B: 信じるだけじゃなくて、することも決まってるの？
A: 「五行」という5つの務めがある。心だけでなく、ことば・体・時間・お金を使って信仰を表す。
B: 「ジハード」って、戦争のことでしょ？
A: それがよくある誤解。講義でも「努力・奮闘」と説明していた。もとは、神の道にそって生きようと、自分の弱さとたたかう努力を指すんだ。
C: 五行で毎日を形づくり、ジハードは努力。
```

```card
五行（行う5つのこと）
- シャハーダ（信仰告白）：「神のほかに神はなし。ムハンマドは神の使徒」と唱える
- サラート（礼拝）：1日5回、メッカの方向に向かって祈る
- サウム（断食）：ラマダーン月は、日の出から日没まで飲食しない
- ザカート（喜捨）：財産の一部を、貧しい人のために出す
- ハッジ（巡礼）：一生に一度、できる人はメッカへ
```

```quiz
Q: 講義で「ジハード」はどう説明された？
1: 戦争だけを指す言葉
2: 努力・奮闘
3: 1日5回の礼拝
4: 豚肉を食べないきまり
C: 2
E: もとの意味は「努力・奮闘」で、神の道にそって生きようとする努力です。ほかの選択肢：「戦争だけ」はよくある誤解です。
```

```quiz
Q: ラマダーン月の断食について、正しいのは？
1: 1か月、昼も夜もずっと食べない
2: 日の出から日没まで飲食しない
3: 肉だけを食べない
4: 一生に一度だけ行う
C: 2
E: 日中だけ飲食をひかえ、日没後には食事をします。毎年行います。ほかの選択肢：一生に一度は巡礼です。
```

## 6. 命の重さと、信仰の自由（3分）

講義の最後には、クルアーンの2つのことばが紹介されました。要点だけ言いかえると、こうです。

```card
最後の2つのことば（要点）
- 罪のない人をひとり殺すのは、人類全体を殺すのと同じ。ひとりを救うのは、人類全体を救うのと同じ
- 神がのぞめば、すべての人が信じたはず。だから、人に信仰を無理におしつけてはいけない
```

```talk
B: 暴力的な宗教っていうイメージとは、ずいぶんちがう。
A: ニュースのイメージだけで決めず、教えそのものを見ることが大事、というのが講義のメッセージだったと思う。
C: 一つの命の重さと、信仰の自由。
```

```quiz
Q: 講義の最後のクルアーンのことばに近いのは？
1: 信仰は力でおしつけるべきだ
2: ひとりの命を救うことは、人類全体を救うことと同じだ
3: 命より、きまりのほうが大切だ
4: ムスリム以外とは話してはいけない
C: 2
E: ひとりの命の重さを、人類全体と同じだと言っています。もう一つのことばでは、信仰の強制を否定しています。
```

## 8. 言いかえ練習：写さずに、自分の文にする（5分）

```quiz
Q: 教科書ふうの文「イスラム教においては信仰と実践が不可分であり、宗教が生活全般を規定する」。いちばん良い言いかえは？
1: イスラム教においては、信仰と実践が不可分で、宗教が生活全般を規定する。
2: イスラム教では、心で信じることと体で行うことが切りはなせず、1日5回の礼拝のように、1日の時間の使い方まで信仰にそって決まっていく。
3: 信仰と実践が一つであること。
4: イスラム教では、信じていれば何を行ってもよいと考える。
C: 2
E: 2は意味を保ち、礼拝の例を入れた自分の文です。ほかの選択肢：1はほぼ写し、3は「〜こと。」の箇条書きふう、4は意味が逆です。
```

```card
言いかえのコツ（3つ）
- 難しい漢語（不可分・規定する）を、ふだんのことばにほどく
- 例を1つ入れる（礼拝で1日が区切られる、ジハードの誤解など）
- 文の終わりまで書き切る（「〜こと。」「〜する。」と並べない）
```

## 9. まず、この3つを覚える

1. **イスラーム＝神にゆだねる**：ムハンマドは人間の預言者、クルアーンは神のことば。
2. **信じる5つ＋行う5つ（五行）**：信仰は毎日の行いで表す。
3. **ジハード＝努力**、ひとりの命は人類全体と同じ重さ、信仰は強制しない。

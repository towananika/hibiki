# 伝統社会と生活文化 8講【会話で読む】― 困ったら役所に訴える

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition8)」。

## 1. 民の訴え状（5分）

```talk
B: 昔の人は、困りごとをどうした？
A: 村で解決できないことは、紙に書いて役所に訴えた。民が役所に出す訴えの書類が訴え状（民状）。書類の形は所志とよばれた。何人もが名前を並べて出すのが等状。
B: 国はなぜ訴えを大事にした？
A: 儒教の考え。民の心は天の心（民心は天心）で、民の心を失うと王は王でいられない。民は国のもと（民本思想）。
B: 例は？
A: 1872年、荷を背負って売り歩く商人が、役所から「穀物を借りなさい」と割り当てられた（還穀）。春に穀物を貸し、秋に利子をつけて返させる制度。利子を払えない彼は「わたしを外してください」と訴え状を出した。
C: もとは貧しい人を助ける制度が、朝鮮後期には役所のかせぎの道具になった。
```

```card
要点
- 民状（訴え状）：民が役所に出す訴えの書類。形は所志。何人もで出すのが等状
- 理由：民心は天心、民本思想（儒教）
- 還穀：春に穀物を貸し、秋に利子をつけて返させる。のちに負担になった
```

## 2. 訴えがふえた朝鮮後期（5分）

```talk
B: 訴えは、いつふえた？
A: 朝鮮後期。物を売り買いし、お金を使う暮らしが広がって（商品・貨幣経済の発展）、もめごともふえた。19世紀の全羅道のある郡では、1日に数十通の訴え状が届いた。「訴え状の洪水」。
B: 書き方の手本は？
A: 『儒胥必知』という19世紀の本。学ぶ人（儒生）と役所の下役（胥吏）が必ず知るべき本。7種類の書類の手本が載っている。
B: 訴え状の書き方は？
A: はじめに住所・身分・名前。書き出しは「つつしんで申し上げます」。本文に困りごと。むすびは「どうかお取り計らいください」。最後にあて先と日付。
B: 返事は？
A: 役所は訴え状の左下に答え（処分）を書いて、本人に返した。この答えが題辞。役所は、訴えと答えを短くまとめた帳面（民状置簿冊）を残した。
C: 本文と題辞がいちばん大事。
```

```card
要点
- 朝鮮後期：商品・貨幣経済が発展 → 訴え状の洪水
- 儒胥必知：書き方の手本の本（19世紀）
- 題辞：役所が訴え状の左下に書く答え
- 民状置簿冊：訴えと答えを短くまとめた役所の控え帳
```

## 3. だれが訴え、だれが裁いた？（10分）

```talk
B: だれが訴えられた？
A: だれでも。身分に関係なかった。女の人、奴婢（召し使いの身分）、牢屋にいる人まで。「昔の人は裁判をいやがった」というのは思いこみ。
B: だれが裁いた？
A: 今のような裁判所はなくて、役所の仕事と裁判が分かれていなかった。ソウルには三法司（刑曹・司憲府・漢城府）などの役所。地方は、郡の長（守令）と道の長（観察使）が、両方の役をかねた。
B: 郡の長の力は？
A: とても強くて、裁きは思いのままになりやすかった。大事な仕事は、裁判と税集め。
B: 裁判の進み方は？
A: 本人が訴え状を出す（代わりはだめ）。訴えた人が相手を自分で連れてくる（当事者主義）。でも力がないと連れて来られない。門番や下役は、訴え状を勝手に追い返してはいけない決まり。
C: 役所の仕事と裁判は分かれていない。
```

```card
要点
- 訴えられるのは、だれでも（女の人・奴婢・牢屋の人まで）
- 役所の仕事と裁判は分かれていない。地方は郡の長（守令）と道の長（観察使）
- 訴えた人が相手を連れてくる（当事者主義）
- 門番や下役は、訴え状を追い返してはいけない
```

## 4. 上へ、上へと訴える道（10分）

```talk
B: 郡の長に不満なときは？
A: 上に訴える道が、法律の本（経国大典）に書いてあった。郡の長 → 道の長（観察使）→ 役人を見張る役所（司憲府）→ 王。
B: 王に直接は？
A: 申聞鼓は、宮殿の門の大きな太鼓をたたいて王に聞いてもらう方法。でも使うのは、ソウルの両班が中心だった。15世紀後半から、代わりに2つ。上言と撃錚。いちばん多かったのは18世紀の正祖王のころ。
B: 2つのちがいは？
A: 上言は、書いた訴えを、王の行列の道で係の役人に出す。学のある上の人たちが好んだ。撃錚は、行列の前に出たり宮殿に入ったりして、鳴らして訴える。字が読めない下の身分の人が好んだ。まず「さわいだ罪」で罰を受けてから、口で訴える。
C: 上言は書いて、撃錚は鳴らして。
```

```card
要点
- 郡の長（守令）→ 道の長（観察使）→ 司憲府 → 王
- 申聞鼓：宮殿の門の太鼓（使うのはソウルの両班が中心）
- 上言：書いて訴える／上の人たちが好んだ
- 撃錚：鳴らして訴える／下の身分の人が好んだ／先に「さわいだ罪」の罰を受ける
```

## 5. 何を訴えた？（10分）

```talk
B: いちばん多いのは？
A: 税。朝鮮後期の3つの大きな税が三政。土地の税（田政）、兵役のかわりに出す布（軍政・軍布）、春に借りて秋に返す穀物（還穀）。貧しい農民は土地がないので、軍布と還穀の訴えが中心。
B: 解決は？
A: むずかしかった。郡ごとに税の合計が決まっていたから、1人を外すと、ほかの人の負担がふえる。
B: ほかには？
A: 土地と奴婢の権利のあらそい。お墓の土地あらそい（山訟）。丁若鏞（茶山）は「なぐり合いや殺人の半分近くは山訟が原因」と書いた。借金、小作の権利と田んぼの水、村の秩序（親孝行をほめてほしい、乱暴者をつかまえてほしい、日照りの税を軽く）。
C: 税が中心。三政＝田政・軍政・還穀。
```

```card
要点
- 三政：田政（土地の税）／軍政（兵役のかわりの布＝軍布）／還穀
- 貧しい農民の訴えは、軍布と還穀が中心
- 税の合計が郡ごとに決まっていた → 1人を外すと、ほかの人の負担がふえる
- 山訟：お墓の土地あらそい（茶山：殺人の半分近くが原因）
```

## 6. 訴えから反乱へ（5分）

```talk
B: 訴えが通らないと、どうなる？
A: 村みんなで出す訴え（等訴）は、法にかなったお願いで、反乱とは別のもの。でも19世紀、国の仕組みがゆらぎ、ひどい取り立て（苛斂誅求）がふえると、訴えでは解決できなくなった。
B: 最後の手段は？
A: 農民の反乱（農民抗争）。1862年の壬戌農民抗争、1894年の甲午農民戦争。
C: 訴え → 聞いてもらえない → 反乱。
```

```card
要点
- 等訴：村みんなで出す、法にかなったお願い
- 訴えで解決できないと、農民抗争へ
- 1862年 壬戌農民抗争 → 1894年 甲午農民戦争
```

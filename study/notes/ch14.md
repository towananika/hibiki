# デジタル経済 14講 ― 仕事の未来：AIができる作業と、人の仕事

**この講で覚えること：AIが代わるのは「職業まるごと」より「仕事の中の作業」。仕事は減る力と増える力の両方で動く。数だけでなく、仕事の質と、移るときの支えも見る。**

## 0. この講の地図（3分）

ニュースでは「AIで〇〇の仕事がなくなる」とよく聞きます。
**では、本当に職業が丸ごと消えるのか？ 消えないなら、何が変わるのか？** これが14講の問いです。

```flow
① 言葉をそろえる → ② 技術で全員が豊かになる？ → ③ 仕事を作業に分ける → ④ 減る力と増える力 → ⑤ 働き方の自由と不安 → ⑥ 自分の仕事でためす
```

読み方：各節は「会話で問いを聞く → 図を1つ見る → 要点カード → 4択」の順。きょうは1節だけでもOKです。

## 1. まず言葉をそろえる（3分）

この講で何度も出てくる言葉は4つだけです。

```card
14講の4つの言葉
- 作業単位で見る：職業を、中の作業（資料集め・字幕づくり・確認…）に分けて見ること
- 代替効果：機械が人の作業を代わり、人手が減る力
- 補完効果：機械を使いこなす人の役割が増える力
- 仕事の質：数だけでなく、収入の安定・時間の決めやすさ・保障があるか
```

## 2. 技術が進めば、すぐ全員が豊かになる？（5分）

```talk
B: 技術が進めば、すぐ全員が豊かになるんじゃないの？
A: 産業革命を思い出して。新しい仕事は生まれた。でも、技能の価値が下がった人や、長い時間・危険な場所で働いた人もいた。
B: でも、最後はみんな良くなったんでしょ？
A: 広がるまでに時間がかかった。その間に困った人の苦しさは消えない。「昔だいじょうぶだった」は「これからもだいじょうぶ」の証明にならないよ。
C: 得をする人と、負担をする人が分かれる。
```

```flow
技術が変わる → 生産や仕事が変わる → 得をする人と負担する人が分かれる
```

だからこの講では、技術の目標を **生産量だけでなく、余暇や生活の質から** 考えます。

```quiz
Q: 過去に新しい仕事が生まれたことから、いえるのは？
1: どの時代も誰も失業しなかった
2: 全員の賃金が導入直後に同じだけ上がる
3: 生活の質と技術は無関係
4: 今後の移行で困る人がいないとは決められない
C: 4
E: 技術の得は、時期や職業によって違った。経済全体の変化と、1人ひとりが移るときの負担を分けて見る。
ほかの選択肢：1は産業革命でも技能の価値が下がった人がいた。2は広がるまで時間がかかった。3はこの講の入口と逆で、目標を生活の質から考える。
```

## 3. 仕事を「作業」に分けて見る（5分）

```talk
B: AIが字幕を作れるなら、動画の仕事はなくなる？
A: 動画の仕事を分けてみて。資料を集める、構成を考える、字幕を作る、相手に確認する。AIが代わるのは、その中の1つかもしれない。
B: じゃあ「この職業は消える」って予測は？
A: 職業で見るか、作業で見るかで、予測が大きく変わるんだ。それに「自動化できる」と「本当に使われる」も別。
C: 職業より、作業で見る。
```

```flow
仕事を作業に分ける → 代われる作業を見つける → 残る作業・新しい役割を考える
```

```card
2つの見方
- 職業で見る：「この職業は自動化されそう？」
- 作業で見る：「中のどの作業を代わり、どこを助ける？」
- 注意：自動化できる ≠ 実際に使われる
```

```quiz
Q: 字幕作成が自動化されたら、動画制作の仕事は全部消える？
1: ほかの作業や、新しい役割もあるので一概にはいえない
2: 必ず全部消える
3: 動画を見る人も必ずゼロになる
4: 自動化された作業も人が必ず同じ時間繰り返す
C: 1
E: 職業はたくさんの作業でできている。代わられる作業と、助けられる作業を分けて見る。
ほかの選択肢：2は職業まるごとで見たまちがい。3は作る側と見る側の話をまぜている。4は自動化した意味がなくなる。
```

## 4. 仕事が減る力と、増える力（10分）

```talk
B: 機械が作業を代わったら、人手は減るだけだよね？
A: 減る力だけじゃない。機械を使いこなす人の役割が増える。安く作れれば、買う人が増えて生産も増える。新しい商品や産業も育つ。
B: じゃあ、結局増えるの？減るの？
A: 両方の力の綱引き。値段が下がらなかったり、買う人が増えなかったりすれば、人手は増えない。
B: 海外に出た工場が国内に戻れば、昔の人数が働ける？
A: 戻った工場が自動化されていたら、同じ人数はいらないかも。「どこで作るか」と「どの作業を人がするか」は別の問いだよ。
C: 雇用は、減る力と増える力の綱引き。
```

```bars
代替効果（機械が代わる） | 40 | 減る力 | r
補完効果（使いこなす人） | 20 | 増える力 | s
生産効果（安く→たくさん売れる） | 15 | 増える力 | s
波及効果（新しい産業） | 10 | 増える力 | s
```

> 補足：棒の長さはイメージで、実際の数字ではありません。どちらが大きいかは、値段・買う人・競争などの条件で変わります。

```card
減る力と増える力
- 減る：代替効果（機械が人の作業を代わる）
- 増える：補完効果・生産効果・波及効果
- 工場が戻っても、自動化されていれば人数は戻るとは限らない
```

```quiz
Q: 技術で生産費用が下がったら、雇用は必ず増える？
1: 必ず増える
2: 価格・需要・競争などによって結果が変わる
3: 必ず全員が失業する
4: どの効果も雇用と無関係
C: 2
E: 減る力（代替）と増える力（補完・生産・波及）の綱引き。どちらが大きいかは条件しだい。
ほかの選択肢：1は値段が下がらない・買う人が増えないと人手は増えない。3は増える力を忘れている。4は4つとも雇用を動かす力。
```

```quiz
Q: 自動化された工場が国内へ戻った場合、雇用は？
1: 必ず元の人数に戻る
2: すべての仕事が手作業になる
3: 昔と同じ人数になるとは限らない
4: 輸送時間や人材は立地に無関係になる
C: 3
E: 「どこで作るか」と「どの作業を人がするか」は別の問い。立地が戻っても、作業の自動化で人数は変わる。
ほかの選択肢：1は自動化を忘れている。2は逆。4は輸送や人材も、戻る理由の1つ。
```

## 5. 柔軟に働けることと、安心して働けること（5分）

```talk
B: 在宅やアプリで受ける仕事って、自由でいいことだらけ？
A: 時間や場所を選べる。少しの時間から始められる。いくつかの仕事を組み合わせられる。
B: じゃあ問題は？
A: いつも連絡に答えなきゃいけない気がする。収入や時間が読めない。けがや病気のとき、保険・年金・休みの保障が弱いこともある。
C: 自由と不安定さは、セット。
```

```card
同じ働き方の、2つの面
- 自由：時間・場所を選ぶ／少しから始める／組み合わせる
- 不安：いつも連絡／収入と時間が読めない／保障が弱い
- だから、仕事の「数」だけでなく「質」も見る
```

> 補足：アプリなどを通して1回ずつ仕事を受ける働き方を「プラットフォーム労働」といいます。

```quiz
Q: 柔軟な働き方を評価するときに必要なのは？
1: 自由なら負担は一切ないと考える
2: 短時間なら必ず高収入になると考える
3: 在宅なら仕事と生活の境目は常に明確と考える
4: 自由度と、収入・予定・保障の安定を両方見る
C: 4
E: 同じ働き方に、選べる自由と、読めない不安の両方がある。仕事の質と社会の保障も見る。
ほかの選択肢：1はいつも連絡などの負担を忘れている。2は短時間と収入は別。3は在宅だと境目がむしろあいまいになりやすい。
```

## 6. 自分の仕事では、どこを助けてもらう？（5分）

```talk
B: じゃあ、自分はどうすればいい？
A: 自分の作業を1つ選んで、道具でためしてみる。かかった時間と、できの良さをくらべる。それから、人がやる部分を決める。
B: 道具にくわしければ、だいじょうぶ？
A: それだけじゃ足りない。問題を見つける、結果を確かめる、相手に伝える。こういう力も要る。
B: 学び直しは、自分だけでがんばるもの？
A: 個人だけに任せず、教育・働くルール・移るときの支えを社会が整えることも大事な問いだよ。
C: 何を任せて、空いた時間をどう使うか。
```

```flow
作業を1つ選ぶ → 道具でためす → 時間とできをくらべる → 人がやる部分を決める
```

> 補足：これは仕事を見直すための練習の例です。どの職業が将来も必ず安全かを保証するものではありません。

```quiz
Q: AIを仕事に取り入れるときの確かめ方は？
1: 具体的な作業で時間と品質を比べ、人の役割も決める
2: 使うだけで必ず改善したと決める
3: 結果を一切見直さない
4: 人に関わる判断もすべて無条件で任せる
C: 1
E: 役に立つかは、実際の作業でくらべて確かめる。道具と、人の判断を組み合わせる。
ほかの選択肢：2と3は確かめていない。4は人に関わる判断こそ、人が見る部分。
```

## まず、この3つ

1. AIが代わるのは **職業まるごと** より **仕事の中の作業**。作業に分けて見る。
2. 雇用は **減る力（代替）と増える力（補完・生産・波及）** の綱引き。結果は条件しだい。
3. 仕事の **数だけでなく質** と、移るときの **社会の支え** も見る。

## ひびきの暮らしでいうと

- 自分の作業を1つ選んで、AIでためして、時間とできをくらべてみる。残ったところが「自分がやる部分」。
- 読み終わったら、「14講をひとことで言うと？」を自分の言葉で言ってみる。言えたら、それをノートに足します。

合格: 70

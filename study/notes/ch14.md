# デジタル経済 14講 ― 仕事の未来：AIができる作業と、人の仕事

**仕事の一部が自動化されることと、職業が丸ごとなくなることは違います。** 働く人にとっての時間・収入・生活の質から考えます。

添付の講義ノートをもとにした教材です。日常の例や図は、理解を助ける補足です。

## 1. 技術が進めば、すぐ全員が豊かになる？

産業革命では、生産方法が変わり、新しい仕事も生まれました。でも、従来の技能の価値が下がった人や、長時間・危険な環境で働く人もいました。

```flow
技術が変わる → 生産や仕事が変わる → 利益を得る人と負担する人が分かれる
```

利益が広がるまでの時間や、その間の苦しさを無視できません。昔、新しい仕事が生まれたから、これからも誰も困らないという証明にはなりません。

**技術の目標を、生産量だけでなく、余暇や生活の質から考える**のが、この講の入口です。

```quiz
Q: 過去に新しい仕事が生まれたことから、いえるのは？
1: どの時代も誰も失業しなかった
2: 全員の賃金が導入直後に同じだけ上がる
3: 生活の質と技術は無関係
4: 今後の移行で困る人がいないとは決められない
C: 4
E: 技術の便益は、時期や職業によって違いました。経済全体の変化と、個々の人の移行の負担を分けます。
```

## 2. 仕事を「作業」に分けて見る

動画を作る仕事なら、資料を集める、構成を考える、字幕を作る、相手に確認するなどの作業があります。AIが字幕を助けても、すべてを任せられるとは限りません。

| 見方 | 注目すること |
|---|---|
| 職業単位 | この職業が自動化されそうか |
| 作業単位 | 中のどの作業を代わり、どこを助けるか |

```flow
仕事を分ける → 代われる作業を見つける → 残る作業や新しい役割も考える
```

見方によって、将来の雇用の予測も違います。「自動化できる可能性」と「実際に採用されること」も別です。

```quiz
Q: 字幕作成が自動化されたら、動画制作の仕事は全部消える？
1: ほかの作業や、新しい役割もあるので一概にはいえない
2: 必ず全部消える
3: 動画を見る人も必ずゼロになる
4: 自動化された作業も人が必ず同じ時間繰り返す
C: 1
E: 職業は複数の作業でできています。代替される部分と、補完される部分を分けて評価します。
```

## 3. 仕事が減る力と、増える力

| 効果 | 何が起こる？ |
|---|---|
| 代替効果 | 人の作業を機械が代わる |
| 補完効果 | 機械を生かす人の役割が増える |
| 生産効果 | 安くなって需要が増え、生産や人手が増える |
| 波及・拡散効果 | 新しい商品や産業が育つ |

```eq
雇用への影響 = 減る力と増える力の組合せ
```

費用が下がっても、価格が十分下がらなかったり、需要が増えなかったりすれば、人手が増えるとは限りません。競争や所得の分配、投資の条件も関わります。

```quiz
Q: 技術で生産費用が下がったら、雇用は必ず増える？
1: 必ず増える
2: 価格・需要・競争などによって結果が変わる
3: 必ず全員が失業する
4: どの効果も雇用と無関係
C: 2
E: 代替される作業だけでなく、補完・需要・新産業の効果を合わせます。どちらが大きいかは条件次第です。
```

## 4. 工場が戻れば、昔と同じ人数が働ける？

安い人件費を求めて海外へ移った生産が、技術や輸送、顧客への近さなどから戻る場合もあります。しかし、戻った工場が高度に自動化されていれば、以前と同じ人数を必要とするとは限りません。

「どの国で作るか」と「どの作業を人がするか」は、関連しますが別の問いです。低賃金だけが、立地を決める理由でもありません。

```quiz
Q: 自動化された工場が国内へ戻った場合、雇用は？
1: 必ず元の人数に戻る
2: すべての仕事が手作業になる
3: 昔と同じ人数になるとは限らない
4: 輸送時間や人材は立地に無関係になる
C: 3
E: 立地の変化だけで雇用人数は判断できません。作業の自動化、人材、需要なども見ます。
```

## 5. 柔軟に働けることと、安心して働けること

在宅や短時間、プラットフォームを通じた仕事には、時間や場所を選びやすい面があります。一方、収入が不安定、予定が直前に変わる、仕事から離れにくいといった負担もありえます。

| 自由になる面 | 確かめる負担 |
|---|---|
| 時間や場所を選ぶ | いつも連絡に対応する圧力 |
| 少ない時間から参加 | 収入や勤務時間の不確実さ |
| 複数の仕事を組み合わせる | 保険・年金・休業時の保障 |

**仕事の数だけでなく、仕事の質も見る**ことが大切です。

```quiz
Q: 柔軟な働き方を評価するときに必要なのは？
1: 自由なら負担は一切ないと考える
2: 短時間なら必ず高収入になると考える
3: 在宅なら仕事と生活の境目は常に明確と考える
4: 自由度と、収入・予定・保障の安定を両方見る
C: 4
E: 同じ働き方でも、選べる自由と不確実さの両方があります。労働条件と社会保障も重要です。
```

## 6. 自分の仕事では、どこを助けてもらう？

新しい道具に詳しいことだけでなく、問題を見つけ、結果を確かめ、相手に伝える力も必要です。状況に応じた判断や対人関係など、決まった手順にしにくい作業にも注目します。

```flow
自分の作業を1つ選ぶ → 道具で試す → 時間と品質を比べる → 人が担う部分を決める
```

> 補足：これは仕事を見直すための学習用の例です。どの職業が将来も必ず安全かを保証するものではありません。

学び直しだけを個人に任せず、教育・働くルール・移行期の支援をどう整えるかも、社会の問いです。

```quiz
Q: AIを仕事に取り入れるときの確かめ方は？
1: 具体的な作業で時間と品質を比べ、人の役割も決める
2: 使うだけで必ず改善したと決める
3: 結果を一切見直さない
4: 人に関わる判断もすべて無条件で任せる
C: 1
E: 役立つかは、実際の作業で確認します。技術の導入と、人の判断・働く条件を組み合わせて考えます。
```

## 7. 持ち帰る考え

**「AIに代わられるか」だけでなく、「何を任せ、空いた時間をどう使い、どう暮らしたいか」**も問いになります。個人の工夫と、社会の支えを両方考えます。

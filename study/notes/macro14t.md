# 上級マクロ経済論 14講【会話で読む】― 値段がすぐ変わらないと、何が起こる？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro14)」。

## 0. この講の地図（3分）

```talk
B: 不況で物が売れず、人が余るなら、値段や給料が下がればすぐ解決しない？
A: すぐ下がるならね。でも実際は、値段や給料はすぐには変わらない。だから不況が何か月も続く。それが14講の問い。
B: 12講・13講とのちがいは？
A: 12講は値段が自由に動く話、13講はつり合う場所そのものが動く話。14講は、値段が動きにくいので、つり合う場所に着くまでの間、作る量や人手がずれる話。
B: どんな順で学ぶ？
A: 言葉をそろえる → 動きにくいものを3つ順に見る（給料の額・給料の買える力・商品の値段）→ くらべる → 不況への手当て。
C: 何が動きにくいかで、結果が3通りに分かれる。
```

```card
この講の道すじ
- ① 言葉：硬直性・総需要・本来の生産水準・総生産ギャップ
- ②〜④ 動きにくい3つ：給料の額／給料の買える力／商品の値段
- ⑤ くらべる　⑥ 金利で不況をやわらげる
```

## 1. 言葉をそろえる（5分）

```talk
B: いつも100個売れるパンが、今日は70個しか売れなかったら？
A: パン屋がすぐ値段を変えられないなら、翌日は作る量を減らし、人手も減らすかもしれない。
B: 値段が変わりにくいことを、何という？
A: 硬直性。絶対に変わらないのではなく、変わるまでに時間がかかる、という意味。
B: 「本来の生産水準」って？
A: 働きたい人がみな働けて、値段も自由に動くときの生産。実際の生産との差を総生産ギャップという。不況ではマイナス。
B: マイナスって、どういうこと？
A: 本来100作れる力があるのに、実際は90しか作っていない状態。10の力が余っていて、もったいない。
C: 買いたい量が減る → 値段は動かない → 生産・人手が減る。
```

```card
要点
- 硬直性：値段や給料が、変わるまでに時間がかかること
- 総需要：国全体で買いたい量
- 総生産ギャップ ＝ 実際の生産 − 本来の生産水準（不況ではマイナス）
```

## 2. 型①：給料の額が動きにくい（10分）

```talk
B: 月給20万円で決まっていて、物価が下がったら？
A: 給料の額（名目賃金）はそのまま。同じ20万円で多く買えるから、実質賃金は上がる。
B: なぜ給料の額はすぐ変わらないの？
A: 契約で決まっていて、会社ごとに更新の月がずれているから。テイラーの重複賃金契約モデルという。
B: 投資が減ったら、どうなる？
A: 総需要が減る → 物価が下がる → 給料の額はそのまま → 会社にとって給料が重くなる → 雇う人が減る → 生産が減る。
B: 弱点は？
A: 不況で実質賃金が上がることになる。データでは、実質賃金はむしろ好況で上がることが多いので、合いにくい。
C: 型①は、需要で生産が動くが、実質賃金の向きがデータと逆。
```

```card
要点
- 実質賃金 ＝ 給料の額 ÷ 物価
- 投資↓ → 物価↓ → 実質賃金↑ → 雇用↓ → 生産↓
- 弱点：不況で実質賃金が上がる方向になる
```

## 3. 型②：給料の買える力が動きにくい（7分）

```talk
B: 今度は、会社が実質の給料を高めに保つ場合は？
A: 辞めにくく、まじめに働き、よい人が集まるなら、会社にも得がある。これが効率賃金。
B: 全員を雇える？
A: 高い給料で採算が合う人数しか雇わない。働きたいのに働けない非自発的失業が残る。
B: 買いたい量がふえたら？
A: このモデルでは生産も雇用もふえない。生産は給料と生産性で決まるから。需要は物価や利子率を動かすだけ。
B: 生産性が上がったら？
A: 1人を雇う価値が上がるので、雇用がふえ、非自発的失業はへる。
C: 型②は、失業が残る理由は説明できるが、需要で生産は動かない。
```

```card
要点
- 効率賃金：会社が、実質の給料を高めに保つ
- 非自発的失業：働きたいのに働けない
- 需要がふえても生産はふえない（総供給の線が垂直）
```

## 4. 型③：商品の値段が動きにくい（10分）

```talk
B: 商品の値段が変わりにくい理由は？
A: 値札だけでなく、メニュー・広告・契約も直す手間がある。これをメニューコストという。
B: 値段が据え置きのとき、注文がふえたら？
A: 作る余力があれば、作る量がふえ、人手もふえ、所得もふえる。減れば、その逆。
B: つまり？
A: 総需要（買いたい量）が生産を動かす。ここがいちばん大事。
B: 12講とのちがいは？
A: 12講は値段が自由なので、お金や金利では生産は変わらない。型③は値段が動きにくいので、需要を通して変わりうる。
C: 型③は、好況で消費・投資・雇用・実質賃金がそろってふえる動きを説明しやすい。
```

```card
要点
- メニューコスト：値段を変える手間や費用
- 注文がふえれば生産がふえ、減れば生産が減る
- 中央銀行は金利を目標どおりに保つため、お金の量を合わせる
```

## 5. 同じ不況を、3つの型で見くらべる（7分）

```talk
B: くらべるときは、何を見ればいい？
A: 同じできごとで見る。投資が減って、買いたい量が減ったとき。見るのは「作る量」と「給料で買える量（実質賃金）」の2つだけ。
B: 型①は？
A: 物価が下がるのに、給料の額はそのまま。だから実質賃金は上がる。会社には重いので、人を減らして、生産も減る。
B: 型②は？
A: 生産も実質賃金も変わらない。会社が自分から、給料の買える力を高めに保っているから。下げると、よい人が辞めたり、やる気が落ちたりして損をする。
B: 人数も変わらないの？
A: 雇う人数は、給料の高さと、1人がどれだけ作れるかで決まる。どちらも変わらないので、人数も生産も変わらない。
B: 型③は？
A: 値段はそのままで注文が減るので、作る量を減らす。人手が要らなくなって、給料は下がりやすい。だから実質賃金は下がりうる。
B: データに合うのは？
A: 実際は、不況で生産も実質賃金も下がることが多い。その向きに合うのは型③。
C: 見るのは「生産」と「実質賃金」の2つ。
```

```card
不況のとき（需要が減ったとき）
- 型①：生産 減る／実質賃金 上がる
- 型②：生産 変わらない／実質賃金 変わらない（会社が下げない）
- 型③：生産 減る／実質賃金 下がる（データに合う）
```

## 6. 金利で注文を支える（5分）

```talk
B: 需要が足りないとき、金利は役に立つ？
A: 金利が下がれば借りやすくなり、消費や投資がふえる。注文がふえれば、生産や雇用が戻る方向。
B: どこまで下げればいい？
A: 目安は自然利子率。値段が自由なとき、需要と本来の生産力がつり合う実質利子率。そこまで下げると、生産は本来の水準に戻る方向へ動く。
B: 自然利子率は、銀行の金利？
A: ちがう。直接は見えず、推計する目安。中央銀行が決める政策金利は、ふつう名目の短期金利。
B: 下げれば必ず回復する？
A: しない。下げられる幅や、借りる人の状態、物価の動きにも左右される。
C: 自然利子率と、総生産ギャップ。
```

```card
要点
- 金利を下げる → 消費・投資を支える → 注文がふえる → 生産・雇用が戻る方向
- 自然利子率：値段が自由なとき、需要と本来の生産力がつり合う実質利子率（見えない、推計）
```

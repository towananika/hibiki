# 上級マクロ経済論 14講【会話で読む】― 値段がすぐ変わらないと、何が起こる？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro14)」。

## 1. パンが売れなくなった（5分）

```talk
B: いつも100個売れるパンが、今日は70個しか売れなかったら？
A: パン屋がすぐ値段を変えられないなら、翌日は作る量を減らし、必要な人手も減らすかもしれない。
B: 値段が変わりにくいことを、何という？
A: 硬直性。絶対に変わらないのではなく、変わるまでに時間がかかる、という意味。
B: 13講とのちがいは？
A: 13講は、つり合う場所自体が動く話。14講は、価格調整が遅いので、生産や雇用が本来の水準から外れる話。
C: 買いたい量が減る → 値段は動かない → 生産・人手が減る。
```

```card
要点
- 硬直性：値段や給料が、変わるまでに時間がかかること
- 14講：価格調整が遅く、生産や雇用が本来の水準から外れる
```

## 2. 給料の額が変わりにくい（10分）

```talk
B: 月給20万円で決まっていて、物価が下がったら？
A: 同じ20万円でも、前より多くの物が買える。実質賃金 ＝ 給料の額 ÷ 物価。働く人の購買力は上がる。
B: 会社にとっては？
A: 売値が下がって、給料の額がそのままなら、人を雇う負担が重くなる。だから雇用が減る。名目賃金（物価で調整する前の給料の額）が硬直的なモデル。
B: 給料を決め直す時期は？
A: 会社ごとに契約の更新月が違うと、経済全体の給料は一度には変わらない。ほかの人との差を気にすると、調整が長引く（テイラーの重なる契約）。
B: 弱点は？
A: 単純な説明だと「不況で実質賃金が上がる」方向になる。13講のデータ（好況で実質賃金が上がる）とは合いにくい。
C: 名目賃金が硬い → 売値が下がると人件費が重い。
```

```card
要点
- 実質賃金 ＝ 給料の額 ÷ 物価
- 名目賃金が硬い：売値が下がる → 給料はそのまま → 雇う負担↑ → 雇用↓
- テイラーの重なる契約：更新時期がずれて、調整が長引く
- 弱点：不況で実質賃金が上がる方向になる
```

## 3. 給料の買える力が変わりにくい（5分）

```talk
B: 今度は、会社が実質の給料を高めに保つ場合は？
A: 人材が辞めにくくなったり、意欲が高まったりするなら、会社にも理由がある。これを効率賃金という。
B: 全員を雇える？
A: 雇うとは限らない。働きたいのに働けない非自発的失業が残りうる。
B: 生産性が上がると？
A: 同じ給料でも雇う価値が上がり、雇用と生産がふえる方向。買いたい量だけがふえても、この単純なモデルでは、雇用や生産はふえない。
B: 図では？
A: 縦軸が実質利子率、横軸が生産の図で、実質総供給曲線が垂直になる。
C: 効率賃金 → 非自発的失業。
```

```card
要点
- 効率賃金：会社が、実質の給料を高めに保つ（辞めにくい・意欲が高い）
- 非自発的失業：働きたいのに働けない
- 実質賃金が一定のモデルでは、実質総供給曲線が垂直
```

## 4. 商品の値段が変わりにくい（10分）

```talk
B: 商品の値段が変わりにくい理由は？
A: 値札だけでなく、メニュー・広告・契約なども変える手間がある。値段を変える費用をメニューコストという。
B: 値段が据え置きのとき、注文がふえたら？
A: 余力があれば、注文がふえた店は生産をふやす。減れば、生産を減らす。
B: ここで大事なのは？
A: 短期に価格を固定するモデルでは、総需要（買いたい量）が生産を動かす。ただし、店が無限に作れるという意味ではない。
B: 12講とのちがいは？
A: 12講は価格が自由に動くので、お金の量だけでは実質が変わらない。この節は価格が短期には動きにくいので、需要を通して変わりうる。
C: メニューコスト → 価格が動かない → 需要が生産を動かす。
```

```card
要点
- メニューコスト：値段を変える費用
- 注文がふえれば生産がふえ、減れば生産が減る
- 12講：価格が自由 → お金の量では実質は変わらない／14講：価格が硬い → 需要を通して変わる
```

## 5. 金利で注文を支える（5分）

```talk
B: 需要が足りないとき、金利は役に立つ？
A: 借りる利子が下がれば、家計や会社が買いやすくなる。中央銀行の金利引下げが、生産や雇用を支える可能性がある。
B: 2つの言葉は？
A: 自然利子率は、値段が柔軟に動くとき、需要と本来の生産力がつり合う実質利子率。総生産ギャップは、実際の生産と本来の生産水準との差。不況で実際の生産が下回れば、マイナスのギャップ。
B: 自然利子率は、銀行の金利？
A: ちがう。直接は見えず、推計する目安。中央銀行が決める政策金利は、通常は名目の短期金利。
B: 下げれば必ず回復する？
A: しない。下げられる幅や、借り手の状態、物価の動きなどにも左右される。
C: 自然利子率と、総生産ギャップ。
```

```card
要点
- 金利を下げる → 消費・投資を支える → 注文がふえる → 生産・雇用が回復する方向
- 自然利子率：値段が柔軟なとき、需要と本来の生産力がつり合う実質利子率（見えない、推計）
- 総生産ギャップ ＝ 実際の生産 − 本来の生産水準（不況ではマイナス）
```

## 6. 3つの動きにくさを整理する（5分）

```talk
B: 3つをまとめると？
A: 給料の額（名目賃金）が硬いと、売値が下がったときに会社の実質の人件費が上がる。給料の購買力（実質賃金）が硬いと、高めの給料でも全員は雇われない。商品の値段が硬いと、注文に応じて生産や人手が動く。
B: どれがデータに合う？
A: 講義の比較では、商品価格が動きにくいモデルは、消費・投資・雇用・実質賃金が好況でふえる動きを説明しやすいとされる。でも、どんな不況も1つのモデルで説明できるわけではない。
C: 動きにくいものによって、結果が変わる。
```

```card
要点
- 名目賃金が硬い：売値が下がると、会社の実質の人件費が上がる
- 実質賃金が硬い：高めの給料でも、全員を雇うとは限らない
- 商品の値段が硬い：注文に応じて、生産や人手が動く
```

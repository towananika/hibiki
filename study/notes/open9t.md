# 開かれた社会と21世紀 9講【会話で読む】― まちを変える法と制度

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=open9)」。

## 1. ルールにする意味（10分）

```talk
B: なぜ住民の活動をルールにするの？
A: 市長や担当者が交代しても、活動が止まらないようにするため。住民と支援組織の役割と責任（権限と責任）もはっきりする。ルールにして支えることを制度化という。
B: 流れは？
A: みんなで話し合う（社会化）→ 議会と調整（政治化）→ きまりにする（制度化）→ 施策にする（政策化）。
B: 気をつけることは？
A: 全国同じ点数表（評価指標）で評価するとまちに順位がついて個性が消える。補助金が役所寄りの団体の力になった例もある。成果主義だと、話し合いという過程が軽く見られる。
C: ルールが住民の自由をうばってはいけない。
```

```card
要点
- 制度化：国の法律・自治体の条例・みんなの当たり前にして支える
- 社会化 → 政治化 → 制度化 → 政策化
- 注意：同じ点数表で個性が消える／補助金の偏り／過程が軽く見られる
```

## 2. 良い条例と、ソウル市の例（10分）

```talk
B: 良い条例の中身は？
A: だれも差別しない。18歳未満の子どもにも、年齢に合った参加の権利がある。住民票の住所ではなく、そこで暮らしている人（生活者）の目で考える。住民にも責任がある。行政と住民をつなぐ支援センターを置く。
B: ソウル市は？
A: 窓口を一つにまとめ、住民がいつでも提案できるようにした。まちの育ち具合で支援を変える。たね（つながりが弱い）→ 新芽（つながりができた）→ 希望（活動が活発）。
C: まちづくりの始まりと終わりは、住民とまち。
```

```card
要点
- 良い条例：差別しない／18歳未満も参加／生活者の目／住民の責任／支援センター
- ソウル市：窓口一つ。たね → 新芽 → 希望で支援を変える
- 日本の「まちづくり条例」とほぼ同じ考え方
```

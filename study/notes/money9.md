# 貨幣金融論 9講 ― 銀行のお金は、どう増える？

**財布のお金は数えられる。でも、銀行の口座にあるお金は、どうやって増えるの？**

この回は、その仕組みを学びます。経済学を初めて学ぶ人も、まずは1〜7を順番に読めば大丈夫。公式と記号は最後にまとめました。

## 1. 口座の数字も、支払いに使えるお金

買い物の支払いには、財布の現金だけでなく、銀行口座のお金も使えます。だから、社会のお金を考えるときは、現金だけでなく預金も数えます。

銀行が会社にお金を貸すと、借りた会社の口座に預金が記録されます。会社がそのお金で仕入れ代を払うと、今度は取引先の口座にお金が移ります。

```flow
銀行が会社に貸す → 会社の口座に預金ができる → 仕入れ代を払う → 取引先の預金になる
```

こうして、銀行の貸し出しは、支払いに使える預金を生みます。これを**信用創造**といいます。

ただし、借りた会社には返済する義務もあります。**預金が増えることと、社会がその分だけ豊かになることは別**です。

```quiz
Q: 銀行が会社に貸し出し、会社の口座に預金が記録された。このときの説明は？
1: 現金のお札が同じ額だけ新しく印刷された
2: 支払いに使える預金ができ、会社には返済義務も生じた
3: 借金がなくなり、会社がただで豊かになった
4: 口座のお金は支払いには使えない
C: 2
E: 銀行の貸し出しで預金が生まれますが、借りた側には借金も生じます。預金の増加と、富の増加は同じではありません。
```

## 2. でも、いくらでも貸せるわけではない

口座のお金を送金したり、現金で引き出したりすると、銀行には支払いへの備えが必要です。そのために持つお金が**準備金**です。

準備金には、法律で「最低これだけは持つ」と決められた分があります。その割合を**法定準備率**といいます。

たとえば、預金100につき準備を10持つという決まりなら、残す割合は10％です。

### 計算を簡単にした世界で考える

全員が現金を手元に増やさず、銀行も余分な準備を持たず、定期預金もないとします。
この条件では、**準備100で、預金1000を支えられる**計算になります。1000の10％が100だからです。

```eq
預金1000 × 残す割合10％ = 必要な準備100
```

「もとのお金に対して何倍になるか」という倍率を、**通貨乗数**といいます。この例では10倍です。

> この講義は、仕組みを理解するためのモデルです。実際の銀行は、借りたい人がいるか、返済してもらえるか、銀行自身の資本は十分か、なども考えます。必ず10倍になるという約束ではありません。

```quiz
Q: 準備を10％持つ、簡単な世界。準備100に対応する預金はいくら？
1: 10
2: 100
3: 10000
4: 1000
C: 4
E: 預金1000の10％が準備100です。人が現金を増やさず、銀行が余分な準備を持たず、定期預金もない条件での計算です。
```

## 3. みんなが財布に現金を置くと？

ここから、少し現実に近づけます。
「口座より、財布に現金を置いておきたい」と考える人もいます。その分のお金は、銀行の外にとどまります。

**現金も支払いに使えるお金です。消えるわけではありません。** ただ、銀行の準備として使える分が減るので、同じ土台のお金でも、預金は増えにくくなります。

```bars
現金を増やさない例 | 10 | 10倍 | b
現金も持つ例 | 4 | 4倍 | s
```

上の比較は、法定準備率10％、余分な準備と定期預金なしという条件です。下の例は、要求払い預金100に対して現金20を持つ場合。計算は最後に載せています。

```quiz
Q: 人々が現金を手元に多く持つと、講義の通常の条件ではどうなる？
1: 現金はなくならないが、預金の増え方は小さくなる
2: 財布に入れた現金が社会から消える
3: 銀行が使える準備が必ず増える
4: 現金を持つ人だけ借金がなくなる
C: 1
E: 現金は人々の手元に残ります。同じ土台のお金のうち、銀行の準備になる分が減り、預金が増える働きが弱まります。
```

## 4. 銀行が「多めに備えたい」と思ったら？

銀行も、「急な引き出しに備えたい」と考えることがあります。
決まりで必要な分を超えて、準備を多く持つこともできます。この余分な備えが**超過準備金**です。

```flow
銀行が準備を多めに持つ → 同じ土台で支えられる預金が少なくなる → お金の増え方が小さくなる
```

たとえば、最低10％に加え、余分に10％残すなら、合計20％。準備100で支えられる預金は500です。500の20％が100だからです。
これは、現金の保有増加と定期預金がない場合の練習例です。

```quiz
Q: ほかの条件が同じで、銀行が余分な準備を増やすと？
1: 必ず預金が2倍になる
2: 準備が不要になる
3: 同じ土台で支えられる預金は少なくなる
4: 預金の金利が必ず上がる
C: 3
E: 準備に回る割合が大きくなるため、同じ土台のお金で支えられる預金は少なくなります。
```

## 5. 定期預金も考えると、何が変わる？

預金には、日々の支払いに使うものと、一定期間置いておく定期預金などがあります。後者を、ここでは**貯蓄性預金**と呼びます。

この講義では、数えるお金の範囲を**「人々の現金＋要求払い預金」**に絞っています。要求払い預金とは、いつでも引き出せる預金です。

**定期預金などは、この範囲には足しません。** でも、その預金のためにも、銀行は決められた準備を持つ必要があります。

そのため、ほかの条件が同じで、貯蓄性預金が要求払い預金に対して多くなると、同じ土台で支えられる要求払い預金は少なくなります。

> 預金が「お金に含まれるか」は、集計する範囲によって変わります。定期預金に価値がない、という意味ではありません。

```quiz
Q: この講義で、定期預金などの割合が増えると倍率が下がるのはなぜ？（その預金にも準備が必要な場合）
1: 定期預金の価値がゼロになるから
2: 数える通貨量には足さないが、準備は必要だから
3: 定期預金は現金と同じものだから
4: すべての銀行口座が使えなくなるから
C: 2
E: このモデルが数える通貨量は、現金と要求払い預金です。貯蓄性預金のための準備も必要になるため、同じ土台で支えられる要求払い預金は少なくなります。
```

## 6. お金の量を決めるのは「土台」と「倍率」

ここまでの話を、2つに整理します。

- **土台**：中央銀行が供給するお金。人々の現金と銀行の準備金を合わせたもの。正式には**本源通貨**。
- **倍率**：その土台に対して、数えるお金の量が何倍になるか。正式には**通貨乗数**。

```eq
世の中のお金の量 = 土台のお金 × 倍率
```

土台が100、倍率が3なら、お金の量は300です。
倍率が3のまま、土台が200になれば、お金の量は600です。

一方、土台が同じでも、人が現金を多く持ったり、銀行が準備を多く残したりして倍率が下がると、お金の量は少なくなります。

この関係を式で表したものが、**通貨供給関数**です。「関数」という言葉が難しければ、「何が変わると、お金の量が変わるかを表す式」と読めば大丈夫です。

```quiz
Q: 土台のお金が200、倍率が3。講義のモデルでは、お金の量はいくら？
1: 203
2: 200
3: 3
4: 600
C: 4
E: 土台×倍率なので、200×3＝600です。倍率も変わる場合には、前と同じ倍率のままでは計算できません。
```

## 7. ここまでの話を、30秒でおさらい

| 何が変わる？ | ほかの条件が同じなら |
|---|---|
| 土台のお金が増える | お金の量は増える |
| 人々が現金を多く持つ | 通常の条件では、増える倍率は小さくなる |
| 銀行が準備を多く残す | 増える倍率は小さくなる |
| 準備が必要な貯蓄性預金の割合が増える | この講義の範囲では、倍率は小さくなる |

**中央銀行だけでなく、人々と銀行の行動も、お金の量に関わっている。** これが第9講の中心です。

ここまで理解できたら、まずは十分。次は、同じ話を試験用の言葉と記号で確かめます。

## 8. 試験に向けて：言葉と公式

### 記号は、金額と割合に分ける

| 金額の記号 | 意味 |
|---|---|
| M | 数える通貨量。現金＋要求払い預金 |
| B | 本源通貨。現金＋銀行の準備金 |
| C | 人々の現金 |
| D | 要求払い預金 |
| T | 貯蓄性預金。この講義の M には足さない |
| E | 超過準備金 |

| 割合の記号 | 意味 |
|---|---|
| c＝C÷D | 現金預金比率（現金選好比率） |
| r | 要求払い預金の法定準備率 |
| r′ | 貯蓄性預金の法定準備率 |
| t＝T÷D | 要求払い預金に対する貯蓄性預金の比率 |
| e＝E÷D | 超過準備率 |

c＝0.2 は、**要求払い預金100に対して現金20**という意味です。「現金＋預金の合計の20％」ではありません。割合の分母を確かめましょう。

### 公式は、簡単な場合から読む

| 条件 | 通貨乗数 m |
|---|---|
| 現金の保有増加・超過準備・Tなし | 1÷r（1÷法定準備率） |
| 現金あり。超過準備・Tなし | (1＋c)÷(r＋c)（(1＋現金の比率)÷(準備率＋現金の比率)） |
| 超過準備あり。現金の保有増加・Tなし | 1÷(r＋e)（1÷(準備率＋余分に残す率)） |
| Tあり。現金の保有増加・超過準備なし | 1÷(r＋r′×t)（1÷(準備率＋貯蓄性預金の準備率×貯蓄性預金の比率)） |
| すべてある | (1＋c)÷(c＋r＋r′×t＋e) |

第3節の4倍は、r＝0.1、c＝0.2 を入れた計算です。
(1＋0.2)÷(0.1＋0.2)＝1.2÷0.3＝4。

### 全部合わせた式は、足し算からできる

数えるお金は、M＝C＋D＝(c＋1)×D。
（世の中のお金 M ＝ 現金 C ＋ 要求払い預金 D）
土台は、B＝C＋r×D＋r′×T＋E＝(c＋r＋r′×t＋e)×D。
（お金のもと B ＝ 現金 ＋ 預金に義務で残す分 ＋ 貯蓄性預金に義務で残す分 ＋ 余分に残す分 E）
M（世の中のお金）を B（お金のもと）で割ると、共通の D が消えて、最後の行の倍率になります。

練習例として、c＝0.2、r＝0.1、r′＝0.04、t＝0.5、e＝0.08 を入れると、分子は1.2、分母は0.4。倍率は3です。実際の制度の準備率ではなく、説明用の数字です。

**全体の量は M＝m×B**（世の中のお金 ＝ 倍率 × お金のもと）。増えた量は、比率が一定なら **ΔM＝m×ΔB**（お金の増えた分 ＝ 倍率 × お金のもとの増えた分）。「Δ（デルタ）」は変化した量を表します。倍率が変わるときは、同じ倍率のまま計算しません。

> 発展：現金の比率 c を上げると倍率 m が下がるのは、r＋r′×t＋e＜1（準備率と余分に残す率などの合計が1より小さい）の場合です。分子にも c があるので、「いつでも必ず下がる」とは限りません。貯蓄性預金比率 t の影響は、その法定準備率 r′ が正の場合に生じます。

```quiz
Q: 現金預金比率 c＝0.2 の正しい読み方は？
1: 要求払い預金100に対して、現金を20持つ
2: 現金と預金の合計100のうち、現金が20
3: 預金の利息が20％
4: 銀行が余分な準備を20％持つ
C: 1
E: c＝C÷D。分母は要求払い預金です。現金と預金を足した合計ではありません。
```

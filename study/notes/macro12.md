# 上級マクロ経済論 12講 ― お札が増えると、豊かになる？

**買える物が増えることと、お金の数字が増えることは違います。** この講では、値段や給料が自由に動くモデルを使って、その違いを考えます。

## 1. パンもお金も、2倍になった？

ある町で、パンは1個100円。お金の量だけが2倍になり、パンの値段も200円になったとします。

持つお金が1,000円から2,000円になっても、買えるのはどちらも **10個** です。パンを作る力が増えていなければ、お札が増えただけでは豊かになりません。

```eq
買えるパン10個 = 2,000円 ÷ 1個200円
```

お金で測った額を **名目**、物価を考慮した購買力や量を **実質** といいます。この講の「所得」は主に実質所得です。給料の額が動かない場合は、第14講で考えます。

```quiz
Q: 給料と物価が同じ割合で2倍になったら、買える量は？
1: 買える量は同じ
2: 買える量は2倍
3: 買える量は半分
4: 買える量は必ずゼロ
C: 1
E: 同じです。名目の給料は増えても、実質の給料は変わりません。
```


## 2. 第9〜11講の話を、つなぐ

- 第9講：会社が設備を買う量を決める。
- 第10講：働く量と、作れる量が決まる。
- 第11講：人が持ちたいお金と、供給されるお金を比べる。

これらが全部つり合う状態を **一般均衡** といいます。順に読むと理解しやすいですが、実際には互いに関係しながら同時に決まります。

```flow
労働と財の市場を考える → 生産・雇用・実質利子率を求める → 貨幣市場から物価を求める
```

| 市場 | 比べるもの |
|---|---|
| 労働市場 | 働きたい量と、雇いたい量 |
| 財市場（物の市場） | 買いたい量と、作れる量 |
| 貨幣市場 | 供給されるお金と、持ちたいお金 |

```quiz
Q: 一般均衡とは？
1: 労働市場だけがつり合うこと
2: すべての商品の価格が同じになること
3: 関係する市場が同時につり合うこと
4: 全員が同じ金額の給料を得ること
C: 3
E: 労働・財・貨幣など、関係する市場が同時につり合うことです。
```


## 3. お金の数字と、実際の量を分ける

このモデルでは、生産・雇用・実質賃金・実質利子率が、まず労働と財の市場で決まります。お金の量は、物価の高さに反映されます（**古典派の二分法**）。

```eq
実質のお金の量 = 名目のお金の量 ÷ 物価
```

名目のお金が2倍でも、物価が2倍なら、実質のお金は同じ。所得や利子率が同じなら、持ちたい実質のお金の量ともつり合ったままです。

**お金の量を変えても、生産や雇用など実質の量は変わらない**ことを、貨幣の中立性といいます。

> 補足：ここでの結論は、値段や給料が自由に動くなどの仮定によります。現実の短期の金融政策が効かない、と決めつける話ではありません。

```quiz
Q: 貨幣の中立性とは？
1: お金が増えると必ず生産も同じ割合で増える
2: お金の量だけ変えても実質の量が変わらない
3: お金が増えても物価は絶対に変わらない
4: 中央銀行が何も政策をしないこと
C: 2
E: お金の量を変えても、生産や雇用など実質の量が変わらないことです。
```


## 4. 実質利子率は、何を合わせる？

設備を買う会社や赤字の政府は、資金を必要とします。一方、家計は貯蓄で資金を出します。

```eq
家計の貯蓄 = 投資 + 政府の赤字
```

正式には **S(Y,r)＝I(r)＋(G−T)**。Y は実質所得、r は実質利子率、G は政府の購入、T は税です。輸出入のない経済を考えています。

実質利子率が、この資金の需要と供給をつり合わせます（**貸付資金説**）。現金を持ちたい量を比べる「貨幣市場」と、区別しましょう。

```quiz
Q: 貸付資金説では、何と何がつり合う？
1: 現金の枚数と、商品の種類
2: 人口と、企業の数
3: 物価と、名目の給料の金額
4: 貯蓄と、投資・政府の赤字に必要な資金
C: 4
E: 貯蓄と、投資や政府の赤字に必要な資金です。その調整に実質利子率が働きます。
```


## 5. 政府の購入が増えると？

政府が道路工事などを増やすと、買いたい量が増えます。このモデルでは、将来の税負担も見込んで、家計が休みを減らして働く方向に動きます。

```flow
政府の購入が増える → 将来の税負担を見込む → 労働供給が増える → 生産が増える
```

基本ケースでは、雇用と実質所得が増え、実質賃金は下がります。資金の需要も増えるので、実質利子率は上がる方向です。物価の結果は、お金の供給や需要についての仮定にもよります。

> 補足：政府の予算にも制約があります。支出や借金の返済は、税・新しい借金などで賄います。このモデルでは、政府の購入が家計の生活を直接便利にする効果などを単純化しています。

```quiz
Q: このモデルで政府の購入が増え、家計が多く働く理由は？
1: 紙幣が増えれば必ず働くから
2: 将来の税負担を見込むため
3: 休みの価値が完全に消えるから
4: 政府の購入が家計の給料を必ず倍にするから
C: 2
E: 将来の税負担を見込み、生涯の使えるお金が減ると考えるため、休みを減らす方向に動くというモデルです。
```


## 6. 「今よくなる」と「将来よくなる」は違う

| 生産性の変化 | 最初に注目すること | この講の基本ケースの実質利子率 |
|---|---|---|
| 今よくなる | 今、多く作れる | 下がる |
| 将来よくなると予想 | 将来に備えて、今投資したい | 上がる |

将来の生産性が上がると、今の設備投資が増えます。利子が上がると、今働いて貯め、休みを将来に回す効果も働きます。これが第10講の **異時点間代替** です。

> 補足：「今だけか」「将来も続くか」で結果は変わります。技術の改善がいつも金利を下げる、という暗記はしないでください。

```quiz
Q: 将来の生産性がよくなる予想は、今の投資をどう動かす方向？
1: 必ずすべての設備を捨てる
2: 投資には一切関係しない
3: 今の技術が必ず悪化する
4: 将来に備える投資を増やす
C: 4
E: 将来、設備から得られる生産が増えると期待すれば、今のうちに設備をそろえる動機が強まります。
```


## 7. モデルが説明しにくいこともある

金融危機では、借りにくさが消費や投資を減らします。この講のモデルで所得や雇用の減少を説明できても、物価や実質賃金の動きまで、現実に合うとは限りません。

また、政策のやり方が変わると、人の予想や行動も変わります。**昔のデータの関係を、そのまま新しい政策に当てはめるのは危険**です（ルーカス批判）。データを使ってはいけない、という意味ではありません。

たとえば「今回だけの減税」と「今後も続く減税」では、同じ金額でも使い方が変わりえます。

```quiz
Q: ルーカス批判は、データを使ってはいけないという意味？
1: 政策が変わると過去の関係が変わりうるという注意
2: データを一切使うなという主張
3: 人の予想は政策で変わらないという主張
4: 昔の式はどんな政策にも必ず使えるという主張
C: 1
E: 違います。政策が変わると人の予想や行動も変わるので、昔の関係がそのまま続くとは限らない、という注意です。
```


## 8. まず、この3つ

1. 名目はお金の数字、実質は物価を考えた量や購買力。
2. このモデルでは、お金が増えても実質の生産や雇用は変わらない。
3. 結論を読むときは、値段が自由に動くなどの仮定も一緒に見る。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。上級マクロは重点科目なので6問。


```quiz
Q: お金の量だけが2倍、物価も2倍になったとき、正しいものは？
1: 買えるパンの数（実質）は変わらない
2: 買えるパンの数も2倍
3: 生産が2倍になる
4: 利子率が2倍になる
C: 1
E: 名目が2倍でも物価も2倍なら、実質は同じ。
ほかの選択肢：物価も2倍なので、買える数は2倍にならない。生産や利子率は、お金の数字だけでは変わらない。
```

```quiz
Q: お金の量を変えても、生産や雇用などの実質の量は変わらない、という考えを何という？
1: 貨幣の中立性
2: リカードの等価定理
3: 政策無力命題
4: 資本の逓減
C: 1
E: 貨幣の中立性。値段や給料が自由に動く、という仮定のもとでの結論。
ほかの選択肢：リカードの等価定理は減税の話（8講）。政策無力命題は予想された政策の話（13講）。資本の逓減は成長の話（15講）。
```

```quiz
1: 一般均衡

4: 総生産ギャップ
C: 1
E: 一般均衡。この講は、すべての市場が同時につり合う姿を見る。
ほかの選択肢：部分均衡は1つの市場だけを見る。不均衡・総生産ギャップは、つり合っていない状態の話（14講）。
```

```quiz
Q: この講のモデルで、実質利子率を決めるつり合いは？

2: 現金 ＝ 預金
3: 輸出 ＝ 輸入

C: 1
E: 貯蓄（資金を出す側）と、投資と政府の赤字（資金を使う側）がつり合う（貸付資金説）。
ほかの選択肢：現金＝預金、輸出＝輸入、給料＝物価は、実質利子率を決めるつり合いではない。
```

```quiz
1: 雇用がふえる
2: 実質利子率が上がる
3: 実質賃金が下がる
4: 実質利子率が下がる
C: 4
E: 資金の需要がふえるので、実質利子率は上がる。
ほかの選択肢：1〜3はこの講の結果。資金がもっと必要になるので、利子率は上がる（下がるはまちがい）。
```

```quiz

1: 上がる
2: 下がる
3: 変わらない

C: 1

ほかの選択肢：今の生産性が上がるときは利子率が下がる。将来の場合は逆なので注意。
```

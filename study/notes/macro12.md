# 上級マクロ経済論 12講 ― お金をふやすと、どうなる？

韓国の放送大学「上級マクロ経済論」12講を、むずかしい言葉をへらして、やさしくまとめたもの。（　）の中は試験に出る正式な言い方。

**この回の答え：このモデルでは、収入や働く量や利子率は「働く市場」と「物の市場」だけで決まり、お金の市場で決まるのは物価だけ。だからお金をふやしても物価が上がるだけ（貨幣の中立性）。**

```flow
働く市場で 働く量と給料 → 物の市場で 収入と利子率 → お金の市場で 物価
```

## 1. 3つの市場をいっしょに見る
- 働く市場・物の市場・お金の市場が、全部同時につりあう（一般均衡）。
- 政府のお金の出入りも、つじつまが合う（政府の予算制約）。

| 市場 | つりあい | ここで決まる |
|---|---|---|
| 働く市場（労働市場） | 雇いたい量 ＝ 働きたい量 | 働く量・給料（実質賃金） |
| 物の市場 | 買いたい量 ＝ 作れる量 | 収入（所得 Y）・利子率（実質利子率 r） |
| お金の市場 | お金の量 ＝ 持ちたいお金の量 | 物価 P |

> 補足：政府の予算制約は「使うお金 ＋ 前の借金の返済 ＝ 税 ＋ 新しい借金」。

## 2. ふつうのモデル（AD-AS）とのちがい
| | このモデル（新しい古典派） | AD-AS（ケインズ派など） |
|---|---|---|
| 式の作り方 | 一人ひとりの「いちばんよい選び方」から作る | データを見て決める |
| お金の効き方 | 物価にだけ効く | 利子率を通して景気にも効く |
| 値段と給料 | 短い間でも自由に動く | 短い間は給料が動きにくい |

### 2.1 昔のデータの式は使えない
- 政策が変わると、人の予想と行動も変わる。式の数字も変わってしまう。
- だから、過去のデータで作った式で新しい政策を評価するのはまちがい（ルーカス批判）。
- 一人ひとりの選び方から式を作るこのモデルは、この批判に比較的強い。

### 2.2 本当の量とお金の量は別々に決まる
- 本当の量（収入・働く量・給料・利子率）は物と働く市場で、物価はお金の市場で、別々に決まる（古典派の二分法）。
- 利子率は「借りたいお金」と「貸したいお金」で決まる。お金の市場とは関係ない（貸付資金説）。

```eq
投資 + 政府の赤字 = 人々の貯金
```
- 正式には I(r)＋(G−T)＝S(Y,r)。これは物の市場のつりあいと同じこと。

## 3. 政府がお金を使うと（財政政策）
```flow
政府の支出↑ → 物を買う量↑ → 将来の税↑で一生のお金がへる → 休みをへらして多く働く → 作る量↑
```
| | 結果 |
|---|---|
| 収入 | ふえる |
| 利子率 | 上がりやすい |
| 働く量 | ふえる |
| 給料（実質賃金） | 下がる |
| 物価 | 古典派の見方では下がる |

## 4. お金をふやすと（金融政策）
```bars
お金の量 | 200 | 2倍 | b
物価 | 200 | 2倍 | r
収入・働く量 | 100 | 変わらない | m
```
- お金が2倍になると、物価も2倍。収入や働く量は変わらない。

### 4.1 でも現実は…
- データでは、お金がふえると収入や雇用もふえやすい。
- 利子率は「お金の値段」なのに、お金の量が利子率に効かないのは不自然。

## 5. 技術がよくなると（生産性のショック）
| | 利子率 | 働く量・収入 | 物価 |
|---|---|---|---|
| 今の技術がよくなる | 下がる | ふえる | 下がる |
| 未来の技術がよくなる | 上がる | ふえる | 下がる |

- 技術の力全体を「全要素生産性」という。
- 今よくなる：作れる量がふえ、利子率は下がる。
- 未来がよくなる：投資がふえ、利子率が上がる。利子が高いと「今働いて、あとで休む」ほうが得なので、今多く働く（異時点間代替）。

## 6. 金融危機をこのモデルで見ると
```flow
先が見えない・資産の値段↓ → お金を借りにくい → 消費・投資↓ → 物を買う量↓
```
| | モデルの答え | 現実（2008年のあと） |
|---|---|---|
| 収入・雇用 | へる | へった（合う） |
| 物価 | 上がる | 上がらなかった（合わない） |
| 給料（実質賃金） | 上がる | のびなかった（合わない） |

- このモデルだけでは、金融危機の不況をうまく説明できない。

## 7. まとめ（6点）
1. 3つの市場が同時につりあう（一般均衡）。
2. 式は一人ひとりの選び方から作る。昔のデータの式は使えない（ルーカス批判）。
3. 利子率は「投資＋政府の赤字＝貯金」で決まる（貸付資金説）。
4. 政府の支出↑：収入↑、利子率は上がりやすい。
5. お金↑：物価が同じ割合で上がるだけ（貨幣の中立性）。でも現実とは合わない。
6. 技術↑は収入↑・物価↓。金融危機は物価と給料の動きが現実と合わない。

## 8. 確かめる問い：答えを言ってから開く
```quiz
Q: 一般均衡とは？
A: 働く市場・物の市場・お金の市場が、同時につりあうこと。
Q: 収入と利子率はどこで決まる？ 物価は？
A: 収入と利子率は物の市場（と働く市場）。物価はお金の市場。
Q: ルーカス批判とは？
A: 政策が変わると人の行動も変わるので、昔のデータの式で政策を評価するのはまちがい、という考え。
Q: 古典派の二分法とは？
A: 本当の量と物価が、別々の場所で決まること。
Q: 貨幣の中立性とは？
A: お金をふやしても、収入や働く量は変わらないこと。
Q: 貸付資金説の式は？
A: 投資＋政府の赤字＝人々の貯金。I(r)＋(G−T)＝S(Y,r)。
Q: 政府が支出をふやすと、なぜ人は多く働く？
A: 将来の税がふえて一生のお金がへるから。
Q: 政府が支出をふやすと、収入と利子率は？
A: 収入はふえる。利子率は上がりやすい。
Q: お金の量を2倍にすると？
A: 物価が2倍になるだけ。収入や働く量は変わらない。
Q: 貨幣の中立性が現実と合わない理由を1つ。
A: データでは、お金がふえると収入や雇用もふえやすい。
Q: 今の技術がよくなると、利子率と物価は？
A: どちらも下がる。
Q: 未来の技術がよくなると、利子率は？
A: 投資がふえて、上がる。
Q: 利子が高いと今多く働くのはなぜ？
A: 今働いて、あとで休むほうが得だから（異時点間代替）。
Q: 金融危機で、モデルが現実と合わない点は？
A: モデルでは物価と給料が上がるが、現実は上がらなかった。
```

## 9. 自分の暮らしにつなげる
- 「お金を刷ればみんな豊かになる？」に、このモデルは「物価が上がるだけ」と答える。現実は、短い間は景気に効き、長い目では物価に出やすい。

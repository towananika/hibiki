# 上級マクロ経済論 12講 ― お札が増えると、豊かになる？

**買える物が増えることと、お金の数字が増えることは違います。** この講では、値段や給料が自由に動くモデル（新古典派のモデル）で、「実際の生産」と「お金の数字」がどう別々に決まるかを見ます。第8〜11講でバラバラに学んだ話を、ここで1つにまとめる回です。

```flow
物の市場 → 労働の市場 → お金の市場 → 3つが同時につり合う
```

## 1. パンもお金も、2倍になった？

ある町で、パンは1個100円。お金の量だけが2倍になり、パンの値段も200円になったとします。

持つお金が1,000円から2,000円になっても、買えるのはどちらも **10個** です。パンを作る力が増えていなければ、お札が増えただけでは豊かになりません。

```eq
買えるパン10個 = 2,000円 ÷ 1個200円
```

お金で測った額を **名目**、物価を考えた購買力や量を **実質** といいます。この講の「所得」は主に実質所得です。

```quiz
Q: 給料と物価が同じ割合で2倍になったら、買える量は？
1: 買える量は同じ
2: 買える量は2倍
3: 買える量は半分
4: 買える量は必ずゼロ
C: 1
E: 同じです。名目の給料は増えても、実質の給料は変わりません。ほかの選択肢：2は物価も2倍になっていることを忘れた答え。3・4は物価が上がった分だけ給料も上がるので、あてはまらない。
```

## 2. 3つの市場を、同時に見る

| 市場 | 比べるもの | ここで決まるもの | 何講でやった？ |
|---|---|---|---|
| 労働の市場 | 働きたい量と、雇いたい量 | 雇用 N（働く人の量）と実質賃金 w（物で測った給料） | 10講 |
| 物の市場 | 買いたい量と、作れる量 | 所得 Y（実質の生産）と実質利子率 r（物で測った金利） | 8・9講 |
| お金の市場 | 持ちたいお金と、供給されるお金 | 物価 P | 11講 |

この3つが全部つり合う状態を **一般均衡** といいます。政府も、長い目では「使う分は税金や借金でまかなう」と考えます（政府の予算の制約）。

> 補足（式で書くと）：労働 N^d＝N^s、物 Y^d＝Y^s、お金 M＝P×L(Y,r)。M はお金の量、P は物価、L(Y,r) は「持ちたい実質のお金」です。

```quiz
Q: 一般均衡とは？
1: 労働市場だけがつり合うこと
2: すべての商品の価格が同じになること
3: 労働・物・お金など、関係する市場が同時につり合うこと
4: 全員が同じ金額の給料を得ること
C: 3
E: 関係する市場が同時につり合う状態です。ほかの選択肢：1は1つの市場だけを見る話（部分均衡）。2と4は、一般均衡の意味とは関係がない。
```

## 3. 実際の量と、お金の数字はわかれている

このモデルのいちばんの特徴です。

```flow
労働の市場と物の市場 → 所得・雇用・実質賃金・実質利子率が決まる → お金の市場 → 物価だけが決まる
```

- 所得・雇用・実質賃金・実質利子率（**実質の量**）は、お金と関係なく、労働の市場と物の市場だけで決まる。
- お金の市場が決めるのは、**物価（名目の量）だけ**。

この「実質」と「名目」が別々に決まることを **古典派の二分法** といいます。その結果、お金の量を変えても実質の量は変わりません。これが **貨幣の中立性** です。

```eq
実質のお金の量 = 名目のお金の量 ÷ 物価
```

名目のお金が2倍でも、物価が2倍なら、実質のお金は同じです。

> 補足：この結論は「値段や給料が自由に動く」などの仮定のもとでの話です。現実の短期の金融政策が効かない、と決めつける話ではありません。

```quiz
Q: 貨幣の中立性とは？
1: お金が増えると必ず生産も同じ割合で増える
2: お金の量だけを変えても、生産や雇用など実質の量は変わらない
3: お金が増えても物価は絶対に変わらない
4: 中央銀行が何も政策をしないこと
C: 2
E: お金の量だけ変えても、実質の量は変わらないことです。ほかの選択肢：1は逆。3も逆で、変わるのは物価。4は中立性の意味ではない。
```

## 4. 実質利子率は、どうやって決まる？

設備を買う会社や、赤字の政府は、お金（資金）を借りたいと考えます。一方、家計は貯金（貯蓄）で資金を出します。

```eq
家計の貯蓄（出す側） = 会社の投資 + 政府の赤字（使う側）
```

実質利子率が、この「出す側」と「使う側」をつり合わせます。これを **貸付資金説** といいます。

ここがポイントです。**実質利子率は、お金の市場ではなく、物の市場（資金の貸し借り）で決まる**。だから、お金の量を変えても、実質利子率は動きません。

> 補足（式で書くと）：S(Y,r)＝I(r)＋(G−T)。S は貯蓄、Y は実質所得、r は実質利子率、I は投資、G は政府の購入、T は税。輸出入のない経済を考えています。物の市場のつり合いを書き直しただけなので、同じ式です。

```quiz
Q: 貸付資金説では、何と何がつり合う？
1: 現金の枚数と、商品の種類
2: 人口と、企業の数
3: 物価と、名目の給料の金額
4: 貯蓄と、投資・政府の赤字に必要な資金
C: 4
E: 貯蓄と、投資や政府の赤字に必要な資金です。その調整を実質利子率がします。ほかの選択肢：1〜3は、実質利子率を決めるつり合いではない。
```

## 5. 総需要・総供給のモデルとのちがい

以前の「総需要・総供給のモデル」（ケインズ派）と、この講のモデル（新古典派）には、3つのちがいがあります。

| | 総需要・総供給のモデル | この講のモデル |
|---|---|---|
| ① 作り方 | 現実を見て、消費や投資の決め方を「仮定」する | 人や会社の最適な行動から「導き出す」 |
| ② お金と実質 | お金が実質に影響する（金利を通じて） | 実質とお金は別。お金は中立 |
| ③ 値段と給料 | 短期は給料が動きにくい（硬い） | 短期でも自由に動き、いつもつり合う |

②の理由は、金利の決まり方が違うからです。総需要・総供給のモデルではお金の市場で金利が決まり、この講では物の市場で決まります。

①は **ルーカス批判** から来ています。「昔のデータで決めた式は、政策が変わると、人の予想や行動が変わるので、使えなくなる」という注意です。だから行動のルールを最初から人の最適な行動で導いておこう、という考えです。データを使うな、という意味ではありません。

たとえば「今回だけの減税」と「今後も続く減税」では、同じ金額でも使い方が変わりえます。

```quiz
Q: ルーカス批判は、データを使ってはいけないという意味？
1: 政策が変わると過去の関係が変わりうるという注意
2: データを一切使うなという主張
3: 人の予想は政策で変わらないという主張
4: 昔の式はどんな政策にも必ず使えるという主張
C: 1
E: 違います。政策が変わると人の予想や行動も変わるので、昔の関係がそのまま続くとは限らない、という注意です。ほかの選択肢：2は言いすぎ。3と4は、批判の内容と逆。
```

## 6. 政府の購入が増えると？

政府が道路工事などを増やすと、物の買いたい量が増えます。さらに、このモデルでは「将来の税金が増える」と家計が考えるので、使えるお金が減ったと感じて、休みを減らして多く働きます。

```flow
政府の購入が増える → 将来の増税を見こむ → 労働供給が増える → 雇用と生産が増える
```

| 変数 | どうなる？ |
|---|---|
| 所得 Y（実質の生産） | **必ず増える**（買う量も、作る量も増えるから） |
| 実質利子率 r | 資金の需要が増えるので、上がるのが基本ケース（上がらない場合もある） |
| 雇用 N | 増える（金利が上がると、今働くほうが得になり、さらに増える） |
| 実質賃金 w | 下がる |
| 物価 P | お金の需要の考え方しだい（下記） |

物価は、持ちたいお金が「所得」で決まると考える古典派では下がり、「金利」にも敏感だと考えるケインズの見方では上がることもあります。

> 補足：政府の予算にも制約があります。支出や借金の返済は、税・新しい借金などで賄います。

```quiz
Q: このモデルで政府の購入が増えたとき、家計が多く働く理由は？
1: 紙幣が増えれば必ず働くから
2: 将来の税負担を見こみ、使えるお金が減ったと感じるため
3: 休みの価値が完全に消えるから
4: 政府の購入が家計の給料を必ず倍にするから
C: 2
E: 将来の税負担を見こんで、生涯に使えるお金が減ると考え、休みを減らす方向に動くというモデルです。ほかの選択肢：1は、お札と働く量は無関係。3と4は、モデルにない話。
```

## 7. お金の量を増やすと？

中央銀行がお金の量を2倍にしたとします。

- 物価 P も、**同じ割合で上がる**（2倍になる）。
- 所得・雇用・実質賃金・実質利子率は、**何も変わらない**。

お金の市場だけが動いて、実際の経済は動かない。これが貨幣の中立性です。

**でも、現実には信じられていません。** 理由は2つです。
- 実際のデータでは、お金の量は、所得・消費・投資・雇用と同じ方向に動く。
- 金利は「お金の価格」なのに、お金の量が金利に関係しないという貸付資金説の結論は、納得しにくい。

> 補足：あくまで、値段や給料が自由に動くという仮定のモデルの結論です。

```quiz
Q: このモデルで、お金の量が2倍になった。正しいのは？
1: 物価が2倍になり、実質の量は変わらない
2: 所得が2倍になる
3: 実質利子率が2倍になる
4: 雇用が2倍になる
C: 1
E: お金の量に比例して物価が上がり、実質の量は変わりません。ほかの選択肢：2〜4は、お金の量だけでは実質の量が変わらないので、まちがい。
```

## 8. 生産性（技術）がよくなると？

「今」よくなるのと、「将来」よくなると予想されるのでは、動きが逆になります。

| | 今、生産性がよくなる | 将来、生産性がよくなると予想 |
|---|---|---|
| 最初の動き | 雇いたい人が増える（労働需要が増える） | 今のうちに設備を買う（投資が増える） |
| 実質利子率 | **下がる** | **上がる** |
| 雇用・所得 | どちらも増える | どちらも増える |
| 物価 | 下がる | 下がる（所得が増えて、お金の需要が増える） |

利子率が上がると「今働いて、休みを将来に回そう」となり、利子率が下がると「今休もう」となります。これが第10講の **異時点間代替** です。

> 補足：今よくなるときは、金利が下がって働く量が減る力もあります。ただ、生産性が上がる直接の効果のほうが大きいと考えるので、雇用は増えます。技術の改善がいつも金利を下げる、という暗記はしないでください。

```quiz
Q: 将来の生産性がよくなる予想は、今の投資をどう動かす方向？
1: 必ずすべての設備を捨てる
2: 投資には一切関係しない
3: 今の技術が必ず悪化する
4: 将来に備える投資を増やす
C: 4
E: 将来、設備から得られる生産が増えると期待すれば、今のうちに設備をそろえる動機が強まります。ほかの選択肢：1〜3は、将来への期待と投資の関係に合わない。
```

## 9. 金融危機は、このモデルで説明できる？

2008年のような危機では、不安が広がり、土地や株の値段が下がります。すると、借りにくくなり、消費や投資が減ります。

```flow
消費・投資が減る → 実質利子率が下がる → 労働供給が減る → 雇用・所得が減る
```

モデルの答えは「所得と雇用は減る。実質賃金と物価は上がる」です。

| 結果 | 現実と合う？ |
|---|---|
| 消費・投資・所得・雇用が減る | **合う**（危機のあとの大不況のとおり） |
| 物価・実質賃金が上がる | **合わない**（実際は、給料が上がらず、物価も上がらない・下がった） |

つまり、「借りにくくなる」を足しただけでは、現実の不況は説明しきれません。

```quiz
Q: 金融危機を入れたこのモデルの結果で、現実に合わないのは？
1: 所得が減る
2: 雇用が減る
3: 消費と投資が減る
4: 物価と実質賃金が上がる
C: 4
E: 実際は、危機のあと給料の伸びがおくれ、物価も上がらない・下がる動きが多く出ました。ほかの選択肢：1〜3は現実の大不況と合う。
```

## 10. まず、この3つ

1. 名目はお金の数字、実質は物価を考えた量や購買力。お金の量を変えても、実質の量は変わらない（貨幣の中立性）。
2. 実質利子率は、貯蓄と投資・政府の赤字で決まる（貸付資金説）。物価だけがお金の市場で決まる。
3. 結論を読むときは、値段や給料が自由に動くなどの仮定も一緒に見る。

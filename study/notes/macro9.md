# 上級マクロ経済論 9講 ― 会社は、いつ機械を買う？

**新しい機械で増える稼ぎが、機械を使う費用より大きければ買う。** これが、この回の出発点です。

まずパン屋の例で考えます。式は、例がわかってから読めば大丈夫です。

## 1. パン屋に、オーブンを1台足す

パン屋が、新しいオーブンを買うか迷っています。

- オーブンの値段は **100万円**。
- 1年使うと、材料費などを引いた稼ぎが **20万円増える**とします。
- 1年後、オーブンは古くなって、売れる値段が **10万円下がる**とします。
- お金を借りる利子は、1年で **5万円**です。

機械の代金100万円を、毎年まるごと費用にするわけではありません。1年後にも機械には値うちが残るので、ここでは「1年間使う費用」を比べます。

```eq
使う費用15万円 = 利子5万円 + 値下がり10万円
```

20万円稼ぎが増えて、費用は15万円。**差し引き5万円の得**なので、この1台は買う価値があります。

> 補足：説明用の数字です。税金や機械の値上がりなどは、いったん考えません。「古くなって値うちが減ること」を減価償却（げんかしょうきゃく）といいます。

## 2. 得なら、何台でも買ってよい？

**同じだけ得をするとは限りません。** お客さんや働く人の数が同じなら、オーブンだけ増やしても使い切れなくなるからです。

| 追加するオーブン | その1台で増える年の稼ぎ | 年の費用 | 判断 |
|---|---|---|---|
| 1台目 | 20万円 | 15万円 | 買うと得 |
| 2台目 | 17万円 | 15万円 | 買うと得 |
| 3台目 | 12万円 | 15万円 | 買わない |

見るのは、店全体の稼ぎではなく、**「次の1台」で増える分**です。

```flow
次の1台の稼ぎを考える → 使う費用と比べる → 得なら追加する
```

機械の量を細かく調整できる理論では、増える稼ぎと費用が同じになる所まで増やします。実際のように1台ずつ買うなら、表のように得になる台数までです。

### 試験の言葉で読むと

- **資本**：生産に使う機械や建物。ここではオーブンです。
- **資本の限界生産（MPK）**：資本をもう1単位足すと、どれだけ生産が増えるか。
- **資本の使用者費用**：資本を一定期間使う費用。

機械の値段を1とし、生産物と同じ単位で比べる単純なモデルでは、次の形になります。

```eq
MPK = r + d
```

r は実質利子率、d は減価償却率です。「実質」は、物価の変化を考慮するという意味です。パン屋の費用15万円は、100万円の機械に対して **15%＝5%＋10%** に当たります。

自分のお金で買う場合も、利子を考えます。機械を買わずに運用すれば得られた利子を、あきらめるからです。これを **機会費用** といいます。

## 3. 何が変わると、機械を買う量が変わる？

### 利子が上がると、買いにくくなる

利子が5万円から10万円に上がると、使う費用は15万円から20万円に増えます。さっきまで得だった計画も、得ではなくなります。

```flow
利子が上がる → 機械を使う費用が増える → 得になる計画が減る → 投資が減る
```

ここでいう **投資** は、生産のために機械や建物を増やすことです。株を売り買いする話とは区別します。

| 変わること | 投資はどうなる？ | なぜ？ |
|---|---|---|
| 利子が上がる | 減る方向 | 使う費用が増える |
| 将来の生産性が上がる | 増える方向 | 同じ機械で多く作れる |
| 機械が早く古くなる | 一方向には決まらない | 費用は増えるが、買い替えも必要になる |

> 補足：ほかの条件は同じとして比べています。生産性とは、同じ人・設備でどれだけ作れるか、という力です。

## 4. 将来の稼ぎは、まだわからない

ここまでの例では、将来の稼ぎを数字で置きました。でも、社長は未来を知りません。

「来年もパンが売れるだろう」と思うと買いやすく、「売れないかもしれない」と思うと買い控えます。ケインズは、こうした **将来の見通しや、行動しようとする気持ち** も重視しました（アニマル・スピリット）。計算をしない、という意味ではありません。

### 試験で出る2つの言葉

- **資本の限界効率（MEC）**：設備の購入費と、将来得られると予想する収益から求める収益率。借りる利子率より高ければ、投資する理由になります。
- **投資の限界効率（MEI）**：投資を増やしたときの設備価格などの変化も考えた収益率。みんなが一度に設備を買って値上がりすると、同じ稼ぎでも収益率は下がります。

第9講の新古典派の2期間モデルは、「今」と「将来」に分けて、会社の判断を整理します。

**将来の設備＝今の設備の残り＋今の投資**。

## 5. 銀行が貸すときに、利子を上乗せすると？

銀行は「この会社は、きちんと返せるか」を完全には見分けられません。この情報の差を **情報の非対称性** といいます。

返してもらえない危険が大きいと、貸す利子に上乗せを求めます（債務不履行プレミアム x）。

```eq
借りて買う費用 = r + d + x
```

金融危機などで x が大きくなると、借りて投資する会社には負担です。投資が減る方向に働きます。条件を並べ直すと、ノートの式 **MPK2 − d − x ＝ r** になります。2 は「将来」を表します。

> 補足：このモデルでは、上乗せは借りる会社に直接効きます。現実の危機では、借金の少ない会社も売上の減少などの影響を受けます。

## 6. 株の値段から考える方法もある

もう1つの目安が **トービンの q（キュー）** です。

```eq
q = 市場で評価された資本の価値 ÷ 同じ資本をそろえ直す費用
```

たとえば、100万円でそろえられる設備が、市場では150万円の価値を生むと評価されていれば、q は1.5です。新しく設備を増やす動機になります。

- **q＞1**：増やす方向。
- **q＜1**：増やすのを控える方向。すぐに設備を捨てる、という意味ではありません。

会社全体を比べるのが「平均 q」、**次の1単位**を比べるのが「限界 q」です。投資の判断に直接関係するのは限界 q。単純なモデルでは、限界 q＝1 が MPK＝r＋d に対応します。

> 補足：株の時価総額だけで会社全体の資本価値を測れるとは限りません。借金もあるためです。平均 q と限界 q も、いつも一致するわけではありません。

## 7. 会社の話から、国全体の話へ

会社が設備を買うことも、国全体の「買いたい量」の一部です。

**家計の消費 C ＋ 会社などの投資 I ＋ 政府の購入 G ＝ 総需要 Yd**。ここでは、輸出入のない経済を考えます。

利子が上がると、会社は投資を減らす方向に動きます。家計の消費も減ると考えるこのモデルでは、国全体の需要が減ります。

縦に実質利子率、横に生産・所得を取ると、需要の線は **右下がり** です（実質総需要曲線。財市場のつり合いを表す IS 曲線に対応）。物価と生産を比べる図とは、縦軸が違います。

政府の購入が増えたり、将来の技術に期待して投資が増えたりすると、**同じ利子率でも需要が増える**ため、線が右へ動きます。

## 8. まず、この3つを言えれば大丈夫

1. 機械は「次の1台で増える稼ぎ」と「使う費用」を比べて買う。
2. 利子が上がると費用が増え、投資は減る方向に動く。
3. 将来の見通しや、銀行の貸す条件も投資を動かす。

## 9. 確かめる問い

```quiz
Q: 次のオーブンで年17万円稼ぎが増え、使う費用は年15万円。買うと得？
A: 得です。差し引き2万円増えるからです。店全体ではなく、追加する1台の稼ぎを見ます。
Q: なぜ、機械を何台でも買うわけではない？
A: お客さんや働く人が同じなら、機械だけ増やしても使い切れず、次の1台で増える生産が小さくなるからです。
Q: 自分のお金で買うなら、利子は考えなくてよい？
A: 考えます。買わずに運用すれば得られた利子をあきらめるからです。これが機会費用です。
Q: MPK＝r＋d は、何と何を比べている？
A: 次の1単位で増える生産と、その設備を使う費用（利子＋古くなる分）です。単位をそろえたモデルの条件です。
Q: 借りる利子の上乗せ x が増えると、投資は？
A: 借りて投資する会社の費用が増え、投資は減る方向に動きます。
Q: q＞1 は、何を表す？
A: そろえ直す費用より、市場で評価された資本の価値が高いことです。設備を増やす動機になります。
Q: 実質総需要曲線が右下がりというとき、縦軸は？
A: この講の図では実質利子率です。利子が高いほど、消費や投資が少なくなると考えます。
```

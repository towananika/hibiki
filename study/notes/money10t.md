# 貨幣金融論 10講【会話で読む】― 中央銀行のお金のかじ取り

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money10)」。

## 1. しくみの全体（5分）

```talk
B: 中央銀行は、景気をどうやって整えるの？
A: 金利を上げ下げしたり、お金の量を増やしたり減らしたりして、景気と物価をちょうどよくする。
B: 道具は？
A: 3つ。銀行への貸し出し（再割引）、銀行に積ませるお金（支払準備）、国債の売り買い（公開市場操作）。
B: 最後のゴールは？
A: 物価の安定、お金の仕組みの安全（金融安定）、みんなが働ける（完全雇用）と成長。
C: 道具 → 途中の目印 → 最後のゴール。
```

```card
要点
- 道具：貸し出し（再割引）／支払準備／国債の売買（公開市場操作）
- 途中の目印：通貨量・為替・インフレ率
- ゴール：物価安定・金融安定・完全雇用と成長
```

## 2. 効き目が届く5つの道（10分）
例：金利を下げたとき。

```talk
B: 金利を下げると、どうして景気がよくなるの？
A: 5つの道で届く。1つめは金利の道。会社は借りて投資し、家計はローンで買い物をする。
B: 2つめは？
A: 財産の値段の道（資産価格経路）。株や家の値段が上がると、会社は資金を集めやすくなり、家計は持っている財産が増えて気が大きくなる（資産効果）。
B: 3つめは？
A: 為替の道。自国の預金の利息が下がると、ウォン安になり、輸出が増える。輸入品は高くなる。
B: 4つめと5つめは？
A: 4つめは貸し出しの道（信用経路）。会社に余裕ができて、銀行も貸しやすくなる。5つめは予想の道（期待経路）。「景気がよくなる」と思うと、給料も物価も上がる。
C: 金利・財産の値段・為替・貸し出し・予想。
```

```card
要点
- ①金利の道 ②財産の値段の道（トービンの q・資産効果） ③為替の道 ④貸し出しの道 ⑤予想の道
- 先行きが暗いと、金利が低くても投資は増えにくい
- 大企業は銀行に頼らないので、④はあまり効かない
```

> 補足：トービンの q ＝ 会社の株の値打ち ÷ 同じ設備を新しく買う費用。1より大きいと、投資が得。

## 3. 昔ながらの3つの道具（5分）

```talk
B: 3つの道具は、それぞれどう使うの？
A: 支払準備は、預金のうち手元に置かせる割合。下げるとお金が増える。全部の銀行にすぐ効くけど、細かい調整ができない。
B: 貸し出しは？
A: 銀行に貸す量や金利を変える。困った銀行を助けられる。先進国ではあまり使わない。
B: 国債の売り買いは？
A: 買うとお金が増えて金利が下がる。売るとお金が減って金利が上がる。細かく調整でき、まちがえてもすぐ直せるから、いちばんよく使う。
C: 国債を買う → お金が増える → 金利が下がる。
```

```card
要点
- 支払準備：すぐ強く効くが、細かい調整が苦手
- 再割引・貸し出し：困った銀行を助ける。先進国ではあまり使わない
- 公開市場操作：買う＝お金が増え金利が下がる／売る＝お金が減り金利が上がる。いちばんよく使う
```

## 4. 金利がほぼ0のときの特別な道具（5分）

```talk
B: 金利がもう下げられないときは？
A: 特別な道具がある。1つは先の約束（フォワードガイダンス）。「しばらく低い金利を続けます」と前もって言う。
B: もう1つは？
A: お金を大量に流す（量的緩和）。国債などをたくさん買う。アメリカは、持つ資産を約1兆ドルから約9兆ドルに増やした（2022年）。
B: 組み替えって？
A: オペレーション・ツイスト。短い国債を売って、長い国債を買い、長期金利を下げる。
C: 先の約束と、量的緩和。
```

```card
要点
- フォワードガイダンス：低い金利を続けると、前もって約束する
- 量的緩和：国債などを大量に買って、お金を増やす
- オペレーション・ツイスト：短い国債を売り、長い国債を買う → 長期金利を下げる
```

# 伝統社会と生活文化 13講 ― 生まれる・大人になる・結婚する

韓国の放送大学「伝統社会と生活文化」13講（対談の講義、約45分）を、音声から文字を起こしてやさしくまとめたもの。（　）の中は試験に出る正式な言い方。人名や数字は聞き取りなので、少しずれているかもしれない。

```flow
子どもを願う → 生まれる（出産の儀式） → 100日・1歳 → 大人になる（冠礼） → 結婚（婚礼）
```

## 0. ひとことで
人の一生の節目の儀式（**人生儀礼**、一生儀礼）のうち、**生まれる・大人になる・結婚する** の回。
生まれることは「村に新しい仲間がふえる」こと。結婚は「子どもから、大人の男・女になる」いちばん大事な節目。
朝鮮の結婚式は、儒学者が中国式に変えようとしたけれど、**暮らしが変わるのに約600年** かかった。

> 補足：講師は「人生儀礼は、生まれるところ（出産の儀式）から数えるのがよい」と話していた。

## 1. 子どもを願う・おなかの子を守る
- 子が生まれないと、**山やお寺で祈ったり**（致誠）、家で手を合わせたりした。
- 赤ちゃんを産んだ家に米とわかめを持っていき、ごはんとスープを作ってあげて、少し分けてもらって食べる。産んだ人の服をもらって着る。そうして「子をさずかりたい」と願った。
- **胎教**：両班の家は心がまえの決まりにしたがった。身分を問わず **食べてはいけないもの**（うさぎの肉など）を守り、お葬式や結婚式にも行かなかった。

## 2. お産と、生まれたあと
- お産を手伝うのは、しゅうとめ・実家の母、いなければ村のお年寄り（**産ばあさん**）。
- 床にわらをしき、黒いスカートでお産をした。むずかしいお産のときは、夫の服を妻にかけるなどのおまじないもあった。

| もの・こと | 意味 |
|---|---|
| **胎夢**（たいむ） | 生まれる子の夢。大きな動物や植物なら男の子、小さいものなら女の子。虎や竜なら、えらい人になると期待した |
| **三神の膳**（三神床） | お産の部屋に、わかめ・水・米をそなえる。生まれたら、わかめスープとごはんを子の神さま（三神）にささげた |
| **胎のつぼ**（胎壺） | 胎（へその緒など）には命の力があると考えた。王室や両班はつぼに入れて山にうめ、ふつうの家は燃やすか、きれいな場所にうめた |
| **しめ縄**（禁縄） | 門に張る。左よりの縄。**赤ちゃんが生まれたしるし** と、**人が入らないようにして赤ちゃんを守る** 2つの意味。男の子は唐辛子、女の子は松の葉や紙をはさんだ |

- 3日目に、母も赤ちゃんもお湯で体を洗う。家族はこの日から赤ちゃんに会える。
- 7日目か21日目（三七日）にしめ縄を外す。ここで **親せきや近所の人が会いに来られる**。社会に「お披露目」する日。

```quiz
Q: 赤ちゃんが生まれた家の門に張った「しめ縄（禁縄）」の意味は？
1: お金持ちの家のしるし
2: 赤ちゃんが生まれたことを知らせ、人の出入りを止めて赤ちゃんを守る
3: 結婚式の日を知らせる
4: お葬式のしるし
C: 2
E: しめ縄は「生まれたしるし」と「出入り禁止で赤ちゃんを守る」の2つ。男の子は唐辛子、女の子は松の葉や紙をはさんだ。
ほかの選択肢：1、3、4はしめ縄の意味ではない。
```

## 3. 100日と1歳のお祝い
- 昔は、生まれてすぐや1歳になる前に亡くなる子が多かった。だからそれまでは、あまり期待をかけすぎないようにした。
- **100日** と **1歳（トル）** を越えると「元気に育つ」と考え、大きくお祝いした。
- 1歳のお祝いでは **トルジャビ**：いろいろな物を並べ、子が何をつかむかで将来をうらなう。男の子には筆・お金・本、女の子には糸巻きや物差しをつかんでほしいと願った。
- お膳には、きびだんご・糸の束・めん。**長生きと元気** を願うもの。

```quiz
Q: 1歳のお祝いで、並べた物の中から子が何をつかむかで将来をうらなう行事は？
1: トルジャビ
2: 冠礼
3: 胎夢
4: 奠雁礼
C: 1
E: トルジャビ。糸の束やめんは長生きの願い。
ほかの選択肢：2は大人になる儀式。3は生まれる前に見る夢。4は結婚式で花婿が雁をささげる儀式。
```

## 4. 大人になる儀式（冠礼）
いまの **成人式** にあたる。子どもから大人になるあぶない時期を、儀式で無事に越えさせる。
| | すること |
|---|---|
| 両班の男性（冠礼） | 髪を頭の上でまとめ（まげ）、大人の冠をかぶる |
| 両班の女性（笄礼） | 髪を後ろでまとめ、かんざしをさす |
| ふつうの家の男性 | 大きな石を持ち上げて、大人の力を見せる |

- 朝鮮では、冠礼より **結婚式のほうがずっと大事** だった。冠礼は結婚の前に、つけ足しのように行うことも多かった。

## 5. 結婚式は3つの形がある
| 形 | 中身 |
|---|---|
| **古い伝統の婚礼**（婿入り婚、男帰女家婚） | 1日目、花婿が花嫁の家で親の許しを得て、まず同じ部屋で寝る。2日目、花婿の家族や友だちが来て宴会。3日目、2人がごちそうのお膳を受けて完成。花婿はしばらく花嫁の家で暮らす |
| **中国式の婚礼**（親迎） | 花婿が当日に花嫁を **自分の家** に連れてきて、式をして、自分の親にあいさつする |
| **新しい伝統の婚礼** | 式（大礼）を **先に** して、その日に同じ部屋で寝る。でも最初の夜は花嫁の家 |

- 世界の約7割の社会では、結婚後に夫の家で暮らす。朝鮮では、婿入りと嫁入りが **ならんで** あったと考えられる。
- 儒学者（鄭道伝など）が問題にした点：①式の前に夫婦が寝る、②花嫁の家で式をする、③花婿の親へのあいさつがない。
- 中国の昔の6つの手順（**六礼**）を、朱子は4つ（**四礼**：結婚の相談→申しこみの品→贈り物→花嫁を迎える）にまとめた。

**どれくらいかけて変わった？**
```flow
1300〜1400年代 儒学者が変えようとする → 1600年代 「式を先に、その日に寝る」が定着 → 1800年代 ソウル・京畿の一部で「当日に夫の家へ」 → 1970年代ごろまで
```
- 「花嫁がその日に夫の家に行き、夫の家で最初の夜をすごし、夫の親にあいさつする」は、1800年代でも **一部の地域だけ**。

```quiz
Q: 朝鮮の儒学者が、もとの朝鮮の結婚のやり方で問題にしなかったものは？
1: 式の前に夫婦が同じ部屋で寝ること
2: 花嫁の家で式をすること
3: 花婿の親へのあいさつがないこと
4: 仲人を通して相手を決めること
C: 4
E: 儒学者が問題にしたのは1〜3の3つ。仲人を通す結婚は、むしろ正しいやり方とされた。
ほかの選択肢：1、2、3は、鄭道伝などが「直すべき」と言った点。
```

## 6. 式の当日（大礼）
| 道具・場面 | 意味 |
|---|---|
| 四柱（生まれた年・月・日・時）の手紙 | 花婿の家から花嫁の家へ送る |
| **箱（函）** | 結婚の書状や花嫁への贈り物、品物のリストを入れて運ぶ。最近まで続いた行事 |
| 式のテーブル（醮礼床） | 雌鳥と雄鳥、ろうそく、松と竹、もち、小豆、大豆。2人が仲よく暮らせるように |
| 花婿が花嫁の家へ行く（初行） | 名前は「迎える（親迎）」でも、実際は花婿が花嫁の家で式をした |

**大礼の3つの流れ**
1. **奠雁礼**（てんがんれい）：花婿が花嫁の母に **雁（がん）** をささげる
2. **交拝礼**：2人がおじぎをし合う
3. **合巹礼**（ごうきんれい）：お酒の杯を交わして飲む

- そのあと花嫁は **かご（輿）** で夫の家へ（**新行**）。悪いものを防ぐため、かごに虎の皮（なければ虎もようの布）をかけた。行くのは当日・数日後・年が明けてからなど、いろいろ。
- 1年ほどして花嫁が実家に里帰りして（**覲親**）、結婚がしめくくられる。
- 特徴は **2回の宴会**（花嫁の家と花婿の家）と **2回のごちそうのお膳**（花嫁が夫の家で、花婿が花嫁の家で）。

```quiz
Q: 結婚式の大礼で、花婿が花嫁の母に雁をささげる儀式は？
1: 交拝礼
2: 合巹礼
3: 奠雁礼
4: 覲親
C: 3
E: 奠雁礼（てんがんれい）。そのあと交拝礼（おじぎ）、合巹礼（杯を交わす）と続く。
ほかの選択肢：1は2人がおじぎをし合う儀式。2はお酒の杯を交わす儀式。4は花嫁の里帰り。
```

## 7. いろいろな人の結婚
- **巫女の儀式（クッ）**：結婚がうまくいくかを、前もって占う儀式もあった。
- **ふつうの民**：すべての手順はできなくても、「花嫁の家で式と宴会、花婿の家でも宴会」の形は守った。
- **奴婢**：水を1杯置いて、おじぎをし合うだけのことも。主人が手伝うこともあった。
- **20世紀**：昔の婚礼は「むだな形だけの儀式」と批判され、宗教団体や知識人が **新しい式（新式婚礼）** を広めた。

## ひびきの暮らしでいうと
- 100日・1歳のお祝いは、「ここまで元気に育った」ことへの感謝。節目ごとに **ここまでの自分をほめる** のは、いまも大事。
- 結婚の形が600年かけて変わったように、**新しい習慣は少しずつしか根づかない**。勉強のやり方も、少しずつ変えていけばいい。

## 期末テストの練習

> 補足：期末（単位認定試験）は、4つから1つ選ぶ問題が中心。「正しくないものは？」「（　）に入る言葉は？」の形が多い。下は形をまねて作った練習問題（本物の過去問ではない）。

```quiz
Q: 朝鮮の出産の儀式について、正しくないものは？
1: 生まれる子の夢（胎夢）で、男の子か女の子かを占った
2: 胎は命の力があるとして、つぼに入れて山にうめることもあった
3: しめ縄は生まれた日から1年間、外さなかった
4: 3日目に、母も赤ちゃんも体を洗った
C: 3
E: しめ縄は7日目か21日目（三七日）に外した。そこで親せきや近所の人が会いに来られた。
ほかの選択肢：1、2、4はどれも講義のとおり正しい。
```

```quiz

2: 男帰女家婚（婿入り婚）
3: 新行
4: 四礼
C: 2
E: 男帰女家婚（古い伝統の婚礼）。3日目に式が完成した。
ほかの選択肢：1は花婿が花嫁を自分の家に迎える中国式。3は花嫁がかごで夫の家に行くこと。4は朱子がまとめた結婚の4つの手順。
```

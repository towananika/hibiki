# 伝統社会と生活文化 13講【会話で読む】― 生まれる・大人になる・結婚する

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=tradition13)」。

## 1. 生まれる（10分）

```talk
B: 人生の節目の儀式は、どこから数える？
A: 生まれるところ（出産の儀式）から。生まれることは「村に新しい仲間がふえる」こと。人生儀礼（一生儀礼）という。
B: 生まれる前は？
A: 子が生まれないと山やお寺で祈った（致誠）。おなかの子を守る胎教では、身分を問わず食べてはいけないもの（うさぎの肉など）を守った。
B: お産のときは？
A: 手伝うのはしゅうとめ・実家の母、いなければ産ばあさん。お産の部屋に、わかめ・水・米をそなえる（三神床）。門には左よりのしめ縄（禁縄）。赤ちゃんが生まれたしるしと、人を入れず守る意味。
B: いつ人に会える？
A: 3日目に家族。7日目か21日目（三七日）にしめ縄を外すと、親せきや近所の人が来られる。社会へのお披露目。
C: 胎夢・三神床・禁縄・三七日。
```

```card
要点
- 人生儀礼は、生まれるところから数える
- 三神床：わかめ・水・米をそなえる／胎壺：胎をつぼに入れてうめる
- 禁縄：生まれたしるし＋赤ちゃんを守る（男は唐辛子、女は松の葉や紙）
- 三七日：しめ縄を外し、人に会える
```

## 2. 100日・1歳と、大人になる儀式（5分）

```talk
B: 100日と1歳を大きく祝うのは、なぜ？
A: 昔は幼いうちに亡くなる子が多く、それまでは期待しすぎなかった。100日と1歳（トル）を越えると「元気に育つ」と考えた。
B: 1歳のお祝いは？
A: トルジャビ。物を並べ、子が何をつかむかで将来をうらなう。お膳のきびだんご・糸・めんは、長生きと元気の願い。
B: 大人になる儀式は？
A: 両班の男性は冠礼（まげに冠）、女性は笄礼（かんざし）。ふつうの家の男性は大きな石を持ち上げて力を見せた。でも朝鮮では、冠礼より結婚式のほうがずっと大事。
C: 100日と1歳が最初の山。
```

```card
要点
- 100日・1歳（トル）：越えると元気に育つ。トルジャビで将来をうらなう
- 冠礼（男）・笄礼（女）＝いまの成人式
- 冠礼より結婚式のほうがずっと大事だった
```

## 3. 結婚式の3つの形（10分）

```talk
B: 結婚式の形は？
A: 3つ。古い伝統の婚礼（婿入り婚、男帰女家婚）は、花婿が花嫁の家で式をして、しばらくそこで暮らす。中国式（親迎）は、花婿が花嫁を自分の家に連れてくる。新しい伝統の婚礼は、式（大礼）を先にして、その日に同じ部屋で寝る。最初の夜は花嫁の家。
B: 儒学者は何が不満？
A: 式の前に夫婦が寝る、花嫁の家で式をする、花婿の親へのあいさつがない、の3つ。鄭道伝などが問題にした。中国の六礼を、朱子は四礼にまとめた。
B: どれくらいかけて変わった？
A: 1300〜1400年代に変えようとして、1600年代に「式を先に、その日に寝る」が定着。1800年代にソウル・京畿の一部で「当日に夫の家へ」。1970年代ごろまでかかった。約600年。
C: 新しい習慣は少しずつしか根づかない。
```

```card
要点
- 婿入り婚（男帰女家婚）／親迎（中国式）／新しい伝統の婚礼（式を先に）
- 儒学者の不満：式の前に寝る／花嫁の家で式／親へのあいさつなし
- 朱子：六礼 → 四礼
- 暮らしが変わるのに約600年
```

## 4. 式の当日と、いろいろな人の結婚（10分）

```talk
B: 式の当日の流れは？
A: 大礼は3つ。奠雁礼（花婿が花嫁の母に雁をささげる）、交拝礼（おじぎをし合う）、合巹礼（お酒の杯を交わす）。式のテーブル（醮礼床）には雌鳥と雄鳥、ろうそく、松と竹など。2人が仲よく暮らせるように。
B: そのあとは？
A: 花嫁はかご（輿）で夫の家へ（新行）。魔よけに虎の皮をかけた。約1年後に里帰り（覲親）して結婚がしめくくられる。2回の宴会と2回のごちそうのお膳が特徴。
B: 身分ごとのちがいは？
A: ふつうの民は、花嫁の家で式と宴会、花婿の家でも宴会の形は守った。奴婢は水を1杯置いて、おじぎをし合うだけのことも。20世紀には昔の婚礼が批判され、新式婚礼が広まった。
C: 奠雁礼・交拝礼・合巹礼。
```

```card
要点
- 大礼：奠雁礼（雁）→ 交拝礼（おじぎ）→ 合巹礼（杯）
- 新行：花嫁がかごで夫の家へ（虎の皮）／覲親：約1年後の里帰り
- 2回の宴会と2回のお膳
- 奴婢は水1杯とおじぎだけのことも
```

# 上級マクロ経済論 13講【会話で読む】― 景気の波は、なぜ起こる？

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=macro13)」。

## 1. 売値が上がった。なぜ？（5分）

```talk
B: パンの売値が上がったら、パン屋はどう考える？
A: 2つの場合がある。自分のパンだけ人気が出て高く売れるなら、もっと作ると得。でも、世の中の物価全体が上がったなら、材料も高くなるから、得が増えたとは限らない。
B: その違いが、すぐわからない？
A: そう。ここから始めるのが、ルーカスの説明（不完全情報モデル）。予想外にお金がふえて物価全体が上がっても、初めは自分の商品だけの値上がりだと受け取る。
B: それで生産がふえる？
A: ふえる。合理的な人でも、情報が足りなければ、そうなる。
C: 全体の値上がりを、自分だけの値上がりと取りちがえる。
```

```card
要点
- ルーカス：値段の変化が「自分だけ」か「全体」か、見分けられない（不完全情報モデル）
- 予想外のお金の増加 → 自分の商品だけ有利と受け取る → 生産がふえる
```

## 2. 予想できる変化と、できない変化（5分）

```talk
B: みんなが物価上昇を予想していたら？
A: 自分の売値が上がっても、「全体が上がったのだろう」と判断できる。だから、生産はふえない。
B: 結論は？
A: ルーカスの単純なモデルでは、予想された金融政策は、生産を持続的にはふやせない。政策無力性の命題という。予想外の変化なら、一時的に生産が動く。
B: 弱点は？
A: 全体の物価がわかれば、受け取りちがいは直る。何年も続く景気の波を、これだけで説明するのは難しい。
C: 予想された政策 ＝ 実質は動かない。
```

```card
要点
- 政策無力性の命題：予想された金融政策は、生産を持続的にはふやせない
- 予想外の変化なら、一時的に生産が動く
- 弱点：何年も続く景気の波を説明しにくい
```

## 3. もう1つの説明：生産性（RBC）（10分）

```talk
B: 景気の波を、別の理由で説明できる？
A: 新しい製法で、同じ人手と設備から多く作れるようになった場合。これは受け取りちがいではなく、実際に作る力が変わった例。
B: 流れは？
A: 生産性がよくなる → 人手や設備を使う価値が上がる → 雇用や投資がふえる → 生産がふえる。
B: この理論の名前は？
A: 実物的景気循環理論（RBC）。キドランドやプレスコットらが発展させた。
B: 「実物的」と「ショック」って？
A: 実物的は、お金の数字ではなく、生産性などに注目すること。ショックは、モデルの外から起こる変化で、悪い出来事だけを指す言葉ではない。
C: 生産性の変化から、景気を説明する。
```

```card
要点
- RBC（実物的景気循環理論）：実際の生産性の変化から景気を説明する
- 「実物的」：お金の数字ではなく生産性などに注目
- 「ショック」：モデルの外から起こる変化（悪い出来事だけではない）
- 生産性の改善が将来も続くと予想されると、設備投資にもつながる
```

## 4. データで見る（5分）

```talk
B: データでは、何を比べるの？
A: 生産・雇用・物価などが、GDPと一緒にどう動くか。GDPと同じ向きに動くのが景気順応的、逆の向きが景気逆行的。
B: 相対変動性って？
A: その変数の標準偏差 ÷ GDPの標準偏差。標準偏差は、変動の大きさを測る数字。投資は消費より大きく揺れやすい。
B: 韓国のデータは？
A: 1970〜2019年の整理では、消費・投資・雇用・実質賃金・M1はGDPと同じ向き。実質利子率・物価は逆向き。
C: どの国・時期でも同じとは限らない。
```

```card
要点
- 景気順応的：GDPと同じ向き／景気逆行的：GDPと逆向き
- 相対変動性 ＝ その変数の標準偏差 ÷ GDPの標準偏差
- 韓国（1970〜2019年の整理）：消費・投資・雇用・実質賃金・M1は同じ向き、実質利子率・物価は逆向き
```

## 5. 2つの説明をくらべる（5分）

```talk
B: ルーカスとRBCを比べると？
A: 波の出発点は、ルーカスが予想外のお金と不完全な情報。RBCは生産性の変化。
B: 生産がふえる理由は？
A: ルーカスは「自分の商品が有利」と受け取るから。RBCは実際に作る力が高まるから。
B: データと合う？
A: 実質賃金・物価の方向は、ルーカスはこの講のデータと合いにくく、RBCは合う部分がある。
B: 苦手な点は？
A: ルーカスは波が長く続く理由。RBCは生産性の変化の測定と、不況の説明。
C: どちらも「つり合う場所そのものが動く」と考える（均衡景気循環理論）。
```

```card
要点
- ルーカス：予想外のお金＋不完全な情報／受け取りちがい／データと合いにくい
- RBC：生産性の変化／実際に作る力／合う部分がある
- どちらも均衡景気循環理論。第14講は、つり合いから外れる説明
```

## 6. お金が先に増えたら、お金が原因？（5分）

```talk
B: お金が先にふえて、生産があとでふえたら、お金が原因？
A: そうとは限らない。景気がよくなる見通しを受けて、会社が先に借り、銀行が貸し出しをふやすこともある。
B: 流れは？
A: 景気改善の予想 → 先に借入れと預金がふえる → あとで生産がふえる。
B: 政策は？
A: ルーカスは、予想された金融政策では実質の生産をふやし続けられない。基本的なRBCは、ゆがみがない条件では、波を消す政策が望ましいとは限らない。
B: 不況は放っておいていい？
A: ちがう。失業や金融の問題などを加えると、結論も変わりうる。
C: 先に動いただけでは、原因は決められない。
```

```card
要点
- 先に動いたことだけでは、原因は決められない
- 景気改善の予想 → 先に借入れ・預金がふえる → あとで生産がふえる
- どんな政策も不要、という意味ではない
```

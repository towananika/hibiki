# 貨幣金融論 14講【会話で読む】― IS-LMモデル

1節5〜10分。きょうは1節だけでOK。会話の3人は日替わり（アカリ・ツバサ・シオン）。詳しいノートは「[ふつうのノート](view.html?n=money14)」。

> 動かして理解する「[IS-LMを動かす](islm.html)」（5分）もあります。

## 1. 前に習ったことを思い出す（5分）

```talk
B: ISとかLMとか、前に習ったけど忘れた。
A: 3つの道具の組み合わせ。道具1は13講。国全体の買いたい量と作る量が一致した所で国の所得が決まる。投資＝貯蓄のときに物の市場がつり合う。ただし13講には金利が出てこなかった。
B: 道具2は？
A: 11・12講の、お金を持ちたい量。買い物・もしものためは所得で決まり、もうけ待ちは金利で決まる。金利が上がると債券が得になり、お金で持つ分はへる。金利がとても低いと流動性のわな。
B: 道具3は？
A: 8〜10講の、お金を出す側。お金の量＝土台（中央銀行が出すお金）×倍率（貨幣乗数）。
B: それでISとLMは？
A: ISは Investment＝Saving、物の市場。LMは Liquidity＝Money、お金の市場。ISは金利が上がると投資が減って所得が減るので右下がり。LMは所得がふえるとお金がほしくなって金利が上がるので右上がり。
C: 13講＋11・12講＋8〜10講。
```

```card
要点
- 道具1（13講）：買いたい量＝作る量で所得が決まる／投資＝貯蓄／乗数。金利なし
- 道具2（11・12講）：持ちたいお金＝所得の分＋金利の分。流動性のわな
- 道具3（8〜10講）：お金の量＝土台×倍率
- IS＝Investment＝Saving（右下がり）／LM＝Liquidity＝Money（右上がり）
```

## 2. IS-LMモデルってなに？（5分）

```talk
B: IS-LMモデルって、何を調べるの？
A: 物の市場（財貨市場）とお金の市場（貨幣市場）が、同時につり合う状態。ISが物の市場、LMがお金の市場。
B: 13講のモデルとのちがいは？
A: 金利を入れたこと。政府支出がふえると、国民所得がふえて、お金がほしい量（貨幣需要）もふえ、金利が上がる。すると会社の投資が減って、国民所得が一部打ち消される。
C: 2つの市場を同時に見る。
```

```card
要点
- IS＝物の市場（実物部門）／LM＝お金の市場（金融部門）
- 2つが同時につり合う所で、国民所得と金利が決まる
- 13講との差：金利を入れた（政府支出↑ → 金利↑ → 投資↓）
```

## 3. IS曲線（10分）

```talk
B: IS曲線って？
A: 物の市場の均衡条件 I＝S（投資＝貯蓄）を満たす、国民所得と金利の組み合わせ。金利が上がると投資が減り、均衡国民所得が減るので、右下がり。
B: 傾きは何で決まる？
A: 投資の金利弾力性が大きいほど、IS曲線はゆるやか。乗数が大きい（限界消費性向が大きい）ときもゆるやか。
B: 動くときは？
A: 政府支出や税収が変わると、IS曲線全体が動く。拡大財政政策（政府支出↑・減税）は右へ、緊縮財政政策（政府支出↓・増税）は左へ。
C: 右下がり。財政政策で動く。
```

```card
要点
- IS曲線：I＝S を満たす組み合わせ。右下がり
- 傾き：投資の金利弾力性が大きい／乗数が大きい → ゆるやか
- 拡大財政 → 右へ／緊縮財政 → 左へ
```

## 4. LM曲線（10分）

```talk
B: LM曲線って？
A: お金の市場の均衡条件 L＝M（貨幣需要＝貨幣供給）を満たす、国民所得と金利の組み合わせ。国民所得が上がると貨幣需要が増え、均衡金利が上がるので、右上がり。
B: 傾きは？
A: 貨幣需要の所得弾力性が大きいと急。貨幣需要の金利弾力性が小さいと急。古典派は金利弾力性が 0 で垂直。ケインズの流動性のわなでは水平。
B: 動くときは？
A: 貨幣供給量がふえると金利が下がり、右（下）へ。ただし金利弾力性が大きいほど、移動の幅は小さい。流動性のわなでは、まったく動かない。
C: 右上がり。垂直（古典派）と水平（わな）。
```

```card
要点
- LM曲線：L＝M を満たす組み合わせ。右上がり
- 金利弾力性が小さい → 急／古典派＝垂直／流動性のわな＝水平
- 貨幣供給↑ → 右（下）へ。わなでは動かない
```

## 5. 財政政策と金融政策（10分）

```talk
B: 財政政策をやると？
A: 政府支出↑でIS曲線が右へ動き、国民所得も金利も上がる。金利が上がると民間の投資が減る。これが押し出し効果（クラウディング・アウト）。
B: 押し出しの大きさは？
A: 貨幣需要の金利弾力性（LM曲線の傾き）で決まる。LM曲線が垂直なら、完全な押し出しで国民所得はふえない。水平（流動性のわな）なら、押し出しがなく、財政政策の効果は最大。
B: 金融政策は？
A: 貨幣供給↑でLM曲線が右へ。金利↓ → 投資↑ → 国民所得↑。貨幣需要の金利弾力性が小さく、投資の金利弾力性が大きいほど、効果は大きい。流動性のわなでは効果がない。
C: 垂直なら金融政策、水平なら財政政策。
```

```card
要点
- 財政政策：IS曲線を動かす。国民所得↑・金利↑。押し出し効果あり
- 完全な押し出し：LM曲線が垂直のとき
- 金融政策：LM曲線を動かす。金利↓ → 投資↑ → 国民所得↑
- 流動性のわな：財政政策は最大、金融政策は効果なし
```
